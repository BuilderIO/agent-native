# Third-party notices

The macOS app links [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp)
0.4.1 for Local Whisper transcription. It builds ggml, miniz and Silero VAD's
segmentation code into the same native library. Whisper model files are
downloaded at runtime and are not part of the app.
