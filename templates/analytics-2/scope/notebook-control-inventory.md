## Cell menu: recovered previous source build

The current archived bundle contains the `CELL_MORE_ACTIONS` selector but not the component body. The previous archived source map contains `src-20261027/maps/home/circleci/project/packages/client/components/cell/cell-container/CellActionsMorePopover.tsx:607–786`. For an ordinary editable SQL cell it renders Add above, Add below, Move up, Move down, Add to section, Duplicate, Select cell and... (all upstream, all downstream, all upstream + downstream), New component, Copy cell, Copy link (logic view and latest published app), Embed, Full screen, and Delete cell. Duplicate to chart is conditional on a parent block; component-import and collapsible cells change the menu, and Open cell debugger requires internal developer access. These are source-conditional controls, not verified assumptions about a fresh SQL cell. New component's relation to the Labs catalog requires a scope decision; no automatic exclusion is applied.

`NotebookCell.tsx` currently renders Move up/down, Duplicate, Rename cell and Delete cell. The check compares the ordinary SQL-cell menu and reports the missing actions. The check includes the nested selection and link labels when their menus are present; their effects, component import, parent-block, published-app and internal-user conditions still need their own fixtures. This is a partial inventory until those conditions and the remaining toolbar controls are observed.
