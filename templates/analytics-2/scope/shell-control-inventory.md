## Backed controls outside the shell rows

- **App last published** (`dateLastPublished`, `appLastPublished`). `list-projects` reads the current published version's timestamp from `listProjectRows()`. A missing referenced version raises a stored-data error. [Projects list read](../server/model/projects-store.ts)
- **Setup and connections.** `get-workspace-context-setup` reads persisted completion and the selected connection. `get-data-browser-catalog` reads authorized catalog nodes. The BigQuery form has create and operation readback actions. Unsupported warehouse templates require their own form, provider and catalog proof. [Setup read](../server/model/context-setup.ts) and [connector catalog](../app/components/data/connection-catalog.ts)
- **dbt metadata.** `list-dbt-semantic-metrics` reads a selected current native connection and checks its credential and authority before returning a page. [Metrics readback test](../actions/list-dbt-semantic-metrics.spec.ts)
- **Inherited default skill.** Settings uses the shared resources panel. The resource read marks inherited defaults and the menu keeps Open and Download available. Remove follows the server mutation policy for the resource. [Settings bridge](../app/components/settings/SettingsShellBridgedPages.tsx) and [menu proof](../../../packages/toolkit/src/app/resources/ResourceSettingsGroups.spec.tsx)
- **Agent and keyboard aliases.** Create project, notebook actions, Data, and published app links consume the corresponding workspace or resource decision. The same destinations must remain scoped for direct links. A rejected route or action requires a typed error and zero navigation or mutation side effects. [Capability evaluator](../server/lib/analytics-capabilities.ts)
