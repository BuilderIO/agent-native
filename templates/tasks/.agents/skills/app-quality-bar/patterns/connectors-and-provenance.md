# Connectors and provenance

Use when app output depends on external, indexed, or shared sources.

- Discover scoped workspace connections first. Offer one-click reuse of an
  eligible OAuth grant and show the selected workspace, account, and scope.
  Start consent only for an absent or insufficient grant. Keep credentials
  in the approved connection store.
- Show which sources were indexed, their last successful refresh, and current
  sync or error status. Preserve browsing and display stale data with a
  freshness marker. Give each result a source, verification time, and a link
  when the viewer has access.
- Inherit the source item's access by default. Keep privately created items
  private and offer explicit item-level sharing with audience and revocation
  controls. Apply the same permissions to retrieval, previews, and agent tools.

Verify an existing grant, expired or insufficient consent, stale and failed
indexing, and access to a shared item as a second permitted viewer.
