# Changelog

All notable user-facing changes to Agent-Native Macros are documented here. Open it any
time from the command menu (Cmd+K → "What's new").

Older updates live in [the changelog folder](./changelog/) and are included in the in-app "What's new" view.

## 2026-07-29

### Improved

- Sidebar footers now keep Feedback, Search, and Collapse together without a separate language shortcut.

### Improved

## 2026-07-24

### Improved

- Sidebar utility controls now follow a consistent footer order.

### Improved

## 2026-07-13
