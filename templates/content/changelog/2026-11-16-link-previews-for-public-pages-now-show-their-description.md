Link previews for public pages and databases (in Slack, for example) now show the description from the page's Info panel, or else its first paragraph, and name Agent-Native Content as the site. A public database with no description is called a database rather than "a public document". Pages that aren't public still get the plain Content card, so a preview never shows a private page's title.
