# Slides

The shipped Slides app: the deck list home with its composer and Templates and Recent tabs, Templates, Design Systems, the deck editor (header, contextual toolbar, slide rail with selection, reordering and context menus, canvas, speaker notes, comments, history, share), the agent chat sidebar, present mode, and presenter view. The review strip's Scenario switch shows an empty deck list, a deck mid-generation, view-only access, and offline with unsaved changes.

Artifact: https://claude.ai/artifact/SKFFSBvDk1xP5GQuBMFhm5

```bash
node prototypes/kit/build.ts slides
```
