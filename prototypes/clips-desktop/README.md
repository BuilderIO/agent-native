# Clips desktop

The Clips desktop app on a fake macOS desktop: the menu bar tray icon and its menu, the recorder popover (modes, source, camera, mic, system audio), the countdown, camera bubble, recording control bar with pause, restart and discard, the completion card after stopping, sign-in, and the meeting notification.

Artifact: https://claude.ai/artifact/PUNqcFC3kAogDLzHDo2XKx

```bash
node prototypes/kit/build.ts clips-desktop
```
