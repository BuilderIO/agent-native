# Clips web

The Clips web app: the library (folders, cards, selection, search, sort, import), a recording page with the player, transcript, comments, agent and settings tabs, Share (people, agents, social, embed), the views popover, the account menu, and the agent sidebar.

Artifact: https://claude.ai/artifact/YBWtSNr8esvyFwkDpBHGNw

```bash
node prototypes/kit/build.ts clips-web
```
