# Design

The Design template's editor: the top bar and modes (Interact, Design, Code), the rail and its panels (File, Agents, Tokens, Threads), the canvas and floating toolbar, the inspector and color picker, menus, Share, version history, keyboard shortcuts, and Settings.

Artifact: https://claude.ai/artifact/MC9u3UmtuV3vbB865gU1kH

```bash
node prototypes/kit/build.ts design
```

`settings.json` holds the Settings pages' content. The review strip across the top holds prototype-only switches: Labs flags, the history style, scenarios such as an empty design or unsaved changes, the spacing overlay, the theme, and Changes.
