# Analytics

The Analytics template as it ships: Ask (the chat home and a conversation where the agent answers with a live chart), the sidebar with chats and dashboards, the Dashboards overview, a full SQL dashboard (filters, custom date range, saved views, share, panel menus, View SQL, full screen, add and edit panels, email reports, history), Data Sources with setup walkthroughs, the agent sidebar, the ⌘K command menu, and Settings. The review strip's Scenario switch shows no data sources connected, an empty dashboard, and the agent building a chart.

Artifact: https://claude.ai/artifact/RtQ5m2aQTSdjdZxAZajX2H

```bash
node prototypes/kit/build.ts analytics
```
