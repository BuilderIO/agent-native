`FontSizeField` from the design tweaks entry is a compact font size combobox: type a size and press Enter, pick one from a caller-provided type scale (with optional named sizes listed first), or step through the scale with the arrow keys. An optional `scrubIcon` adds a drag handle that previews and commits like the inspector's scrub fields, and `allowRelativeExpressions` reports a typed `Mixed+2` on a mixed selection as `meta.relativeExpression`.
