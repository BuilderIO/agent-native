Labs settings show a Lab the host product decides as set and read-only, instead of a switch whose choice the server wouldn't apply. After a save, a row shows what the server says it applies, rather than the choice it sent, and a failed save reads the Labs again so the row shows what was saved. A Lab with a saved choice offers Use default, which clears the choice. Keyboard focus stays on the row after a save, on its switch or its first button, instead of dropping to the page while the switch waits for the server.
