`McpInstallActions` from `@agent-native/toolkit/app/sharing` renders a share dialog's "Add to Cursor" and "Add to VS Code" rows plus a link to the app's other agent guides. It reads the server name and MCP URL from the app's connect identity and its labels from the shared guides, so a share dialog installs the same entry as Settings → MCP server.
