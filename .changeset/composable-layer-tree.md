Add a composable layer tree with keyboard navigation, selection, renaming, visibility, locking and subtree reordering. Set a viewport height to render large expanded trees with a bounded number of rows while preserving selection, focus, and keyboard navigation. Keep focus inside the tree when a document update removes the focused row, and navigate visible rows by typing their names. Horizontal arrow keys follow the reading direction. Drag previews check the selection and target without rebuilding the document order.
