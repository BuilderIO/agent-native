Analytics' dashboard chart components now live in the toolkit. `DashboardPanelChart` (`@agent-native/toolkit/app/dashboard-charts/DashboardPanelChart`) draws a dashboard panel from rows already loaded, the way an Analytics dashboard draws it, and `DashboardPanelChartHostProvider` lets an app add its own data notes and session replay links.
