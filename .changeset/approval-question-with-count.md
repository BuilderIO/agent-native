An action can set `approvalLabel` to word its approval card's question for the arguments that will run, and `set-resource-visibility` uses it to ask with the count ("Make 5 recordings public?"). A batch change's result card repeats the count in its detail line, where a long first title can't cut it off, and a live chat draws an action's result card once, as it does after a reload.
