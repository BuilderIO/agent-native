Served documents name their release: SSR pages and the hand-built auth, reset-password, desktop sign-in and deploy-settings pages carry `<meta name="agent-native-build-sha">`, preferring the baked workspace commit (or `observability.buildSha` / `AGENT_NATIVE_BUILD_SHA`) over a per-app content build id. Workspace deploys can be split across machines with the new `deployCache.onlyApps` (`AGENT_NATIVE_DEPLOY_ONLY_APPS`) and `deployCache.prebuiltApps` (`AGENT_NATIVE_DEPLOY_PREBUILT_APPS`) settings; a split leg records its build id in `.agent-native-app-build-id`, and neither the selectors nor that file change an app's build cache key. The Netlify build check accepts a bare ingestion import that resolves to a file shipped inside the server bundle. Also: `ssrfSafeFetch` takes a synchronous `beforeDispatch(url)` hook that runs before every dispatch, including redirects; `resourceMoveIfCurrent(resource, newPath)` moves a resource only while it is unchanged and its destination is free; the profile display name accepts up to 256 characters; completing first-run onboarding refreshes the session before navigation continues; and the shared Vitest config passes `--no-experimental-webstorage` on Node versions that support it so jsdom keeps `localStorage`.
