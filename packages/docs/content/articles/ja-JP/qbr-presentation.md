QBR資料とは、四半期ビジネスレビュー（QBR）で使う資料です。QBRでは、顧客と一緒に前四半期を合意した目標と照らし合わせて振り返り、次の四半期の目標を決めます。作業の大半は、CRM、プロダクト分析、サポートツール、請求システムから数値を集め、それぞれを目標と照らし合わせて確認することです。このガイドではその作業を先に行い、スライドは最後に作ります。

![架空の顧客Brightline Logisticsの資料例から4枚のスライド。今日決めたいことを載せた表紙、4つの目標のうち3つを達成したスコアカード、今四半期に削減した配車担当者の作業410時間、Q4の3つの目標が並んでいます。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F8dfc321ccfe64b00a56a3bf5105c44a5)

## 用意するもの

- 前四半期の目標
- 初めてのQBRの場合は、サクセスプラン
- CRM、分析ツール、サポートツール、請求システムへのアクセス
- 参加者のリスト

## QBR資料の作り方

### 1. QBRの対象者を決める

顧客側の参加者を書き出し、**ミーティングで決めたいことを1つに絞ります**。たとえば早期の契約更新や、利用チームの追加です。「このミーティングの終わりまでに、〜について合意する」という一文で書きます。

エグゼクティブスポンサー（契約更新を決める立場の上位者）が求めるのは、成果と決定事項です。日常的にやり取りする担当者は、製品がどう使われているかの詳細を知りたがります。両方が参加する場合は成果から話し、詳細は付録に回します。

### 2. 各ツールから四半期の数値を集める

前四半期の目標（初めてのQBRならキックオフ資料かサクセスプラン）を出発点に、**それぞれの目標を測る数値を集めます**。契約の基本情報として、シート数、契約金額、更新日、未解決のチケットも加えます。すべての数値で、顧客と合意した四半期という同じ集計期間を使います。

| 数値 | 主な保存場所 |
|---|---|
| 契約金額、シート数、更新日 | CRMの取引先または商談 |
| アクティブユーザー、機能の利用率 | プロダクト分析 |
| 起票チケット数、解決までの時間 | サポートツール |
| 請求書、従量課金 | 請求システム |

商談をHubSpotで管理しているなら、[Agent-Native Analyticsに普段の言葉で商談の数値を聞けます](https://www.agent-native.com/use-cases/ai-sales-analytics/)。すべての数値を1つのシートにまとめ、横に出典と集計期間を書きます。

### 3. 各数値を目標と並べる

シートに目標を1行ずつ追加し、目標値、実績、差を書きます。**各目標を「達成」「未達」「進行中」（期限がまだ先の目標）のいずれかで記録し**、未達の目標には何を変えるかを書き添えます。目標を測る数値でも、目標の説明に必要な数値でもないものは外します。架空の顧客Brightline Logisticsの例を示します。

| 目標 | 目標値 | 実績 | 状況 |
|---|---|---|---|
| 平均配車時間の短縮 | −15% | −22% | 達成 |
| 週間アクティブシート数 | 200のうち180 | 200のうち184 | 達成 |
| ドライバーアプリの利用率 | 70% | 76% | 達成 |
| 8時間以内に解決したチケット | 90% | 81% | 未達 |

この表だけで、四半期の結果が顧客に伝わります。

### 4. スライドの前に数値を確認する

各数値を前四半期の資料と比べます。**同じ定義**を使っているか、たとえば「アクティブユーザー」を同じ方法・同じ期間で数えているかを確認します。合計が元のツールと一致するかを確かめ、大きく増減した数値があれば理由を突き止めます。

シートの各数値の横に定義と集計期間を書いておきます。意外な数値があれば、顧客は出どころを尋ねてくるからです。

### 5. 顧客が得た価値を示す

達成した目標を、時間の削減、回避できたコスト、売上といった**顧客にとっての価値**に置き換えます。変化はベースラインと比べて測ります。ベースラインには、キックオフ資料やサクセスプランにある開始時点の数値か、製品の導入前の同じ指標を使います。どちらもない場合は、顧客のチームに見積もってもらいます。変化に、時間あたりのコストなど顧客から提供された数値を掛けます。

Brightlineの例では、ルート作成が速くなったことで配車担当者の作業が410時間減りました（1ルートあたりの短縮分数 × 作成したルート数）。Brightlineから提示された1時間あたり$40のコストで計算すると、約$16,400になります。金額に換算できる目標がない場合は、期日どおりに出荷した注文数など、成果そのものを示します。

シートに計算式と入力値を書き、顧客から提供された入力値には印を付けます。ミーティングの前に、**入力値を担当者に確認してもらいます**。

### 6. 四半期のストーリーを書く

目標の表を上から順に見て、**行ごとに数値の意味を伝える見出しを1つ書きます**。Brightlineの配車の目標なら「配車担当者のルート作成が22%速くなりました」などです。さらに、価値を示す数値、最大のリスク、顧客にお願いしたいことについても見出しを1つずつ書きます。各見出しがスライドのタイトルになるので、資料は指標の羅列ではなく1つのストーリーになります。

### 7. 来四半期の目標とお願いを提案する

来四半期の目標を2〜3個提案し、それぞれに数値と測定に使うツールを添えます。別チームの紹介、機能へのフィードバック、契約更新の話し合いの日程など、お願いしたいことも加えます。ミーティングで顧客が変更できるよう、**目標は提案であると明記します**。

### 8. アウトラインからスライドを作成する

このアウトラインの各スライドには、**伝えたいこと1つと、その裏付け**を載せます。

| スライド | 元にするもの |
|---|---|
| 今日決めたいこと | 「このミーティングの終わりまでに」の一文 |
| スコアカード：全目標の達成・未達 | 目標の表 |
| 目標ごとに1枚、見出しを先頭に | 各目標の見出し、数値、出典 |
| 提供した価値 | 価値を示す数値とその計算式 |
| 未達の目標と今後のリスク | 未達の目標、変更点、リスクの見出し |
| 来四半期の目標案 | 目標の草案 |
| 顧客にお願いしたいこと | お願いしたいこと |
| 担当者と期日 | ミーティング中に記入 |
| 任意：アカウントの健全性 | 追跡している場合はヘルススコア |
| 付録：数値と定義 | 出典をまとめたシート |

推移には折れ線グラフを、目標には目標値を示した棒グラフを使います。このガイドの冒頭にあるBrightlineのスライドは、このアウトラインで作った資料のうちの4枚です。

### 9. 資料を事前に送り、フォローアップする

チームメイトと一度リハーサルをしてから、**ミーティングの前に資料を参加者に送ります**。そうすれば参加者はスライドを読む代わりに、質問を持って参加できます。ミーティングは、決めたいことから話し始めます。終了後は、合意した内容と、次のステップそれぞれの担当者と期日を短くまとめて送ります。このメモが、来四半期の目標の表の出発点になります。

## Agent-Native SlidesでQBR資料を作る方法

[Agent-Native Slides](https://www.agent-native.com/apps/slides/)は、[スライド構成](#8-アウトラインからスライドを作成する)とお手元の資料から資料を作成します。数値、ストーリー、目標を決めるのはあなたです。Slidesは渡された情報をもとに作業し、数値の確認はしません。Slidesはアルファ版のため、粗い部分があることをご了承ください。

### 1. QBRの内容を説明し、資料を添付する

Slidesのホーム画面で、顧客、四半期、参加者、必要なスライドなど、作りたい資料の内容を説明します。前四半期のQBR資料と、シートからPDFとして保存した目標の表を添付します。

![SlidesのプロンプトボックスにQ3のQBRの依頼が入力され、前四半期のPowerPoint資料とQ3の目標をまとめたPDFが添付されている画面。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2Fae16a9e75220453c9b53e2e1b69d7c63)

### 2. エージェントがスライドを作る様子を確認する

Slidesのエージェントは依頼内容からアウトラインを組み立て、エディター上でスライドを1枚ずつ作成します。その様子はリアルタイムで確認できます。前四半期のスライドをそのまま使いたい場合は、[以前のPowerPoint資料をインポートしてください](https://www.agent-native.com/docs/template-slides-features/)。インポートした資料では、スライドとスピーカーノートがそのまま残ります。

![QBRの最初の3枚が完成し、4枚目を生成中のSlidesエディター。エージェントのチャットにはアウトラインが表示されています。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F10a6b2f1cfb343fc89cb5e5e037540fc)

### 3. スライドを編集し、スピーカーノートを追加する

テキストはその場で編集できます。スライド全体を変えたいときは、スライドを選んでエージェントに依頼します。たとえば、サポートの内容を付録に移すといった依頼です。各スライドのスピーカーノートもエージェントに書いてもらえます。

資料を共有する前に、**スライド上のすべての数値を目標の表と照らし合わせてください**。

![Slidesエディターの全体画面。上部にツールバー、左側にスライド一覧があり、中央にスコアカードのスライドが開いています。その下にスピーカーノートがあり、右側のエージェントのチャットがすべてのスライドのノートを書き終えています。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F397a6e6c392d4cfc9970050b85d8f095)

### 4. レビューのために共有するか、エクスポートする

顧客に送る前にチームメイトに見てもらうには、**共有**をクリックします。チームメイトはスライドごとにコメントしたり、あなたと同時に編集したりできます。Slidesから全画面で発表することも、**エクスポート**を開いてPowerPointファイル、PDF、またはGoogle Slidesにインポートするファイルとして保存することもできます。

![QBRの表紙スライドの上にSlidesのエクスポートメニューが開き、HTML、PDF、PowerPoint、Google Slidesの選択肢が表示されている画面。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F01de5fb8352f49978deefbebb9490223)

## よくある問題

### 顧客の数値とこちらの数値が一致しない

顧客側の管理者が、ユーザーやチケットを別の定義や集計期間で数えている可能性があります。付録のスライドに、各数値の定義と集計期間を載せておきます。顧客の数値と食い違う場合は、結果をめぐって言い争うのではなく、ミーティングの場で定義を比べます。

### 計画の話に入る前に時間切れになる

こうなるのは、たいてい振り返りのスライドに詳細を詰め込みすぎているときです。振り返りはミーティングの半分までにし、元の表は付録に移します。時間が足りない場合は、来四半期の目標を目標ごとのスライドより前に置きます。

### 今四半期は大半の目標が未達だった

スコアカードは正直に保ち、未達の目標はすべて示します。振り返りでは、それぞれの未達に対して何を変えたかから話し、ミーティングで決める内容を、来四半期に顧客がこちらに求めることに切り替えます。

### エグゼクティブスポンサーが参加しない

エグゼクティブスポンサーがいなければ、予定していた決定には至りません。見出しをまとめた1ページの要約をスポンサーに送り、決定事項だけを話す15分の時間をお願いします。

## よくある質問

### QBR資料にはどんなスライドを入れますか？

QBR資料は、前四半期に合意した目標を軸に構成します。スコアカード、目標ごとのスライド、提供した価値、未達だった目標、来四半期の目標とお願いしたいことです。元の数値と定義は付録にまとめます。

### QBRのアジェンダはどう組み立てますか？

1時間のQBRなら、次の配分を試してみてください。今日決めたいことに5分、スコアカード・目標・価値のスライドに25分を使います。続いて来四半期の目標とお願いしたいことに20分、担当者と期日に10分を充てます。配分は調整してかまいませんが、振り返りはミーティングの半分以内に収めてください。

### QBRはどのくらいの頻度で開くべきですか？

名前のとおり四半期ごとに、ミーティングを開く価値がある規模の顧客を対象に開きます。規模の小さい顧客には、年2回の短いレビューや、ミーティングの代わりに書面のまとめを用意する方法もあります。

### QBRとEBRの違いは何ですか？

EBR（エグゼクティブ・ビジネス・レビュー）は、顧客の経営層と年に1〜2回行う戦略的なレビューです。成果、戦略、契約更新を扱い、製品の細かい話はQBRより少なくなります。QBRは四半期ごとに開き、目標を1つずつ確認します。通常はスポンサーに加えて、日常的にやり取りする担当者も参加します。

### 四半期ビジネスレビューとは何ですか？

四半期ビジネスレビュー（QBR）は、ベンダーが四半期ごとに顧客と行う会議です。前四半期の結果を双方で合意した目標と照らし合わせ、次の四半期の目標を決めます。進行役は通常カスタマーサクセスマネージャーかアカウントマネージャーで、顧客側からは日常的にやり取りする担当者とエグゼクティブスポンサーが参加します。QBR資料は、この会議の進行に使う資料です。
