営業資料とは、ヒアリングの後に見込み客1社と一緒に見ていく資料です。相手の課題、その解決方法、相手に近い顧客の実績、次のステップを扱います。商談を前に進める営業資料を作るには、ヒアリングで見込み客から聞いた内容をもとに作ります。このガイドでは、ヒアリングのメモから、発表にも後から渡す資料にも使える資料を作るまでを説明します。

## 用意するもの

- ヒアリングのメモまたは録画
- CRMにある商談の情報
- チームの標準資料
- 紹介できる顧客事例2〜3件

## 営業資料の作り方

### 1. ミーティングで合意したい次のステップを決める

営業資料の目的は商談を1歩進めることなので、**スライドを作る前にその1歩を書き出します**。試験導入、相手の財務責任者とのミーティング、期日までの提案書など、見込み客がその場で合意できることにします。「このミーティングの終わりまでに、Pinecrestが2つのホテルでの30日間の試験導入に合意する」のように、1つの文で書きます。

次に、参加者と、それぞれが何を決める立場かを書き出します。契約にサインする**決裁者**は、コストとリスクを知りたがります。変化を望んでいる窓口の担当者、つまりチャンピオンには、社内で説明しきれる資料が必要です。製品を使う人たちは、自分の仕事がどう変わるかを知りたがります。

### 2. ヒアリングで見込み客から聞いた内容を集める

資料で見込み客について述べることは、すべてヒアリングから来ます。そのため、**相手の言葉のまま**1ページに集めます。

| 集める内容 | 主な保存場所 |
|---|---|
| 相手の言葉で表した課題 | 通話のメモまたは録画 |
| 課題によって生じているコスト | 通話のメモ、フォローアップのメール |
| すでに試したこと | 通話のメモ |
| 決める人と、ほかに関わる人 | CRMの商談 |
| 期限、または今検討を始めたきっかけ | 通話のメモ、CRMの商談 |
| 相手から出た質問や懸念 | 通話のメモまたは録画 |

商談をHubSpotで、通話をGongで管理しているなら、[1件の商談とその通話についてAgent-Native Analyticsに聞けます](https://www.agent-native.com/use-cases/ai-sales-analytics/)。引用はそのまま写します。相手自身の言葉で書いたスライドは、こちらの言い換えより相手に響きます。Pinecrestの経理部長Priyaは、14のホテルで請求書の承認をメールの転送で行っていると話しており、これがスライド2になりました。足りない情報は、ミーティングの早い段階で聞くようにします。

### 3. ストーリーをスライドの見出しとして書く

ヒアリングのページをもとに、**見込み客の状況から始めて、スライドごとに見出しを1つ書きます**。相手の状況、それによるコスト、課題ごとの見出し、そして他の選択肢ではなく自社を選ぶ理由、という順番がおすすめです。表紙と次のステップを含めて、見出しは6〜10個を目安にします。Pinecrestの例なら、最初の見出しは「請求書は承認されるまで14の受信トレイで止まっています」「承認の遅れで、Pinecrestは早期支払いの割引を逃しています」などです。

自社の紹介は多くても1枚にします。見出しだけを読んでもミーティングのストーリーが伝わるようにします。これは、コンサルタントが[コンサルティング資料を作る前にすべてのスライドのタイトルを書く](https://www.agent-native.com/articles/consulting-deck/)ときと同じ確認方法です。

### 4. 各課題を自社の製品と結びつける

見込み客が挙げた課題ごとに、**何がそれを解決し、どう見せるか**を書きます。どんなに優れた機能でも、リストにある課題に答えないものは外します。Pinecrestの例は次のとおりです。

| 相手の課題 | 解決するもの | 見せ方 |
|---|---|---|
| 請求書がメールに埋もれている | 14のホテルすべてに共通の承認キュー | キューのスクリーンショット |
| 誰が請求書を止めているのかわからない | 各請求書に承認者と待ち時間が表示される | 2分間のライブデモ |
| 早期支払いの割引を逃している | 割引期限の前に届くリマインダー | 似た顧客の実績 |

この表が資料の中盤になり、1行につき1枚のスライドになります。続いて、相手が今使っている方法ではなく自社を選ぶ理由を1行書きます。ヒアリングのページの「すでに試したこと」をもとにします。Pinecrestの場合、それはメールと、会計システムの承認機能です。

### 5. 相手に近い顧客の実績を選ぶ

実績は、見込み客が自分たちの姿を重ねられるときに効きます。そのため、手持ちの一番有名な社名より、業界、規模、課題が**相手に最も近い顧客を選びます**。表の最後の列に、課題ごとに実績を1つずつ入れます。数値と出典を添えた成果、短い引用、またはスライドより実物を見せたほうが伝わる場合はライブデモでもかまいません。

各顧客が社名の公開に同意しているかを確認します。同意がない場合は、「中西部にある20ホテルのグループ」のように顧客の特徴で説明します。

### 6. アウトラインからスライドを作成する

次のアウトラインを使い、各スライドに**見出し1つと、その裏付けとなる実績**を載せます。見込み客向けのスライドは新しく作り、それ以外は標準資料から持ってきます。

| スライド | 元にするもの |
|---|---|
| 表紙（提案する次のステップを添えて） | 次のステップの一文 |
| 相手の言葉で表した相手の状況 | ヒアリングでの引用 |
| それによって生じているコスト | 相手が話したコスト |
| 課題ごとに1枚 | 課題の表の各行と、その実績 |
| 他の選択肢ではなく自社を選ぶ理由 | 自社を選ぶ理由の1行 |
| 仕組み | 標準資料、または短いデモ |
| 費用（商談がその段階にある場合） | 相手の規模に合わせた価格 |
| 次のステップ、担当者、期日 | 次のステップの一文 |
| 予備スライド | 想定される懸念への回答と、標準資料のスライド |

本編は10枚程度に収め、ミーティングの半分を会話に残します。次回をもっと早く進めるには、**見込み客ごとにこの資料をコピーし**、見込み客向けのスライドだけを変えます。

### 7. 懸念への答えを準備する

ヒアリングで見込み客から出た懸念を書き出し、価格、時期、切り替えの手間、「すでに同じようなものがある」といった、よくある懸念も加えます。**それぞれに短い回答を書き、予備スライドを1枚ずつ**本編の後に追加します。Pinecrestの場合、「会計システムにはすでに承認機能がある」という懸念には、承認済みの請求書は引き続き会計システムに送られて支払われることを示す予備スライドを用意します。

### 8. 会話として発表する

決裁者役のチームメイトと一度リハーサルをします。ミーティングでは相手の状況のスライドから始め、先に進む前に**その内容が今も合っているかを確認します**。ヒアリングからミーティングまでの間に状況が変わることがあるからです。課題のスライドごとに質問を投げかけ、見込み客が関心を持たないスライドは飛ばします。最後は次のステップのスライドで締めくくり、そのステップをはっきりお願いします。

ビデオ通話では、スライドを1枚ずつ全画面で共有します。途中から参加した人もついてこられるよう、通話の前に資料のリンクを送っておきます。

### 9. 資料と次のステップを添えてフォローアップする

**その日のうちに短いまとめを送ります**。合意した内容、担当者と期日つきの各ステップ、そして資料です。その資料は、あなたがいなくても伝わるようにしておきます。口頭で話した要点は、スライドかスピーカーノートに書き込みます。チャンピオンは、その場にいなかった人たちに資料を転送するからです。

Pinecrestの場合、まとめには、経理部長のPriyaが11月14日までに選ぶ2つの試験導入ホテルと、12月19日の振り返りの日付を書きます。商談が成立したら、同じヒアリングのメモを使って、その顧客の最初の[四半期ビジネスレビュー（QBR）資料](https://www.agent-native.com/articles/qbr-presentation/)を作り始められます。

## Agent-Native Slidesで営業資料を作る方法

[Agent-Native Slides](https://www.agent-native.com/apps/slides/)は、[アウトライン](#6-アウトラインからスライドを作成する)とヒアリングのメモからスライドを作成し、新しい見込み客ごとに資料のコピーで見込み客向けのスライドを作り直します。次のステップ、課題の表、実績を決めるのはあなたです。Slidesは渡された情報をもとに作業し、内容の確認はしません。Slidesはアルファ版のため、粗い部分があることをご了承ください。

### 1. ミーティングの内容を説明し、メモを添付する

Slidesのホーム画面で、見込み客、参加者、目指す次のステップ、アウトラインにあるスライドなど、ミーティングの内容を説明します。ヒアリングのメモか通話の文字起こしと、標準資料を添付します。標準のスライドをそのまま残したい場合は、代わりに先に[PowerPoint資料をインポートしてください](https://www.agent-native.com/docs/template-slides-features/)。インポートした資料では、スライドとスピーカーノートがそのまま残ります。エージェントは、見込み客の課題、目標、懸念を抜き出し、相手の言葉と数値をそのまま残すように作られています。

![SlidesのプロンプトボックスにPinecrest Hotels向け営業資料の依頼が入力され、ヒアリングのメモのファイルと標準の営業資料が添付されている画面。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F902ac324d65548f195ead1c268e94c39)

### 2. エージェントがスライドを作る様子を確認する

Slidesのエージェントは依頼内容からアウトラインを組み立て、エディター上でスライドを1枚ずつ作成します。その様子はリアルタイムで確認できます。

![Pinecrest向けの最初の3枚が完成し、4枚目を生成中のSlidesエディター。エージェントのチャットには、ヒアリングのメモから組み立てたアウトラインが表示されています。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2Fc7308b54c03442a38eeb27899fb189f5)

### 3. スライドを編集し、スピーカーノートを追加する

テキストはその場で編集できます。スライドを選んでエージェントに変更を依頼することもできます。たとえば、別の顧客の実績に差し替えるといった依頼です。各スライドのスピーカーノートもエージェントに書いてもらえます。ミーティングの前に、**すべての引用、数値、顧客名をメモと照らし合わせてください**。

![Slidesエディターの全体画面。上部にツールバー、左側にスライド一覧があり、中央に課題のスライドが開いています。その下にスピーカーノートがあり、右側のエージェントのチャットがすべてのスライドのノートを書き終えています。](https://cdn.builder.io/api/v1/image/assets%2FYJIGb4i01jvw0SRdL5Bt%2F1ccd9d3b55d94fe7bc48ccd4324c711b)

### 4. 資料を共有し、次の見込み客向けにコピーする

**共有**をクリックし、後から渡す資料として閲覧専用の公開リンクを見込み客に送ります。または**エクスポート**を開き、**PPTX としてダウンロード**か**PDF としてダウンロード**を選びます。**Google Slides にエクスポート**では、Google Slidesに自分でインポートするPPTXファイルが作られます。次の見込み客向けには、左上のアプリメニューを開いて**ファイル**、**デッキを複製**の順に選びます。そのうえで、新しいヒアリングのメモから見込み客向けのスライドを作り直すようエージェントに依頼します。

## よくある問題

### ヒアリングのメモがない

きちんとしたヒアリングをしないままミーティングが決まることもあります。課題のスライドは短く一般的な内容にとどめ、ミーティングの冒頭でヒアリングの質問を2〜3個します。そのうえで、見込み客の答えに合うスライドに進みます。

### 決裁者が参加しない

次のステップには、たいていサインする人が必要です。参加した人たちとミーティングを続け、お願いの内容を決裁者との短いミーティングに切り替えます。まとめと後から渡す資料を送り、窓口の担当者が社内で説明できるようにします。

### スライド2の段階で価格を聞かれる

価格の幅か価格の決め方を答え、課題について合意できたら費用の全体をお見せすると伝えます。待てない見込み客のために、予備スライドに費用のスライドを用意しておきます。

### ミーティングがデモになってしまう

製品を見たいという見込み客は関心を持っているので、見せましょう。デモの各部分を課題の表にある課題と結びつけ、時間がなくなる前に次のステップのスライドに戻ります。

## よくある質問

### 営業資料にはどんなスライドを入れますか？

営業資料に必要なのは、見込み客の状況、それによって生じているコスト、実績を添えた課題ごとのスライド、他の選択肢ではなく自社を選ぶ理由、そして明確な次のステップです。それ以外は任意です。会社の沿革、チームの写真、機能の一覧は、買い手ではなく自社についての話なので、真っ先に削るスライドです。

### 営業資料のプレゼンはどのくらいの長さにすべきですか？

長くてもミーティングの半分を目安にします。30分のミーティングなら、スライドに約15分、会話に15分です。これは6〜10枚の本編と予備スライドに収まる長さです。資料を最後まで説明するより、見込み客の質問のほうが大切です。

### 営業資料とピッチ資料の違いは何ですか？

営業資料は顧客に製品を売るためのもので、見込み客1社に向けて、相手から聞いた内容をもとに作ります。[ピッチ資料](https://www.agent-native.com/use-cases/ai-pitch-deck-maker/)は通常、投資家に資金を求めるためのもので、課題、市場、ビジネスモデル、チームといった会社全体を扱います。ピッチ資料は投資家ごとにほとんど変わりません。

### 営業のプレゼンの後には何を送ればよいですか？

ミーティングの記憶が新しいうちに、その日のうちにまとめと資料を送ります。セキュリティ関連の資料や価格など、ミーティングで約束したものがあれば、まとめと一緒に送るか、送る日付を伝えます。添付ファイルではなく閲覧専用のリンクを送れば、見込み客は常に最新版を見られます。

### 営業資料をもっと早く作るにはどうすればよいですか？

ベースとなる資料を1つ用意し、見込み客ごとにコピーします。そうすれば、変えるのは表紙、状況、コスト、課題のスライドだけです。ヒアリングのメモは毎回同じ形式で残し、どのコピーも同じ見出しから埋められるようにします。Agent-Native SlidesのようなAIスライドツールを使えば、メモから見込み客向けのスライドを作れますが、使われた引用と数値はすべて確認してください。

### 営業プレゼンの5つのステップとは何ですか？

ステップは営業手法によって異なります。よくある流れは、ヒアリングをもとに準備する、見込み客の状況から話し始める、各課題をどう解決するかを示す、懸念に答える、次のステップをお願いする、の5つです。このガイドでは、作業の大半を占める準備をさらに細かいステップに分けています。
