Blockquote marks a passage quoted from another source. Use it for an excerpt that stands apart from the surrounding narrative.

The component renders a semantic blockquote. Show a visible attribution or source link when readers need to follow it. The HTML cite attribute alone does not display an attribution.

```tsx
import { Blockquote } from "@agent-native/toolkit/ui/base-ui/blockquote";

<Blockquote cite="https://example.org/research">
  Participants found the shortcut useful.
</Blockquote>;
```
