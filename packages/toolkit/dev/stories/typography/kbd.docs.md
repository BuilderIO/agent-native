Kbd displays a key or shortcut a person can type. Use it next to the command it activates or in instructions that teach the shortcut.

Rendering Kbd does not register a keyboard shortcut. Bind the command separately and show the correct keys for the platform. The States story includes a button for editing a shortcut with its own accessible name.

```tsx
import { Kbd } from "@agent-native/toolkit/ui/base-ui/kbd";

<Kbd>⌘S</Kbd>;
```
