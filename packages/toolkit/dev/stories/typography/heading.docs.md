Heading names a section and gives screen-reader users a way to navigate the document outline. Its semantic level and visual size are independent.

Choose `as` from the surrounding hierarchy, then choose the text style for the layout. Keep a descriptive heading even when the visual design calls for a small type size.

```tsx
import { Heading } from "@agent-native/toolkit/ui/base-ui/heading";

<Heading as="h2" textStyle="title-small">
  Recent projects
</Heading>;
```
