Code identifies a literal identifier, command or filename inside prose. Its monospace face distinguishes exact input from the surrounding sentence.

Use inline Code for short literals. Put multi-line examples inside a preformatted block to preserve whitespace. The truncate and wrap examples show how long identifiers behave in a constrained row.

```tsx
import { Code } from "@agent-native/toolkit/ui/base-ui/code";

<p>
  Run <Code>pnpm dev</Code> to start the preview.
</p>;
```
