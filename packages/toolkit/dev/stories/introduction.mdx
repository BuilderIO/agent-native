# Agent-Native design system

The toolkit provides React components built on Base UI. The design-system package provides their tokens, themes and CSS.

[Browse components](?path=/docs/components-overview--docs) to choose a control. Each guide includes a usage example, supported props and interaction details. For example, [Select](?path=/docs/components-select--docs) chooses a value, [Combobox](?path=/docs/components-combobox--docs) searches choices, and [Menu](?path=/docs/components-menu--docs) offers commands.

## Use a component

Load the tokens and component styles once at your app entry point. Import each component from its public toolkit module. The Controls table lists the sizes, variants and colors it supports.

```tsx
import "@agent-native/design-system/tokens.css";
import "@agent-native/design-system/styles.css";
import { Button } from "@agent-native/toolkit/ui/base-ui/button";

<Button variant="soft" color="gray" size="sm">
  Cancel
</Button>;
```

For a screen that uses a few controls, replace `styles.css` with their component stylesheets. Button, Icon Button, Dialog, Autocomplete and Combobox have focused imports. Each includes its built-in parts. Keep the tokens and app theme imports.

```css
@import "@agent-native/design-system/components/dialog.css";
@import "@agent-native/design-system/components/combobox.css";
```

## Theme a region

[ThemeProvider](?path=/docs/components-theme-provider--docs) sets the appearance of an application or an individual surface. Load its theme stylesheet alongside the design-system styles. Menus and dialogs inherit the theme where they open.

```tsx
import "@agent-native/design-system/themes/design.css";
import { ThemeProvider } from "@agent-native/toolkit/ui/base-ui/theme-provider";

<ThemeProvider appTheme="design" appearance="dark" density="compact">
  {children}
</ThemeProvider>;
```
