A Spinner signals short, ongoing work when a meaningful percentage is unavailable. It works for a brief mutation or a status beside an existing label.

An unlabeled spinner is decorative. Supply `label` when the spinner owns the announcement. For a button with a pending action, the Button loading state also manages its accessible name, width and disabled behavior.

```tsx
import { Spinner } from "@agent-native/toolkit/ui/base-ui/spinner";

<Spinner label="Saving changes" />;
```
