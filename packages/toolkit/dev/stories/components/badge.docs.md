A Badge gives a short status or category a consistent visual weight beside the item it describes. It fits compact tables and lists where a full message would crowd the row.

Put the meaning in the text so it survives grayscale and forced colors. The dot reinforces the label. Put a filter action on a button or toggle with its own interaction state.

```tsx
import { Badge } from "@agent-native/toolkit/ui/base-ui/badge";

<Badge color="success" dot>
  Published
</Badge>;
```
