# Chat

Chat is a developer starter for building your own agent. Create the app and you get a working conversation screen, saved chat history, and sign-in, with a single example action the agent can already use. It replaces the weeks of wiring a chat interface, conversation storage, and login onto a model by hand, so you start with a deployable app and spend your time on what your agent actually does.

Chat is not a finished product for a specific job. If you're not a developer, or you want something ready to use today, start with [Clips](/docs/template-clips) for screen recordings, [Slides](/docs/template-slides) for decks, or [Design](/docs/template-design) for interactive prototypes.

## What you get

When you first open Chat, you see a single message box and the question "How can I help?" Ask anything and the agent answers right there. The rest of what's included is deliberately small.

- **A full-page chat.** Conversations take up the whole screen, with the message box centered until you send your first message.
- **A conversation list.** The sidebar lists your chats so you can start a new one, reopen an old one, rename it, pin it, or archive it.
- **A Get started page.** A short landing page with links to the guides for adding your first action and your first screen. You can edit it or replace it.
- **Sign-in and teams.** Login, signup, and organizations work from the start.
- **One example action.** The agent can already run a simple example, so you can see how an action works before writing your own.
- **Admin pages.** A database viewer and an observability dashboard are included, whether or not you ever open them.
- **Room for mini-apps.** Routes for small sandboxed tools called Extensions are included but switched off. A developer can switch them on.

Chat leaves out anything specific to a business: no ready-made data, dashboards, forms, or connections to outside services. You add those.

## Chat in a multi-app workspace

If you're running Chat alongside other apps under [Dispatch](/docs/template-dispatch), it can act as the front door to your workspace. A single conversation can reach into the apps around it instead of living on its own. See [Chat in a Multi-App Workspace](/docs/template-chat-integrations) for how the connection works.
