# CLI, MCP & AI SDKs

Every action you define with `defineAction()` is immediately usable from a **terminal CLI**, an **MCP server** (Claude, ChatGPT, Cursor, Codex), and popular **AI SDKs** (Vercel AI SDK, Anthropic SDK, OpenAI SDK) — without duplicating a single schema or auth check.

## Built-In CLI (`@agent-native/actions/cli`) {#cli}

`npx @agent-native/actions init` adds `"action": "actions"` to your `package.json`. It automatically discovers `actions/*.ts` (or reads `--registry ./lib/actions.ts` if you use explicit registration):

```bash
# List every action and its one-line description
pnpm action --list

# Auto-generated help from your Zod .describe() annotations
pnpm action create-todo --help

# Call with CLI flags
pnpm action create-todo --title "Ship docs"

# Or pass structured JSON (ideal for coding agents and scripts)
pnpm action create-todo '{"title":"Ship docs"}'
```

### Approval Gates in the Terminal

When an action declares `needsApproval`, the CLI enforces it automatically:

- **Interactive TTY:** Prints the action name and parsed arguments, then asks `Approve and run? [y/N]`.
- **Non-interactive (coding agent / CI):** Exits with a structured approval-required message showing the exact command so the agent asks the human for confirmation before re-running with `--approved`.

<Callout tone="success">

**Let coding agents build & run actions automatically:** `npx @agent-native/actions init` installs `.agents/skills/agent-native-actions/SKILL.md` into your repo (or run `npx @agent-native/actions skill` anytime). It teaches Claude Code, Codex, and Cursor to build every new feature as a typed action in `actions/` and verify it via `pnpm action --list` instead of writing ad-hoc routes or throwaway scripts.

</Callout>

### Coding Agent Skill (`npx @agent-native/actions skill`) {#skill}

Install or update the bundled skill at any time — or print it to stdout so any agent can load it directly:

```bash
# Install into .agents/skills/agent-native-actions/SKILL.md
npx @agent-native/actions skill

# Overwrite an existing copy with the latest version
npx @agent-native/actions skill --force

# Print the skill markdown directly (useful inside agent prompts or CI)
npx @agent-native/actions skill --print
```

## MCP Server (`@agent-native/actions/mcp`) {#mcp}

Every integration mounts a Streamable HTTP MCP server automatically at `/api/agent-native/mcp` — zero extra route files required.

### Streamable HTTP (Hosted / Remote MCP)

Point Claude, ChatGPT, Cursor, or Codex at:

```text
https://your-app.com/api/agent-native/mcp
```

### Local `stdio` MCP (Zero Web Server Required)

Connect Claude Desktop, Cursor, or Codex directly to your local repo's `actions/` folder over `stdio`:

```json
{
  "mcpServers": {
    "my-app": {
      "command": "npx",
      "args": ["@agent-native/actions", "mcp"]
    }
  }
}
```

### Automatic MCP Tool Metadata

`@agent-native/actions` maps your action fields onto standard MCP tool annotations automatically:

| Action option                       | MCP behavior                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| `description`                       | Tool description shown to the model                                                |
| `schema`                            | Converted to provider-safe JSON Schema (handles strict-mode model quirks)          |
| `outputSchema`                      | Published as MCP `outputSchema` + validated `structuredContent`                    |
| `readOnly: true`                    | Sets `annotations.readOnlyHint = true`                                             |
| `destructive: true`                 | Sets `annotations.destructiveHint = true`                                          |
| `retrySafe: true`                   | Sets `annotations.idempotentHint = true`                                           |
| `mcpTool: false`                    | Keeps the action available to UI hooks/HTTP while hiding it from MCP clients       |
| `fail(msg, { errorCode, details })` | Returns structured `isError: true` with machine-readable `errorCode` and `details` |

## Export to AI SDKs (Vercel AI SDK, Anthropic, OpenAI) {#ai-sdks}

Building an in-app chat assistant or agent workflow with the **Vercel AI SDK**, **Anthropic SDK**, or **OpenAI SDK**? Export your actions directly into their native tool format in one line so your LLM loop shares the exact same schemas, validation, and authorization as your UI:

## Browser Agents with WebMCP {#webmcp}

Expose actions to browser-embedded AI agents (such as Chrome's `navigator.modelContext`) under the user's live signed-in session:

```ts
import { registerWebMcpTools } from "@agent-native/actions/webmcp";

registerWebMcpTools({
  include: ["list-todos", "create-todo"],
});
```
