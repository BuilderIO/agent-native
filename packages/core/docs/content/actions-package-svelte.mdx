# Svelte & SvelteKit

`@agent-native/actions/svelte` provides reactive client helpers (`createActionQuery`, `createActionMutation`, `callAction`), paired with `@agent-native/actions/svelte/server` (`createSvelteKitHandler`, `callSvelteKitAction`) for SvelteKit.

### SvelteKit {#sveltekit-setup}

1. Add `agentNativeActionsPlugin({ devMiddleware: false })` to `vite.config.ts` so SvelteKit's `hooks.server.ts` and `+server.ts` route own every request in both dev and production:

```ts
// vite.config.ts
import { sveltekit } from "@sveltejs/kit/vite";
import { defineConfig } from "vite";
import { agentNativeActionsPlugin } from "@agent-native/actions/vite";

export default defineConfig({
  plugins: [sveltekit(), agentNativeActionsPlugin({ devMiddleware: false })],
});
```

2. Mount the single catch-all server route:

```ts
// src/routes/api/agent-native/[...path]/+server.ts
import { createSvelteKitHandler } from "@agent-native/actions/svelte/server";
import { actions } from "../../../../../.generated/actions";

export const { GET, POST, PUT, PATCH, DELETE, OPTIONS } =
  createSvelteKitHandler(actions);
```

### Svelte 5 + Vite (Without SvelteKit) {#vite-svelte}

For a client-side Svelte 5 app on Vite without SvelteKit, omit `devMiddleware: false` so `agentNativeActionsPlugin()` serves `/api/agent-native/*` during development, and mount `.generated/actions.ts` on your production server (see [Vite → Production](/docs/actions-package-vite#production)).

## Usage {#usage}

### Components

```svelte
<script lang="ts">
  import {
    createActionQuery,
    createActionMutation,
  } from "@agent-native/actions/svelte";

  let done = $state(false);
  const todos = createActionQuery("list-todos", () => ({ done }));
  const createTodo = createActionMutation("create-todo", {
    invalidate: ["list-todos"],
  });
</script>

<button onclick={() => createTodo.mutate({ title: "Ship docs" })}>
  Add todo
</button>

{#if todos.isLoading}
  <p>Loading...</p>
{:else}
  {#each todos.data ?? [] as todo (todo.id)}
    <p>{todo.title}</p>
  {/each}
{/if}
```

### Server Load (`+page.server.ts`)

Call actions directly from SvelteKit server loaders with zero HTTP hop using `callSvelteKitAction()`:

```ts
// src/routes/todos/+page.server.ts
import { callSvelteKitAction } from "@agent-native/actions/svelte/server";
import { actions } from "../../../../.generated/actions";
import type { PageServerLoad } from "./$types";

export const load: PageServerLoad = async (event) => {
  const todos = await callSvelteKitAction(
    actions,
    "list-todos",
    { done: false },
    event,
  );
  return { todos };
};
```
