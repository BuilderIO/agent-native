# Design

Design is an agent-native prototyping studio. Instead of a layered drawing
canvas, the agent generates complete, self-contained Alpine and Tailwind HTML
prototypes, shows them in a live preview, and refines the result through
prompts and tweak controls. The live preview runs the same HTML that the agent edits and exports.

## Design in a multi-app workspace

If you run Design alongside other apps in
[Dispatch](/docs/template-dispatch), it's not the only way to reach it.
Design also runs as a hosted tool other agents can call directly, including
Claude Code and Claude Desktop, over the same kind of connection point a
workspace app already exposes. See [Design in a Multi-App
Workspace](/docs/template-design-integrations) for how the connection
actually works and the real mechanisms behind it.

## What you can do with it

- **Generate complete prototypes.** Describe the screen or page you need and the agent writes a working HTML document with Tailwind styling and Alpine interactions.
- **Compare variants.** Generate a few different directions, pick the strongest one, and keep refining instead of starting over.
- **Apply a brand.** Link a design system, import brand from a site or codebase, or bring in a Figma frame as an editable starting point. See [Features](/docs/template-design-features).
- **Keep quality consistent.** The agent runs an accessibility and visual check before calling a prototype ready, and repeated patterns can become reusable components. See [Features](/docs/template-design-features).
- **Export real files.** Export HTML, ZIP, PDF, or a genuinely vector Figma SVG, or hand the prototype to a coding agent with a ready-made handoff bundle. See [Features](/docs/template-design-features).
