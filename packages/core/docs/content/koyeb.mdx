# Koyeb

Use Nitro's `koyeb` preset to build an output for Koyeb's managed application
runtime.

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "koyeb" } })],
});
```

Build the app and deploy the generated server with Koyeb's git or container
workflow:

```bash
pnpm build
node .output/server/index.mjs
```

Set `DATABASE_URL`, `BETTER_AUTH_SECRET`, and any app secrets as Koyeb
environment variables. Use a persistent PostgreSQL database instead of local files.

See [Nitro's Koyeb provider guide](https://nitro.build/deploy/providers/koyeb)
for the current provider workflow.
