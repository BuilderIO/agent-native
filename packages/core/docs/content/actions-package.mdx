# Actions Package

Add Agent-Native's action layer to any existing app — Next.js, Vite, SolidJS, Vue, Nuxt, SvelteKit, Hono, Express, or plain Node.js — without adopting the full framework.

Define each backend operation once with `defineAction()`. From one validated definition you get typed UI hooks, an HTTP API, a CLI, an MCP server, and tool definition exporters for the Vercel AI SDK, Anthropic SDK, and OpenAI SDK.

## What You Get {#what-you-get}

<Cards columns={2}>

### :components: [Typed UI Hooks](/docs/actions-package-quickstart#call-from-ui)

End-to-end inferred hooks and reactive primitives for **React**, **SolidJS**, **Vue**, and **Svelte 5**, plus a zero-dependency client. Mutations invalidate related queries automatically.

### :server: [Framework Adapters](/docs/actions-package-next)

Single catch-all handlers and build plugins for **Next.js**, **Vite**, **SolidJS**, **Vue / Nuxt**, **SvelteKit**, **Hono**, **Express**, **Fastify**, and **Node.js**.

### :plug: [MCP & AI SDK Exporters](/docs/actions-package-surfaces#mcp)

Serve actions over Streamable HTTP or local `stdio` MCP, or export tool definitions with `toAiSdkTools()`, `toAnthropicTools()`, and `toOpenAiTools()`.

### :terminal: [Built-In CLI](/docs/actions-package-surfaces#cli)

Run actions from any terminal or coding agent via `pnpm action <name>` (or `npx @agent-native/actions <name>`) with flag parsing, JSON input, and approval gates.

</Cards>

`npx @agent-native/actions init` detects your framework, generates `.generated/actions.ts` and `.generated/action-types.d.ts`, scaffolds a starter `actions/hello.ts`, installs `.agents/skills/agent-native-actions/SKILL.md` for coding agents, and adds `"action": "actions"` when `package.json` is present.

## Example {#example}

Create one file per operation in `actions/`. The filename becomes the action name, the Zod (or Standard Schema) validator types every caller, and `run()` is server TypeScript:

```ts
// actions/create-todo.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "Create a new todo item",
  schema: z.object({
    title: z.string().describe("What needs to be done"),
  }),
  run: async ({ title }) => {
    return db.todos.create({ title });
  },
});
```

Once mounted, that action is available across every enabled surface:

| Surface     | Example                                                                   |
| ----------- | ------------------------------------------------------------------------- |
| **UI hook** | `const createTodo = useActionMutation("create-todo")`                     |
| **HTTP**    | `POST /api/agent-native/actions/create-todo`                              |
| **CLI**     | `pnpm action create-todo --title "Ship docs"`                             |
| **MCP**     | `create-todo` over `/api/agent-native/mcp` or `stdio`                     |
| **AI SDKs** | `toAiSdkTools(actions, { context })`, `toAnthropicTools`, `toOpenAiTools` |
