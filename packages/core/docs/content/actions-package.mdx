# Actions Package

Add Agent-Native's action system to **any existing app** — Next.js, Vite, SolidJS, Vue, Nuxt, SvelteKit, Hono, Express, or plain Node.js — without adopting the full framework.

Define each backend operation once with `defineAction()`. From that single file you get typed UI hooks, an HTTP API, a CLI for developers and coding agents, a spec-compliant MCP server, and drop-in tools for the Vercel AI SDK, Anthropic SDK, and OpenAI SDK.

## What You Get from One Action {#what-you-get}

<Cards columns={2}>

### :components: [Typed UI Hooks](/docs/actions-package-quickstart#call-from-ui)

End-to-end inferred hooks and reactive primitives for **React**, **SolidJS**, **Vue**, and **Svelte 5** — plus a zero-dependency client. Mutations auto-invalidate related queries.

### :server: [First-Class Framework Support](/docs/actions-package-next)

Minimal-boilerplate integrations and single catch-all handlers for **Next.js**, **Vite**, **SolidJS**, **Vue / Nuxt**, **SvelteKit**, **Hono**, **Express**, and **Node.js**.

### :plug: [Instant MCP & AI SDKs](/docs/actions-package-surfaces#mcp)

Expose every action as a Streamable HTTP or `stdio` MCP server automatically, or export them in one line to the **Vercel AI SDK**, **Anthropic SDK**, and **OpenAI SDK**.

### :terminal: [Built-In CLI](/docs/actions-package-surfaces#cli)

Run `pnpm action create-todo --title "Ship docs"` from any terminal. Humans, scripts, CI, and coding agents like Claude Code and Codex all share the exact same validated entry point.

</Cards>

## What an Action Looks Like {#example}

Drop one file per operation in `actions/`. The filename is the action name, the Zod (or Standard Schema) validator types every caller, and `run()` is plain server TypeScript:

```ts
// actions/create-todo.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "Create a new todo item",
  schema: z.object({
    title: z.string().describe("What needs to be done"),
  }),
  run: async ({ title }) => {
    return db.todos.create({ title });
  },
});
```

With zero extra wiring, that single file is immediately callable from:

- **UI Hooks:** `const createTodo = useActionMutation("create-todo");`
- **HTTP:** `POST /api/agent-native/actions/create-todo`
- **CLI:** `pnpm action create-todo --title "Ship docs"`
- **MCP:** `create-todo` tool on `/api/agent-native/mcp` (or local `stdio`)
- **AI SDKs:** `toAiSdkTools()`, `toAnthropicTools()`, `toOpenAiTools()`
