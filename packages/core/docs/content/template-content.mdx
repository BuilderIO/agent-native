# Content

Content is open-source Obsidian for MDX: a local-file-friendly document
workspace where the agent can read, write, reorganize, and publish pages for
you. Open a doc, ask "rewrite this paragraph to be more concise" or "create a
page called Q4 Planning with sub-pages for Goals, Metrics, and Risks" - same
result whether you do it yourself or ask.

## What it replaces

<Comparison>

### Before

- Obsidian, or a folder of local Markdown files, for private notes
- A separate Notion workspace for docs a team can browse together
- A headless CMS for anything that ships to a live site
- Copying content between all three by hand whenever one falls behind

### After

- One workspace for private pages, team docs, and published content
- The same document can sync to local files, Notion, or Builder CMS instead of being retyped into each
- The agent reads and writes through the same actions and the same pages you do
- A change from an outside source lands as a reviewable change set, never a silent overwrite

</Comparison>

Documents are private by default, with viewer/editor/admin sharing and a public read-only mode when you want one out in the world. Multiple people (and the agent) can edit the same page at once without clobbering each other. See [Writing and organizing documents](/docs/template-content-editing), [Databases, properties, and forms](/docs/template-content-databases), and [Local files, Notion, and Builder CMS sync](/docs/template-content-sync) for each of those in depth.

## Get started {#get-started}

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

See [Content: Developer Guide](/docs/template-content-developers#quick-start) for install, first run, and connecting an LLM.

When you open the app, click **+ New page** in the sidebar, give it a title, and start writing, or ask the agent directly:

- "Create a page called Onboarding and add three sub-pages under it."
- "Rewrite this paragraph to be more concise." (with a page open)
- "Pull the latest from Notion." (after linking a Notion page)

Select text and hit Cmd+I to focus the agent with that selection pre-loaded — "make this punchier" then operates on exactly what you highlighted.
