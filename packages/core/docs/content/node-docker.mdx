This URL is kept for older links. Node.js and Docker are separate deployment
choices, so use the individual guides:

- [**Node.js**](/docs/node-js) - run the default Nitro server preset
- [**Docker**](/docs/docker) - package the server in a container
- [**Workspace Deployment**](/docs/workspace-deployment#workspace-docker-compose) - run several apps with Docker Compose
