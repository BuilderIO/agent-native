# Slides

Slides is an agent-powered deck editor. Ask the agent for a deck and it generates one from a prompt, streaming slides into the editor as it builds them, then edits, restyles, or exports the deck whenever you ask, in plain English or with a click. It replaces Google Slides, Pitch, and PowerPoint with one app, so generating, editing, presenting, and exporting a deck are never separate tools you have to switch between.

## What it replaces

### Before

- Google Slides, Pitch, or PowerPoint for building the deck itself
- A per-seat subscription just to keep editing and presenting
- Copy-pasting your brand colors, fonts, and logo onto every new deck by hand

## Slides in a multi-app workspace

If you're running Slides alongside other apps under [Dispatch](/docs/template-dispatch), a deck stops being just a page you open by hand. The agent can submit a deck to a Library other apps can reuse, or answer a plain-English request from a sibling app the same way it answers you in chat. See [Slides in a Multi-App Workspace](/docs/template-slides-integrations) for how the connection actually works and the real mechanisms behind it.

## What you can do with it

- **Generate decks from a prompt.** "Generate a 10-slide pitch deck for a coffee subscription service, audience is investors." See [Features](/docs/template-slides-features).
- **Edit slides visually.** Double-click text to edit, click a block for the bubble menu, use `/` for the slash menu to insert blocks. See [Features](/docs/template-slides-features).
- **Present full-screen**, comment, collaborate in real time, and share a deck with specific teammates or publicly. See [Features](/docs/template-slides-features).
- **Bring in existing content.** Import a PPTX, DOCX, PDF, or Google Doc as a starting point. Export to PPTX, Google Slides, or a standalone HTML file. See [Features](/docs/template-slides-features).
- **Apply a design system built from your brand.** Save colors, type, and logos once and reuse them on every new deck. Set one up from a Figma file, a connected codebase, or a website. See [Features](/docs/template-slides-features).
- **Restore earlier versions.** Every change is snapshotted. List or restore any prior version. See [Features](/docs/template-slides-features).

## Getting started

When you open the app:

1. Click **New deck**.
2. Ask the agent: "Generate a 10-slide pitch deck for a coffee subscription service, audience is investors."
3. Watch slides stream in. Click any slide to edit, or keep asking the agent to refine. Select text and click **Revise with AI** in the bubble menu to hand the agent that exact selection.

### Useful prompts

- "Generate a 10-slide pitch deck for a coffee subscription service, audience is investors."
- "Add a pricing slide after slide 3."
- "Make the title on this slide bigger and change the accent color to green."
- "Summarize this PDF as a 6-slide deck." (attach the PDF)

To scaffold your own copy of Slides:

```bash
npx --yes @agent-native/core@latest create my-slides --standalone --template slides
```

See [Getting started](/docs/getting-started) for the rest of the setup (`cd`, `pnpm install`, `pnpm dev`) and the framework fundamentals.
