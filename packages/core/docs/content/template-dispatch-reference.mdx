# Dispatch action and data reference

Lookup material for Dispatch: every action grouped by area, the database schema behind the vault and workspace resources, and the full route list. See [Dispatch developer guide](/docs/template-dispatch-developers) for the narrative version of how these pieces fit together.

## Action inventory {#actions}

Dispatch ships close to a hundred actions. Most of the UI-facing ones are already covered by task on [Features](/docs/template-dispatch-features). This is the full reference, grouped by area.

### App discovery, launch, and delegation

| Action                                                                                                                 | What it does                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list-workspace-apps`                                                                                                  | Lists apps mounted in this deployment: paths, URLs, audience, and live agent-card metadata.                                                                                                                                     |
| `list-connected-agents`                                                                                                | Lists agents available for A2A delegation: built-in apps plus custom connections. This is a separate list from `list-workspace-apps` on purpose, see [Dispatch in a Multi-App Workspace](/docs/template-dispatch-integrations). |
| `list_apps`                                                                                                            | Lists apps reachable through the MCP gateway, filtered by the current access policy.                                                                                                                                            |
| `open_app`                                                                                                             | Builds a deep link or embeddable route for a granted app.                                                                                                                                                                       |
| `ask_app` / `ask_app_status`                                                                                           | Sends a plain-English request to another app's agent over A2A, and polls a durable task by id.                                                                                                                                  |
| `list-mcp-app-access` / `set-mcp-app-access`                                                                           | Reads or writes which apps are exposed through the MCP gateway.                                                                                                                                                                 |
| `connect-external-agent`                                                                                               | Registers public HTTP/A2A metadata for an external agent.                                                                                                                                                                       |
| `create_embed_session` / `create-workspace-app-embed-session`                                                          | Mints the short-lived ticket used to embed another app's screen.                                                                                                                                                                |
| `create-browser-chat-session`                                                                                          | Creates a session for the browser-extension chat bridge.                                                                                                                                                                        |
| `send-code-agent-remote-command`                                                                                       | Sends a remote command to a connected code-agent session.                                                                                                                                                                       |
| `remove-pending-workspace-app` / `archive-workspace-app` / `unarchive-workspace-app` / `update-workspace-app-metadata` | Manage a mounted app's lifecycle and metadata.                                                                                                                                                                                  |

### Creating new apps

| Action                                                          | What it does                                                         |
| --------------------------------------------------------------- | -------------------------------------------------------------------- |
| `start-workspace-app-creation`                                  | Turns a chat request into a new, independent app under `apps/`.      |
| `get-app-creation-settings` / `set-app-creation-settings`       | Read or update app-creation defaults.                                |
| `list-available-workspace-templates`                            | Lists the built-in template catalog.                                 |
| `list-curated-workspace-templates` / `remix-workspace-template` | List reviewed private sources and clone one into an independent app. |
| `scaffold-workspace-app`                                        | Runs the actual scaffold step.                                       |

### Secrets vault

| Action                                                                                          | What it does                                             |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `create-vault-secret` / `update-vault-secret` / `delete-vault-secret`                           | Manage a stored credential.                              |
| `create-vault-grant` / `revoke-vault-grant` / `list-vault-grants`                               | Grant, revoke, or list per-app secret access.            |
| `request-vault-secret` / `approve-vault-request` / `deny-vault-request` / `list-vault-requests` | The request-and-review workflow for a new secret.        |
| `grant-vault-secrets-to-app` / `sync-vault-to-app`                                              | Push access, or push the full vault, to one app.         |
| `list-vault-secrets` / `list-vault-secret-options` / `list-vault-audit`                         | Read secret metadata (never values) and the audit trail. |
| `get-vault-access-settings` / `set-vault-access-settings`                                       | Read or change the all-apps vs. manual access mode.      |

### Agent and workspace resources

| Action                                                                                                                                 | What it does                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `create-workspace-resource` / `update-workspace-resource` / `delete-workspace-resource`                                                | Manage a skill, instruction, agent profile, knowledge, or MCP-server resource. |
| `create-workspace-resource-grant` / `revoke-workspace-resource-grant` / `grant-workspace-resources-to-app`                             | Manage per-app access to a `selected`-scope resource.                          |
| `list-workspace-resources` / `list-workspace-resource-options` / `list-workspace-resource-grants` / `list-workspace-resources-for-app` | List resources and their grants.                                               |
| `get-workspace-resource-effective-context`                                                                                             | Previews workspace to org/app to personal precedence for a resource.           |
| `preview-workspace-resource-change`                                                                                                    | Previews reach, overrides, and approval behavior before a write.               |
| `restore-starter-workspace-resources`                                                                                                  | Restores missing starter-pack files without overwriting existing ones.         |

### Agent profiles and packs

| Action                                  | What it does                                                                        |
| --------------------------------------- | ----------------------------------------------------------------------------------- |
| `import-agent`                          | Normalizes a Claude Markdown or JSON definition into `agents/<slug>.md`.            |
| `import-agent-pack` / `list-agent-pack` | Imports a Claude Project- or Cowork-style folder, or inspects one already imported. |

### Integrations, messaging, and destinations

| Action                                                             | What it does                                                               |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| `list-integrations-catalog` / `resolve-integration-source-context` | List available provider integrations and resolve one app's source context. |
| `upsert-destination` / `delete-destination` / `list-destinations`  | Manage saved delivery targets.                                             |
| `send-platform-message`                                            | Sends a message through a saved destination.                               |
| `read-slack-thread-context`                                        | Reads a Slack thread's content from a permalink.                           |
| `create-pylon-ticket`                                              | Creates a support ticket in Pylon.                                         |
| `create-link-token` / `list-linked-identities`                     | Link an external sender's account to a workspace user.                     |

### Workspace connections

| Action                                | What it does                                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `plan-workspace-connection-setup`     | Inspects a provider or an existing connection and returns what's needed to set it up, without ever returning secret values. |
| `apply-workspace-connection-setup`    | Saves a connection using credential reference names only; rejects anything that looks like a raw secret.                    |
| `set-workspace-connection-grant`      | Grants or revokes one app's access, or switches the whole connection between all-apps and selected-apps only.               |
| `preview-workspace-connection-impact` | Shows which apps would lose access before a connection is revoked, disabled, or deleted.                                     |
| `list-workspace-connections`          | Lists the provider catalog, saved connections, and every app's current access in one call.                                   |
| `delete-workspace-connection`         | Removes a connection's metadata and grants; secret values stay in Vault or OAuth stores either way.                          |

### Provider APIs (ad hoc access)

| Action                                                                    | What it does                                                           |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `provider-api-catalog` / `provider-api-docs` / `provider-api-register`    | List configured providers, fetch their docs, or register a custom one. |
| `provider-api-request`                                                    | Makes an authenticated request directly against a provider's HTTP API, and can stage its response into a dataset instead of returning it inline. |
| `list-staged-datasets` / `query-staged-dataset` / `delete-staged-dataset` | Manage scratch datasets staged from a broad API scan.                  |

### Approvals and audit

| Action                                                   | What it does                                      |
| -------------------------------------------------------- | -------------------------------------------------- |
| `approve-dispatch-change` / `reject-dispatch-change`     | Resolve a pending approval request.               |
| `set-dispatch-approval-policy` / `get-dispatch-settings` | Configure or read the approval policy.            |
| `list-dispatch-approvals` / `list-dispatch-audit`        | List pending approvals or the change-history log. |

### Overview, usage, and reliability

| Action                                                                                                      | What it does                                      |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `list-dispatch-overview`                                                                                    | Counts and recent activity for the Overview page. |
| `list-dispatch-usage-metrics`                                                                               | Workspace or personal LLM usage and spend.        |
| `get-workspace-info`                                                                                        | Workspace identity: name and app count.           |
| `list-agent-run-failures` / `get-agent-thread-debug` / `list-agent-thread-sources` / `search-agent-threads` | Cross-app thread and run diagnostics.             |

### Dreams

| Action                                                                      | What it does                                                      |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `list-dream-candidates` / `create-dream-report`                             | Find threads with grounded signals, and write a report from them. |
| `get-dream` / `list-dreams`                                                 | Read one report or list recent ones.                              |
| `preview-dream-proposal` / `apply-dream-proposal` / `reject-dream-proposal` | Review one proposal.                                              |
| `get-dream-settings` / `set-dream-settings` / `ensure-dream-job`            | Configure the recurring schedule and materialize the job.         |

### Navigation and context

| Action        | What it does                                                                 |
| ------------- | ------------------------------------------------------------------------------ |
| `navigate`    | Moves the UI to a view, path, or chat thread.                                |
| `view-screen` | Reads back the current navigation state and a view-specific context payload. |
