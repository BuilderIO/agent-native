# Other Frameworks & Servers

`@agent-native/actions` has **zero framework dependencies**. Run it in a plain TypeScript CLI/MCP project with no web server at all, mount one catch-all handler on Hono, Express, Fastify, or Cloudflare Workers, or call actions from any JS/TS client.

## Set Up with Your AI Coding Agent {#setup}

Paste this prompt into **Claude Code**, **Codex**, or **Cursor**:

```text
Set up @agent-native/actions in this repo following https://agent-native.com/docs/actions-package-servers.md.
Run `npx @agent-native/actions init`, mount the catch-all handler on our server (or keep it standalone for CLI & stdio MCP), create a sample action in actions/, and verify with `pnpm action --list`.
```

## Standalone (Plain Node / TypeScript — No Web Framework) {#standalone}

Building an internal tool, backend service, CLI, or local MCP server without a frontend framework? You only need `@agent-native/actions` and `zod`:

<Steps>

### Initialize in any Node / TS repo

```bash
pnpm add @agent-native/actions zod
npx @agent-native/actions init
```

### Drop an action in `actions/`

```ts
// actions/create-todo.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "Create a new todo item",
  schema: z.object({
    title: z.string().describe("What needs to be done"),
  }),
  run: async ({ title }) => db.todos.create({ title }),
});
```

### Call it from code, CLI, or MCP

```bash
# Run directly from the terminal
pnpm action create-todo --title "Ship docs"

# Inspect resolved actions without executing them
npx @agent-native/actions inspect

# Or expose actions/ directly as a local stdio MCP server
npx @agent-native/actions mcp
```

Or invoke actions programmatically in scripts, cron jobs, workers, and tests:

```ts
import { createActions } from "@agent-native/actions";
import createTodo from "./actions/create-todo";

const actions = createActions({
  actions: { "create-todo": createTodo },
});

const todo = await actions.call("create-todo", { title: "Ship docs" });
```

</Steps>

## Zero-Dependency Vanilla Client (`@agent-native/actions/client`) {#vanilla-client}

Call your actions with full TypeScript inference from React Native, Electron, Chrome extensions, browser scripts, or another microservice:

```ts
import {
  createActionClient,
  actionErrorMessage,
} from "@agent-native/actions/client";
import type { AppActions } from "../.generated/actions";

const client = createActionClient<AppActions>({
  baseUrl: "https://app.example.com/api/agent-native/actions",
  headers: async () => ({
    Authorization: `Bearer ${await getAccessToken()}`,
  }),
});

const todos = await client.call("list-todos", { done: false });

try {
  await client.call("create-todo", { title: "Ship docs" });
} catch (error) {
  console.error(actionErrorMessage(error));
}
```
