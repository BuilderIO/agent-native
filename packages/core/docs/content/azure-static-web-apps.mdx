# Azure Static Web Apps

Nitro provides the `azure-swa` preset for Azure Static Web Apps. It packages
the public assets and server routes for the provider's static and API hosting
model.

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "azure-swa" } })],
});
```

Build the provider output:

```bash
npx @agent-native/core@latest build
```

Deploy the generated output with the Azure Static Web Apps CLI or your CI
workflow. Use a persistent external SQL database and configure
`DATABASE_URL`, `BETTER_AUTH_SECRET`, and app secrets in the Azure environment.

See [Nitro's Azure provider guide](https://nitro.build/deploy/providers/azure)
for the current provider workflow.
