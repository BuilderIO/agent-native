# ¿Qué es Agent-Native?

Agent-Native es un framework TypeScript de código abierto para crear agentes
autónomos con interfaces intuitivas. Defines cada capacidad una sola vez como
una [acción](/docs/actions-overview): una función tipada que el agente usa como
herramienta y que la UI llama desde el código.

Los agentes de programación pueden hacer que un cuadro de texto parezca
suficiente. Pero el cuadro de texto es solo una parte de su entorno de trabajo.
El código fuente aporta contexto, las herramientas les ofrecen formas claras de
actuar, y los archivos, las pruebas y las vistas previas hacen visibles los
resultados.

La mayor parte del trabajo del conocimiento no cuenta con esa estructura. Ante
un cuadro de texto vacío, las personas tienen que adivinar qué puede hacer el
agente, qué contexto tiene y qué deberían pedirle.

Una UI aporta lo que le falta al cuadro de texto. Hace visibles las capacidades
del agente, incorpora el contexto y los flujos de trabajo a la experiencia, y
permite que las personas vean y den forma al trabajo mientras se desarrolla.

Agent-Native te permite crear agentes de esta forma. La UI ofrece puntos de
partida claros sin reducir al agente a un flujo de trabajo fijo. Como el agente
y la UI usan las mismas capacidades, las personas pueden delegar trabajo al
agente, inspeccionarlo o cambiarlo en la UI y pasar de uno a otro sin perder el
progreso.

Agent-Native conecta el agente y la UI mediante tres bases compartidas:

- **[Acciones compartidas](/docs/actions-overview).** Cada capacidad se define
  una vez. El agente la llama como herramienta y la UI la llama desde el código.
  Ambas vías usan la misma validación, permisos e implementación.
- **[Datos compartidos](/docs/server-database).** Las acciones leen y actualizan
  los mismos datos, por lo que el trabajo del agente aparece en la UI y el
  trabajo realizado en la UI queda disponible para el agente.
- **[Estado compartido de la aplicación](/docs/context-awareness).** El estado
  de la aplicación describe lo que ocurre en la UI, como la página actual, el
  registro seleccionado o la vista activa. Agent-Native proporciona al agente
  el estado relevante como contexto para que entienda en qué está trabajando la
  persona.

El agente no hace clic por la UI. Trabaja mediante la misma capa de acciones que
la UI.

Por ejemplo, una persona puede asignar un ticket de soporte desde la UI o pedirle
al agente que lo haga. Ambas vías ejecutan la misma acción y actualizan el mismo
ticket. La persona puede inspeccionar o cambiar el resultado en la UI y dejar
que el agente continúe desde ahí.

## ¿Cuándo deberías usar Agent-Native?

Agent-Native es adecuado cuando:

- el agente debe hacer trabajo real, no solo responder preguntas;
- las personas necesitan una UI para ver qué puede hacer el agente y para
  inspeccionar, editar, aprobar o compartir su trabajo;
- las personas deben poder pasar entre el agente y la UI sin perder progreso ni
  contexto.

Si solo necesitas una única respuesta generada, llama a un modelo directamente.
Si el trabajo sigue una secuencia fija y predecible, la lógica de aplicación o
la automatización habituales son más simples. Usa Agent-Native cuando tanto el
agente como la UI deban desempeñar un papel continuo en el mismo trabajo.
