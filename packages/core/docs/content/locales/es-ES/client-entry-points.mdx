# Puntos de entrada

`app/entry.client.tsx` hidrata en el navegador el HTML renderizado en el servidor, y `app/entry.server.tsx` renderiza ese HTML en el servidor. Ambos son wrappers ligeros generados por React Router. Rara vez necesitas editarlos.

```ts filename="app/entry.server.tsx"
import {
  createDocumentRequestHandler,
  streamTimeout,
} from "@agent-native/core/server/entry-server";
import { ServerRouter } from "react-router";

export default createDocumentRequestHandler(ServerRouter);
export { streamTimeout };
```

Recurre a estos solo para personalización avanzada de SSR, por ejemplo cambiar el comportamiento de streaming. Las páginas, el layout y los datos ordinarios no necesitan cambios aquí. Consulta [Enrutamiento](/docs/client-routing) para agregar páginas en su lugar.
