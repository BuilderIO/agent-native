# Guía para desarrolladores

Esta página es para cualquiera que personalice la plantilla Clips o la extienda: el inicio rápido, todas las acciones, el modelo de datos, la superficie de rutas y cómo añadir a ella. Consulta [Clips](/docs/template-clips) para ver qué hace la app.

## Inicio rápido

<Steps>

### Crea la app

```bash
npx @agent-native/core@latest create my-clips --standalone --template clips
cd my-clips
pnpm install
```

Esto necesita tener instalados antes [Node.js](https://nodejs.org) 22.22 o posterior y [pnpm](https://pnpm.io). Consulta [Primeros pasos](/docs/getting-started) si todavía no has instalado ninguno de los dos, o si no tienes configurada una conexión LLM (Builder.io, una clave de Anthropic/OpenAI o un Ollama local).

### Inicia el servidor de desarrollo

```bash
pnpm dev
```

La app se abre automáticamente en tu navegador. La grabación funciona sin ninguna configuración adicional, ya que el navegador o la aplicación de escritorio capturan localmente. Solo te encontrarás con un error en una acción que necesite almacenamiento de archivos o créditos de IA antes de que se configure alguno de los dos.

</Steps>

<Callout tone="info">

La grabación, la transcripción y los títulos/resúmenes de IA necesitan que el almacenamiento de archivos y los créditos de IA estén configurados antes de que funcionen de principio a fin. Conecta Builder.io desde **Settings** para ambos a la vez (su plan gratuito incluye créditos de IA gestionados), o conecta almacenamiento compatible con S3 por separado y usa tu propia clave de Groq para la transcripción. Consulta [Transcripción y metadatos de IA](/docs/template-clips-features#transcription-and-ai-metadata).

</Callout>

## Inventario de acciones

Cada operación es un archivo TypeScript en `templates/clips/actions/`, montado automáticamente en `POST /_agent-native/actions/:name`.

### Biblioteca y grabaciones

| Action                                                                                    | What it does                                                                           |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `list-recordings`, `search-recordings`                                                    | Listados de la Biblioteca, compartido conmigo, papelera y por espacio                  |
| `create-recording`, `finalize-recording`                                                  | Crea la fila; finaliza la carga                                                        |
| `import-loom-recording`                                                                   | Importa un vídeo de Loom o una URL directa de MP4/WebM                                 |
| `update-recording`                                                                        | Título, descripción, contraseña, caducidad, visibilidad                                |
| `move-recording`                                                                          | Mueve una o varias grabaciones a una carpeta o a la raíz                               |
| `archive-recording`, `trash-recording`, `restore-recording`, `delete-recording-permanent` | Ciclo de vida: ocultar, eliminar de forma reversible, deshacer o eliminar para siempre |
| `reprocess-recording`                                                                     | Repara medios no navegables o congelados                                               |
| `generate-filmstrip`                                                                      | El sprite de fotogramas de la línea de tiempo del editor                               |
| `tag-recording`, `set-thumbnail`                                                          | Etiquetado y un fotograma de miniatura elegido manualmente                             |

### Carpetas y espacios

| Action                                            | What it does                                                               |
| ------------------------------------------------- | -------------------------------------------------------------------------- |

| `add-space-member`, `remove-space-member`         | Roles de espectador, colaborador y administrador a nivel de espacio        |

## Modelo de datos

Definido en `templates/clips/server/db/schema.ts`.

<Callout tone="warning">

Las filas de equipos, miembros e invitaciones viven en las propias tablas del framework `organizations`, `org_members` y `org_invitations`, no en una tabla específica de Clips. `organization_settings` es el propio sidecar de Clips: color de marca, logotipo y visibilidad predeterminada, una fila por organización. Un par más antiguo `workspaces`/`workspace_members` todavía existe solo para que una migración de arranque de una sola vez pueda rellenar las tablas del framework en un despliegue existente. No construyas funciones nuevas sobre ellas.

</Callout>

## Recorrido por una acción

`create-recording-agent-link` muestra patrones que merece la pena reutilizar en cualquier acción que genere una credencial limitada: comprobar el estado real del recurso antes de entregar nada, delegar la generación real del token en un ayudante compartido del framework en lugar de crear el tuyo propio, y derivar cada URL que necesita quien llama a partir de esa misma concesión.

    'import { defineAction } from "@agent-native/core/action";\nimport {\n  buildAgentAccessUrl,\n  createScopedAgentAccessGrant,\n  getRequestContext,\n  getRequestUserEmail,\n} from "@agent-native/core/server";\nimport { ForbiddenError, resolveAccess } from "@agent-native/core/sharing";\nimport { z } from "zod";\n\nimport {\n  CLIPS_AGENT_ACCESS_TTL_SECONDS,\n  getServerAppBasePath,\n} from "../server/lib/public-agent-context.js";\nimport {\n  buildAgentApiUrls,\n  CLIP_AGENT_ACCESS_TOKEN_PREFIX,\n} from "../shared/agent-context.js";\nimport { BUG_REPORT_AGENT_ACCESS_TTL_SECONDS } from "../shared/bug-report.js";\n\nfunction appOrigin(): string {\n  const origin =\n    getRequestContext()?.requestOrigin ||\n    process.env.APP_URL ||\n    process.env.BETTER_AUTH_URL ||\n    "http://localhost:3000";\n  try {\n    return new URL(origin).origin;\n  } catch {\n    return "http://localhost:3000";\n  }\n}\n\nexport default defineAction({\n  description:\n    "Create a temporary private agent-readable link for one Clips recording. The URL is scoped to that recording and expires after two hours.",\n  schema: z.object({\n    recordingId: z.string().describe("Recording ID"),\n    agentLabel: z\n      .string()\n      .trim()\n      .min(1)\n      .max(60)\n      .optional()\n      .describe(\n        "Name of the agent that will read this link (e.g. \'Fusion\', \'Claude Code\'). Recorded against every read the link produces, so the owner sees a name instead of an unidentified agent.",\n      ),\n    ttlSeconds: z\n      .number()\n      .int()\n      .positive()\n      .max(BUG_REPORT_AGENT_ACCESS_TTL_SECONDS)\n      .optional()\n      .describe(\n        "Optional scoped-link lifetime in seconds, capped at seven days. Defaults to two hours.",\n      ),\n  }),\n  readOnly: true,\n  run: async (args) => {\n    const access = await resolveAccess("recording", args.recordingId);\n    if (!access) {\n      throw new ForbiddenError(`No access to recording ${args.recordingId}`);\n    }\n\n    const recording = access.resource as {\n      id: string;\n      archivedAt?: string | null;\n      trashedAt?: string | null;\n    };\n    if (recording.archivedAt || recording.trashedAt) {\n      throw new ForbiddenError(\n        `Recording ${args.recordingId} is not shareable`,\n      );\n    }\n\n    const grant = createScopedAgentAccessGrant({\n      resourceKind: CLIP_AGENT_ACCESS_TOKEN_PREFIX,\n      resourceId: recording.id,\n      viewerEmail: getRequestUserEmail() || undefined,\n      agentLabel: args.agentLabel,\n      ttlSeconds: args.ttlSeconds ?? CLIPS_AGENT_ACCESS_TTL_SECONDS,\n    });\n    const origin = appOrigin();\n    const basePath = getServerAppBasePath();\n    const pageUrl = buildAgentAccessUrl({\n      path: `/share/${encodeURIComponent(recording.id)}`,\n      origin,\n      basePath,\n      token: grant.token,\n    });\n    const api = buildAgentApiUrls(recording.id, {\n      origin,\n      basePath,\n      token: grant.token,\n    });\n\n    return {\n      recordingId: recording.id,\n      url: pageUrl,\n      contextUrl: api.contextUrl,\n      expiresAt: grant.expiresAt,\n      ttlSeconds: grant.ttlSeconds,\n    };\n  },\n});\n'

## Personalizarlo

Cada parte de la app es código fuente editable. Empieza aquí:

- `templates/clips/actions/` — añade un archivo nuevo con `defineAction` para exponer una nueva capacidad tanto al agente como al frontend.
- `templates/clips/app/routes/` — la interfaz, listada arriba.
- `templates/clips/server/db/schema.ts` — añade columnas o tablas con Drizzle. Mantén el esquema compatible con PostgreSQL para que la plantilla funcione con PGlite local y Postgres alojado.
- `templates/clips/server/lib/` — integraciones con proveedores: `google-calendar-client.ts`, `s3-upload-provider.ts`, `slack-oauth.ts`, `video-remux.ts`, `video-filmstrip-sprite.ts`.
- `templates/clips/AGENTS.md` — instrucciones del agente. Actualiza esto cuando le enseñes al agente nuevas capacidades o convenciones.
- `templates/clips/.agents/skills/` — patrones detallados que sigue el agente. Skills relevantes: `recording`, `ai-video-tools`, `video-editing`, `video-sharing`, `screen-memory`.
- `templates/clips/shared/api.ts` — los tipos de TypeScript compartidos que usan tanto el servidor como el cliente.
- `templates/clips/desktop/` y `templates/clips/chrome-extension/` — paquetes separados para las superficies de captura nativas, cada uno con su propio `package.json` y compilación.

Si añades una función, recuerda actualizar las cuatro áreas: UI, acción, skill o entrada de AGENTS.md, y cualquier estado de la aplicación que el agente necesite ver. Eso es lo que mantiene al agente y a la UI en paridad.
