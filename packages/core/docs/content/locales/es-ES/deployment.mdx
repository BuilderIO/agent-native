## Antes de implementar: elige una base de datos persistente {#persistent-database}

Cada aplicación implementada necesita una base de datos SQL persistente. Configura `DATABASE_URL` en el entorno de implementación antes del primer despliegue de producción. Usa `DATABASE_AUTH_TOKEN` si tu proveedor requiere un token separado.

Las aplicaciones independientes necesitan un `BETTER_AUTH_SECRET` estable. Los espacios de trabajo con solicitudes firmadas entre aplicaciones necesitan `A2A_SECRET`.

## Destinos compatibles

Agent-Native admite [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) y [Render](/docs/render).

Consulta la [referencia de variables de entorno de implementación](/docs/deployment-environment-variables) para los ajustes avanzados, secretos y valores de producción.
