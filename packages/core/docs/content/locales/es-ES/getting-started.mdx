# Primeros pasos

Las aplicaciones Agent-Native dan al agente y a la interfaz de usuario las mismas
[acciones](/docs/actions-overview), datos SQL y estado de la aplicación. Este recorrido
empieza con Chat, que ya crea las tablas del framework que necesita y guarda el
historial del chat en SQLite local por defecto. Añade tus propias tablas solo
cuando tu aplicación necesite conservar datos del dominio.

<Steps>

### Crea una aplicación de chat y configura un agente

Genera la plantilla Chat, instala las dependencias, inicia el servidor de desarrollo
y configura un agente. Tendrás una aplicación de chat funcional que podrás ampliar.
**Estás aquí.**

### Añade una acción

Define un analizador de texto tipado y muestra su resultado como un gráfico en el chat.

### Añade una página

Crea una ruta de React que invoque la misma acción fuera de la transcripción.

</Steps>

## 1. Crea una aplicación de chat {#create-your-app}

Necesitarás [Node.js 22+](https://nodejs.org) y [pnpm](https://pnpm.io).

Abre un terminal, ve al directorio donde quieras crear tu aplicación Agent Native y ejecuta:

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

La aplicación se abre en `http://localhost:8080`. Si ves la pantalla de inicio de
sesión, regístrate con un login inventado. El desarrollo local no requiere verificar
el correo electrónico.

La plantilla Chat incluye hilos de chat duraderos, autenticación, sincronización en
tiempo real, un directorio `actions/` y las acciones estándar `view-screen` y
`navigate`.

### Elige un punto de partida diferente

Si Chat no es el punto de partida adecuado, ejecuta `create` sin `--template` y
elige otra opción en la CLI. Consulta [Crear plantillas](/docs/creating-templates)
para conocer las demás opciones.

## 2. Configura un agente {#connect-ai}

La plantilla Chat se abre directamente en la superficie de chat. Si el agente no
está listo para responder, abre **Configuración > Gestionar agente** o usa
**Cmd/Ctrl+K > Gestionar agente** para configurar un modelo y un proveedor.

Cuando el agente responda, continúa con [Añadir una acción](/docs/getting-started-actions).
