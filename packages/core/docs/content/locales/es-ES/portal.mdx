# Portal

Portal empareja un ordenador para ejecutar trabajo entre dispositivos. Abre **Configuración → Espacio de trabajo → Emparejar o reparar** y guarda el token del dispositivo en `~/.agent-native/remote-device.json` del ordenador.

Los modos de ejecución son **Local**, **Computer** y **Cloud**. **Cloud** está en lista de espera y no inicia una ejecución hasta que se habilite el acceso.
