# Actualizar aplicaciones existentes a Core 0.198.0

Sigue esta guía para actualizar una aplicación existente a Core 0.198.0.
Ejecuta los comandos desde la raíz de la aplicación o del workspace y conserva
un diff revisable antes de empezar. Comprueba por separado la configuración de
despliegue remota: la CLI puede leer los archivos de entorno locales, pero no
puede inspeccionar entornos remotos ni ajustes de funciones guardados en la
base de datos.

## 1. Previsualizar la actualización y los codemods de imports

Usa la CLI de Core 0.198.0 para cargar el manifiesto de migración de esa versión:

    npx @agent-native/core@0.198.0 upgrade --codemods --dry-run

Una vez instalado Core 0.198.0 en la app, puedes ejecutar la misma vista previa con el binario local del CLI:

    npx agent-native upgrade --codemods --dry-run

El comando `--codemods` usa `ts-morph`. Si el paquete aún no se puede resolver desde la app, instálalo primero como dependencia de desarrollo: `pnpm add -D ts-morph`.

`--codemods` aplica por defecto las modificaciones de importación compatibles. Añade
`--dry-run` para previsualizar los cambios previstos en las dependencias, el diff de archivos
y las advertencias antes de continuar. Ya no es necesario usar `--yes`.

El codemod utiliza los manifiestos de migración activos de Core y Toolkit.
Analiza únicamente archivos .ts y .tsx (excepto archivos de declaración y directorios
generados o de dependencias) y reescribe los especificadores de import y
re-export compatibles. Si los exports con nombre pasan a módulos distintos,
puede dividir una declaración por símbolo y conservar alias e imports de tipo.
También actualiza rutas sencillas de CSS @import y añade una dependencia si una
ruta resuelta cruza el límite de un paquete.

El diagnóstico también detecta las formas CommonJS `require()` y las formas de `import()` dinámico. El codemod reescribe las llamadas literales a `import()` cuando el módulo antiguo tiene un único destino nuevo. Deja sin cambios y con una advertencia `require()` y las importaciones dinámicas que necesitan dividirse por símbolo. Sustitúyelas usando el nuevo destino indicado en el informe y vuelve a ejecutar Vite o `agent-native doctor`. Las rutas CSS `@import url(...)` se modifican tanto si están entre comillas como si no.

No cambia los puntos de llamada ni mueve archivos. Deja sin cambios los
movimientos planificados o no resueltos y muestra advertencias. No puede dividir
imports ni exports default, namespace, side-effect o star; tampoco puede dividir imports CSS por símbolo. Revisa estos casos manualmente.
Los exports eliminados pueden requerir cambios en el código; sigue la guía de
migración indicada en la advertencia de la CLI.

La previsualización también muestra el plan completo: overrides o patches del
framework que bloquean la actualización, cambios pendientes de versiones
@agent-native/\*, dependencias de funciones inferidas de la configuración local,
la instalación del gestor de paquetes, la actualización de las skills de
scaffold y typecheck si el paquete raíz tiene ese script. El comando cambia las
versiones a latest en el registro y después fija las versiones resueltas por la
instalación. Ejecútalo cuando 0.198.0 sea la versión actual que quieres usar;
si más adelante necesitas una versión exacta, comprueba los pins resueltos.

## 2. Confirmar Toolkit y paquetes opcionales

Las importaciones trasladadas a `@agent-native/toolkit/*` requieren instalar `@agent-native/toolkit`. El codemod añade Toolkit cuando mueve allí una importación o exportación compatible y resoluble. Si la app usa una exportación de Toolkit y no se añadió la dependencia, instala la versión de Toolkit que corresponde a Core 0.198.0:

    pnpm add @agent-native/toolkit@0.198.0
    # npm install @agent-native/toolkit@0.198.0
    # yarn add @agent-native/toolkit@0.198.0

### Dependencias que selecciona el CLI de actualización

El CLI añade estas dependencias cuando las comprobaciones del entorno local coinciden. No puede inspeccionar entornos remotos ni ajustes de funciones guardados en la base de datos; comprueba por separado producción y previsualización.

## 3. Aplicar la actualización

Después de revisar la simulación y confirmar los paquetes de funciones, aplica
el plan con la CLI versionada. Esto importa si la app aún tiene Core 0.196 u
otra CLI anterior, porque incluye un manifiesto de migración antiguo:

    npx @agent-native/core@0.198.0 upgrade --codemods

Cuando Core 0.198.0 ya esté instalado en la app, el comando está disponible en
la CLI local:

    npx agent-native upgrade --codemods

Ambas invocaciones actualizan las versiones aptas de dependencias
@agent-native/\*, alinean las dependencias de funciones detectadas, ejecutan el
gestor de paquetes, fijan las versiones de Agent-Native resueltas, aplican los
codemods compatibles, actualizan las skills de scaffold y ejecutan el script
typecheck raíz si existe. No ejecutes otro comando upgrade solo para aplicar los
codemods. Corrige las advertencias y los errores de la aplicación en su propio
código; no añadas overrides ni patches del framework.

## 4. Verificar el resultado

Revisa el diff completo, en especial las advertencias de codemods omitidos y
las versiones de dependencias, y ejecuta:

    npx @agent-native/core@0.198.0 upgrade check
    npx agent-native doctor
    pnpm typecheck

Doctor ejecuta de forma predeterminada las comprobaciones `migration-manifest` y
`feature-dependencies`. Informa de imports obsoletos y de peers opcionales que
faltan para las funciones detectadas en la configuración local. No puede
inspeccionar la configuración de despliegue remota ni los ajustes de funciones
guardados en la base de datos, así que confírmalos por separado.

Usa el comando de typecheck equivalente de npm o Yarn. Ejecuta los scripts de
pruebas y compilación de la aplicación cuando existan, normalmente `pnpm test` y
`pnpm build`. Confirma que la tabla de peers opcionales cubra la configuración
local y la desplegada. Busca los imports antiguos de la tabla siguiente; los
resultados restantes deben ser intencionados, no compatibles con el manifiesto o
explicados por una advertencia.
