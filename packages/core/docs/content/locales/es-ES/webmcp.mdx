# WebMCP

WebMCP es una API experimental del navegador que permite a las páginas
registrar herramientas para que un agente autorizado las descubra y ejecute.
Consulta la [guía de WebMCP en inglés](/docs/webmcp) para conocer el registro,
el consumo, las sesiones del navegador y los límites de seguridad.
