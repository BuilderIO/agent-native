# Implementar una aplicación

Consulta la [guía completa en inglés para implementar una aplicación](/docs/deploy-an-app) para ver los pasos y comandos de cada proveedor.

Antes de implementar, configura una base de datos SQL persistente y un `BETTER_AUTH_SECRET` estable. Elige [Node.js y Docker](/docs/node-docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify) o [Cloudflare](/docs/cloudflare).

Para varias aplicaciones bajo un mismo origen, usa [Implementación de espacios de trabajo](/docs/workspace-deployment).
