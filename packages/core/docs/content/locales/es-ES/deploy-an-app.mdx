# Implementar una aplicación

Consulta la [guía completa en inglés para implementar una aplicación](/docs/deploy-an-app) para ver los pasos y comandos de cada proveedor.

Antes de implementar, configura una base de datos SQL persistente y un `BETTER_AUTH_SECRET` estable. Elige [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) o [Render](/docs/render).

Para varias aplicaciones bajo un mismo origen, usa [Implementación de espacios de trabajo](/docs/workspace-deployment).
