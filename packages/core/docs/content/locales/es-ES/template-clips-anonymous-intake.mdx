# Recepción anónima de Clips

Este flujo permite que un visitante envíe una grabación privada sin iniciar sesión en Clips. El producto de confianza crea el enlace de recepción. El enlace está separado de los enlaces de lectura del agente.

Si se pierde la respuesta de creación, la misma solicitud firmada se puede repetir de forma segura después de asociar la grabación; no se crea una segunda grabación.

Consulta la [guía completa en inglés](/docs/template-clips-anonymous-intake) para la integración, los límites de seguridad y los requisitos de alojamiento propio.
