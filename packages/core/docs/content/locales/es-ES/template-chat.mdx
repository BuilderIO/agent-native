# Chat

Chat es un starter para desarrolladores que quieren crear su propio agente. Crea la app y obtendrás una pantalla de conversación funcional, un historial de chats guardado e inicio de sesión, con una única acción de ejemplo que el agente ya puede usar. Te ahorra las semanas de conectar a mano una interfaz de chat, el almacenamiento de conversaciones y el inicio de sesión a un modelo, así que empiezas con una app desplegable y dedicas tu tiempo a lo que tu agente realmente hace.

Chat no es un producto terminado para un trabajo específico. Si no eres desarrollador, o quieres algo listo para usar hoy, empieza con [Clips](/docs/template-clips) para grabaciones de pantalla, [Slides](/docs/template-slides) para presentaciones o [Design](/docs/template-design) para prototipos interactivos.

## Qué incluye

Después de iniciar sesión, Chat se abre en una página «Empieza aquí» con un cuadro de mensaje. Pregunta lo que quieras y el agente responde en una conversación a pantalla completa. El resto de lo que se incluye es deliberadamente pequeño.

- **Un chat a pantalla completa.** Las conversaciones ocupan toda la pantalla, con el cuadro de mensaje centrado hasta que envías tu primer mensaje.
- **Una lista de conversaciones.** La barra lateral muestra tus chats para que puedas iniciar uno nuevo, reabrir uno antiguo, renombrarlo, fijarlo o archivarlo.
- **Una página de Get started.** Una breve página de bienvenida con enlaces a las guías para añadir tu primera acción y tu primera pantalla. Puedes editarla o reemplazarla.
- **Inicio de sesión y equipos.** El login, el registro y las organizaciones funcionan desde el principio.
- **Una acción de ejemplo.** El agente ya puede ejecutar un ejemplo sencillo, para que veas cómo funciona una acción antes de escribir la tuya.
- **Páginas de administración.** Se incluyen un visor de base de datos y un panel de observabilidad, los abras o no.
- **Espacio para mini-apps.** Se incluyen rutas para pequeñas herramientas aisladas llamadas Extensiones, pero están desactivadas. Un desarrollador puede activarlas.

Chat deja fuera todo lo específico de un negocio: no incluye datos, paneles, formularios ni conexiones a servicios externos ya preparados. Los añades tú.

## Chat en un espacio de trabajo con varias apps

Si ejecutas Chat junto con otras apps bajo [Dispatch](/docs/template-dispatch), puede actuar como la puerta de entrada a tu espacio de trabajo. Una sola conversación puede llegar a las apps que la rodean en lugar de vivir aislada. Consulta [Chat en un espacio de trabajo con varias apps](/docs/template-chat-integrations) para saber cómo funciona la conexión.
