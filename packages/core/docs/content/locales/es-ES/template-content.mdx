# Contenido

Contenido es Obsidian de código abierto para MDX: un espacio de trabajo de
documentos compatible con archivos locales donde el agente puede leer,
escribir, reorganizar y publicar páginas por ti. Abre un documento y pide
"reescribe este párrafo para que sea más conciso" o "crea una página llamada
Planificación del T4 con subpáginas para Objetivos, Métricas y Riesgos". El
resultado es el mismo, ya sea que lo hagas tú mismo o se lo pidas al agente.

## Qué puedes hacer con él

- **Escribe y organiza documentos.** Edición de texto enriquecido, un árbol de páginas anidado de forma infinita, favoritos, comentarios, historial de versiones y uso compartido. Consulta [Escribir y organizar documentos](/docs/template-content-editing).
- **Crea bases de datos estilo Notion.** Tablas donde cada fila es un documento propio, con propiedades tipadas y vistas de tabla, lista, galería, tablero, calendario, línea de tiempo y formulario. Consulta [Bases de datos, propiedades y formularios](/docs/template-content-databases).
- **Recopila envíos estructurados.** Convierte una base de datos en un formulario de admisión en el que el agente, Slack u otra aplicación pueden enviar datos de forma segura. Consulta [Bases de datos, propiedades y formularios](/docs/template-content-databases).
- **Edita archivos en disco como en Obsidian** y mantén los documentos sincronizados con Notion o Builder CMS. Consulta [Sincronización con archivos locales, Notion y Builder CMS](/docs/template-content-sync).
- **Colabora en tiempo real.** Varias personas (y el agente) pueden editar el mismo documento al mismo tiempo sin pisarse el trabajo entre sí.
- **Comparte documentos** con tu equipo o hazlos públicos. Son privados de forma predeterminada, con roles de espectador, editor y administrador.
- **Pídele al agente lo que necesites**: "Reescribe este párrafo". "Agrega un TL;DR al principio". "Encuentra todas mis notas de reuniones de la semana pasada". "Crea una base de datos de registro para la beta con un formulario para envíos desde Slack".

## Para empezar

Demostración en vivo: [content.agent-native.com](https://content.agent-native.com).

Cuando abras la aplicación, haz clic en **+ Nueva página** en la barra lateral, dale un título y empieza a escribir. Para usar el agente, escribe en la barra lateral:

- "Crea una página llamada Incorporación y agrégale tres subpáginas."
- "Reescribe este párrafo para que sea más conciso." (con una página abierta)
- "Agrega una sección sobre precios con tres viñetas."
- "Resume este documento en un TL;DR al principio."
- "Trae lo último desde Notion." (después de vincular una página de Notion)

Selecciona texto y presiona Cmd+I para enfocar al agente con esa selección precargada. Así, "hazlo más contundente" actúa exactamente sobre lo que resaltaste.

Para crear tu propia copia de Contenido:

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

Consulta [Primeros pasos](/docs/getting-started) para el resto de la configuración (`cd`, `pnpm install`, `pnpm dev`) y los fundamentos del framework.
