# Contenido

Contenido es Obsidian de código abierto para MDX: un espacio de trabajo de
documentos compatible con archivos locales donde el agente puede leer,
escribir, reorganizar y publicar páginas por ti. Abre un documento y pide
"reescribe este párrafo para que sea más conciso" o "crea una página llamada
Planificación del T4 con subpáginas para Objetivos, Métricas y Riesgos". El
resultado es el mismo, ya sea que lo hagas tú mismo o se lo pidas al agente.

## Qué reemplaza

<Comparison>

### Before

- Obsidian, o una carpeta de archivos Markdown locales, para notas privadas
- Un espacio de trabajo de Notion separado para documentos que un equipo pueda consultar en conjunto
- Un CMS headless para todo lo que se publique en un sitio en vivo
- Copiar contenido manualmente entre los tres cada vez que uno se queda atrás

### After

- Un solo espacio de trabajo para páginas privadas, documentos de equipo y contenido publicado
- El mismo documento puede sincronizarse con archivos locales, Notion o Builder CMS en lugar de volver a escribirse en cada uno
- El agente lee y escribe a través de las mismas actions y las mismas páginas que tú
- Un cambio proveniente de una fuente externa llega como un conjunto de cambios revisable, nunca como una sobrescritura silenciosa

</Comparison>

Los documentos son privados de forma predeterminada, con permisos de espectador, editor y administrador, y un modo de solo lectura público para cuando quieras que uno esté disponible para todo el mundo. Varias personas (y el agente) pueden editar la misma página al mismo tiempo sin pisarse el trabajo entre sí. Consulta [Escribir y organizar documentos](/docs/template-content-editing), [Bases de datos, propiedades y formularios](/docs/template-content-databases) y [Sincronización con archivos locales, Notion y Builder CMS](/docs/template-content-sync) para profundizar en cada uno de ellos.

## Primeros pasos {#get-started}

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

Consulta [Contenido: Guía para desarrolladores](/docs/template-content-developers#quick-start) para conocer la instalación, la primera ejecución y cómo conectar un LLM.

Cuando abras la aplicación, haz clic en **+ Nueva página** en la barra lateral, dale un título y empieza a escribir, o pídeselo directamente al agente:

- "Crea una página llamada Incorporación y agrégale tres subpáginas."
- "Reescribe este párrafo para que sea más conciso." (con una página abierta)
- "Trae lo último desde Notion." (después de vincular una página de Notion)

Selecciona texto y presiona Cmd+I para enfocar al agente con esa selección precargada. Así, "hazlo más contundente" actúa exactamente sobre lo que resaltaste.
