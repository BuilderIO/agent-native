# 版本與穩定性

Agent-Native 套件尚未達到 1.0。發布流程提供 nightly 快照、穩定版本、遷移工具和 doctor 檢查。Alpha 或 beta 不代表正式環境支援承諾。

## 發布管道

合併至 `main` 後會使用 npm `nightly` 標籤發布快照，不會移動 `latest` 標籤。穩定版本透過 Changesets 協調。排程工作會在太平洋時間週一至週四中午準備 patch 版本。每次執行不一定都會發布。

## 1.0 前的相容性

Patch 版本旨在修正錯誤並提供相容改進。Minor 版本可能新增功能，也可能變更仍處於 alpha 或 beta 階段的 API 或行為。Major 版本用於大範圍的重大變更。升級前請查看發布說明和遷移步驟。

支援的遷移會在 `migration-manifest.json` 記錄 import 路徑移動和符號重新命名。先預覽 codemod、檢查 diff，再套用：

```bash
npx @agent-native/core@latest upgrade --codemods
npx @agent-native/core@latest upgrade --codemods --yes
agent-native doctor --only migration-manifest
```

移除的路徑可能暫時保留 tombstone 模組，說明替代項目和遷移命令。沒有固定的保留期限。

## 範本版本與目標

CLI 會將 `@agent-native/core` 固定在提供範本的確切版本。請用遷移工具升級，不要手動改為 `latest`。

目前目標為 2026 年 10 月中旬推出 beta，並於 2026 年底前達到 1.0。這些是目標而非承諾。回報可重現問題時，請附上套件版本、資料庫供應商和遷移輸出。
