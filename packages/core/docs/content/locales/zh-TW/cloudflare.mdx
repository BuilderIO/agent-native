# Cloudflare

使用 Nitro 原生的模組輸出來產生一個 Cloudflare Worker。這樣可以
保持 SSR 啟用，並在 `.output/server` 和 `.output/public` 下產生
Worker 進入點和靜態資源:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Build and deploy the generated Worker with Wrangler:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

你也可以用 `NITRO_PRESET=cloudflare_module` 明確選擇這個預設。
部署之前請設定一個持久的外部 PostgreSQL 資料庫。Worker 的檔案系統
不是一個持久的應用程式儲存。
