# 新增頁面

這是入門指南系列的第三部分。在[新增動作](/docs/getting-started-actions)中，您建立了 `analyze-text`。這裡會從路由呼叫相同的動作。這個範例不需要新的資料庫資料表。Chat 已經將聊天記錄儲存在 SQL 中；只有在需要持久化領域資料時，才新增自己的資料表。

## 建立路由 {#add-a-page}

開發伺服器會在啟動時讀取路由檔案。建立 `app/routes/text-analyses.tsx`；如果 `pnpm dev` 已在執行，請建立檔案後重新啟動。路由會在 `http://localhost:8080/text-analyses` 提供服務。

```tsx filename="app/routes/text-analyses.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";

type TextAnalysis = {
  summary: {
    characters: number;
    words: number;
    sentences: number;
    paragraphs: number;
  };
};

export default function TextAnalysesRoute() {
  const { data: analysis, isLoading } = useActionQuery<TextAnalysis>(
    "analyze-text",
    { text: "Hello world. How are you today?" },
  );

  return (
    <main className="mx-auto flex max-w-3xl flex-col gap-6 p-6">
      <header>
        <h1 className="text-2xl font-semibold">Text analyses</h1>
        <p className="text-muted-foreground">The same action, on a page.</p>
      </header>
      <section className="grid gap-3 sm:grid-cols-2">
        {isLoading && <p className="text-muted-foreground">Analyzing...</p>}
        {analysis &&
          Object.entries(analysis.summary).map(([label, value]) => (
            <article key={label} className="rounded-lg border p-4">
              <p className="text-sm capitalize text-muted-foreground">
                {label}
              </p>
              <p className="text-2xl font-semibold">{value}</p>
            </article>
          ))}
      </section>
    </main>
  );
}
```

`useActionQuery` 會呼叫代理使用的相同唯讀動作。頁面暫時不需要自訂 API 路由、第二個資料層或 SQL。

開啟 `http://localhost:8080/text-analyses`，或詢問代理：

> Navigate to `/text-analyses`.

這個路由已足夠完成本教學。如果之後成為主要工作流程，再新增側邊欄項目。若要了解完整的 `view-screen`、`navigate` 和 application-state 模式，請參閱[Context Awareness](/docs/context-awareness)。
