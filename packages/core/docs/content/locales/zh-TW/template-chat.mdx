# 聊天

聊天是一個讓開發者打造自己代理的起點。建立應用程式後，您會得到一個可運作的對話畫面、已儲存的聊天記錄和登入功能，以及一個代理已經可以使用的範例 action。它省去了手動把聊天介面、對話儲存和登入串接到模型上所需的數週時間，讓您從一個可部署的應用程式開始，把時間花在代理真正要做的事情上。

聊天不是為特定工作打造的成品。如果您不是開發者，或是想要今天就能使用的東西，請從用於螢幕錄影的 [Clips](/docs/template-clips)、用於簡報的 [Slides](/docs/template-slides)，或用於互動式原型的 [Design](/docs/template-design) 開始。

## 您會得到什麼

第一次開啟聊天時，您會看到一個訊息框和一句「How can I help?」。問任何問題，代理就會直接在那裡回答。其餘內含的功能刻意保持精簡。

- **全頁聊天。** 對話佔滿整個畫面，在您送出第一則訊息之前，訊息框會置中顯示。
- **對話清單。** 側邊欄列出您的聊天，讓您可以開始新的對話、重新開啟舊的對話、重新命名、釘選或封存。
- **Get started 頁面。** 一個簡短的起始頁面，附有連結，引導您閱讀如何新增第一個 action 和第一個畫面的指南。您可以編輯或取代它。
- **登入與團隊。** 登入、註冊和組織功能從一開始就能運作。
- **一個範例 action。** 代理已經可以執行一個簡單的範例，讓您在撰寫自己的 action 之前，先看看 action 是如何運作的。
- **管理頁面。** 內含一個資料庫檢視器和一個可觀察性儀表板，不論您是否會開啟它們。
- **為小工具預留空間。** 內含供名為擴充功能的小型沙盒化工具使用的路由，但預設是關閉的。開發者可以將它們開啟。

聊天不包含任何特定於企業的內容：沒有現成的資料、儀表板、表單，也沒有與外部服務的連線。這些都由您來新增。

## 多應用工作區中的聊天

如果您在 [Dispatch](/docs/template-dispatch) 之下與其他應用程式一起執行聊天，它可以成為您工作區的入口。單一對話可以延伸到周圍的應用程式，而不是孤立存在。這種連接如何運作，請參閱[多應用工作區中的聊天](/docs/template-chat-integrations)。
