# 開始使用

<GettingStartedPaths />

本指南中，您將建立一個具備聊天 UI 的代理，並從代理和 UI 呼叫其內含的 `hello` action。

## 先決條件

- [Node.js](https://nodejs.org) 22 或更新版本
- [pnpm](https://pnpm.io)
- 供代理使用的 LLM 連線：Builder.io、Anthropic 或 OpenAI API 金鑰，或本機 Ollama 模型

## 建立代理

在新目錄中從 Chat 範本開始：

```bash
npx @agent-native/core@latest create my-app --standalone --template chat
cd my-app
pnpm install
```

範本為代理提供瀏覽器 UI、驗證、持久對話、即時同步、應用程式上下文和 `actions/` 目錄。它還包含一個小型 `hello` action，您會在本指南中一直使用它。

## 啟動開發伺服器

啟動開發伺服器：

```bash
pnpm dev
```

瀏覽器 UI 會在 `http://localhost:8080` 開啟。若未自動開啟，請在瀏覽器中造訪該 URL。

<Callout tone="info">

在歡迎畫面中，選取 **Continue as local dev**。本機開發不需要輸入電子郵件或密碼。

</Callout>

接著連線 LLM。選取 **Connect Builder.io** 使用免費額度，或選取 **Custom keys**，選擇提供者並輸入所需的連線詳細資料。

## 從代理執行 action

Action 是 React UI 可從程式碼呼叫、代理可作為工具使用的具型別函式。Chat 範本包含一個簡單的 `hello` action，讓您能在自行撰寫 action 前先嘗試這個模式。

在代理面板中輸入：

> Call the hello action for Alex.

代理會透過描述和輸入 schema 找到 `hello`，將 `Alex` 作為 `name` 輸入傳入，並回覆：

```text
Hello, Alex!
```

## 檢視 action

開啟 `actions/hello.ts`：

```ts filename="actions/hello.ts"
import { defineAction } from "@agent-native/core/action";
import { z } from "zod";

export default defineAction({
  description: "Return a friendly greeting.",
  schema: z.object({
    name: z.string().default("world").describe("Name to greet"),
  }),
  http: { method: "GET" },
  run: async ({ name }) => {
    return { message: `Hello, ${name}!` };
  },
});
```

目前請聚焦於四個部分：

- `description` 告訴代理何時使用這個 action。
- `schema` 驗證輸入，並向代理提供具型別的工具定義。
- `http` 透過 `GET` 公開這個唯讀 action，讓 `useActionQuery` 可從 React 呼叫它。
- `run` 包含由代理與 UI 共用的應用程式邏輯。

完整 API 請閱讀[定義 actions](/docs/actions-defining)。

## 從 React 呼叫 action

在 `app/routes/hello.tsx` 新增路由：

```tsx filename="app/routes/hello.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";
import { useState } from "react";

import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function HelloRoute() {
  const [name, setName] = useState("Alex");
  const { data } = useActionQuery("hello", { name });

  return (
    <main className="mx-auto grid w-full max-w-xl gap-6 p-6">
      <h1 className="text-2xl font-semibold">Hello action</h1>
      <div className="grid gap-2">
        <Label htmlFor="name">Name</Label>
        <Input
          id="name"
          value={name}
          onChange={(event) => setName(event.target.value)}
        />
      </div>
      <p className="text-xl font-medium">{data?.message}</p>
    </main>
  );
}
```

<Callout tone="warning">

重新啟動開發伺服器，讓它探索新路由，然後開啟 `http://localhost:8080/hello`。

</Callout>

輸入名稱時，`useActionQuery` 會呼叫 `hello` 並渲染結果。它會推斷 action 的輸入與結果型別，因此頁面不需要自訂 API 路由或第二份問候語實作。

## 修改 action

在 `actions/hello.ts` 中，修改回傳值：

```ts
return { message: `Welcome, ${name}.` };
```

重新整理 `/hello`，接著請代理再次呼叫 `hello`。兩者都會回傳更新的問候語，因為它們呼叫的是相同 action。

## 用其他方式呼叫 actions

您已從代理和 UI 呼叫相同的 action。這個 action 還可以從下列位置呼叫：

| 從這裡呼叫                              | 用途                                           |
| --------------------------------------- | ---------------------------------------------- |
| [HTTP API](/docs/http-api)              | 從指令碼、後端或整合呼叫 action。              |
| [CLI](/docs/actions-other-surfaces#cli) | 在終端機中執行或測試 action。                  |
| [MCP](/docs/actions-other-surfaces#mcp) | 讓外部 AI 用戶端探索並以工具形式呼叫 actions。 |
| [A2A](/docs/actions-other-surfaces#a2a) | 讓另一個代理將工作委派給您的代理。             |

每個呼叫端都使用相同的 action 定義。您不需要為每個呼叫端建立單獨實作。這個共用 action 模型是 Agent-Native 的核心：隨著您新增能力，UI、代理與整合的行為、驗證及權限都會維持一致。

## 您建立了什麼

您建立了一個具備聊天 UI 的代理，從代理與 React UI 呼叫同一個 `hello` action，接著只變更一次問候語，並看見兩者更新。您之後撰寫的每個 action 都會遵循相同模式。
