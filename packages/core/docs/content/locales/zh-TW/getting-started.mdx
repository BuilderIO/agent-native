# 開始使用

Agent-Native 應用程式讓代理和 UI 共用相同的[動作](/docs/actions)、SQL 資料和應用程式狀態。這條路徑從 Chat 開始，Chat 已經建立所需的框架資料表，並預設將聊天記錄儲存在本機 SQLite 中。只有當應用程式需要持久化領域資料時，才新增自己的資料表。

<Steps>

### 建立聊天應用程式並設定代理

建立 Chat 範本、安裝相依套件、啟動開發伺服器並設定代理。您會得到一個可繼續擴充的聊天應用程式。
**您目前在這裡。**

### 新增動作

定義一個具型別的文字分析器，並在對話中將結果渲染為圖表。

### 新增頁面

建立一個在對話記錄之外呼叫相同動作的 React 路由。

</Steps>

## 1. 建立聊天應用程式 {#create-your-app}

您需要 [Node.js 22+](https://nodejs.org) 和 [pnpm](https://pnpm.io)。

開啟終端機，前往您要建立 Agent Native 應用程式的目錄，然後執行：

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

應用程式會在 `http://localhost:8080` 開啟。如果看到登入畫面，請使用虛構的登入資訊註冊。本機開發不需要驗證電子郵件。

Chat 範本包含持久化聊天對話串、驗證、即時同步、`actions/` 目錄，以及標準的 `view-screen` 和 `navigate` 動作。

### 選擇其他起點

如果 Chat 不是合適的起點，可以執行 `create` 而不使用 `--template`，並在 CLI 中選擇其他選項。其他路徑請參閱[建立範本](/docs/creating-templates)。

## 2. 設定代理 {#connect-ai}

Chat 範本會直接開啟對話介面。如果代理尚未準備好回應，請開啟 **Settings > Manage agent**，或使用 **Cmd/Ctrl+K > Manage agent** 來設定模型和提供者。

代理開始回應後，繼續閱讀[新增動作](/docs/getting-started-actions)。
