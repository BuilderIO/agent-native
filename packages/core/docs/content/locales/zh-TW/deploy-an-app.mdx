# 部署應用程式

步驟和各供應商的指令，請參閱[完整的英文應用程式部署指南](/docs/deploy-an-app)。

部署前，請設定持久性 SQL 資料庫和穩定的 `BETTER_AUTH_SECRET`。可選擇 [Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb) 或 [Render](/docs/render)。

若要在單一來源下執行多個應用程式，請使用[工作區部署](/docs/workspace-deployment)。
