# 部署應用程式

步驟和各供應商的指令，請參閱[完整的英文應用程式部署指南](/docs/deploy-an-app)。

從[入門指南](/docs/getting-started)開始。部署前，請在託管提供者的環境設定中儲存 `DATABASE_URL`，而不只是在本機 `.env`。使用 `openssl rand -hex 32` 產生穩定的 `BETTER_AUTH_SECRET` 並儲存在同一位置。**Continue as local dev** 僅限本機使用；已部署的應用程式使用註冊與登入。可選擇 [Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Amplify](/docs/aws-amplify)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb) 或 [Render](/docs/render)。

若要在單一來源下執行多個應用程式，請使用[工作區部署](/docs/workspace-deployment)。
