# Design

Design 是一款 Agent-Native 原型設計工作室。代理不使用分層繪圖畫布，而是產生
完整、獨立的 Alpine 和 Tailwind HTML 原型，在即時預覽中顯示，並透過提示和
調整控制項來完善結果。它取代了靜態模型工具，以及隨之而來的交接流程，因為
您在預覽中看到的已經是真正、可運作的程式碼。

每一次產生、微調和匯出，讀寫的都是同一個 HTML 檔案，因此預覽畫面和您下載
的內容之間不會有任何東西在轉譯過程中遺失。

## 它取代的內容

<Comparison>

### 之前

- 使用 Figma 或類似工具製作靜態模型，再交給另一位開發人員把它們轉換成真正的標記
- 透過調整畫板尺寸來猜測設計的回應方式，而不是即時瀏覽器渲染
- 匯出規格與手動比對還原之間緩慢的交接流程
- 設計檔案與實際上線的程式碼隨著時間逐漸脫節

### 之後

- 代理產生、預覽並完善同一個 HTML 原型，不需要另外的建置步驟
- 真正的 Alpine 和 Tailwind 標記，可以在任何中斷點即時預覽
- 向代理要求版面配置、文案或互動變更，看著同一個檔案即時更新
- 直接匯出成 HTML、ZIP、PDF 或編碼交接套件，讓設計與程式碼始終是同一個成品

</Comparison>

## Design 在多應用工作區中

如果您在[調度](/docs/template-dispatch)之下與其他應用程式一起執行 Design，
這並不是使用它的唯一方式。Design 也會以託管工具的形式執行，讓其他代理可以直
接呼叫它，包括 Claude Code 和 Claude Desktop，透過工作區應用程式已經公開
的同一種連接點。若想了解這種連接實際上如何運作，以及背後真正的機制，請參
閱[Design 的跨應用使用](/docs/template-design-integrations)。

## 你可以用它做什麼

- **產生完整的原型。** 描述您需要的畫面或頁面，代理就會寫出一份具有
  Tailwind 樣式和 Alpine 互動的可運作 HTML 文件。
- **比較不同變體。** 產生幾個不同的方向，選出最強的一個，然後不斷完善而
  不是重新開始。
- **套用一個品牌。** 連結一個設計系統、從網站或程式碼庫匯入品牌，或帶入
  一個 Figma 畫框，取得像素級精準的起點。詳見[功能](/docs/template-design-features)。
- **維持一致的品質。** 代理會在把原型標記為完成之前執行無障礙和視覺檢
  查，反覆出現的模式也可以變成可重複使用的元件。詳見[功能](/docs/template-design-features)。
- **匯出真正的檔案。** 匯出 HTML、ZIP、PDF，或真正的向量 Figma SVG，或
  用一個現成的交接套件把原型交給編碼代理。詳見[功能](/docs/template-design-features)。
