# 跨應用程式連線與 Agent-Native 市集

這是一鍵連線應用程式的設計方向。使用 Dispatch 作為身分權威與現有 PKCE 流程，不新增萬用 Cookie。

- Dispatch 仍是身分權威，組織成員資格透過簽署的 assertion 傳遞。
- `/_agent-native/open` 處理深層連結，本機登入作為備援。
- 動態註冊、Client ID 中繼資料、同意與撤銷是市集的後續階段。
- 啟用 `labs.connectApps` 後，`/connect` 會顯示快取的 `/apps.json` 目錄，並在現有身分交接前驗證代理卡。中心的動態註冊與撤銷仍是下一階段。
- 此版本不顯示連線狀態或中斷操作；中心必須先提供應用程式註冊表。
- 請參閱[跨應用程式 SSO](/docs/cross-app-sso)。
