# 組織、團隊與權限

組織定義團隊成員和租戶界線。工作區彙整應用程式與部署設定，但不會取代組織。權限必須由伺服器檢查。在介面隱藏按鈕並不等於存取控制。

## 三種角色範圍

- 組織角色 `owner`、`admin` 和 `member` 控制團隊管理。
- 應用程式角色控制單一應用程式內的操作。一位成員可以有多個應用程式角色。
- 資源角色 `viewer`、`editor` 和 `admin` 控制單筆資料的存取。

應用程式程式碼宣告角色和權限鍵。管理員可在團隊頁面取代成員的整組角色，並將已宣告的權限對應到角色。沒有覆寫時採用應用程式預設值。邀請可以預先包含應用程式角色。應用程式管理員不會因此取得組織管理權限。

邀請和設定請參閱[管理式部署指南](/docs/administered-deployments)。資料存取請參閱[資料範圍控制](/docs/security#data-scoping)。
