# 與 Agent 對話

表單中的每一項功能，代理都能透過 UI 所使用的相同 actions 取得，所以只要是您能點選的操作，也都可以直接用簡單的文字提出請求。本頁涵蓋代理如何看到您的畫面，以及依任務分類的實用提示。總覽請參閱 [表單](/docs/template-forms)。

## 代理如何看到您的畫面

代理永遠知道您目前開啟的是哪份表單或哪個檢視畫面，精確到瀏覽器分頁層級。如果您在一個分頁中開啟一份表單，在另一個分頁中開啟回覆清單，代理會把它們分開處理。這就是為什麼您可以問「幫這份表單加一個必填的 NPS 問題」或「這個有多少筆回覆」，而不需要指名表單。代理早就知道您指的是哪一份。當您在檢視一份表單的回覆時，代理也能看到這些回覆的預覽內容，範圍限於您有權檢視的部分。

## 依任務分類的實用提示

以下每個提示都會對您實際的表單執行一個真正的 action，就是 UI 讀寫的同一份表單。這裡有一個實際範例。

<Comparison>

### :blue: 您的提問

「建立一個包含角色、團隊規模和優先使用情境的 beta 註冊表單。」

### :green: 發生的事

這會建立一份全新的東西。代理會建置好一份已經包含這些欄位的表單，並立即出現在您的表單清單中，隨時可以微調或發布。不需要重新整理頁面，新表單就這樣直接出現在那裡。

</Comparison>

<Cards columns={2}>

### 建置

- **「建立一個包含角色、團隊規模和優先使用情境的 beta 註冊表單。」** 新表單會立即出現在您的表單清單中，隨時可以微調。
- **「新增一個必填的 NPS 問題，以及一個自由文字的後續問題。」** 欄位會立即顯示在表單上。
- **「在不遺漏路由所需欄位的情況下，把這份表單縮短。」** 代理會精簡表單，同時保留您的目的地所依賴的欄位。

### 發布並保護

- **「發布這份表單，並給我連結。」** 表單會立即上線，您也會馬上拿到它的公開網址。
- **「建立一個匿名的客戶意見回饋表單，並給我公開連結。」** 表單從一開始就以匿名方式發布，永遠不會擷取任何提交者資訊。
- **「只允許這份表單從 https://example.com 提交。」** 表單會開始拒絕來自其他任何地方的提交。目前這項功能只能透過請代理設定來使用，建置器中沒有對應的開關。

### 回覆與洞察

- 「beta 註冊表單有多少筆回覆？」
- 「今天有誰提交了？」
- 「總結這週的提交內容，並依客戶區隔分組。」
- 「按天繪製提交圖表。」
- 「這個月我所有表單的提交趨勢如何？」
- 「把這個匯出成 CSV。」

### 路由

- **「把每一筆新回覆都發布到產品 Slack 頻道。」** 一旦連接好目的地，新回覆一到就會立即出現在 Slack 中。
- 「我的 beta 註冊表單目前是什麼設定？」
