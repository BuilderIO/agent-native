# 開發者指南

本頁是為任何要自訂或擴充剪輯範本的人準備的：快速入門、每一個 action、資料模型、路由介面，以及如何新增內容。這個應用程式的作用請參閱 [剪輯](/docs/template-clips)。

## 快速入門

<Steps>

### 建立應用程式

```bash
npx @agent-native/core@latest create my-clips --standalone --template clips
cd my-clips
pnpm install
```

這需要先安裝 [Node.js](https://nodejs.org) 22.22 或更新版本，以及 [pnpm](https://pnpm.io)。如果您還沒有安裝其中任何一項，或還沒有設定 LLM 連線（Builder.io、Anthropic/OpenAI 金鑰，或本機 Ollama），請參閱 [開始使用](/docs/getting-started)。

### 啟動開發伺服器

```bash
pnpm dev
```

應用程式會自動在您的瀏覽器中開啟。錄製功能不需要任何額外設定就能運作，因為瀏覽器或桌面應用程式是以本機方式進行捕捉。您只會在需要檔案儲存或 AI 額度、但兩者都還沒設定的 action 上遇到錯誤。

</Steps>

<Callout tone="info">

錄製、轉錄，以及 AI 標題/摘要，都需要先設定好檔案儲存和 AI 額度，才能完整運作。可以從**設定**一次連接 Builder.io 來同時取得兩者（它的免費方案包含託管的 AI 額度），或分別連接 S3 相容儲存，並自備 Groq 金鑰用於轉錄。請參閱 [逐字稿和 AI 中繼資料](/docs/template-clips-features#transcription-and-ai-metadata)。

</Callout>

## Action 清單

每一項操作都是 `templates/clips/actions/` 中的一個 TypeScript 檔案，自動掛載在 `POST /_agent-native/actions/:name` 上。

### 媒體庫和錄音

| Action                                                                                    | 作用                                           |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `list-recordings`、`search-recordings`                                                    | 媒體庫、與我共用、垃圾桶，以及空間範圍內的清單 |
| `create-recording`、`finalize-recording`                                                  | 建立資料列；完成上傳                           |
| `import-loom-recording`                                                                   | 匯入 Loom 影片，或直接匯入 MP4/WebM 網址       |
| `update-recording`                                                                        | 標題、描述、密碼、到期日、可見性               |
| `move-recording`                                                                          | 把一段或多段錄音移到資料夾或根目錄             |
| `archive-recording`、`trash-recording`、`restore-recording`、`delete-recording-permanent` | 生命週期：隱藏、軟刪除、復原，或永久刪除       |
| `reprocess-recording`                                                                     | 修復無法拖曳或凍結的媒體                       |
| `generate-filmstrip`                                                                      | 編輯器時間軸的畫格縮圖條                       |
| `tag-recording`、`set-thumbnail`                                                          | 標籤，以及手動選擇的縮圖畫格                   |

### 資料夾和空間

| Action                                            | 作用                                 |
| ------------------------------------------------- | ------------------------------------ |
| `create-folder`、`rename-folder`、`delete-folder` | 巢狀資料夾；刪除一個會把內容往上移   |
| `create-space`、`rename-space`、`delete-space`    | 組織範圍、以主題為基礎的錄音容器     |
| `add-recording-to-space`                          | 把一段錄音加入或移出空間（多對多）   |
| `add-space-member`、`remove-space-member`         | 空間層級的檢視者、貢獻者和管理員角色 |

### 編輯

| Action                                   | 作用                                 |
| ---------------------------------------- | ------------------------------------ |
| `trim-recording`、`split-recording`      | 疊加一個剪切指令；永不動到原始媒體   |
| `remove-silences`、`remove-filler-words` | 由代理執行：讀取逐字稿，為您套用修剪 |
| `stitch-recordings`                      | 依序把多段錄音合併成一段             |
| `undo-edit`、`clear-edits`               | 移除最近一次編輯，或重設為原始狀態   |

### 逐字稿和 AI 中繼資料

| Action                                                                          | 作用                                         |
| ------------------------------------------------------------------------------- | -------------------------------------------- |
| `request-transcript`、`cleanup-transcript`                                      | 轉錄；使用 `force`/`regenerate` 重新進行一次 |
| `regenerate-title`、`regenerate-summary`、`regenerate-chapters`、`set-chapters` | AI 中繼資料，或手動設定章節                  |
| `get-builder-credit-status`                                                     | Builder.io 的 AI 額度是否已被暫停            |

### 留言和 reactions

| Action                                                                                   | 作用                         |
| ---------------------------------------------------------------------------------------- | ---------------------------- |
| `add-comment`、`update-comment`、`delete-comment`、`reply-to-comment`、`resolve-comment` | 對話串化、帶時間戳的留言     |
| `react-to-comment`、`react-to-recording`                                                 | 表情符號 reactions           |
| `list-comments`、`list-recording-mention-members`                                        | 讀取留言；查詢誰可以被 @提及 |

### 螢幕記憶（Rewind）

| Action                                                                                                                          | 作用                                       |
| ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `get-screen-memory-status`、`query-screen-memory-context`                                                                       | 讀取本機 Rewind 緩衝區                     |
| `request-rewind-extension`、`get-rewind-extension-request`、`list-rewind-extension-requests`、`update-rewind-extension-request` | 把 Rewind 歷史紀錄加進剪輯的審核與核准流程 |
| `apply-rewind-extension`、`make-recording-private-for-rewind`                                                                   | 套用已核准的延伸內容；先強制將剪輯設為私人 |

### 跨應用和洞察

| Action                                                                       | 作用                                                            |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `export-to-brain`                                                            | 把已就緒的逐字稿傳送到 Brain，支援回填和可續傳的游標            |
| `prepare-crm-call-evidence`                                                  | 給 CRM 自動化使用的不透明剪輯 id，加上一個持久的 `/r/<id>` 連結 |
| `create-recording-agent-link`                                                | 為一段錄音發行一個範圍受限、限時的 `agent_access` 連結          |
| `get-recording-insights`、`get-organization-insights`、`export-insights-csv` | 觀看次數、參與度，以及整個組織的 CSV 匯出                       |
| `list-viewers`、`list-clip-views`                                            | 誰看過，以及何時看的                                            |

### 組織

| Action                                                                                  | 作用                                          |
| --------------------------------------------------------------------------------------- | --------------------------------------------- |
| `create-organization`、`invite-member`、`accept-invite`、`decline-invite`、`get-invite` | 組織建立和邀請                                |
| `remove-member`、`update-member-role`                                                   | 管理成員資格和角色                            |
| `set-organization-branding`、`list-organization-state`                                  | 品牌顏色/標誌、預設可見性、整個組織範圍的讀取 |

### 導覽、嵌入和錯誤回報

| Action                                                                                | 作用                                                                |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `view-screen`、`navigate`、`refresh-list`                                             | 讀取脈絡；移動 UI                                                   |
| `get-playback-position`、`save-playback-position`、`get-recording-player-data`        | 恢復播放；完整逐字稿和診斷資訊                                      |
| `create-recording-intake-link`、`create-intake-recording`、`create-intake-agent-link` | 匿名的第三方嵌入流程。請參閱 [嵌入剪輯](/docs/template-clips-embed) |
| `save-bug-report-context`、`save-browser-diagnostics`、`save-browser-transcript`      | 嵌入式錯誤回報啟動器，以及 Chrome 擴充功能診斷資訊                  |

## 資料模型

定義於 `templates/clips/server/db/schema.ts`。

<Callout tone="warning">

團隊、成員和邀請資料列存放在框架自己的 `organizations`、`org_members` 和 `org_invitations` 表格中，不是剪輯專屬的表格。`organization_settings` 是剪輯自己的附屬表格：品牌顏色、標誌和預設可見性，每個組織一列。較舊的 `workspaces`/`workspace_members` 這一對表格之所以還存在，只是為了讓一次性的啟動遷移可以在既有部署上回填框架表格。請不要針對它們建構新功能。

</Callout>

## 逐步解析一個 action

`create-recording-agent-link` 展示了值得在任何發行範圍受限憑證的 action 中重複使用的模式：在交出任何東西之前先檢查資源的真實狀態，把實際的權杖發行工作委派給共用框架輔助函式，而不是自己重新發明一套，並從那一個授權中衍生出呼叫者需要的每一個網址。

<AnnotatedCode
  id="doc-block-clips-agent-link"
  title="發行一個範圍受限的 agent-access 連結"
  filename="templates/clips/actions/create-recording-agent-link.ts"
  language="ts"
  code={
    'import { defineAction } from "@agent-native/core/action";\nimport {\n  buildAgentAccessUrl,\n  createScopedAgentAccessGrant,\n  getRequestContext,\n  getRequestUserEmail,\n} from "@agent-native/core/server";\nimport { ForbiddenError, resolveAccess } from "@agent-native/core/sharing";\nimport { z } from "zod";\n\nimport {\n  CLIPS_AGENT_ACCESS_TTL_SECONDS,\n  getServerAppBasePath,\n} from "../server/lib/public-agent-context.js";\nimport {\n  buildAgentApiUrls,\n  CLIP_AGENT_ACCESS_TOKEN_PREFIX,\n} from "../shared/agent-context.js";\nimport { BUG_REPORT_AGENT_ACCESS_TTL_SECONDS } from "../shared/bug-report.js";\n\nfunction appOrigin(): string {\n  const origin =\n    getRequestContext()?.requestOrigin ||\n    process.env.APP_URL ||\n    process.env.BETTER_AUTH_URL ||\n    "http://localhost:3000";\n  try {\n    return new URL(origin).origin;\n  } catch {\n    return "http://localhost:3000";\n  }\n}\n\nexport default defineAction({\n  description:\n    "Create a temporary private agent-readable link for one Clips recording. The URL is scoped to that recording and expires after two hours.",\n  schema: z.object({\n    recordingId: z.string().describe("Recording ID"),\n    agentLabel: z\n      .string()\n      .trim()\n      .min(1)\n      .max(60)\n      .optional()\n      .describe(\n        "Name of the agent that will read this link (e.g. \'Fusion\', \'Claude Code\'). Recorded against every read the link produces, so the owner sees a name instead of an unidentified agent.",\n      ),\n    ttlSeconds: z\n      .number()\n      .int()\n      .positive()\n      .max(BUG_REPORT_AGENT_ACCESS_TTL_SECONDS)\n      .optional()\n      .describe(\n        "Optional scoped-link lifetime in seconds, capped at seven days. Defaults to two hours.",\n      ),\n  }),\n  readOnly: true,\n  run: async (args) => {\n    const access = await resolveAccess("recording", args.recordingId);\n    if (!access) {\n      throw new ForbiddenError(`No access to recording ${args.recordingId}`);\n    }\n\n    const recording = access.resource as {\n      id: string;\n      archivedAt?: string | null;\n      trashedAt?: string | null;\n    };\n    if (recording.archivedAt || recording.trashedAt) {\n      throw new ForbiddenError(\n        `Recording ${args.recordingId} is not shareable`,\n      );\n    }\n\n    const grant = createScopedAgentAccessGrant({\n      resourceKind: CLIP_AGENT_ACCESS_TOKEN_PREFIX,\n      resourceId: recording.id,\n      viewerEmail: getRequestUserEmail() || undefined,\n      agentLabel: args.agentLabel,\n      ttlSeconds: args.ttlSeconds ?? CLIPS_AGENT_ACCESS_TTL_SECONDS,\n    });\n    const origin = appOrigin();\n    const basePath = getServerAppBasePath();\n    const pageUrl = buildAgentAccessUrl({\n      path: `/share/${encodeURIComponent(recording.id)}`,\n      origin,\n      basePath,\n      token: grant.token,\n    });\n    const api = buildAgentApiUrls(recording.id, {\n      origin,\n      basePath,\n      token: grant.token,\n    });\n\n    return {\n      recordingId: recording.id,\n      url: pageUrl,\n      contextUrl: api.contextUrl,\n      expiresAt: grant.expiresAt,\n      ttlSeconds: grant.ttlSeconds,\n    };\n  },\n});\n'
  }

## 自訂它

應用程式的每一部分都是可編輯的原始碼。從這裡開始：

- `templates/clips/actions/` — 用 `defineAction` 新增一個檔案，把新能力同時公開給代理和前端。
- `templates/clips/app/routes/` — UI，如上所列。
- `templates/clips/server/db/schema.ts` — 用 Drizzle 新增欄位或表格。請保持架構與 PostgreSQL 相容，讓範本能同時在本機 PGlite 和託管的 Postgres 上執行。
- `templates/clips/server/lib/` — 提供者整合：`google-calendar-client.ts`、`s3-upload-provider.ts`、`slack-oauth.ts`、`video-remux.ts`、`video-filmstrip-sprite.ts`。
- `templates/clips/AGENTS.md` — 代理指示。當您教代理新的能力或慣例時，請更新這裡。
- `templates/clips/.agents/skills/` — 代理遵循的詳細模式。相關的 skills：`recording`、`ai-video-tools`、`video-editing`、`video-sharing`、`screen-memory`。
- `templates/clips/shared/api.ts` — 伺服器和用戶端共用的 TypeScript 型別。
- `templates/clips/desktop/` 和 `templates/clips/chrome-extension/` — 原生捕捉介面各自獨立的套件，各自擁有自己的 `package.json` 和建置流程。

如果您新增一項功能，請記得更新全部四個領域：UI、action、skill 或 AGENTS.md 項目，以及代理需要看到的任何 application state。這正是讓代理和 UI 保持一致的關鍵。
