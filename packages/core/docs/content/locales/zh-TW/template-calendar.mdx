# 行事曆

行事曆是一款由代理驅動的排程應用程式。連線您的 Google Calendar 後，代理就能讀取您的行程、尋找空閒時段、建立活動，並管理 Calendly 風格的預訂連結，只需用簡單的文字描述，或用滑鼠點一下即可完成。它用一個應用程式取代了 Google Calendar 加 Calendly 的組合，讓您的真實行程和公開預訂頁面不再是需要手動同步的兩件事。

## 它取代的內容

<Comparison>

### 之前

- Google Calendar 用於管理您的真實行程
- Calendly（或類似工具）用於公開預訂連結，需要手動保持同步
- 需要某人的電子郵件時，另外進行聯絡人搜尋
- 在每個邀請中複製貼上 Zoom 連結

### 之後

- 一個檢視畫面：您的真實行事曆與預訂連結整合在一起
- 一套可用性模型，供預訂連結和代理共同讀取
- 人員搜尋直接內建在排程提示中
- 有人預訂時自動附上 Zoom 或 Google Meet

</Comparison>

## 行事曆在多應用工作區中

如果您在[調度](/docs/template-dispatch)之下與其他應用程式一起執行行事曆，您的行事曆就不再只是一個您自己開啟的頁面。它會變成其他頻道和應用程式都能動作的對象：從新預訂觸發的自動化，到姊妹應用程式直接把排程請求交給行事曆處理。若想了解這種連接實際上如何運作，以及背後真正的機制，請參閱[行事曆的跨應用使用](/docs/template-calendar-integrations)。
