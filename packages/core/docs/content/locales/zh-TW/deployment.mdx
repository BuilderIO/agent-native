### [部署工作區](/docs/workspace-deployment)

## 部署前：選擇持久性資料庫 {#persistent-database}

每個已部署的應用程式都需要持久性 SQL 資料庫。在第一次正式環境部署前，請將 `DATABASE_URL` 設定在部署環境中。如果資料庫供應商需要獨立權杖，也請設定 `DATABASE_AUTH_TOKEN`。

獨立應用程式需要穩定的 `BETTER_AUTH_SECRET`。使用簽署跨應用程式要求的工作區需要 `A2A_SECRET`。

## 支援的部署目標

Agent-Native 支援 [Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb) 和 [Render](/docs/render)。

如需進階設定、密鑰和正式環境值，請參閱[部署環境變數參考](/docs/deployment-environment-variables)。
