# 剪輯

剪輯是一款由代理驅動的螢幕錄製應用程式。錄下您的螢幕，代理就會為它轉錄逐字稿、加上標題、寫出摘要，並將它索引到一個可搜尋的媒體庫中，讓您可以問「找到我們討論推出計畫的那段剪輯」，並搜尋您曾經錄製過的每一段影片。它用一個應用程式取代了 Loom，因此您錄製的每段影片都存放在一個您自己擁有、可搜尋的地方，而不是散落在一個各有自己逐字稿的獨立工具裡。

代理是每段錄音中一流的編輯者，您所捕捉的一切都歸您所有，而不是某個 SaaS 廠商的。剪輯還讓共用的錄音可以被任何代理讀取，不只是它自己的代理。把一段剪輯的分享連結貼到 Claude、ChatGPT 或其他助理裡，它就能讀取逐字稿並看到帶時間戳的螢幕畫格，不需要下載原始影片。這實際上如何運作，請參閱 [剪輯的跨應用使用](/docs/template-clips-integrations)。

## 它取代的內容

<Comparison>

### 之前

- 使用 Loom 進行螢幕錄製
- 另外使用一個工具，或手動處理逐字稿、標題和摘要
- 只是為了讓 AI 幫忙清理一下，就要重新錄製或重新上傳一段剪輯
- 外部代理沒有辦法真正理解一段錄音裡的內容

### 之後

- 一個錄製工具，任何您已經存在別處的內容都可以透過 Loom 匯入
- 代理會自動為每段錄音加上標題、摘要和章節
- 只需一句話就能修剪、移除填充詞，或合併多段剪輯
- 任何代理都能讀取的分享連結，不只是剪輯自己的

</Comparison>

## 剪輯在多應用工作區中

如果您在[調度](/docs/template-dispatch)之下與其他應用程式一起執行剪輯，一段錄音就不再只是您自己手動觀看的東西。其他應用程式可以把已就緒的逐字稿拉進 Brain，把可靠的通話證明連結交給 CRM 自動化，或是直接向剪輯的代理提出問題，就像您在聊天中一樣。這實際上如何運作，請參閱 [剪輯的跨應用使用](/docs/template-clips-integrations)。

## 您可以用它做什麼

- **錄製您的螢幕，或從 Loom 匯入。** 試著說「錄下我的螢幕」，或貼上一個公開的 Loom 連結，把它帶進您的媒體庫。請參閱 [建立一段剪輯](/docs/template-clips-features#create-a-clip)。
- **透過聊天進行非破壞性編輯。** 試著說「移除裡面的嗯和啊」或「修剪掉前 10 秒」。請參閱 [非破壞性編輯](/docs/template-clips-features#non-destructive-editing)。
- **分享並保護您錄製的內容。** 設定可見性、密碼或到期日，並讓任何代理讀取共用剪輯的逐字稿。請參閱 [分享](/docs/template-clips-features#share)。
