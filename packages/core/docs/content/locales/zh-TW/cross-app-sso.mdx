# 跨應用程式 SSO

瀏覽器中的「Sign in with Agent-Native」選項和自動瀏覽器跳轉已移除。對於
Web 使用者，每個應用程式獨立登入仍是預設方式。本頁只介紹剩餘的明確
Desktop 流程和伺服器端聯邦協定。

## 保留的功能

### Desktop 工作區

工作區登入是 Desktop 設定中的明確操作。啟用後，Desktop 可以透過專用
broker 為符合條件且已註冊的應用程式設定登入。每個目標應用程式仍然擁有
自己的使用者儲存、工作階段和存取檢查。Desktop 不會攔截瀏覽器前往應用
程式登入頁面的匿名導覽。

應用程式必須同時符合以下條件：

- Desktop 為該應用程式啟用工作區 SSO。
- 生產 URL 是精確的 HTTPS 位址。
- Dispatch 為該應用程式保存了精確的伺服器端註冊。
- <code>desktop.workspace-sso</code> 發布旗標已啟用。

裝置層級偏好設定 <code>desktopSsoEnabled</code> 預設啟用。明確設定為
false 仍然表示退出。如果旗標、偏好設定、註冊或資格檢查不可用，普通的
應用程式登入仍可使用。

### 伺服器端聯邦

剩餘的 broker 和伺服器端呼叫方使用短時、由伺服器驗證的協定。它不會
作為瀏覽器登入控制項提供：

1. 呼叫方要求一個精確的已註冊應用程式繫結。
2. Dispatch 驗證工作區身分並返回短時的一次性授權碼。
3. 目標應用程式伺服器使用 PKCE 驗證器兌換程式碼。
4. 目標應用程式驗證簽署斷言、精確應用程式繫結、回呼、範圍、nonce 和過期時間。
5. 目標應用程式按已驗證電子郵件連結或建立本機使用者，並簽發自己的普通工作階段。

斷言只透過伺服器對伺服器交換返回。它不會出現在瀏覽器 URL 中，也不是
可重複使用的 bearer token。

## 組織聯邦

<code>organization.cross-app-federation</code> 旗標預設關閉。啟用後，來源
應用程式向 Dispatch 註冊本機組織，並儲存精確的
<code>(identity_authority, identity_id)</code> 對應。目標應用程式只接受
來自伺服器驗證斷言的規範組織 ID、名稱和已驗證成員角色。

組織名稱、電子郵件網域和瀏覽器 Cookie 不是連結鍵。沒有對應的本機組織在
明確遷移前保持不變。已連結的成員關係仍使用目標應用程式的普通存取檢查。

組織聯邦為每個已註冊來源應用程式使用獨立認證：

- 在來源應用程式設定 <code>AGENT_NATIVE_IDENTITY_FEDERATION_SECRET</code>。
- 在 Dispatch 設定相符的
  `AGENT_NATIVE_IDENTITY_FEDERATION_SECRET_<NORMALIZED_APP_ID>`。
- 不要為此權限邊界重複使用 <code>A2A_SECRET</code>。

應用程式 ID 後綴會將每段非英數字元替換為底線，並將結果轉換為大寫。
例如，應用程式 ID <code>workspace-reports</code> 使用

<code>AGENT_NATIVE_IDENTITY_FEDERATION_SECRET_WORKSPACE_REPORTS</code>。

身分和組織寫入只會新增資料。相同電子郵件的現有使用者會原樣重用。新的
已驗證電子郵件會建立本機使用者。停用聯邦不會刪除資料。

## 設定

<code>AGENT_NATIVE_IDENTITY_HUB_URL</code> 僅用於剩餘的伺服器端和 Desktop
路徑。自我託管應用程式需要指定 Dispatch 部署時才設定它。它不會新增
瀏覽器登入選項或自動瀏覽器跳轉。

對於自我託管的 Dispatch，請透過

<code>IDENTITY_SSO_APP_REGISTRY_JSON</code> 為每個自訂應用程式註冊精確的
應用程式 ID、用戶端 ID、HTTPS 來源、回呼路徑和 <code>identity-sso</code> 能力。

生產註冊必須使用 HTTPS 和精確的回呼路徑。Localhost 只允許用於本機開發。
未知子網域、不相符的應用程式 ID、任意路徑和跨來源回呼都會被拒絕。

## 驗證和回滾

部署後：

1. 驗證瀏覽器中的電子郵件、密碼、魔法連結和已設定的提供者登入仍然有效。
2. 驗證瀏覽器驗證頁面不提供 Agent-Native 登入選項。
3. 如果啟用了 Desktop SSO，從 Desktop 設定中的明確操作驗證一個精確註冊的應用程式。
4. 如果啟用了組織聯邦，驗證目標應用程式中的精確組織 ID 和成員角色。

要回滾剩餘路徑，請關閉相應功能旗標，並從自我託管部署移除

<code>AGENT_NATIVE_IDENTITY_HUB_URL</code>，然後重新部署。已新增的身分和
組織記錄會保留，可繼續用於普通本機驗證。
