# 與 Agent 對話

Design 中的每一項功能，代理都能透過 UI 所使用的相同 actions 取得，所以只要
是您能點選的操作，也都可以直接用簡單的文字提出請求。本頁涵蓋代理如何看
到您的畫面，然後依任務分類的實用提示。總覽請參閱[Design](/docs/template-design)。

## 代理如何看到您的畫面

在做任何事情之前，代理會先檢查您正在看的東西：目前開啟的是哪個設計或範
本、您在哪個檢視畫面（設計清單、範本、編輯器、設計系統，或一個公開的呈
現檢視）、您選取了哪個畫面和元素、哪個檢查器分頁是啟用中的（Design、留
言，或程式碼與測量），以及哪個左側邊列面板是開啟的（檔案、代理、資產、
匯入、工具，或代幣）。這就是為什麼「讓這個更密集一點」或「修一下這個按
鈕的對比度」不需要您說出畫面或元素的名稱，就能正確解析。代理早就知道
「這個」指的是什麼。

有幾種情況會改變代理接下來做的事：

- **一個模糊的提示。** 如果您的請求沒有給代理足夠的資訊，它會顯示一個
  全畫布的釐清問題覆蓋層，而不是用猜的，並在聊天中等待您的回答之後才開
  始產生任何東西。
- **一個從範本製作的設計。** 代理已經知道範本鎖定的尺寸和字型，會就地
  完善現有畫面，而不是重新產生或調整它們的大小。
- **一個您正在比較的變體。** 如果您正在幾個提出的微調之間做選擇，代理
  知道哪些還沒決定、哪些您已經選過了，所以「用第二個」能夠正確解析。
- **未解決的審閱留言。** 代理知道目前畫面上有多少則未解決的留言，以及
  哪些已經在它待處理的佇列中，所以它不會漏掉您留下的意見。

## 依任務分類的實用提示

以下每個提示都會對您真實的設計執行一個真正的 action，就是 UI 讀寫的同
一個設計。這裡有一個實際範例：

<Comparison>

### :blue: 您的提問

「這個畫面上有未解決的留言嗎？」

### :green: 發生的事

這是一個唯讀問題。代理會檢查這個畫面真實的留言討論串數量，然後直接在
聊天中回答，例如「有 2 則未解決的留言，其中 1 則已經在我的待處理佇列
中。」畫面上什麼都不會改變，因為沒有建立或編輯任何東西。

</Comparison>

### 產生和完善

- **「為一個技術性分析產品建立三個不同的到達頁面方向。」** 會出現幾個
  真正不同的變體，供您比較和挑選。
- **「讓這個儀表板更密集，更方便維運團隊瀏覽。」** 選取的畫面會即時更
  新。
- **「把這張重複的卡片變成一個可重複使用的元件。」** 之後對某一個實例
  的編輯，會與其他實例保持獨立，除非您要求全部一起更新。
- **「幫這個按鈕加上一個懸停動畫。」** 會建立一個動效軌道，不需要您自
  己開啟動效面板。
- **「幫主視覺背景加上一個波浪著色器。」** 會直接套用這個效果，不需要
  透過效果選單的選取器。

### 檢查品質

- **「對這個畫面執行一次無障礙稽核。」** 代理會檢查它，並回報發現的問
  題。
- **「修好你剛才發現的對比度問題。」** 這個修正會直接套用到設計上。

### 帶入外部內容

- **「匯入這個 Figma 畫框：[連結]。」** 這個畫框會以一個新的、可編輯的
  畫面出現。
- **「把這段 HTML 貼進來當作一個新畫面。」** 不需要您自己開啟匯入面
  板就能新增它。
- **「從 Figma 帶入我們的定價頁面，並精準比對它。」** 像素級精準的匯
  入，並附上一份保真度報告，說明哪些內容在結構上無法帶過來。

### 品牌和設計系統

- **「套用我們儲存的設計系統，並簡化行動版面配置。」** 這之後的每一次
  產生都會維持在品牌之內。
- **「從我們的 GitHub 存放庫開始一個設計系統。」** 會為您真實、已部署
  的代幣建立索引，而不是用猜的。
- **「根據 Material 3 建立一個設計系統。」** 從一個真正、有人維護的公
  開系統開始，而不是一個仿製品。

### 範本

- **「用到達頁面範本開始一個新設計。」** 會把它的檔案、尺寸和鎖定圖層
  複製到一個新設計中。
- **「把這個儲存為一個叫做『產品發布』的範本。」** 下次您或您分享的任
  何人都能在範本頁面找到它。

### 導覽和整理

- **「切換到總覽畫布。」** 跳出單一畫面檢視。
- **「開啟留言分頁。」** 讓檢查器聚焦在那個分頁上。
- **「把這個設計重新命名為『第三季發布頁面』。」** 立即更新，無論這個
  設計列在哪裡都會反映出來。

### 匯出和歷史

- **「把這個匯出成 ZIP。」** 不需要您自己開啟專案選單就能下載。
- **「幫這個畫面複製一段編碼交接提示。」** 已經準備好可以貼到外部編碼
  代理中。
- **「還原成一小時前的版本。」** 把設計帶回那個確切的已儲存狀態。

</Cards>

## 擴充功能

Design 支援擴充功能：一種您或代理可以建立、並放進編輯器裡的小型沙盒化小工
具。檢查器的左側邊列公開了一個擴充功能可以渲染的插槽，開啟中設計的 id
和標題、作用中畫面的檔名和內容、目前的檢視模式和縮放比例、選取的畫面和
元素，以及作用中的工具，都已經提供給它使用。您今天在編輯器中看到的資產
庫、著色器填色選取器、品牌代幣稽核工具，以及動效預設集，全都是建立在這
同一個插槽上。如何建立擴充功能，請參閱[擴充功能](/docs/extensions)。
