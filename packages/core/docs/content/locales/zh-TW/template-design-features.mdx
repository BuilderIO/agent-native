# 功能

Design 的每一項核心功能：運作方式，以及如何設定。總覽請參閱
[Design](/docs/template-design)，完整的提示清單請參閱[與 Agent
對話](/docs/template-design-agent)。功能依應用程式中真實的畫面分組：
**設計清單**、**編輯設計**、**範本**，以及**設計系統**。

## 設計清單 {#designs}

`/home` 清單頁面。您可以存取的每一個設計都在這裡，這裡也是您開始建立新
設計的地方。

### 檢視設計清單 {#view-designs}

設計以卡片網格的形式顯示：一張即時縮圖、標題，以及最後更新日期。切換到
**全部**篩選條件（而不是**我的**）也會顯示每個設計的擁有者。

- **搜尋**會隨著您輸入，依標題篩選網格。
- 網格每頁顯示 11 個設計，「新增設計」磚永遠排在第一個。
- 選取一個或多個卡片（滑鼠移過去會顯示核取方塊）會顯示一個批次工具列：
  選取/清除所有可見項目、加入創意情境，或刪除選取的項目。
- 空帳號會顯示四個可點選的起始提示，而不是空白的網格（一個 SaaS 頁面、一
  個儀表板、一個行動應用程式、一個定價頁面）。

### 建立一個設計 {#create-a-design}

「新增設計」的兩個入口，也就是標題列按鈕和網格中的虛線磚，都會開啟同一
個彈出視窗。您可以輸入一個提示，並在編輯器開啟之前，先選擇一個起始範
本、一個設計系統，以及一個創意情境。點選**略過**則可以取得一個空白設計
（或所選範本未套用提示的副本），完全不會有任何 AI 產生內容。

送出後會直接進入新設計的編輯器，並顯示「正在開啟設計」的覆蓋層，任何產
生工作都會在背景繼續完成。

### 管理一個設計 {#manage-a-design}

設計卡片上的「⋯」選單有四個項目：

- **重新命名**：一個帶有文字欄位的小型對話方塊。
- **複製**：立即建立一個副本並開啟它，不需要確認。
- **加入情境**：把設計加到一個創意情境。
- **刪除**：會先要求確認。

## 編輯設計 {#edit-a-design}

以下內容都是您點進一個設計之後適用的功能。

### 檔案設定 {#file-settings}

畫面和圖層存在同一棵合併的樹狀結構中，而不是兩個獨立的面板。設計中的每
個畫面（各自是一個 HTML 檔案）都是一個頂層項目，該畫面的圖層則嵌套在下
方。

- **新增、重新命名、複製、刪除和重新排序**，對畫面和圖層的運作方式都相
  同。
- **鎖定**一個圖層讓它保持固定。這與範本和範本副本所保留的「鎖定圖層」
  概念是同一個。
- **顯示或隱藏**任何圖層，而不用刪除它。

### 代理 {#agent-in-editor}

每個 Agent-Native 應用程式都有的那個相同的代理聊天，在編輯器裡也一樣存
在，並不是一個 Design 專屬的聊天介面。您可以請它產生一個畫面、比較不同變
體、微調細節，或檢查品質和無障礙，就像要求其他任何變更一樣。它也會在把
一個設計標記為完成之前，自動執行品質和無障礙檢查，不需要您採取任何動
作。依任務分類的提示請參閱[與 Agent 對話](/docs/template-design-agent)。

#### 模式

工具旁邊還有一個獨立的三段式切換器：

- **編輯**：一般模式。移動、畫框、圖形、筆和文字在這個模式下都能使用。
- **標註**：繪圖和釘選留言需要啟用的模式。
- **互動**：畫布的一個獨立模式，與編輯和標註分開。

### Design 分頁 {#design-tab}

目前選取項目的主要屬性面板。各個區塊只會在適用於目前選取項目時才顯示：

- **填色**和**筆畫**：顏色、漸層或圖片填色，並附上一份文件色票以重複使
  用既有的顏色。
- **效果**：陰影、圖層模糊、背景模糊，以及一個由程式碼驅動的著色器效
  果，附有具名滑桿（速度、顏色、中心點）和一個顯示原始 GLSL 的程式碼面
  板。
- **位置與版面**、**版式**、**外觀**（圓角、混合模式、可見性）：標準的
  單一元素屬性群組。
- **版面配置**和**自動版面配置**：一個畫框子項目的彈性排列方式。
- **版面格線**：一個畫框的版面配置指引覆蓋層。
- **元件**：一旦一個元素是一個元件實例，這個區塊會顯示它的變體和屬性。
  變更一個屬性會立即在該實例上預覽並套用。沒有一個獨立儲存的元件定義，
  每個實例都是標記的獨立副本，因此「前往主元件」會跳回最早的實例，作為
  一個參考點，而不是一個標準範本。

### 留言分頁 {#comments-tab}

一個位於 Design 分頁旁邊的真正分頁，附有一個未讀數量徽章。任何有存取權的人
都可以把一則留言釘選到一個特定元素上，而不是留下一則籠統的備註。一則留
言可以維持一則單純的備註，也可以直接送給代理處理。當代理處理一則留言
時，它會編輯該留言指向的確切部分，確認變更確實生效，然後要不解決該討論
串並附上一句說明變更內容的備註，要不在這不是代理應該自行決定的事情時，
回覆詢問對方要如何決定。

### 程式碼與測量分頁 {#code-tab}

顯示目前選取項目的：精確的像素位置和尺寸、計算後的樣式（顯示方式、定
位、字型、顏色），以及底層 HTML，並附有一個一鍵**複製**按鈕。這是一個
唯讀的檢查工具，不是一個編輯器。

### 設計預覽 {#design-preview}

標題列上的播放按鈕選單。**設計預覽**會在一個新的瀏覽器分頁中開啟目前畫
面真正渲染後的 HTML，效果和它在編輯器外面顯示的完全一樣。在畫面還沒有
內容之前，這個功能會是停用的。

### 版本歷史 {#version-history}

在同一個左側邊列選單中，**版本歷史**會開啟一個面板，列出設計的已儲存快
照，並附上相對時間戳記（「剛剛」、「5 分鐘前」等等）。選取其中一個會顯
示該版本畫面的預覽，**還原這個版本**會把設計帶回那個確切的狀態。

## 範本 {#templates}

兩種比空白畫布更快開始的方式。

### 檢視範本 {#view-templates}

範本頁面有兩個區塊，**您的範本**和**內建範本**，加上一個依標題、說明和
分類篩選的搜尋框。每張範本卡片會顯示一個即時預覽、它的分類（廣告、單頁
文件、到達頁面、社群、簡報，或其他）、它的尺寸，以及有多少圖層被鎖定。
您自己的範本（不包括內建範本）會有一個「⋯」選單，提供**共用**（檢視
者、編輯者，或管理員存取權）和**刪除**。

### 使用一個範本 {#use-a-template}

點選**使用範本**會開啟一個小型對話方塊：一個選填的提示、一個要套用的
設計系統（或建立一個的連結），以及一個**直接使用**按鈕，可以略過提示直
接取得一個副本。無論哪種方式，都會建立一個新的設計，並直接進入它的編輯
器。

### 儲存為範本 {#save-as-template}

這個功能不在範本頁面上。編輯設計時，開啟匯出和版本歷史所使用的同一個左
側邊列選單，選擇**儲存為範本**。它的尺寸、檔案和鎖定的圖層，會以內建範
本相同的方式保留下來。

<Callout tone="info">

目前只有內嵌的 Design 專案才能儲存為範本。由 `/visual-edit` 或完整應用程式
建置支援的設計無法儲存為範本。

</Callout>

### 開啟一個設計 {#open-a-design}

沒有獨立的「開啟」步驟。使用一個範本，就像根據提示產生一個新設計一樣，
最後永遠會直接開啟該設計的編輯器。

## 設計系統 {#design-systems}

一個設計系統就是 Design 套用到每個連結原型上的品牌識別：顏色、字型、間距和
標誌。

### 檢視和共用設計系統 {#view-and-share}

設計系統頁面是一個網格：第一個是「新增設計系統」卡片，然後每個系統各有
一張卡片，附上色票預覽、您預設系統上的**預設**徽章，以及可見度徽章（私
人、組織，或公開）。每張卡片都有一個真正的**共用**按鈕，提供檢視者、編
輯者，或管理員角色，和範本所使用的共用模型相同。標題列上的**選取**切換
開關可以啟用多選並批次刪除。

### 新增設計系統 {#new-design-system}

建立一個設計系統一開始要選擇一個來源：

- **Figma**：上傳一個 `.fig` 檔案。
- **公司/品牌**：一個網站網址。
- **程式碼**：一個已連結的 GitHub 存放庫。
- **Design.md**：一份書面的設計指引文件。
- **設計檔案**：直接上傳檔案。
- **匯入既有內容**：重複使用一個您已經擁有的設計系統或專案。
- **備註**：從頭描述您的品牌，或從一個真正、有人維護的公開系統開始，
  例如 Material 3、Carbon 或 Primer，而不是憑記憶重新製作一個。

<Callout tone="info">

每個公開系統都附有真正的語意代幣、一套字級規模、間距，以及出處說明。Design
不會讓一個提示悄悄把一個公開系統變成外觀相似、但底層資料不同的仿製
品。每個設計系統也都附有一組選填的自訂指示，以及一段對圖像風格的描述，
讓產生的攝影和插畫，始終保持和品牌其餘部分一致的視覺語言。

</Callout>
