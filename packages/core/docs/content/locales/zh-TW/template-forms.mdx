# 表單

表單是一款表單建置器，適合任何需要在不寫程式的情況下收集資訊的人使用。可以用於註冊、意見回饋、報名或問卷調查。向代理描述您想要的表單，當您需要更直接的控制時，再以視覺化方式進行微調，然後發布一個任何人都能填寫的連結。

## 它取代的內容

<Comparison>

### 之前

- Typeform、Google Forms，或自己手動打造用來收集回覆的表單
- 手動把新提交的內容複製到 Slack 或試算表中
- 需要另一個工具才能總結收到的回覆
- 設定 Zapier 自動化，才能把回覆送進 Sheets 或 webhook

### 之後

- 一份表單，代理和視覺化編輯器都會更新它
- 新回覆一到，就會立即傳送到 Slack、Discord、Sheets 或 webhook
- 只要開口要求摘要，就能得到圖表、表格，或兩者兼具，不需要另一個工具
- 條件欄位、垃圾提交防護和匿名模式全都內建在同一個建置器中

</Comparison>

## 表單在多應用工作區中

如果您在[調度](/docs/template-dispatch)之下與其他應用程式一起執行表單，一份表單就不再只是您自己手動開啟的頁面。表單代理可以把屬於其他應用程式的問題轉交出去，其他應用程式也能直接把回覆送進您的表單，就像框架自帶的回饋按鈕一樣。若想了解實際運作方式，請參閱[表單的跨應用使用](/docs/template-forms-integrations)。

## 您可以用它做什麼

- **以對話方式建置表單。** 試試看像是「建立一個聯絡表單」、「新增一個 NPS 分數問題」或「把電子郵件欄位設為必填」這類提示。請參閱[可用的欄位類型](/docs/template-forms-features#field-types)。
- **視覺化微調。** 當您需要更直接的控制時，可以直接在表單建置器中編輯標籤、預留位置、必填欄位、選項和欄位順序。
- **發布並保護一份公開表單。** 分享一個公開連結，並在需要時開啟垃圾提交防護或完全匿名回覆。請參閱[功能](/docs/template-forms-features)。
- **檢視回覆並要求洞察。** 試試看像是「總結這週的提交內容」或「按天繪製提交圖表」這類提示。請參閱[功能](/docs/template-forms-features#response-insights)。
- **自動路由提交內容。** 貼上 Slack、Discord、Google Sheets 或一般 webhook 網址，新回覆一到就會立即傳送過去。
