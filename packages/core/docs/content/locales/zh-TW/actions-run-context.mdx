# 執行情境

`run` 會收到一個選用的第二個引數 `ctx`，其中帶有已解析的請求身分，以及呼叫此 action 的介面。請直接讀取它，而不要手動呼叫 `getRequestUserEmail()` / `getRequestOrgId()`，並將整個 `ctx` 傳給追蹤功能：

```ts
export default defineAction({
  description: "Log an audit entry for the current request.",
  schema: z.object({ event: z.string() }),
  run: async (args, ctx) => {
    // ctx is undefined-safe: a 1-arg `run(args)` is still valid.
    const actor = ctx?.userEmail ?? "system";
    if (ctx?.caller === "frontend") {
      // tighter rules for browser-initiated calls, looser for "tool"/"cli"
    }
    await db.insert(audit).values({
      actor,
      orgId: ctx?.orgId ?? null,
      source: ctx?.caller ?? "unknown",
      event: args.event,
    });
    return { ok: true };
  },
});
```

大多數 action 就只會讀取 `ctx?.userEmail` 和 `ctx?.orgId`，也就是幾乎每個實際的 action 都會用到的[存取控制範圍限定](/docs/actions-access-control#access-control)。本頁其餘部分則涵蓋追蹤與自動化歸因等跨領域關注點，這些是較少 action 需要用到的。

## `ctx` 引數 {#ctx}

### `caller` 聯合型別 {#caller}

`caller` 是聯合型別 `"tool" | "http" | "frontend" | "cli" | "mcp" | "a2a" | "automation"`：

| `caller`       | 設定時機…                                                                                                                                            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `"tool"`       | 應用程式內的代理迴圈、子代理或代理團隊，或是驅動同一個代理迴圈的自然語言跨應用程式 A2A 委派，其工具呼叫都會是 `"tool"`。                             |
| `"frontend"`   | 透過 `useActionMutation()`、`useActionQuery()` 或 `callAction()` 發出的瀏覽器呼叫（標記有 `X-Agent-Native-Frontend: 1` 標頭）。                      |
| `"http"`       | 對 `/_agent-native/actions/<name>` 發出、不帶前端標記的單純程式化 `POST` 或 `GET`。                                                                  |
| `"cli"`        | `pnpm action <name>`（CLI 執行器）。                                                                                                                 |
| `"mcp"`        | 透過 MCP `tools/call` 端點呼叫的外部代理。                                                                                                           |
| `"a2a"`        | 對 `/_agent-native/actions/<name>` 發出、帶有已簽署 A2A 委派權杖的直接 HTTP 呼叫。這是明確曝露的跨應用程式分派，與上方的自然語言 `"tool"` 路徑不同。 |
| `"automation"` | 從儲存的工作區觸發器分派的事件觸發自動化。`ctx.automation` 帶有觸發脈絡。請參閱[自動化](/docs/automations)。                                         |
