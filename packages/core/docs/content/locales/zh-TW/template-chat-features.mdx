# 功能

聊天內含的每一項功能：運作方式，以及如何設定。總覽請參閱
[聊天](/docs/template-chat)，可以嘗試的提示請參閱
[與 Agent 對話](/docs/template-chat-agent)。

## 對話

聊天會開啟到一個訊息框，上方的標題是「How can I help?」。輸入一則訊息，代理
就會在同一個畫面上回答。在您送出第一則訊息之前，訊息框會維持置中，之後隨著
對話增長，它會移到底部。

側邊欄把您的對話分成兩組。**已置頂** 的聊天會留在頂端，**最近** 則顯示其
餘所有聊天，最新的在前。仍在運作中的聊天，標題旁會顯示一個旋轉圖示，讓您可以
開始另一場對話，同時不會漏掉第一場。

- **開始新的聊天**：使用側邊欄頂端的 **新建聊天**。
- **重新開啟**任何聊天：在清單中選取它。
- **重新命名、釘選或封存**聊天：從該列的選項選單操作。封存會把它從清單中
  移除。
- **收合側邊欄**：當您想要為對話留出更多空間時使用。

<Steps>

### 重新命名聊天

開啟該聊天所在列的選項選單，然後選擇 **Rename Chat**。輸入新的標題並按下
Enter。標題最多可以有 160 個字元。

### 釘選您經常回來查看的聊天

從同一個選單選擇 **置頂聊天**。該聊天會移到 **已置頂**，直到您選擇
**Unpin Chat** 為止。

### 封存您已經處理完的聊天

選擇 **封存聊天**。如果封存失敗，會出現一則訊息，且聊天會留在原處。

</Steps>

## 連線模型

代理需要一個模型才能回答。在連線模型之前，訊息框會顯示「Connect AI to start
chatting...」。選擇 **使用 Builder.io** 可取得免費額度，或選擇 **加入您自己的金鑰** 以使用您自己的提供者金鑰。之後代理就能立即回答。

若要在之後變更模型，請開啟 **Settings** 並選擇 **Model**。該頁面會設定預設
模型，以及應用程式可以使用的提供者。

<Callout tone="info">

聊天不會替您挑選模型。您可以從哪些模型中選擇，取決於您所連線的提供者。

</Callout>

## 語音輸入

訊息框包含一個麥克風按鈕。選取它即可用口述取代打字來輸入訊息，然後像任何其他
訊息一樣送出。語言和聽寫選項位於 **Settings → Preferences**。

## 範例 action

聊天內含一個名為 **hello** 的範例 action。action 是應用程式可以做的單一一件
事，例如問候某人、建立一則筆記，或查詢一筆記錄。每個 action 都有一個名稱、
一段說明它做什麼的描述，以及執行時所需的細節。代理會閱讀這些描述，以決定針對
您的請求要使用哪個 action。

請代理問候某個人，例如「Call the hello action for Alex」，它就會用那個名字
執行 hello 並顯示結果。它的存在是為了讓您在撰寫自己的 action 之前，先完整看過
一次整個流程，從您的訊息，到代理執行 action 並顯示回傳的內容。

action 是 Agent-Native 應用程式的共用介面。代理會使用它們，應用程式自己的畫面
也可以，所以新的 action 不需要任何額外設定，就能在兩個地方運作。開發者會隨著
應用程式的成長新增自己的 action。它們的運作方式請參閱
[Actions](/docs/actions-overview)，撰寫一個請參閱
[定義 Actions](/docs/actions-defining)。

## 在 Settings 中調整代理

開啟 **Settings**，並查看 **Agent** 群組。這些頁面控制代理在每一場聊天中的
行為。

| 頁面       | 它控制什麼                                     |
| ---------- | ---------------------------------------------- |
| **Model**  | 預設模型和提供者金鑰。                         |
| **指示**   | 代理在每一場聊天中都會遵循的常設指引。         |
| **個人化** | 您自己的自訂指令和記憶偏好設定。               |
| **Memory** | 代理已學到並會在各場聊天之間記住的內容。       |
| **技能**   | 代理可以針對某類任務載入的可重複使用操作指南。 |
| **Files**  | 代理可以讀取的參考檔案。                       |
| **子代理** | 主代理可以把工作交付給它們的輔助代理。         |

**Connections** 群組包含 **Integrations** 和 **API 金鑰**，**Account** 群組則
包含 **個人檔案**、**Preferences** 和 **安全性**。

<Steps>

### 開啟 Settings

選取側邊欄底部的搜尋按鈕，然後選擇 **Settings**。

### 選擇一個頁面

從左側的清單中選擇一個頁面。變更會套用到您的下一則訊息。

</Steps>

## 登入與團隊

聊天需要登入。登入、註冊和工作階段從第一次執行起就已設定好，而登入方式、
成員和角色，則在 Settings 的 **Organization** 群組下管理。

側邊欄底部的組織切換器會顯示您目前在哪個組織中工作，並讓您切換。每個工作區
請維持單一組織，並把其他人以成員的身分加入其中。您所連線的憑證是依組織儲存
的，因此第二個組織看不到在第一個組織下連線的金鑰。

## Database 與可觀測性

聊天內含兩個管理頁面。它們沒有從側邊欄連結，所以請以網址開啟。

- `/database` 的 **Database** 會顯示應用程式的資料表，讓您瀏覽代理和應用程式
  已儲存的資料列。
- `/observability` 的 **可觀測性** 會顯示代理一直在做什麼，並附有總覽、
  對話、評估、實驗和回饋的分頁。

兩者都是給執行應用程式的人使用的。不論您是否曾經開啟它們，它們都已掛載。

## 小工具

聊天可以執行**擴充功能**，也就是計算機或檢查清單這類小型沙盒化工具。聊天預設將它們關閉。
Settings 中沒有 Extensions 頁面，代理也無法建立它們。開發者需要在兩個地方將它們開啟。它們是什麼，
以及如何啟用，請參閱 [擴充功能](/docs/extensions)。
