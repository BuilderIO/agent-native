# 功能

剪輯的每一項核心功能：運作方式，以及如何設定。總覽請參閱
[剪輯](/docs/template-clips)，完整的提示清單請參閱
[與 Agent 對話](/docs/template-clips-agent)。

## 媒體庫

### 檢視剪輯 {#library-view-clips}

您的媒體庫會先顯示資料夾，再顯示錄音，以縮圖網格呈現，讓您一眼就能看到時長、標題、擁有者、觀看次數和可見性。您可以依最新、最舊或標題排序，依標籤篩選，或搜尋您做過的每一份逐字稿，找到您討論過某件事的那段剪輯，而不只是您記得標題的那段錄音。

### 建立一段剪輯 {#create-a-clip}

有三種方式可以把剪輯加進您的媒體庫，都在**錄製**按鈕和旁邊的**匯入**選單裡。在媒體庫的空白處按右鍵，也會提供相同的三種方式，再加上**新資料夾**。

- **錄製。** 剪輯內建的螢幕錄影機，支援網路攝影機疊加、音訊擷取，以及暫停/修剪控制項。
- **上傳影片檔案。** 直接從您的電腦新增現有的影片，或把它拖放到媒體庫或空間的網格上，不需要錄製。
- **匯入 Loom。** 匯入一段公開的 Loom 影片，不需要重新錄製。在**錄製**旁邊開啟**匯入**，選擇**匯入 Loom**，然後貼上 Loom 的分享或嵌入網址。剪輯會在您的媒體庫中儲存一份副本，並在 Loom 提供公開逐字稿時將它匯入。

### 管理一段剪輯

每段剪輯的三點選單，無論是在媒體庫中還是直接在卡片上按右鍵開啟，都有相同的四個操作：**分享**、**移到資料夾**、**封存**和**移到垃圾桶**。

#### 分享 {#share}

以逐段剪輯的權限分享一段剪輯：公開、團隊/組織，或私人。連結追蹤和對話串留言也能正常運作。您可以在分享對話框中為任何剪輯新增密碼或到期日。這兩者都只會讓存取變得更嚴格。它們都無法授予其上層分享規則本來會拒絕的存取權。

組織管理員可以設定當沒有人明確選擇時，新錄音預設會得到的可見性，詳見下方的 [組織和團隊](#organizations-and-teams)。除非管理員變更設定，否則錄音預設為公開，而明確選擇的可見性永遠會勝過預設值。

為一段剪輯建立嵌入網址，把它放進 wiki 頁面、內部工具，或任何接受 `<iframe>` 的地方：

| 參數              | 意義                                               |
| ----------------- | -------------------------------------------------- |
| `?t=80`           | 從第 80 秒開始播放                                 |
| `?autoplay=1`     | 自動播放（靜音，因為瀏覽器會封鎖未靜音的自動播放） |
| `?hideControls=1` | 隱藏播放器的介面外框                               |
| `?loop=1`         | 循環播放                                           |

一旦您的工作區安裝了剪輯的 Slack 應用程式，公開分享連結也會預覽成一段可播放的 Loom 風格影片。只有已就緒、公開、沒有密碼、沒有到期，也沒有封存/垃圾桶標記的剪輯，才會產生可播放的 Slack 預覽。其他情況都會回退到一般的標題和縮圖連結中繼資料。

想讓共用剪輯的逐字稿和畫格能被 ChatGPT 或 Claude Code 之類的外部代理讀取，不只是人類？請參閱 [剪輯的跨應用使用](/docs/template-clips-integrations)。

一旦剪輯被分享出去，它的擁有者就能看到究竟是誰在觀看：

| 項目         | 顯示內容                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| **錄音洞察** | 觀看次數，人類與讀取剪輯代理脈絡 API 的外部代理分別計數，加上不重複觀看者、完成率、流失曲線和 CTA 點閱率         |
| **組織洞察** | 該期間的整個組織總計、依觀看次數、reactions 和留言排序的熱門剪輯、頂尖創作者，以及逐日的參與趨勢，也就是洞察中心 |
| **CSV 匯出** | 組織中每段錄音的觀看與參與計數，以可下載的 CSV 呈現，最多包含最近 5,000 段錄音                                   |

人類的觀看次數和代理的觀看次數會刻意分開計數，因此代理輪詢一段共用剪輯的逐字稿，永遠不會虛增實際觀看者的人數。

#### 移到資料夾

資料夾能讓您的媒體庫保持整齊，而且可以巢狀嵌套：一個資料夾可以容納其他資料夾，不只是錄音。

<Steps>

### 建立資料夾

從剪輯的**移到資料夾**子選單中選擇**新資料夾**，或從媒體庫的右鍵選單中選擇。

### 把剪輯移進去

從剪輯三點選單的**移到資料夾**中選擇目的地資料夾。這也可以同時套用在多個選取的剪輯上。

</Steps>

您可以隨時從資料夾自己的選項選單重新命名它。刪除一個資料夾永遠不會刪除裡面的內容：其中的每段錄音，以及巢狀子資料夾中的每段錄音，都會往上移到父資料夾，如果您刪除的資料夾已經在最上層，則會移到媒體庫的根目錄。

#### 封存和移到垃圾桶

封存和丟進垃圾桶都會把剪輯從主要的媒體庫中隱藏起來，而不會刪除任何東西。

- **封存**會完整保留剪輯的每一項資料，同時把它從您日常的畫面中移出，適合用在一個已經完成、您不想看到但之後可能還會需要的專案。您可以隨時還原它。
- **移到垃圾桶**是一種軟刪除。剪輯會從媒體庫和封存區中一併消失，但在有人永久刪除它之前，實際上什麼都沒有真正消失。沒有自動清理機制：進了垃圾桶的剪輯會一直留在那裡，直到您或管理員永久移除它。
- **還原**可以一步把剪輯從封存區或垃圾桶中取回。
- **永久刪除**是唯一無法復原的選項，會移除這段錄音以及附加在它上面的一切：留言、reactions、觀看紀錄、逐字稿、分享，以及底層的媒體檔案。

## 與我共用

### 檢視剪輯 {#shared-view-clips}

這個畫面會列出有人直接分享給您或您組織的每段錄音，無論是指名分享，還是透過組織層級的可見性設定。有人手上剛好有的公開連結，不會算進這份清單。

您可以觀看並在共用的剪輯中拖曳時間軸，也可以收合側邊欄，讓影片有更多空間。您可以在這裡留言，但這裡沒有三點選單：管理一段剪輯（移動、封存、進一步分享）仍然由擁有者決定。

### 在剪輯上留言

在您正在觀看的影片中的確切位置新增留言，不只是針對整段錄音。留言會以對話串的形式串接回覆，支援粗體、斜體、行內程式碼和連結（標題會被扁平化為純文字），也可以 @提及隊友來通知他們。留言欄位會隨著您輸入而變高，動態消息也會展開以顯示較長的留言。

## 空間

空間是屬於某一個組織、範圍限定在特定主題的容器，例如「Q3 上線」或「支援團隊」，任何成員都可以把錄音放進去。一段錄音可以同時屬於零個、一個，或多個空間，所以把剪輯加進空間更像是替它加上標籤，而不是移動它：不同於資料夾只會把一段錄音存放在唯一一個地方，空間只是連結到它。空間也有自己的資料夾，與您個人媒體庫的資料夾分開。

組織管理員會建立一個空間，並逐一把成員加進去。空間成員資格有自己的角色：

| 角色       | 可以做的事                         |
| ---------- | ---------------------------------- |
| **管理員** | 新增和移除成員，變更他們的空間角色 |
| **貢獻者** | 從空間中新增和移除錄音             |
| **檢視者** | 檢視空間中的內容                   |

刪除一個空間會移除該空間和它的成員清單。原本在裡面的錄音不會受到影響，只是不會再出現在那裡。

## 隨處捕捉

每一種捕捉方式的結果都會進入同一個共用媒體庫，唯一的例外是 Rewind：它會留在您的裝置上，除非您核准從中分享某個片段。

### 桌面工具列應用程式

桌面應用程式的設計目標，是讓您每天的捕捉工作盡可能順暢：螢幕和網路攝影機錄製，搭配可拖曳的攝影機圓形視窗，並在您錄製時即時轉錄，全程不需要保持瀏覽器分頁開啟。可從 [clips.agent-native.com/download](https://clips.agent-native.com/download) 下載，支援 macOS、Windows 和 Linux。

<Callout tone="info">

您第一次錄製螢幕時，作業系統會要求取得螢幕錄製權限（在 Mac 上：系統設定 → 隱私權與安全性 → 螢幕錄製）。這是作業系統層級的權限，不是剪輯的設定，沒有它剪輯就無法錄製。

</Callout>

### Rewind

Rewind 是一種選用的本機記憶功能，會持續在您的裝置上以本機方式，保留一段捲動更新的螢幕錄製內容，如果您開啟的話，還包括音訊。

<Callout tone="info">

Rewind 預設是關閉的。在您於桌面工具列的設定中開啟它之前，不會捕捉任何內容，而且除非您核准，否則不會有任何內容離開您的裝置（逐次請求審核預設為開啟，可以在 Rewind 的設定中關閉）。您可以隨時自行匯出、搜尋，或清除緩衝區。

</Callout>

在設定中的 Rewind 分頁裡開啟 Rewind。開啟後，您可以問代理類似「我 20 分鐘前在看什麼」的問題，它會從本機緩衝區中讀取螢幕文字、應用程式與視窗脈絡，以及逐字稿片段的文字摘錄。代理永遠不會收到錄音本身，只有一個例外：一個經您審核並核准的請求，會把一段確切的範圍轉換成一段私人剪輯。

#### 加入之前發生的事

在剪輯的編輯器中，**加入之前發生的事**會從您本機的 Rewind 歷史紀錄中拉出前 30 秒或前 5 分鐘的內容，並加到剪輯的開頭。這段剪輯必須是在 Rewind 開啟時，於這台裝置上錄製的，而且那些片段必須仍在 Rewind 保留的歷史紀錄範圍內。

- 剪輯必須是私人的，沒有其他人被授予直接存取權。Rewind 的歷史紀錄可能包含您選擇開始錄製之前的脈絡，所以剪輯會先把這段剪輯設為私人，如果還有其他人擁有存取權，就會停止操作。
- 剪輯的媒體檔案會被替換成合併後的錄音。逐字稿、章節、留言和 reactions 的時間戳都會相應偏移，讓它們仍然對得上，時間軸上也會標示原始剪輯開始的位置。
- 這個操作對每段剪輯只會執行一次，而且只在您要求時才會執行。不會有任何內容從 Rewind 自動加入。

### Chrome 擴充功能瀏覽器紀錄

安裝剪輯的 Chrome 擴充功能，即可在錄製的同時取得您正在除錯的分頁的瀏覽器紀錄和網路活動，適合用於回報產品錯誤和僅限瀏覽器的重現步驟。

它只會監看您正在主動錄製的那個分頁，而且只在錄製進行中才會生效。它會儲存主控台訊息和每個請求的基本資訊（方法、經過編輯的網址、狀態、持續時間，以及請求是否失敗），絕不會儲存請求或回應的內文、標頭或 cookie。日常錄製請使用桌面應用程式，只有在您需要附上那些瀏覽器紀錄時，才特別使用 Chrome 擴充功能。

## 逐字稿和 AI 中繼資料 {#transcription-and-ai-metadata}

轉錄會先嘗試最快、免費的選項，只有在必要時才會回退到付費選項。口述歷史紀錄會顯示逐字稿預覽，可展開成完整逐字稿與對應的操作：

| 順序 | 提供者                           | 備註                                                                                                        |
| ---- | -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1    | 原生（裝置端）                   | 瀏覽器的 Web Speech API，或桌面本機的 Whisper/macOS 語音功能。即時完成，不需要 API 金鑰。                   |
| 2    | Builder.io 託管（Gemini）        | 當原生文字缺失時的雲端備援。一旦連接 Builder，就不需要額外的金鑰。Builder.io 的免費方案包含託管的 AI 額度。 |
| 3    | Groq（`whisper-large-v3-turbo`） | 如果您想帶自己的金鑰，這是選用的備援方式。                                                                  |

一旦逐字稿準備好，代理就會自動填入標題、摘要和章節標記，並在您編輯時持續保持最新。播放時，逐字稿會跟隨目前的播放位置。您也可以直接提出要求：

- 「重新產生標題和摘要。」
- 「加上章節。這段很長。」
- 「幫部落格文章擷取三段引言。」
- 「修正 1:42 處轉錄錯誤的單字。」

對於一段無聲的螢幕錄製，光靠音訊可能會產生誤導，這時可以在 AI 工具選單中開啟**包含完整影片**，讓代理實際觀看錄音本身（這需要 Gemini），而不只是依賴逐字稿。

備援轉錄、逐字稿清理，以及 AI 標題和摘要，預設都是靠 Builder.io 託管的 AI 額度運作，包含免費方案的額度。如果其中一項停止運作，可以問代理。它會檢查目前的額度狀態，並說明額度是否已被暫停，而不是把它當成一個 bug 處理。解決方式是新增 Builder.io 額度、升級方案，或連接您個人的 Groq 金鑰作為轉錄的備援。

## 非破壞性編輯 {#non-destructive-editing}

使用時間軸修剪和分割剪輯、移除靜音或填充詞、合併剪輯，並新增遮蔽處理。拖曳剪切邊界即可調整，並用復原或重做來檢視編輯結果。變更會持續疊加在原始錄音之上，而且在您匯出之前，不會有任何內容被烘進一個新檔案裡。

請代理為您進行以下任何一種編輯：

- 「移除嗯和啊，然後重新拼接。」
- 「修剪掉前 10 秒。」
- 「按這個順序把這三段剪輯合併成一段。」

在錄音的選項選單中，**移除靜音**和**移除填充詞**用一次點選就能做到同樣的事，不需要打字說出來。這兩者背後的實際工作仍然是由代理完成：讀取逐字稿、找出範圍，並套用修剪指令。

## 組織和團隊 {#organizations-and-teams}

任何人都可以建立一個組織，與團隊共用一個剪輯工作區。建立組織會讓您成為它的第一位管理員。

- **品牌識別。** 管理員可以設定品牌顏色和標誌，顯示在整個共用工作區中。
- **預設可見性。** 管理員可以選擇在沒有人明確選擇時，新錄音預設的可見性（公開、組織，或私人）。
- **邀請成員**，透過電子郵件邀請。邀請可以被接受或拒絕，管理員之後也可以變更成員的角色，或移除他們。

| 角色       | 可以做的事                                                               |
| ---------- | ------------------------------------------------------------------------ |
| **管理員** | 邀請和移除成員、變更角色、設定品牌識別和預設可見性，以及成員能做的所有事 |
| **成員**   | 錄製、編輯和分享自己的剪輯，並在任何被加入的空間中工作                   |
