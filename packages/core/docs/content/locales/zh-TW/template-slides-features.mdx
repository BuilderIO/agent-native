# 功能

幻燈片的每一項核心功能：運作方式，以及如何設定。總覽請參閱
[幻燈片](/docs/template-slides)，完整的提示清單請參閱[與 Agent
對話](/docs/template-slides-agent)。

## 簡報

關於建立、編輯、呈現和分享單一簡報的所有內容。

### 根據提示生成簡報

<Steps>

### 像對人簡報一樣向代理說明

「為咖啡訂閱服務生成一份 10 張投影片的推介簡報，受眾是投資者。」給它一個主題、一個長度和一個受眾，它就會依此規劃大綱。

### 觀看它逐張投影片建構

代理會先規劃大綱，再一次建立一張投影片，讓您在編輯器中看著它逐一出現，而不必等待整份簡報一次到位。

### 在同一段對話中持續調整

「在投影片 3 之後新增一張定價投影片。」「把這個部分縮短一點。」只有您提到的投影片會變更。

</Steps>

每一份新簡報預設使用 16:9 寬螢幕畫布。當您需要不同的形狀時，請代理把它切換成 1:1（正方形）、9:16（垂直，限時動態風格）或 4:5（直向）。變更之後，編輯器畫布、呈現模式和 PDF/PPTX 匯出會一起更新，因此您永遠不會遇到匯出結果和您建立的內容不一致的情況。

### 視覺化編輯投影片

- **行內文字編輯。**雙擊任何文字即可直接在投影片上編輯。
- **氣泡選單。**點選一個區塊、標題、項目清單或圖片，就能取得只套用在該區塊上的快速格式設定選項。
- **斜線選單。**輸入 `/` 即可插入新區塊、標題、項目清單、表格、程式碼區塊或圖片預留位置，不需要離開鍵盤。
- **重新排序。**在縮圖列中拖曳投影片即可重新排序；復原和重做的運作方式和您預期的一樣。
- **豐富嵌入內容。**一張投影片除了文字和圖片之外，還可以放入手繪圖表或即時渲染的圖表，而不只是靜態 HTML。
- **移動和調整生成內容的大小。**拖曳一個物件即可移動它，或拖曳其調整大小控點即可改變其大小。若要移動一個有邊框的區塊，請拖曳其文字。

選取投影片上的文字，然後點選氣泡選單中的**用 AI 修訂**按鈕，就能把您選取的確切內容交給代理處理。或者在投影片上選取多個元素，點選**傳送給代理**，然後在右側的聊天視窗中提供提示。選取範圍如何影響編輯，請參閱[與 Agent 對話](/docs/template-slides-agent)。

### 全螢幕呈現

點選**呈現**即可全螢幕開啟這份簡報。控制項會逐漸淡出，直到您移動滑鼠為止，而您的演講者備註只有您自己看得到。開始呈現之後，以下快速鍵即可使用：

| 按鍵                | 動作                       |
| ------------------- | -------------------------- |
| `→`、`↓` 或 `Space` | 下一張投影片               |
| `←` 或 `↑`          | 上一張投影片               |
| `F`                 | 切換全螢幕                 |
| `S`                 | 在另一個視窗開啟演講者備註 |
| `Esc`               | 退出呈現模式               |

### 即時評論與協作

從工具列開啟**評論**面板，即可查看並新增您正在檢視的這張投影片的評論。這個面板的範圍限定在該張投影片：切換到另一張投影片時，內容會隨之更換，因此它不會一次顯示整份簡報的所有評論。您可以先選取文字，在新評論中引用它，或使用工具列的**釘選評論**工具，把一個持續存在的釘選標記直接放在某個元素上。

任何擁有編輯權限的人都可以評論，並在討論串中回覆。討論串一經處理，就可以將它標示為已解決。多個人（以及代理）可以同時編輯同一份簡報，而不會互相覆蓋彼此的變更。背後的運作方式請參閱[即時協作](/docs/real-time-collaboration)。

### 分享簡報

分享一份簡報的方式，和分享任何 Agent-Native 資源一樣：可以保持私密，以檢視者或編輯者身分與特定隊友分享，或產生一個任何人都能不需帳戶開啟的公開唯讀連結。完整的模型請參閱[共用](/docs/sharing)。

### 恢復先前的版本

無論是您或代理做出的變更，只要有意義，都會先為這份簡報建立快照，因此不會有任何內容悄悄遺失。開啟版本歷史即可看到過去快照的時間軸，並恢復其中任何一個版本。恢復本身也會先建立自己的快照，因此恢復絕不會是個死胡同。

### 讓簡報在不同格式之間進出

| 方向 | 格式                         | 會發生什麼事                                                                                                       |
| ---- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 匯入 | PPTX、DOCX、PDF、Google 文件 | 轉換成可編輯的投影片 — PDF 或 DOCX 會依每頁或每個章節變成一張投影片，PPTX 會保留原本的投影片分割方式與演講者備註。 |
| 匯出 | PPTX                         | 原生、可編輯的文字、形狀和圖片 — 不是每張投影片的扁平化圖片。                                                      |
| 匯出 | Google 簡報                  | 幻燈片會生成相同的 PPTX，並提供您一個現成的匯入連結，因為 Google 簡報沒有直接「開啟這個網址」的匯入方式。          |
| 匯出 | 獨立 HTML                    | 單一個自帶內容的檔案，內建鍵盤導覽功能，您可以放到任何地方主機託管或用電子郵件寄送 — 不需要應用程式就能檢視。      |

引入一個 GitHub 儲存庫、一個程式碼庫，或一個網站網址，和匯入一份簡報的內容是不同的功能：那三種來源會餵給[設計系統](#design-systems)中所描述的設計系統索引，而不是逐張投影片的內容匯入。

## 設計系統 {#design-systems}

設計系統是一組可重複使用的品牌識別套件：主色／強調色／背景色、標題和正文字型、間距、標誌，以及自由格式的自訂指示（例如「章節標籤永遠使用小寫」、「絕不使用素材圖庫照片」）。它是獨立於任何一份簡報的資源。儲存一個設計系統之後，每一份新簡報都能使用它，而不必套用一般的預設值。

### 新增設計系統

<Steps>

### 開啟設計系統

從側邊欄開啟**設計系統**，然後點選**新增設計系統**。

### 加入您的品牌素材

填入您手上有的任何資料：公司名稱和網站、一個 GitHub 儲存庫、程式碼檔案、文件、參考圖片或標誌、備註，或自訂指示。

### 點選「繼續產生」

這會開始建立您的設計系統。接下來確切會發生什麼事，取決於您提供了什麼資料。

</Steps>

#### 接下來會發生什麼事，取決於來源

上傳一個 Figma 檔案，或只輸入一個 GitHub 儲存庫，會立刻建立設計系統。其他任何情況都會在側邊欄開啟代理，改在那裡完成。這裡沒有顏色選擇器或字型選擇器：品牌顏色和字型永遠來自代理所解讀的某個來源，或是來自您在備註和自訂指示中輸入的內容。

#### 設定預設值

把一個設計系統標記為您的預設值，讓每一份新簡報自動套用它，或是在開始一份新簡報時明確選擇一個。

### Builder 整合

一個 Figma 檔案、一個已連結的程式碼庫或 GitHub 儲存庫，或一個 `design.md`，都需要真正的分析，因此這些會透過 Builder Design System Intelligence 處理，而不是一次性的本機猜測。

#### 連接 Builder

這需要一個已連接的 Builder.io 帳戶（提供免費方案）。如果您還沒有連接，代理會在需要時提示您進行連接。

#### Builder 保持為唯一真實來源

Builder 會索引來源，並擁有產生的文件、提取出的標記，以及使用指南，而不是幻燈片。幻燈片在本機只保留一個指向結果的輕量指標，因此代理在套用設計系統時，都會從 Builder 取得目前的文件內容。

### Figma 檔案

`.fig` 檔案是唯一一種在您放入的那一刻就會開始索引的來源，不需要任何代理聊天步驟。把檔案拖曳到設定對話框中的 Figma 面板上，或點選瀏覽選取一個檔案。幻燈片會上傳它，並立刻啟動一個 Builder Design System Intelligence 索引工作，索引完成後，結果就會變成一個您可以套用到任何簡報的設計系統。

### 依簡報套用並微調

一旦某個設計系統連結到一份簡報，**微調**面板就會提供快速的即時覆寫，包括強調色色板、標題大小寫、背景色溫，而不需要直接編輯已儲存的系統。您保留下來的變更會回存到設計系統中。
