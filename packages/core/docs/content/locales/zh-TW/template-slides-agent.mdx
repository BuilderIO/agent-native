# 與 Agent 對話

幻燈片的代理透過 UI 所使用的相同 actions 來建立、編輯、匯入、匯出簡報並為簡報設定樣式，所以只要是您能點選的操作，也都可以直接用文字提出請求。本頁涵蓋代理會自動看到的內容，以及依任務分類的提示。無論您是日常使用者，還是在幻燈片之上進行開發，這一頁都很實用。

## 代理如何看到您的畫面

代理永遠知道目前開啟的是哪一份簡報、您正在檢視哪一張投影片，以及那份簡報中的完整投影片清單。您不必特別說「投影片 4」，它早就知道那裡有什麼內容。當您在視覺化編輯器中進行編輯時，它還能看到您目前的選取範圍：您點選的具體元素、您正在使用的工具，以及計算後的樣式細節，因此「把這個放大」會作用在您實際選取的內容上，而不是靠猜測。

聊天視窗位於側邊欄中，方便快速來回溝通。幻燈片也提供全頁的 Agent 檢視畫面，適合需要更多空間、時間較長的工作階段。

### 感知選取範圍的編輯

選取投影片上的文字，然後點選氣泡選單中的**用 AI 修訂**按鈕，或用拖曳框選一個或多個元素，點選浮動小工具上的**傳送給代理**，就能把您標示的內容準確地交給代理處理。這樣一來，「讓這段更有力一點」或「只翻譯這部分」就只會作用在您選取的範圍上，而不是整張投影片。

## 依任務分類的實用提示

以下每一個提示都會對您實際的簡報執行一個真正的 action，就是 UI 讀寫的同一份簡報。這裡有一個實際範例：

<Comparison>

### :blue: 您的提問

「為咖啡訂閱服務生成一份 10 張投影片的推介簡報，受眾是投資者。」

### :green: 發生的事

代理會先規劃大綱，然後在建立每一張投影片時即時串流到編輯器中，讓您看著這份簡報逐步成形，而不必等待整份簡報一次到位。

</Comparison>

<Cards columns={2}>

### 生成

- **「把這份 PDF 概括成一份 6 張投影片的簡報。」**附上這份 PDF，代理就會把它變成一份可編輯的簡報。
- **「把這份 Google 文件變成一份簡報。」**概念相同，只是改成以 Google 文件為起點。

### 編輯與重新設計樣式

_投影片開啟時，「這張投影片」會自動解析。_

- **「在投影片 3 之後新增一張定價投影片。」**新的投影片會立刻出現在縮圖列中。
- **「放大這張投影片的標題，並把強調色改成綠色。」**變更會即時套用到目前開啟的投影片上。
- **「把這份簡報中所有的『客戶』都改成『會員』。」**每一張投影片都會同時更新。

### 匯入與匯出

- 「匯入這份 PPTX，把每一張投影片都變成這裡可編輯的投影片。」
- 「把這份簡報匯出成 PowerPoint。」
- 「把這個準備好，讓我可以在 Google 簡報中開啟。」
