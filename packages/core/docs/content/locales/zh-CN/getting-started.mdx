# 开始使用

Agent-Native 应用让智能体和 UI 共享相同的[动作](/docs/actions-overview)、SQL 数据和应用状态。这条路径从 Chat 开始，Chat 已经创建所需的框架表，并默认将聊天记录存储在本地 SQLite 中。只有当应用需要持久化领域数据时，才添加自己的数据表。

<Steps>

### 创建聊天应用并配置智能体

搭建 Chat 模板、安装依赖、启动开发服务器并配置智能体。你将获得一个可以继续扩展的可用聊天应用。
**你正在这里。**

### 添加动作

定义一个有类型的文本分析器，并在聊天中将其结果渲染为图表。

### 添加页面

构建一个在聊天记录之外调用同一动作的 React 路由。

</Steps>

## 1. 创建聊天应用 {#create-your-app}

你需要 [Node.js 22+](https://nodejs.org) 和 [pnpm](https://pnpm.io)。

打开终端，进入你想要创建 Agent Native 应用的目录，然后运行：

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

应用会在 `http://localhost:8080` 打开。如果看到登录界面，请使用虚构的登录信息注册。本地开发无需验证邮箱。

Chat 模板包含持久化聊天线程、身份验证、实时同步、一个 `actions/` 目录，以及标准的 `view-screen` 和 `navigate` 动作。

### 选择其他起点

如果 Chat 不是合适的起点，可以运行 `create` 而不使用 `--template`，并在 CLI 中选择其他选项。有关其他路径，请参阅[创建模板](/docs/creating-templates)。

## 2. 配置智能体 {#connect-ai}

Chat 模板会直接打开聊天界面。如果智能体还不能响应，请打开 **Settings > Manage agent**，或使用 **Cmd/Ctrl+K > Manage agent** 来配置模型和提供商。

智能体开始响应后，继续阅读[添加动作](/docs/getting-started-actions)。
