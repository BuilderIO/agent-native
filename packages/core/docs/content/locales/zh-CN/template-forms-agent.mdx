# 与 Agent 对话

表单中的一切，代理都可以通过与界面相同的 actions 来访问，因此任何您能点击完成的事，也都能用简单易懂的语言请求代理完成。本页介绍代理如何查看您的屏幕，以及按任务分类的实用提示。有关概览，请参阅 [表单](/docs/template-forms)。

## 代理如何查看您的屏幕

代理始终知道您打开的是哪个表单或哪个视图，精确到具体的浏览器标签页。如果您在一个标签页中打开了一个表单，在另一个标签页中打开了回复列表，代理会把它们区分开。这就是为什么您可以问“给这个表单添加一个必填的 NPS 问题”或“这个有多少条回复”而不必指名具体的表单。代理早已知道您指的是哪一个。当您正在查看某个表单的回复时，代理还能看到这些回复的预览内容，范围以您有权查看的内容为准。

## 按任务分类的实用提示

下面的每一条提示都会转化为针对您真实表单的真实 action，与界面读写的是同一个表单。这里有一个具体示例：

<Comparison>

### :blue: 您的请求

“创建一个包含角色、团队规模和优先用例的 Beta 注册表单。”

### :green: 发生的事情

这是一次创建新内容的操作。代理会构建出一个已经包含这些字段的表单，它会立即出现在您的表单列表中，随时可以进行微调或发布。不需要刷新页面，新表单就这样直接出现了。

</Comparison>

<Cards columns={2}>

### 构建

- **“创建一个包含角色、团队规模和优先用例的 Beta 注册表单。”** 新表单会立即出现在您的表单列表中，随时可以微调。
- **“添加一个必填的 NPS 问题和一个自由文本的后续问题。”** 这些字段会立即出现在表单上。
- **“在不丢失路由所需字段的情况下把这个表单缩短。”** 代理会精简表单，同时保留您的目的地所依赖的字段。

### 发布与保护

- **“发布这个，并把链接给我。”** 表单会立即上线，您会马上拿到它的公开 URL。
- **“创建一个匿名的客户反馈表单，并把公开链接给我。”** 表单从一开始就以匿名方式发布，因此永远不会记录提交者的信息。
- **“只允许从 https://example.com 提交这个表单。”** 表单开始拒绝来自其他任何地方的提交。目前这项功能只能通过请求代理来实现，构建器中还没有对应的开关。

### 回复与洞察

- “Beta 注册表单有多少条回复？”
- “今天谁提交了？”
- “总结本周的提交内容，并按客户细分进行分组。”
- “按天绘制提交图表。”
- “这个月我所有表单的提交趋势如何？”
- “把这个导出为 CSV。”

### 路由

- **“把每一条新回复都发布到产品 Slack 频道。”** 一旦目的地连接完成，新回复就会立即开始出现在 Slack 中。
- “我的 Beta 注册表单目前是什么设置？”

</Cards>
