# 组织、团队与权限

组织定义团队成员关系和租户边界。工作区汇集应用和部署配置，但不能替代组织。权限必须由服务端检查。在界面隐藏按钮并不等于访问控制。

## 三种角色范围

- 组织角色 `owner`、`admin` 和 `member` 控制团队管理。
- 应用角色控制单个应用内的操作。一个成员可以有多个应用角色。
- 资源角色 `viewer`、`editor` 和 `admin` 控制单条数据的访问。

应用代码声明角色和权限键。管理员可以在团队页面替换成员的整个角色集合，并将已声明的权限映射到角色。没有覆盖设置时，使用应用默认值。邀请可预先包含应用角色。应用管理员不会因此获得组织管理权限。

邀请和配置请参阅[管理式部署指南](/docs/administered-deployments)。数据访问请参阅[数据范围控制](/docs/security#data-scoping)。
