# 功能

剪辑的每一项核心功能：它是如何运作的，以及如何进行设置。有关概览，请参阅 [剪辑](/docs/template-clips)；有关完整的提示列表，请参阅 [与 Agent 对话](/docs/template-clips-agent)。

## 库

### 查看剪辑 {#library-view-clips}

你的库会先显示文件夹，再显示录制内容，以缩略图网格的形式呈现，一眼就能看到时长、标题、所有者、观看次数和可见性。你可以按最新、最旧或标题排序，按标签筛选，或者在你做过的每一份转录文本中搜索，找到你曾讨论过某件事的那段剪辑，而不只是你记得标题的那段录制内容。

### 创建一个剪辑 {#create-a-clip}

有三种方式可以把一个剪辑添加到你的库中，都可以从**录制**按钮和它旁边的**导入**菜单进入。在库中的空白处右键点击，会提供同样的三种方式，外加**新建文件夹**。

- **录制。**剪辑内置的屏幕录制工具，支持网络摄像头叠加、音频捕获，以及暂停/修剪控制。
- **上传视频文件。** 直接从你的电脑添加一段已有的视频，或者把它拖放到库或空间的网格中。无需录制。
- **导入 Loom。** 无需重新录制即可引入一个公开的 Loom 视频。在**录制**旁边打开**导入**，选择**导入 Loom**，然后粘贴一个 Loom 分享或嵌入 URL。剪辑会把副本保存到你的库中，并在 Loom 提供公开转录文本时一并导入。

### 管理一个剪辑

每个剪辑的三点菜单，无论是在库中还是直接右键点击卡片打开，都有同样的四个操作：**分享**、**移到文件夹**、**存档**和**移到回收站**。

#### 分享 {#share}

以逐个剪辑设置权限的方式分享一个剪辑：公开、团队/组织，或私密。链接跟踪和带线索的评论同样有效。你可以在分享对话框中为任意剪辑添加密码或过期日期。两者都只会收紧访问权限。它们都不能授予比上层分享规则本应拒绝的更多访问权限。

组织管理员会设置新录制内容在没有人显式选择可见性时所采用的默认可见性，这在下面的[组织和团队](#organizations-and-teams)中有介绍。除非管理员修改了这一设置，录制内容默认是公开的，而显式选择的可见性总会优先于默认值。

为一个剪辑构建一个嵌入 URL，把它放进一个 wiki 页面、一个内部工具，或任何其他接受 `<iframe>` 的地方：

| Param             | 含义                                               |
| ----------------- | -------------------------------------------------- |
| `?t=80`           | 从第 80 秒开始播放                                 |
| `?autoplay=1`     | 自动播放（静音，因为浏览器会阻止未静音的自动播放） |
| `?hideControls=1` | 隐藏播放器的界面控件                               |
| `?loop=1`         | 循环播放                                           |

一旦你的工作区安装了剪辑的 Slack 应用，公开分享链接还会以可播放的、类似 Loom 风格的视频形式进行预览。只有已就绪、公开、没有密码、没有触发过期、也没有存档/回收站标记的剪辑，才会生成可播放的 Slack 预览。其他情况都会回退到普通的标题和缩略图链接元数据。

想让一个共享剪辑的转录文本和画面帧不仅能被人阅读，还能被 ChatGPT 或 Claude Code 这样的外部代理读取吗？请参阅[多应用工作区中的剪辑](/docs/template-clips-integrations)。

一旦一个剪辑被分享出去，它的所有者就可以看到究竟是谁在观看：

| 内容         | 向你展示什么                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **录制洞察** | 观看次数，人类和读取该剪辑代理上下文 API 的外部代理会被分别计数，此外还有独立观看者数、完成率、流失曲线，以及 CTA 点击率 |
| **组织洞察** | 该周期内的组织级总数、按观看次数/表情反应/评论排名靠前的剪辑、排名靠前的创作者，以及逐日的互动趋势，即洞察中心           |
| **CSV 导出** | 组织中的每一段录制内容及其观看和互动计数，作为一个可下载的 CSV 文件，最多包含最近的 5,000 段录制内容                     |

人类的观看次数和代理的观看次数是特意分开计数的，因此一个持续轮询某个共享剪辑转录文本的代理，永远不会虚增真正观看过它的人数。

#### 移到文件夹

文件夹让你的库保持井然有序，而且它们可以嵌套：一个文件夹可以容纳其他文件夹，而不只是录制内容。

<Steps>

### 创建一个文件夹

从一个剪辑的**移到文件夹**子菜单中选择**新建文件夹**，或者从库的右键菜单中选择。

### 把一个剪辑移进去

在剪辑的三点菜单的**移到文件夹**中选择目标文件夹。这同样适用于同时选中的多个剪辑。

</Steps>

你可以随时从文件夹自己的选项菜单中重命名它。删除一个文件夹永远不会删除它里面的内容：其中的每一段录制内容，以及嵌套子文件夹中的每一段录制内容，都会上移到父文件夹，如果你删除的文件夹本来就在最顶层，则会移到库的根目录。

#### 存档和移到回收站

存档和移到回收站都会把一个剪辑从主库中隐藏，而不会删除任何内容。

- **存档**会完整保留一个剪辑的所有数据，同时把它从你日常的视图中移出，适合一个已经完成、你不想看到但可能还会用到的项目。你可以随时恢复它。
- **移到回收站**是一种软删除。该剪辑会同时从库和存档中消失，但在有人永久删除它之前，什么都没有真正消失。没有自动清理机制：一个被移到回收站的剪辑会一直留在那里，直到你或某位管理员将它永久移除。
- **恢复**可以一步把一个剪辑从存档或回收站中带回来。
- **永久删除**是唯一不可逆的操作，会移除该录制内容以及附加在它上面的一切：评论、表情反应、观看历史、转录文本、分享，以及底层的媒体文件。

## 与我共享

### 查看剪辑 {#shared-view-clips}

这个视图列出了所有直接分享给你或你的组织的录制内容，不管是按姓名分享的，还是通过组织级可见性设置分享的。别人碰巧拥有的一个公开链接不计入这个列表。

你可以观看并拖动进度条来查看共享的剪辑，还可以收起侧边栏，为视频留出更多空间。你可以在这里发表评论，但没有三点菜单：管理一个剪辑（移动、存档、继续分享）仍然由所有者决定。

### 对剪辑发表评论

在你正在观看的视频的确切位置添加一条评论，而不只是针对整段录制内容。评论可以串成回复，支持粗体、斜体、行内代码和链接（标题会被压平成纯文本），还可以 @提及一位队友来通知他们。评论输入框会随着你的输入而变高，评论列表也会展开以显示较长的评论。

## 空间

一个空间是一个归属于某个组织、按主题划分的容器，比如“Q3 发布”或“支持团队”，它的任何成员都可以把录制内容放进去。一段录制内容可以同时属于零个、一个或多个空间，因此把一个剪辑添加到一个空间，更接近于给它打标签，而不是移动它：不同于文件夹只把一段录制内容放在唯一一个位置，一个空间只是链接到它。空间也有自己的文件夹，与你个人库的文件夹是分开的。

一位组织管理员创建一个空间，并逐个把成员添加进去。空间成员身份有自己的角色：

| 角色       | 可以做什么                         |
| ---------- | ---------------------------------- |
| **管理员** | 添加和移除成员，更改他们的空间角色 |
| **贡献者** | 从空间中添加和移除录制内容         |
| **查看者** | 查看空间中的内容                   |

删除一个空间会移除这个空间及其成员列表。曾经在其中的录制内容不会受到影响。它们只是不再显示在那里了。

## 随时随地捕获

每一种捕获方式最终都会进入同一个共享库，唯独 Rewind 例外，它会保留在你的设备上，除非你批准从中分享某个片段。

### 桌面托盘应用

桌面应用是为最流畅的日常捕获而构建的：屏幕和网络摄像头录制，带有一个可拖动的摄像头气泡，录制时进行实时转录，全程都不需要保持浏览器标签页打开。可以从 [clips.agent-native.com/download](https://clips.agent-native.com/download) 下载，支持 macOS、Windows 和 Linux。

<Callout tone="info">

你第一次录制屏幕时，你的操作系统会请求屏幕录制权限（在 Mac 上：系统设置 → 隐私与安全性 → 屏幕录制）。这是一个操作系统级别的权限，不是剪辑的设置项，没有它剪辑就无法进行录制。

</Callout>

### Rewind

Rewind 是一个可选的本地记忆功能，会保留你屏幕的一段滚动录制内容，如果你开启了音频，也会保留音频，并全部存储在你的设备本地。

<Callout tone="info">

Rewind 默认是关闭的。在你在桌面托盘的设置中开启它之前，不会捕获任何内容；在你批准之前，也不会有任何内容离开你的设备（逐次请求审核默认是开启的，可以在 Rewind 的设置中关闭）。你可以随时自行导出、搜索或清空这个缓冲区。

</Callout>

在设置中的 Rewind 标签页下开启 Rewind。开启之后，你可以问代理类似“我 20 分钟前在看什么？”这样的问题，它会从本地缓冲区中读取屏幕上文本、应用和窗口上下文，以及转录片段的文本摘录。代理永远不会收到录制内容本身，唯一的例外是：一个经过你审核并批准的请求，会把一个确切的时间范围转换成一个私密剪辑。

#### 添加之前发生的内容

在一个剪辑的编辑器中，**添加之前发生的内容**会从你本地的 Rewind 历史记录中提取之前的 30 秒或 5 分钟，并把它添加到剪辑的开头。该剪辑必须是在 Rewind 开启期间、在这台设备上录制的，并且这些时刻必须仍在 Rewind 保留的历史记录范围内。

- 该剪辑必须是私密的，没有其他人被直接授予访问权限。Rewind 历史记录可能包含你选择录制之前的上下文，因此剪辑会先把剪辑设为私密，如果仍有其他人拥有访问权限，就会停止操作。
- 该剪辑的媒体会被替换为合并后的录制内容。转录文本、章节、评论和表情反应都会相应偏移，使它们的时间戳依然对齐，时间轴上会标出原始剪辑开始的位置。
- 这个操作对每个剪辑只会执行一次，并且只有在你要求时才会执行。不会有任何内容从 Rewind 自动添加进来。

### Chrome 扩展程序浏览器日志

安装剪辑的 Chrome 扩展程序，即可在录制的同时，获取你正在调试的标签页的浏览器日志和网络活动，这对报告产品缺陷和仅在浏览器中出现的复现问题很有用。

它只监视你正在录制的那个标签页，并且只在录制进行期间生效。它会保存控制台消息和基本的逐请求信息（方法、经过编辑处理的 URL、状态、耗时，以及请求是否失败），但绝不会保存请求或响应正文、请求头或 cookie。日常录制请使用桌面应用，只有当你需要附带这些浏览器日志时，才使用 Chrome 扩展程序。

## 转录和 AI 元数据 {#transcription-and-ai-metadata}

转录会先尝试最快的免费选项，只有在必要时才会回退到付费选项。听写历史记录会显示转录文本预览，可以展开查看完整的转录文本及对应的操作：

| 顺序 | 提供方                           | 说明                                                                                                            |
| ---- | -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 1    | 本机（设备端）                   | 浏览器的 Web Speech API，或桌面端本地 Whisper/macOS 语音识别。即时完成，无需 API 密钥。                         |
| 2    | Builder.io 托管（Gemini）        | 当本机文本缺失时的云端回退方案。一旦连接了 Builder，就不需要额外的密钥。Builder.io 的免费套餐包含托管 AI 额度。 |
| 3    | Groq（`whisper-large-v3-turbo`） | 如果你想使用自己的密钥，这是一个可选的备用方案。                                                                |

一旦转录文本准备好，代理就会自动填写标题、摘要和章节标记，并在你编辑时保持它们是最新的。播放期间，转录文本会跟随当前播放位置同步滚动。你也可以直接提出要求：

- “重新生成标题和摘要。”
- “添加章节。这一段比较长。”
- “为一篇博客文章提取三段引言。”
- “修正 1:42 处转录错误的单词。”

对于一段无声的屏幕录制，仅凭音频会产生误导，此时在 AI 工具菜单中开启**包含完整视频**，让代理直接观看录制内容本身（这需要 Gemini），而不只是依赖转录文本。

备用转录、转录文本清理，以及 AI 标题和摘要，默认都运行在 Builder.io 托管的 AI 额度上，包括免费套餐的额度。如果其中某一项停止工作，问一问代理。它会检查当前的额度状态，并说明额度是否被暂停，而不会把这当成一个 bug 来处理。解决办法是增加 Builder.io 额度、升级套餐，或者连接一个个人 Groq 密钥作为转录的备用方案。

## 非破坏性编辑 {#non-destructive-editing}

使用时间轴来修剪和拆分剪辑、移除静音片段或填充词、合并剪辑，以及添加打码遮盖。拖动剪切点即可调整它们，使用撤销或重做来查看编辑历史。改动会一直叠加在原始录制内容之上。在你导出之前，不会有任何改动被固化到一个新文件中。

请代理帮你完成以下任何一种编辑：

- “去掉那些嗯啊之类的口头语，然后重新拼接。”
- “修剪掉前 10 秒。”
- “把这三个剪辑按这个顺序合并成一个。”

在一段录制内容的选项菜单中，**移除静音片段**和**移除填充词**用一次点击就能完成同样的事情，而不需要你把它打出来。这两者背后的实际工作仍然由代理完成：读取转录文本，找到对应的区间，并应用修剪指令。

## 组织和团队 {#organizations-and-teams}

任何人都可以创建一个组织，与团队共享一个剪辑工作区。创建组织的人会成为它的第一位管理员。

- **品牌。** 管理员可以设置一个品牌色和徽标，会显示在整个共享工作区中。
- **默认可见性。** 管理员可以选择当没有人显式选择时，新录制内容默认采用的可见性（公开、组织，或私密）。
- 通过邮箱**邀请成员**。一份邀请会被接受或拒绝，管理员之后可以更改一位成员的角色，或将其移除。

| 角色       | 可以做什么                                                                     |
| ---------- | ------------------------------------------------------------------------------ |
| **管理员** | 邀请和移除成员，更改角色，设置品牌和默认可见性，此外还可以做一位成员能做的一切 |
| **成员**   | 录制、编辑并分享自己的剪辑，并可以在被加入的任何空间中工作                     |
