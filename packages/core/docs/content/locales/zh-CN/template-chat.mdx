# 聊天

聊天是一个供开发者构建自己代理的起步模板。创建应用后，您会得到一个可用的对话界面、已保存的聊天记录和登录功能，还有一个代理已经可以使用的示例 action。它省去了手动为模型接入聊天界面、对话存储和登录所需的数周工作，让您从一个可部署的应用开始，把时间花在代理真正要做的事情上。

聊天不是面向某项具体工作的成品。如果您不是开发者，或者想要今天就能使用的现成应用，请从用于屏幕录制的[剪辑](/docs/template-clips)、用于演示文稿的[幻灯片](/docs/template-slides)，或用于交互式原型的[设计](/docs/template-design)开始。

## 您会得到什么

首次打开聊天时，您会看到一个消息框和一个问题“How can I help?”。随便问点什么，代理就会在原处回答。其余内置的内容刻意保持精简。

- **全页聊天。** 对话占满整个屏幕，在您发送第一条消息之前，消息框会居中显示。
- **对话列表。** 侧边栏列出您的聊天，您可以开始新的聊天、重新打开旧的聊天、重命名、置顶或归档。
- **“开始使用”页面。** 一个简短的落地页，包含指向添加第一个 action 和第一个界面的指南的链接。您可以编辑或替换它。
- **登录与团队。** 登录、注册和组织功能从一开始就可用。
- **一个示例 action。** 代理已经可以运行一个简单的示例，让您在编写自己的 action 之前先看看 action 是如何运作的。
- **管理页面。** 内置了数据库查看器和可观测性仪表板，无论您是否会打开它们。
- **为小型应用预留的空间。** 内置了一个页面，用于存放称为扩展的小型沙盒化工具。开发者可以开启代理构建它们的能力。

聊天不包含任何特定于某项业务的内容：没有现成的数据、仪表板、表单，也没有与外部服务的连接。这些需要由您来添加。

## 多应用工作区中的聊天

如果您在 [Dispatch](/docs/template-dispatch) 下将聊天与其他应用一起运行，它可以充当您工作区的入口。一场对话可以触达周围的其他应用，而不是孤立存在。有关这种连接如何运作，请参阅[多应用工作区中的聊天](/docs/template-chat-integrations)。
