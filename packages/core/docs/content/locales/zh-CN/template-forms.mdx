# 表单

表单是一款面向任何需要收集信息、又不想写代码的人的表单构建器。您可以用它来做注册、反馈、报名或调查。向代理描述您想要的表单，需要更直接的控制时再对其进行可视化微调，然后发布一个任何人都能填写的链接。

## 它取代了什么

<Comparison>

### 之前

- 用于收集回复的 Typeform、Google Forms，或手动搭建的表单
- 手动把新提交内容复制到 Slack 或电子表格中
- 需要一个单独的工具来总结收到的回复
- 需要搭建一个 Zapier 自动化，才能把回复同步到 Sheets 或 webhook

### 之后

- 一个表单，代理和可视化编辑器都可以对其进行更新
- 新回复一到达，就会立即发送到 Slack、Discord、Sheets 或 webhook
- 只需请求一份摘要，就能得到图表、表格，或两者兼有，无需借助单独的工具
- 条件字段、垃圾信息防护和匿名模式都内置在同一个构建器中

</Comparison>

## 多应用工作区中的表单

如果您在 [Dispatch](/docs/template-dispatch) 中让表单和其他应用一起运行，表单就不再只是一个需要手动打开的页面。表单的代理可以把属于其他应用的问题转交出去，其他应用也可以直接向您的表单发送回复，就像框架自带的反馈按钮那样。具体是如何运作的，请参阅[多应用工作区中的表单](/docs/template-forms-integrations)。

## 您可以用它做什么

- **以对话方式构建表单。** 试试类似“创建一个联系表单”“添加一个 NPS 分数问题”或“把电子邮件字段设为必填”这样的提示。参阅[可用的字段类型](/docs/template-forms-features#field-types)。
- **可视化微调。** 需要更直接的控制时，可以直接在表单构建器中编辑标签、占位符、必填状态、选项和字段顺序。
- **发布并保护一个公开表单。** 分享一个公开链接，需要时开启垃圾信息防护或完全匿名回复。参阅[功能](/docs/template-forms-features)。
- **查看回复并请求洞察。** 试试类似“总结本周的提交内容”或“按天绘制提交图表”这样的提示。参阅[功能](/docs/template-forms-features#response-insights)。
- **自动路由提交内容。** 粘贴一个 Slack、Discord、Google Sheets 或通用 webhook 的 URL，新回复一到达就会被发送过去。
