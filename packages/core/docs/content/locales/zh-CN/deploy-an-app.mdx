# 部署应用

有关步骤和各提供商命令，请参阅[完整的英文应用部署指南](/docs/deploy-an-app)。

部署前，请配置持久 SQL 数据库和稳定的 `BETTER_AUTH_SECRET`。可选择 [Node.js 与 Docker](/docs/node-docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify) 或 [Cloudflare](/docs/cloudflare)。

如果要在一个来源下运行多个应用，请使用[工作区部署](/docs/workspace-deployment)。
