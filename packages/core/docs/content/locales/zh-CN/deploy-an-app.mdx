# 部署应用

有关步骤和各提供商命令，请参阅[完整的英文应用部署指南](/docs/deploy-an-app)。

从[入门指南](/docs/getting-started)开始。部署前，请在托管提供商的环境设置中保存 `DATABASE_URL`，而不只是本地 `.env`。使用 `openssl rand -hex 32` 生成稳定的 `BETTER_AUTH_SECRET` 并保存在同一位置。**Continue as local dev** 仅限本地使用；部署后的应用使用注册和登录。可选择 [Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Amplify](/docs/aws-amplify)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb) 或 [Render](/docs/render)。

如果要在一个来源下运行多个应用，请使用[工作区部署](/docs/workspace-deployment)。
