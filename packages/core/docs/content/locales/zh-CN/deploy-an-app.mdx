# 部署应用

有关步骤和各提供商命令，请参阅[完整的英文应用部署指南](/docs/deploy-an-app)。

部署前，请配置持久 SQL 数据库和稳定的 `BETTER_AUTH_SECRET`。可选择 [Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb) 或 [Render](/docs/render)。

如果要在一个来源下运行多个应用，请使用[工作区部署](/docs/workspace-deployment)。
