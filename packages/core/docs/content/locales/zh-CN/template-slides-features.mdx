# 功能

幻灯片的每一项核心功能：它是如何运作的，以及如何进行设置。有关概览，请参阅
[幻灯片](/docs/template-slides)；有关完整的提示列表，请参阅[与 Agent
对话](/docs/template-slides-agent)。

## 演示文稿

关于创建、编辑、演示和共享单份演示文稿的一切。

### 根据提示生成演示文稿

<Steps>

### 像向人交代任务一样向代理说明需求

“为一家咖啡订阅服务生成一份 10 页的推介演示文稿，受众是投资者。” 给它一个主题、一个长度和一个受众，它就会围绕这些信息来搭建大纲。

### 观看它逐张构建幻灯片

代理会先规划大纲，然后逐张构建幻灯片，因此您会看到它们一张一张出现在编辑器中，而不必等待整份演示文稿一次性完成。

### 在同一场对话中持续优化

“在第 3 张幻灯片之后添加一张定价幻灯片。”“把这一部分缩短一点。” 只有您提到的幻灯片会发生变化。

</Steps>

每一份新的演示文稿默认使用 16:9 的宽屏画布。当您需要不同的形状时，可以让代理把它切换为 1:1（正方形）、9:16（竖版，类似 Stories 的样式）或 4:5（竖屏）。更改宽高比会同时更新编辑器画布、演示模式和 PDF/PPTX 导出，因此您导出的文件永远不会和您构建的内容不一致。

### 直观地编辑幻灯片

- **内联文本编辑。**双击任意文本即可直接在幻灯片上编辑它。
- **气泡菜单。**点击一个块——标题、项目符号列表、图片——即可获得仅针对该块的快捷格式选项。
- **斜线菜单。**输入 `/` 即可插入新的块——标题、项目符号、表格、代码块、图片占位符——完全不需要离开键盘。
- **重新排序。**在幻灯片缩略图栏中拖动幻灯片即可重新排序；撤销和重做的行为和您预期的一样。
- **富媒体嵌入。**一张幻灯片除了文本和图片之外，还可以容纳手绘图表或实时渲染的图表，而不只是静态 HTML。
- **移动和调整生成内容的大小。**拖动一个对象即可移动它，或者拖动它的调整手柄来改变它的大小。要移动一个带边框的区域，请拖动它的文字。

选中幻灯片上的文本，然后点击气泡菜单中的**用 AI 修订**按钮，即可把这段确切的选中内容交给代理处理。或者在幻灯片上选中多个元素，点击**发送给代理**，然后在右侧的聊天窗口中提供提示。有关感知选择的编辑如何运作，请参阅[与 Agent 对话](/docs/template-slides-agent)。

### 全屏演示

点击**演示**即可全屏打开演示文稿。控件会自动淡出，直到您移动鼠标才会重新出现，而您的演讲者备注只有您自己可见。演示开始后，以下快捷键即可生效：

| 按键                | 操作                       |
| ------------------- | -------------------------- |
| `→`、`↓` 或 `Space` | 下一张幻灯片               |
| `←` 或 `↑`          | 上一张幻灯片               |
| `F`                 | 切换全屏                   |
| `S`                 | 在单独窗口中打开演讲者备注 |
| `Esc`               | 退出演示模式               |

### 实时评论与协作

从工具栏打开**评论**面板，查看并添加针对当前所查看幻灯片的评论。该面板的范围仅限于这张幻灯片：切换到另一张幻灯片时，面板内容会随之切换，因此它永远不会一次性显示整份演示文稿的评论。您可以先选中文本，将其引用到一条新评论中，也可以使用工具栏中的**固定评论**工具，直接在某个元素上放置一个持久化的图钉。

任何拥有编辑权限的人都可以评论并在讨论串中回复。处理完之后可以将讨论串标记为已解决。多个人（以及代理）可以同时编辑同一份演示文稿，而不会互相覆盖对方的更改。有关其底层运作方式，请参阅[实时协作](/docs/real-time-collaboration)。

### 共享一份演示文稿

共享一份演示文稿的方式和共享任何 Agent-Native 资源是一样的：将其保持私密，以查看者或编辑者身份与特定队友共享，或生成一个任何人都可以在没有账户的情况下打开的公开只读链接。完整的共享模型请参阅[共享](/docs/sharing)。

### 恢复早期版本

无论是您做出的更改还是代理做出的更改，每一次有意义的更改都会先为演示文稿创建快照，因此任何内容都不会被悄悄丢失。打开版本历史即可看到过往快照的时间线，并恢复其中任意一个版本。恢复操作本身也会先创建一次快照，因此一次恢复永远不会是死路一条。

### 在其他格式之间导入导出演示文稿

| 方向 | 格式                         | 会发生什么                                                                                                       |
| ---- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 导入 | PPTX、DOCX、PDF、Google Docs | 转换为可编辑的幻灯片——PDF 或 DOCX 会按页或按段落各生成一张幻灯片，PPTX 则会保留其原有的分页结构和演讲者备注。    |
| 导出 | PPTX                         | 原生、可编辑的文本、图形和图片——不是把每张幻灯片拍平成一张图片。                                                 |
| 导出 | Google Slides                | 幻灯片会生成同一份 PPTX，并为您提供一个可直接使用的导入链接，因为 Google Slides 没有直接“打开此 URL”的导入方式。 |
| 导出 | 独立 HTML                    | 一个内置键盘导航的独立文件，您可以随意托管或通过邮件发送，查看它无需任何应用。                                   |

引入一个 GitHub 仓库、一个代码库或一个网站 URL，是与导入演示文稿内容不同的另一项功能：这三者会被用于[设计系统](#design-systems)中所描述的设计系统索引，而不是逐张幻灯片的内容导入。

## 设计系统 {#design-systems}

设计系统是一套可复用的品牌标识包：主色/强调色/背景色、标题和正文字体、间距、徽标，以及自由格式的自定义说明（例如“章节标签始终使用小写”“绝不使用图库照片”）。它是独立于任何一份演示文稿的资源。保存一个设计系统后，每一份新的演示文稿都可以使用它，而不再使用通用默认样式。

### 添加设计系统

<Steps>

### 打开“设计系统”

从侧边栏打开**设计系统**，然后点击**新建设计系统**。

### 添加您的品牌素材

填入您手上现有的任何素材：公司名称和网站、一个 GitHub 仓库、代码文件、文档、参考图片或徽标、备注，或自定义说明。

### 点击“继续生成”

这会开始构建您的设计系统。接下来具体会发生什么，取决于您提供了哪些内容。

</Steps>

#### 接下来会发生什么取决于素材来源

上传一个 Figma 文件，或者只输入一个 GitHub 仓库，都会立即开始构建设计系统。除此之外的任何其他情况，都会在侧边栏打开代理，转而在那里完成构建。这里没有取色器或字体选择器：品牌颜色和字体始终来自代理解读的某个素材来源，或者来自您在备注和自定义说明中输入的内容。

#### 设置默认项

将某个设计系统标记为默认项，这样每一份新的演示文稿都会自动使用它；也可以在新建演示文稿时手动选择一个。

### Builder 集成

一个 Figma 文件、一个已连接的代码库或 GitHub 仓库，或者一份 `design.md`，都需要真正的分析，因此它们会通过 Builder Design System Intelligence 来处理，而不是依赖一次性的本地猜测。

#### 连接 Builder

这需要连接一个 Builder.io 账户（提供免费套餐）。如果您还没有连接账户，代理会在需要时提示您完成连接。

#### Builder 始终是数据的唯一可信来源

Builder 负责对素材进行索引，并拥有生成的文档、提取出的设计令牌和使用指南，而不是由幻灯片拥有。幻灯片本地只保留一个指向该结果的轻量指针，因此代理每次应用设计系统时，都会从 Builder 获取最新的文档。

### Figma 文件

`.fig` 文件是唯一一种在您拖入的那一刻就会立即开始索引的素材来源，不需要经过代理聊天这一步。将文件拖到设置对话框中的 Figma 面板上，或点击浏览来选择一个文件。幻灯片会立即上传它，并启动一个 Builder Design System Intelligence 索引任务；索引完成后，其结果就会成为一个您可以应用到任何演示文稿上的设计系统。

### 针对单份演示文稿应用与微调

一旦某个设计系统被关联到一份演示文稿，**微调**面板就会为您提供快速的实时覆盖选项——强调色色板、标题大小写、背景色温——而不需要直接编辑已保存的设计系统。您保留下来的更改会持久化写回到该设计系统中。
