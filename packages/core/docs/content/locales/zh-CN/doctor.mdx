# Doctor

生成的应用和 workspace 包含可通过仓库开发工作流更改的源代码，也可以由被有意授予工作区和写入工具的代理 frame 更改。`agent-native doctor` 会扫描源代码中的关键代码安全不变量。它是只读的：doctor 从不编辑代码，只报告结果。

`agent-native doctor` 运行 9 个 guard：8 个安全 guard 和 `migration-manifest`。后者查找已安装 `migration-manifest.json` 中的导入，且没有 opt-out。运行 `agent-native doctor --only migration-manifest`，用 `npx @agent-native/core@latest upgrade --codemods` 预览，再用 `--yes` 应用。JSON 的 `guardsRun` 列出全部 9 项。

CLI 会为每个新建的 app 和 workspace 添加 `pnpm doctor` 与 `pnpm agent-native:doctor` 命令。从 workspace 根目录运行时，会检查 `apps/<name>` 下的每个 app。发现问题时，build 默认会失败；只有经过审查的例外才应使用 `failOnBuild: false`。

标记为 `planned` 的条目只会作为警告显示，不会被重写。active 条目会作为问题报告；codemod 仅在目标 export 已安装时才会重写。
