# 功能

聊天内置的每一项功能：它是如何运作的，以及如何进行设置。有关概览，请参阅
[聊天](/docs/template-chat)；有关可以尝试的提示，请参阅
[与 Agent 对话](/docs/template-chat-agent)。

## 对话

聊天打开后是一个消息框，上方的标题是“How can I help?”。输入一条消息，代理就会
在同一个屏幕上回答。在您发送第一条消息之前，消息框会一直居中显示，之后随着
对话变长，它会移到底部。

侧边栏将您的对话分为两组。**已置顶**的聊天保持在顶部，**最近**显示其余所有聊天，
最新的在前。仍在处理中的聊天，其标题旁会显示一个旋转图标，因此您可以开始另一场
对话，而不会忘记第一场对话。

- 使用侧边栏顶部的**新建聊天**来**开始新的聊天**。
- 在列表中选择任意聊天即可**重新打开**它。
- 通过聊天所在行的选项菜单来**重命名、置顶或归档**聊天。归档会将它从列表中移除。
- 当您想为对话留出更多空间时，可以**折叠侧边栏**。

<Steps>

### 重命名聊天

打开聊天所在行的选项菜单，选择**重命名聊天**。输入新标题并按 Enter 键。标题最多
可以有 160 个字符。

### 置顶您经常回来查看的聊天

从同一个菜单中选择**置顶聊天**。该聊天会移到**已置顶**中，直到您选择**取消置顶聊天**。

### 归档您已完成的聊天

选择**归档聊天**。如果归档失败，会出现一条消息，聊天会保持在原来的位置。

</Steps>

## 连接模型

代理需要一个模型才能回答。在连接模型之前，消息框会显示“Connect AI to start chatting...”。
选择**使用 Builder.io** 可获得免费额度，或选择**添加您自己的密钥**来使用您自己的服务商密钥。
之后代理就可以立即回答。

如需之后更换模型，请打开**设置**并选择**模型**。该页面用于设置默认模型以及应用可以使用的服务商。

<Callout tone="info">

聊天不会替您选择模型。您可以选择哪些模型，取决于您连接的服务商。

</Callout>

## 语音输入

消息框中包含一个麦克风按钮。选择它即可口述消息而不必打字，然后像其他消息一样发送。语言和听写
选项位于**设置 → 偏好设置**。

## 示例 action

聊天包含一个名为 **hello** 的示例 action。action 是应用可以做的一件事，例如问候某人、创建一条笔记
或查找一条记录。每个 action 都有名称、对其功能的描述，以及运行所需的详细信息。代理会读取这些描述，
来决定针对您的请求使用哪个 action。

请代理问候某人，例如“用名称 Alex 调用 hello action”，它就会用该名称运行 hello 并显示结果。
它的存在是为了让您在编写自己的 action 之前，先完整地看一遍整个流程：从您的消息，到代理运行 action，
再到显示返回的内容。

action 是 agent-native 应用的共享接口。代理会使用它们，应用自己的界面也可以使用，因此一个新的 action
无需任何额外设置就能在两处同时生效。随着应用的成长，开发者会添加自己的 action。有关其运作方式，
请参阅 [Actions](/docs/actions-overview)；有关如何编写，请参阅 [定义 Actions](/docs/actions-defining)。

## 在设置中塑造代理

打开**设置**，查看**智能体**分组。这些页面控制代理在每一场聊天中的行为。

| 页面         | 控制的内容                                 |
| ------------ | ------------------------------------------ |
| **模型**     | 默认模型和服务商密钥。                     |
| **指令**     | 代理在每一场聊天中遵循的长期指导。         |
| **个性化**   | 您自己的自定义指令和记忆偏好。             |
| **记忆**     | 代理已学到并在各场聊天之间记住的内容。     |
| **技能**     | 代理可以针对某类任务加载的可复用操作指南。 |
| **文件**     | 代理可以读取的参考文件。                   |
| **子智能体** | 主代理可以把工作交给它们的辅助代理。       |

**连接**分组包含**集成**和 **API 密钥**，**账户**分组包含**个人资料**、**偏好设置**和**安全**。

<Steps>

### 打开设置

选择侧边栏底部的搜索按钮，然后选择**设置**。

### 选择一个页面

从左侧的列表中选择一个页面。更改会应用到您的下一条消息。

</Steps>

## 登录与团队

聊天需要登录。登录、注册和会话从首次运行时就已设置好，登录方式、成员和角色在设置的**组织**分组下管理。

侧边栏底部的组织切换器会显示您正在使用哪个组织，并允许您切换。请为每个工作区保持单一组织，
并将人员作为成员添加到其中。您连接的凭证是按组织保存的，因此第二个组织看不到在第一个组织下连接的密钥。

## 数据库与可观测性

聊天内置了两个管理页面。它们没有链接在侧边栏中，因此请通过地址打开。

- 位于 `/database` 的**数据库**会显示应用的表，并允许您浏览代理和应用已保存的行。
- 位于 `/observability` 的**可观测性**会显示代理一直在做什么，包含概览、对话、评估、实验和反馈等标签页。

两者都是为运行应用的人准备的。无论您是否会打开它们，它们都已挂载。

## 小型应用

聊天有一个**扩展**页面，用于存放在应用内运行的小型沙盒化工具，例如计算器或清单。您可以在设置的扩展下找到它们。
代理目前还不能构建它们。允许它创建扩展是开发者可以开启的一个开关，聊天默认将其关闭。有关它们是什么以及如何启用，
请参阅 [扩展](/docs/extensions)。
