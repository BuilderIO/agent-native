# 日历

日历是一款由代理驱动的日程安排应用。连接您的 Google Calendar 后，代理就可以读取您的日程、查找空闲时间、创建活动，并管理 Calendly 风格的预订链接，无论是用简单易懂的语言描述，还是点击操作即可完成。它用一个应用取代了 Google Calendar 加 Calendly 的组合，让您的真实日程和公开预订页面不再是需要手动保持同步的两件事。

## 它取代了什么

<Comparison>

### 之前

- 用 Google Calendar 管理您的真实日程
- 用 Calendly（或类似工具）管理公开预订链接，需要手动保持同步
- 需要单独搜索联系人才能找到某人的邮箱地址
- 需要在每个邀请中复制粘贴 Zoom 链接

### 之后

- 一个视图：真实日历和预订链接合二为一
- 一套可用性模型，预订链接和代理都从中读取数据
- 人员搜索与日程安排整合在同一个提示中
- 有人预订时自动附加 Zoom 或 Google Meet

</Comparison>

## 多应用工作区中的日历

如果您在 [Dispatch](/docs/template-dispatch) 下将日历与其他应用一起运行，您的日历就不再只是一个可以打开的页面。它会变成其他渠道和应用可以操作的对象，从新预订触发的自动化，到某个同级应用直接向日历提交日程安排请求。有关这种连接实际如何运作及其背后真实机制的说明，请参阅[多应用工作区中的日历](/docs/template-calendar-integrations)。
