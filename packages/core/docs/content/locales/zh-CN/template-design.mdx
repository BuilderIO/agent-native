# Design

Design 是一个代理原生原型设计工作室。代理生成的不是一个分层绘图画布，而是完整的、独立的 Alpine 和 Tailwind HTML 原型，并将它们展示在实时预览中，再通过提示词和调整控件来完善结果。实时预览展示的就是可运行的代码。

每一次生成、调整和导出，读写的都是同一个 HTML 文件，因此预览效果和您下载的内容之间不会有任何信息在转换中丢失。

## 多应用工作区中的 Design

如果您在 [Dispatch](/docs/template-dispatch) 下将 Design 与其他应用一起运行，
那么这并不是触达它的唯一方式。Design 还可以作为一个托管工具，供其他代理直接
调用，包括 Claude Code 和 Claude Desktop，使用的是工作区应用本就暴露的同
一类连接点。有关这种连接实际如何运作及其背后真实机制的说明，请参阅
[多应用工作区中的 Design](/docs/template-design-integrations)。

## 您可以用它做什么

- **生成完整的原型。** 描述您需要的屏幕或页面，代理就会编写一个具有 Tailwind 样式和 Alpine 交互的可运行 HTML 文档。
- **比较多个版本。** 生成几个不同的方向，挑选最强的一个，然后继续完善，而不是从头再来。
- **应用品牌。** 关联一个设计系统、从网站或代码库导入品牌，或者引入一个可编辑的 Figma 画框作为起点。参阅[功能](/docs/template-design-features)。
- **保持质量的一致性。** 代理会在把某个原型判定为可用之前运行无障碍和视觉检查，重复出现的模式还可以变成可复用的组件。参阅[功能](/docs/template-design-features)。
- **导出真实文件。** 导出 HTML、ZIP、PDF，或者真正的矢量 Figma SVG，又或者附带一份现成的交接包，把原型交给编码代理。参阅[功能](/docs/template-design-features)。
