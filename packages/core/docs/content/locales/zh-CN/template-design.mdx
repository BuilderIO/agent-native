# Design

Design 是一个代理原生原型设计工作室。代理生成的不是一个分层绘图画布，而是完整的、独立的 Alpine 和 Tailwind HTML 原型，并将它们展示在实时预览中，再通过提示词和调整控件来完善结果。它取代了静态模型稿工具以及随之而来的交接环节，因为您在预览中看到的已经是真实可运行的代码。

每一次生成、调整和导出，读写的都是同一个 HTML 文件，因此预览效果和您下载的内容之间不会有任何信息在转换中丢失。

## 它取代了什么

<Comparison>

### 之前

- 用 Figma 或类似工具制作静态模型稿，再由另一位开发者把它们转化为真实的标记语言
- 通过调整画板大小来猜测设计的响应式表现，而不是查看真实的浏览器渲染效果
- 在导出的规格说明与手动还原这些规格的人之间，存在一次缓慢的交接
- 设计文件和已上线的代码会随着时间推移逐渐脱节

### 之后

- 代理生成、预览并完善同一个 HTML 原型，不需要单独的构建步骤
- 真实的 Alpine 和 Tailwind 标记语言，可以在任意断点下实时预览
- 向代理请求布局、文案或交互上的更改，即可看到同一个文件随之更新
- 直接导出为 HTML、ZIP、PDF 或编码交接包，让设计与代码始终是同一份工件

</Comparison>

## 您可以用它做什么

- **生成完整的原型。** 描述您需要的屏幕或页面，代理就会编写一个具有 Tailwind 样式和 Alpine 交互的可运行 HTML 文档。
- **比较多个版本。** 生成几个不同的方向，挑选最强的一个，然后继续完善，而不是从头再来。
- **应用品牌。** 关联一个设计系统、从网站或代码库导入品牌，或者引入一个 Figma 画框作为像素级精确的起点。参阅[功能](/docs/template-design-features)。
- **保持质量的一致性。** 代理会在把某个原型判定为可用之前运行无障碍和视觉检查，重复出现的模式还可以变成可复用的组件。参阅[功能](/docs/template-design-features)。
- **导出真实文件。** 导出 HTML、ZIP、PDF，或者真正的矢量 Figma SVG，又或者附带一份现成的交接包，把原型交给编码代理。参阅[功能](/docs/template-design-features)。
