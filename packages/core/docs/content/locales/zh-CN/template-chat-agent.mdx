# 与 Agent 对话

在聊天中，对话是您使用应用的主要方式。代理可以运行应用的 actions、查找信息、记住您告诉它的内容，并带您前往其他页面。本页介绍代理对您屏幕的了解、按任务分类的实用提示，以及它在哪些情况下会超出内置 actions 的范围。有关概览，请参阅 [聊天](/docs/template-chat)。

## 代理如何查看您的屏幕

代理始终知道您在哪个页面，以及打开的是哪一场对话。这就是为什么“带我回到首页”或“我现在在哪个页面？”这样的说法无需任何解释就能生效。每次页面发生变化时，应用都会实时告知代理，因此代理从不需要猜测。

聊天没有可供指向的业务数据，例如选中的活动或打开的文档。代理所知道的其他一切，都来自您在对话中所说的话。

## 按任务分类的实用提示

下面的每一条提示都会针对真实的应用运行。这里有一个具体示例：

<Comparison>

### :blue: 您的请求

“用名称 Alex 调用 hello action。”

### :green: 发生的事情

代理会用名称 Alex 运行示例 **hello** action。该 action 返回“Hello, Alex!”，代理会将其显示在聊天中。应用中的其他内容不会发生任何变化。

</Comparison>

<Cards columns={2}>

### 了解应用能做什么

- **“这个应用能做什么？”** 代理会列出它拥有的 actions，以及每个 action 的功能。
- **“给我看看可用的 actions。”** 同样的思路，以简单的名称列表呈现。
- **“帮我开始使用。”** 代理会建议一个可以首先尝试的事情。

### 在应用中导航

- **“带我去设置。”** 应用会为您打开该页面。
- **“打开数据库页面。”** 代理会打开 `/database`，它没有链接在侧边栏中。
- **“回到首页。”** “开始使用”页面会打开。

### 教代理

- **“记住我喜欢简短的回答。”** 代理会将其保存到它的记忆中，并在之后的聊天中使用。
- **“从现在起，回答之前总是先解释你的推理。”** 代理可以将其保存为一条长期指令。
- **“你记得关于我的什么？”** 代理会把它的记忆读给您听。

### 查看您的数据

- **“这个应用的数据库里有哪些表？”** 代理会读取数据库结构并列出这些表。
- **“我有多少个聊天？”** 代理会针对数据库运行一个只读的查询，并在聊天中回答。

### 了解框架

- **“我该如何给这个应用添加一个新的 action？”** 代理会搜索 Agent-Native 文档并解释具体步骤。
- **“action 和技能有什么区别？”** 同样地，根据文档来回答。

</Cards>

<Callout tone="info">

代理可以读取数据库，但不会直接修改它。要保存新信息，它会使用 action。这使每一次更改都走与应用自身界面相同的路径。开发者可以在应用的设置中更改这一点。

</Callout>
