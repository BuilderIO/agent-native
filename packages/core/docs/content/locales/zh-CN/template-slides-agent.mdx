# 与 Agent 对话

幻灯片的代理通过与界面相同的 actions 来创建、编辑、导入、导出和设计演示文稿的样式，因此任何您能点击完成的事，也都能用请求的方式完成。本页介绍代理自动能看到什么，以及按任务分类的提示。无论您是日常用户，还是在幻灯片基础上进行开发，本页都会有用。

## 代理如何查看您的屏幕

代理始终知道当前打开的是哪一份演示文稿、您正在查看哪一张幻灯片，以及该演示文稿中幻灯片的完整列表。您不必特意说“第 4 张幻灯片”，它已经知道那里有什么内容。当您在可视化编辑器中进行编辑时，它还能看到您当前的选择：您点击的具体元素、您正在使用的工具，以及计算出的样式细节，因此“把这个放大一点”会作用在您实际选中的内容上，而不是靠猜测。

聊天位于侧边栏，方便快速来回沟通。幻灯片还提供一个全页面的 Agent 视图，为更长的会话提供更充足的操作空间。

### 感知选择的编辑

选中幻灯片上的文本，点击气泡菜单中的**用 AI 修订**按钮，或者用框选方式选中一个或多个元素，再点击浮动小标签中的**发送给代理**，即可把您选中的确切内容交给代理处理。这样一来，“让这段话更有力一点”或“只翻译这一部分”这类请求，就只会作用在您选中的内容上，而不是整张幻灯片。

## 按任务分类的实用提示

下面的每一条提示都会转化为针对您真实演示文稿的真实 action，与界面读写的是同一份演示文稿。这里有一个具体示例：

<Comparison>

### :blue: 您的请求

“为一家咖啡订阅服务生成一份 10 页的推介演示文稿，受众是投资者。”

### :green: 发生的事情

代理会先规划大纲，然后在构建每一张幻灯片的同时，将其实时流式传输到编辑器中，因此您能看到整份演示文稿逐渐成形，而不必等待它一次性完成。

</Comparison>

<Cards columns={2}>

### 生成

- **“把这份 PDF 总结成一份 6 页的演示文稿。”** 附上该 PDF，代理就会把它变成一份可编辑的演示文稿。
- **“把这个 Google Doc 变成一份演示文稿。”** 思路相同，只是起点换成了一个 Google Doc。

### 编辑与重新设计样式

_在打开某张幻灯片的情况下，“这张幻灯片”会自动被正确解析。_

- **“在第 3 张幻灯片之后添加一张定价幻灯片。”** 新的幻灯片会立即出现在幻灯片缩略图栏中。
- **“把这张幻灯片上的标题放大，并将强调色改成绿色。”** 更改会实时应用到当前打开的这张幻灯片上。
- **“把这份演示文稿里所有的‘客户’替换成‘会员’。”** 每张幻灯片都会同时更新。

### 导入与导出

- “导入这份 PPTX，把其中的每一张幻灯片都变成这里可编辑的幻灯片。”
- “把这份演示文稿导出为 PowerPoint。”
- “让这份文件准备好可以在 Google Slides 中打开。”

</Cards>
