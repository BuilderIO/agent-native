# 功能

Design 的每一项核心功能：它是如何运作的，以及如何进行设置。有关概览，请参阅
[Design](/docs/template-design)；有关完整的提示列表，请参阅
[与 Agent 对话](/docs/template-design-agent)。功能按应用中真实的屏幕分
组：**设计列表**、**编辑设计**、**模板**和**设计系统**。

## 设计列表 {#designs}

`/home` 列表页面。您可以访问的每一个设计都在这里，也是您新建设计的地方。

### 查看设计列表 {#view-designs}

设计以卡片网格的形式展示：实时缩略图、标题和最后更新日期。切换到**全部**
筛选器（而不是**我的**）还会显示每个设计的所有者。

- **搜索**会随着您的输入按标题筛选网格。
- 网格每页显示 11 个设计，"新建设计"卡片始终排在第一位。
- 选中一张或多张卡片（悬停即可显示复选框）会出现一个批量操作工具栏：全
  选/清除当前可见项、添加到创作上下文，或删除所选项。
- 空账户会显示四个可点击的起始提示（SaaS 页面、仪表板、移动应用、定价
  页面），而不是一个空白网格。

### 创建设计 {#create-a-design}

两个"新建设计"入口——页头按钮和网格中的虚线卡片——打开的是同一个弹出面
板。您可以在编辑器打开之前，输入提示词，并选择一个起始模板、一个设计系
统和一个创作上下文。点击**跳过**则会得到一个空白设计（或者所选模板未经
提示词处理的副本），不涉及任何 AI 生成。

提交后会直接进入新设计的编辑器，并显示一个"正在打开设计"的浮层，同时任
何生成过程都会在后台完成。

### 管理设计 {#manage-a-design}

设计卡片上的"⋯"菜单包含四个选项：

- **重命名**：一个带文本输入框的小对话框。
- **复制**：立即创建一份副本并打开它，无需确认。
- **添加到上下文**：将该设计关联到一个创作上下文。
- **删除**：会先要求确认。

## 编辑设计 {#edit-a-design}

以下内容都是在您点开某个设计之后适用的。

### 文件设置 {#file-settings}

屏幕和图层位于同一个合并的树状结构中，而不是两个独立的面板。设计中的每
个屏幕（各自都是一个独立的 HTML 文件）都是一个顶层条目，该屏幕的图层嵌
套在其下方。

- **添加、重命名、复制、删除和重新排序**对屏幕和图层的操作方式相同。
- **锁定**一个图层可以让它保持固定。这与模板及模板副本所保留的"锁定图
  层"是同一个概念。
- **显示或隐藏**任意图层，而无需删除它。

### 代理 {#agent-in-editor}

编辑器中的代理聊天，和每个 Agent-Native 应用共有的那个代理聊天是同一
个，并不是 Design 专属的聊天界面。您可以像请求任何其他更改一样，让它生成一
个屏幕、比较多个版本、微调细节，或检查质量和无障碍性。在把某个设计判定
为可用之前，它还会自动运行质量和无障碍性检查，不需要您做任何操作。按任
务分类的提示请参阅[与 Agent 对话](/docs/template-design-agent)。

#### 模式

工具旁边有一个独立的三向切换器：

- **编辑**：正常模式。移动、框架、形状、钢笔和文本都在此模式下工作。
- **注释**：绘制和固定评论需要在此模式下才能使用。
- **交互**：画布的一个独立模式，与编辑和注释分开。

### Design 标签页 {#design-tab}

针对当前所选内容的主属性面板。各个区块只在适用于当前所选内容时才会出
现：

- **填充**和**描边**：颜色、渐变或图片填充，并带有一个文档色板，可复
  用已有颜色。
- **效果**：投影、图层模糊、背景模糊，以及一个由代码支撑的着色器效
  果，带有具名的滑块（速度、颜色、中心点）和一个用于原始 GLSL 的代码
  面板。
- **位置与布局**、**排版**、**外观**（圆角、混合模式、可见性）：标准
  的逐元素属性分组。
- **布局**和**自动布局**：为框架的子元素提供类 flex 的排列方式。
- **布局网格**：为框架提供的布局参考叠加层。
- **组件**：一旦某个元素是组件实例，该区块就会显示它的变体和属性
  （props）。更改一个属性会立即预览，并只应用到这一个实例上。这里没
  有单独存储的组件定义，每个实例都是标记语言自身独立的副本，因此"跳
  转到主组件"会跳回最早的那个实例作为参考点，而不是一个规范模板。

### 评论标签页 {#comments-tab}

这是一个真实的标签页，与 Design 标签页并列，并带有一个未读数量徽标。任何
有访问权限的人都可以将评论固定到某个具体元素上，而不是留下一条泛泛的备
注。一条评论既可以保持为一条普通备注，也可以直接发送给代理处理。当代理
处理一条评论时，它会编辑该评论所指向的设计中的确切部分，确认更改确实已
经生效，然后要么用一句话说明更改内容并解决该讨论串，要么在这不是代理应
该自行决定的事情时，回复并请人来决定。

### 代码与测量标签页 {#code-tab}

针对当前所选内容显示：以像素为单位的精确位置和尺寸、计算后的样式
（display、position、字体、颜色），以及底层 HTML，并配有一键**复制**
按钮。这是一个只读的检查器，而不是一个编辑器。

### 设计预览 {#design-preview}

页头的播放按钮菜单。**设计预览**会在新的浏览器标签页中打开当前屏幕真实
渲染后的 HTML，效果与它在编辑器之外的样子完全一致。在屏幕拥有内容之
前，该功能处于禁用状态。

### 导出 {#export}

打开编辑器左侧边栏中的小型菜单按钮（它使用 Agent-Native 标志作为图
标，与"返回设计列表"、"另存为模板"和"版本历史"排在一起）。**导出**是该
菜单靠下位置的一个子菜单。

### 版本历史 {#version-history}

在同一个左侧边栏菜单中，**版本历史**会打开一个面板，列出该设计已保存的
快照，并附有相对时间戳("刚刚""5 分钟前"等)。选择其中一个会显示其屏幕的
预览，**恢复此版本**会将设计恢复到那个确切的状态。

## 模板 {#templates}

有两种方式，能比从空白画布开始更快上手。

### 查看模板 {#view-templates}

模板页面有两个区块，**您的模板**和**内置模板**，外加一个可按标题、描
述和分类筛选的搜索框。每张模板卡片都会显示实时预览、分类（广告、单页
文档、着陆页、社交、演示文稿或其他）、尺寸，以及其上有多少个图层被锁
定。您自己的模板（内置模板除外）会有一个"⋯"菜单，包含**共享**（查看
者、编辑者或管理员权限）和**删除**。

### 使用模板 {#use-a-template}

点击**使用模板**会打开一个小对话框：一个可选的提示词、一个要应用的设
计系统（或创建一个新设计系统的链接），以及一个**直接使用**按钮，可以
跳过提示词直接得到一份副本。无论哪种方式，都会创建一个新设计，并直接
进入其编辑器。

### 另存为模板 {#save-as-template}

这个操作不在模板页面本身上。在编辑设计时，打开用于导出和版本历史的同
一个左侧边栏菜单，选择**另存为模板**。它的尺寸、文件和锁定图层会像内
置模板一样被保留下来。

<Callout tone="info">

目前只能从内联 Design 项目保存模板。由 `/visual-edit` 或完整应用构建支撑
的设计无法另存为模板。

</Callout>

### 打开设计 {#open-a-design}

这里没有单独的"打开"步骤。使用模板和根据提示词生成新设计一样，最终都
会自动打开该设计的编辑器。

## 设计系统 {#design-systems}

设计系统就是品牌识别——它的颜色、字体、间距和标志——Design 会将其应用到与
之关联的每一个原型上。

### 查看和共享设计系统 {#view-and-share}

设计系统页面是一个网格：第一张是"新建设计系统"卡片，之后每个系统各占
一张卡片，带有色板预览、一个显示在您默认设计系统上的**默认**徽标，以
及一个可见性徽标（私有、组织或公开）。每张卡片都有一个真实的**共享**
按钮，提供查看者、编辑者或管理员角色，与模板使用的是同一套共享模型。
页头的**选择**开关可以启用多选和批量删除。

### 新建设计系统 {#new-design-system}

创建一个设计系统，从选择来源开始：

- **Figma**：上传一个 `.fig` 文件。
- **公司/品牌**：一个网站 URL。
- **代码**：一个已连接的 GitHub 仓库。
- **Design.md**：一份书面的设计指导文档。
- **设计文件**：直接上传文件。
- **导入现有内容**：复用您已有的设计系统或项目。
- **说明**：从零开始描述您的品牌，或者从一个真实的、有人维护的公开系
  统（例如 Material 3、Carbon 或 Primer）开始，而不是凭记忆重新创建
  一个。

<Callout tone="info">

每个公开系统都自带真实的语义化令牌、字号体系、间距和署名信息。Design 不
会让一个提示词悄悄把它变成一个底层数据不同的仿制品。每个设计系统还带
有一组可选的自定义指令，以及一段图片风格描述，这样生成的摄影图片和插
画就能与品牌其余部分保持同一种视觉语言。

</Callout>
