# 用 AI 智能体创建应用

你可以让 AI 智能体来创建你的 Agent-Native 应用。你只需粘贴一条提示词，智能体就会运行设置命令，并在完成后向你展示一个正在运行的应用。

如果你更想自己输入命令，请改为按照[开始使用](/docs/getting-started)操作。

## 开始之前

- 一个能运行终端命令的 AI 智能体，例如 Claude Code、Codex 或 Cursor。只能聊天的智能体，例如 ChatGPT 或网页版 Claude，也能提供帮助。请参阅[无法运行命令的智能体](#chat-only-agents)。
- [Node.js](https://nodejs.org) 22.22 或更高版本。
- 一个用于存放新应用的空文件夹。

创建应用不需要 API 密钥。只有当你希望应用自带的智能体回答你时才需要。请参阅[连接 LLM](/docs/getting-started#connect-an-llm)。

## 粘贴这条提示词

在空文件夹中打开你的智能体，然后粘贴下面的提示词。把第一行的 `my-app` 改成你想要的名称。只需要改这一处。

```markdown
在名为 my-app 的新文件夹中创建一个新的 Agent-Native 应用，
并启动它。下面步骤中写着 APP_NAME 的地方都使用这个名称。

1. 检查 Node.js 版本是否为 22.22 或更高，以及 pnpm 是否可用。
   如果缺少 pnpm，运行 `corepack enable`。如果 corepack 也不可用，
   运行 `npm install -g pnpm`。如果 Node.js 版本过旧，请停止并告诉我，
   不要自行安装。
2. 运行：
   npx --yes @agent-native/core@latest create APP_NAME \
    --standalone --template chat
3. 在新建的 APP_NAME 文件夹中运行 `pnpm install`。
4. 阅读 APP_NAME/AGENTS.md，了解应用的结构。
5. 用 `pnpm dev` 启动应用，并让它在后台持续运行。
6. 读取 `pnpm dev` 输出的本地 URL。检查它是否有响应，
   例如用 `curl -I <url>`。不要打开浏览器，也不要使用无头
   浏览器工具。我会自己打开应用。
7. 向我展示结果。告诉我本地 URL 和你从它得到的响应。
   不要只说设置已完成。

规则：

- 不要编造 API 密钥，也不要让我粘贴 API 密钥。连接 LLM 是
  可选的，我会自己来做。
- 不要打印任何 .env 文件中的密钥。
- 如果命令失败，请向我展示错误和你尝试过的做法。不要隐瞒。
```

## 智能体应该完成什么

一次顺利的运行会得到以下结果，你可以自己逐项检查：

- 一个新的应用文件夹，除非你改过名称，否则叫 `my-app`，其中包含 `actions/`、`app/` 和一个 `AGENTS.md` 文件。
- `pnpm dev` 正常运行且没有错误。
- 一个本地 URL，通常是 `http://localhost:8080`，智能体已经检查过它有响应。

然后在你自己的浏览器中打开这个本地 URL。在欢迎界面中选择 **Continue as local dev**。开始使用页面就会出现。

如果缺少其中任何一项，请让智能体展示它最后运行的命令及其输出。

<Callout tone="info">

如果这些命令因对等依赖错误而失败，原因可能是 npx 缓存中有过时的软件包副本。请让智能体运行 `npx clear-npx-cache`，然后重试。

</Callout>

## 为你的智能体选择合适的方式

| 智能体类型        | 示例                                                    | 工作方式                                 |
| ----------------- | ------------------------------------------------------- | ---------------------------------------- |
| 终端和 IDE 智能体 | Claude Code、Codex、Cursor、VS Code 中的 GitHub Copilot | 粘贴提示词。智能体会替你运行每一条命令。 |
| 仅聊天的智能体    | ChatGPT、网页版 Claude                                  | 让它给出命令，然后由你自己运行。         |

### 无法运行命令的智能体 {#chat-only-agents}

仅聊天的智能体无法打开终端，所以不能创建应用。你仍然可以粘贴这条提示词，并在最前面加上这一行：

```markdown
你无法运行命令。请把每条要在我终端中运行的命令逐条给我，
并在继续之前等我告诉你执行结果。
```

智能体会带你完成同样的步骤，并在出现问题时提供帮助。

## 你自己的智能体和应用的智能体

有两个智能体可以处理你的应用，它们的分工不同。

- **你自己的智能体**就是你粘贴提示词的那个，例如 Claude Code、Codex 或 Cursor。它在应用之外，运行在你的终端或编辑器里。
- **应用的智能体**是应用内置的聊天。应用运行时，你在浏览器中打开它。

|                        | 你自己的智能体（应用之外）                                                          | 应用的智能体（应用之内）                                             |
| ---------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 在哪里使用             | 你的终端或编辑器                                                                    | 浏览器中的应用聊天                                                   |
| 处理什么               | 你项目的文件                                                                        | 应用的数据和你正在查看的界面                                         |
| 能做什么               | 创建项目、安装软件包、运行 `pnpm dev`、编写和修改动作、页面和数据库表，以及准备部署 | 把应用的动作当作工具调用、读取和更新应用数据、回答关于屏幕内容的问题 |
| 是否需要为应用连接 LLM | 不需要，它使用自己的模型                                                            | 需要。请参阅[连接 LLM](/docs/getting-started#connect-an-llm)         |
| 最适合                 | 构建和修改应用                                                                      | 使用应用并完成日常工作                                               |

你自己的智能体负责构建应用，应用的智能体负责运行应用。当你自己的智能体添加了一个动作，应用的智能体可以立刻调用它，因为两者使用的是同一个动作。

### 帮助你自己的智能体顺利构建

生成的应用已经配置好，你自己的智能体无需额外说明就能在其中顺利工作。

- 应用根目录中的 `AGENTS.md` 告诉智能体应用的结构以及需要遵守的规则。
- `.agents/skills/` 中是针对常见任务的简短指南，例如添加功能或编写动作。
- 与你所用框架版本完全对应的文档随应用一起提供。智能体可以用 `pnpm action docs-search --query "<topic>"` 搜索这些文档。

当你提出新的需求时，可以让智能体先阅读这些内容。例如："在修改任何内容之前，先阅读 AGENTS.md 和对应的技能。"

如果想让你自己的智能体使用正在运行的应用的工具，而不是它的代码，请参阅[外部智能体](/docs/external-agents)。

## 提出你的第一个修改

应用运行后，请让智能体做一个小修改，并看着它工作。下面是几个示例：

```markdown
添加一个名为 list-notes 的动作，让它返回一个空列表，然后在新的
/notes 页面上显示它。
```

```markdown
修改 hello 动作，让它用 "Welcome" 而不是 "Hello" 来问候，然后为
Alex 调用它来确认。
```

```markdown
阅读关于部署应用的文档，然后告诉我需要完成哪些步骤才能把这个
应用发布到线上。
```

智能体修改的是与 UI 和应用自带智能体相同的动作。正是这种共享的动作模型，让一次修改能在所有地方生效。[核心概念](/docs/key-concepts)介绍了它们是如何组合在一起的。
