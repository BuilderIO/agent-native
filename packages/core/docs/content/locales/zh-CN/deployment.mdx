## 部署前：选择持久数据库 {#persistent-database}

每个已部署应用都需要持久 SQL 数据库。在首次生产部署前，将 `DATABASE_URL` 设置到部署环境中。如果数据库提供商需要单独的令牌，也要设置 `DATABASE_AUTH_TOKEN`。

独立应用需要稳定的 `BETTER_AUTH_SECRET`。使用签名跨应用请求的工作区需要 `A2A_SECRET`。

## 支持的部署目标

Agent-Native 支持 Node.js、Vercel、Netlify、Cloudflare、AWS Lambda 和 Deno Deploy。

有关高级设置、密钥和生产值，请参阅[部署环境变量参考](/docs/deployment-environment-variables)。
