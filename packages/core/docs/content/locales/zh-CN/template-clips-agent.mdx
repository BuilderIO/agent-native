# 与 Agent 对话

剪辑中的一切，代理都可以通过与界面相同的 actions 来访问，因此任何你能点击完成的事，也都能用简单易懂的语言请求代理完成。本页介绍代理如何查看你的屏幕、按任务分类的实用提示，以及它在哪些情况下会用到不太常见的 actions。有关概览，请参阅 [剪辑](/docs/template-clips)。

## 代理如何查看你的屏幕

打开一段录制内容时，代理确切知道是哪一段，细到你正在查看的侧边面板（评论、转录文本，或洞察），以及你暂停所在的时间戳。这就是为什么“在这里加一条评论”或“把这个修剪到精彩的部分”这样的说法，即使你不指名具体的录制内容或时间，也能被正确解析。

如果你是在浏览库，代理同样知道你在那里查看的内容：当前的文件夹、你的搜索内容，以及如果你处于选择模式，你选中了哪些录制内容。

有一件事代理无法代你完成：开始一段录制。浏览器只会在有人点击某个东西之后才会授予麦克风和屏幕的访问权限，因此“录制我的屏幕”会直接把你带到录制工具，而不是在后台无形地开始捕获。

## 按任务分类的实用提示

下面的每一条提示都会转化为针对你真实库的真实 action，与界面读写的是同一个库。这里有一个具体示例：

<Comparison>

### :blue: 你的请求

“为一次产品更新总结这个剪辑。”

### :green: 发生的事情

这是一个只读的问题。代理会读取你打开的那段录制内容的转录文本，并直接在聊天中回答。你屏幕上的内容不会发生任何变化，因为没有创建或移动任何东西。

</Comparison>

### 捕获和导入

- **“录制我的屏幕。”** 代理会为你打开录制工具。开始捕获这一步仍然需要你自己点击，因为浏览器要求这样做。
- **“导入这个 Loom 链接。”** 粘贴 URL，导入完成后这段录制内容就会加入你的库。

### 清理和整理

- **“重新生成标题和摘要。”** 代理会根据当前的转录文本重新拟定两者。
- **“添加章节。这一段比较长。”** 章节标记会立即出现在时间轴上。
- **“修正 1:42 处转录错误的单词。”** 代理会就地修正转录文本。
- **“找到我们讨论推出计划的剪辑。”** 一个只读的问题。代理会在你库中的每一份转录文本中进行搜索，并在聊天中回答。

### 编辑

_打开一段录制内容时，“这个”会被解析为你正在查看的那个剪辑。_

- **“修剪掉前 10 秒。”** 这个剪切会立即出现在时间轴上，在你导出之前不会重新编码任何内容。
- **“去掉那些嗯啊之类的口头语，然后重新拼接。”** 代理会在转录文本中找到这些填充词，并应用同样的修剪方式。
- **“把这三个剪辑按这个顺序合并成一个。”** 代理会把它们拼接在一起，同时保留转录文本和章节。

### 分享和审阅

- **“谁在观看这个剪辑？”** 一个只读的问题。代理会给出观看次数作为回答，并区分是人还是其他读取转录文本的代理。
- **“把这个分享给设计团队，仅限查看。”** 该录制内容的可见性和访问权限会立即更新。

</Cards>

## 不太常见的 actions

并不是每一项剪辑功能都是代理预先加载好的一流 action。Rewind 的屏幕记忆 actions 就是一个很好的例子，因为它们只在你开启 Rewind 之后才有意义。当一个请求需要用到其中之一时，代理会先按名称搜索合适的工具，然后再调用它，就像你可能会搜索一个命令面板，而不是记住每一个快捷键。对于超出日常库和编辑任务范围的请求，你通常会注意到这里会有一个短暂的停顿。
