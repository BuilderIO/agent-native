# 编辑器与画布

编辑器和画布是相关的产品表面，不应把其中任何一个作为唯一旗舰功能。

| 表面         | 当前归属                                                    |
| ------------ | ----------------------------------------------------------- |
| 富文本编辑器 | 归 Toolkit，Core 保留兼容性重导出。                         |
| Blocks       | 本阶段仍归 Core。                                           |
| Design       | 带有 `design-tweaks` 的模板模式，并非完整的即插即用编辑器。 |
| 画布呈现     | Toolkit 或应用的组合。                                      |

请从 `@agent-native/toolkit/editor` 导入编辑器。旧 Core 路径继续作为兼容性重导出。架构、命令和持久化仍由应用负责。Blocks 仍归 Core，但 Toolkit 栏目是可复用 UI 的统一目录，因此文档集中在这里。

Core负责Blocks架构和运行时契约；Toolkit提供可复用的客户端UI。Context X-Ray引擎和actions归Core所有；Toolkit界面从app/context-xray导出。.

## 画布交互和注释

Toolkit提供手势和快捷键的无界面辅助工具，以及用于绘图和文字指令的DrawOverlay、用于可发送给智能体的锚定反馈的CanvasCommentPins。画布模型、渲染、持久化和智能体上下文由应用负责。
