# Démarrage

Les applications Agent-Native donnent à l’agent et à l’interface utilisateur les
mêmes [actions](/docs/actions), données SQL et état de l’application. Ce parcours
pratique commence par le chat, puis ajoute une action et une page. SQL est déjà
configuré dans Chat et devient une étape facultative lorsque les résultats
doivent être conservés.

<Steps>

### Créer une application Chat et configurer un agent

Créez le modèle Chat, installez les dépendances, démarrez le serveur de
développement et configurez un agent. Vous disposerez d’une application Chat
fonctionnelle à étendre.
**Vous êtes ici.**

### Ajouter une action

Définissez un analyseur de texte typé et affichez son résultat sous forme de
graphique dans le chat.

### Ajouter une page

Créez une route React qui appelle la même action en dehors de la transcription.

### Conserver les données dans SQL (facultatif)

Ajoutez une table et des actions de persistance lorsque les résultats doivent
survivre aux conversations.

</Steps>

## 1. Créer une application Chat {#create-your-app}

Vous aurez besoin de [Node.js 22+](https://nodejs.org) et de [pnpm](https://pnpm.io).

Ouvrez un terminal, accédez au répertoire dans lequel vous voulez créer votre
application Agent-Native, puis exécutez :

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

L’application s’ouvre à `http://localhost:8080`. Si l’écran de connexion
s’affiche, inscrivez-vous avec des identifiants fictifs. Le développement local
ne nécessite pas de vérification de l’adresse e-mail.

Le modèle Chat inclut des fils de discussion persistants, l’authentification, la
synchronisation en direct, un répertoire `actions/` et les actions standard
`view-screen` et `navigate`.

### Choisir un autre point de départ

Si Chat n’est pas le bon point de départ, exécutez `create` sans
`--template` et choisissez une autre option dans la CLI. Consultez [Création de modèles](/docs/creating-templates)
pour découvrir les autres possibilités.

## 2. Configurer un agent {#connect-ai}

Le modèle Chat ouvre directement la surface de chat. Si l’agent ne répond pas
encore, ouvrez **Paramètres > Gérer l’agent** ou utilisez **Cmd/Ctrl+K > Gérer l’agent**
pour configurer un modèle et un fournisseur.

Une fois que l’agent répond, passez à [Ajouter une action](/docs/getting-started-actions).
