# Déployer une application

Consultez le [guide complet en anglais pour déployer une application](/docs/deploy-an-app) pour les étapes et les commandes de chaque fournisseur.

Commencez par le [guide de démarrage](/docs/getting-started). Avant le déploiement, définissez `DATABASE_URL` dans les paramètres d’environnement de l’hébergeur, pas seulement dans le `.env` local. Générez un `BETTER_AUTH_SECRET` stable avec `openssl rand -hex 32` et enregistrez-le au même endroit. **Continue as local dev** est réservé au développement local ; l’application déployée utilise l’inscription et la connexion. Choisissez [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Amplify](/docs/aws-amplify), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) ou [Render](/docs/render).

Pour plusieurs applications sous une même origine, utilisez [Déployer un workspace](/docs/workspace-deployment).
