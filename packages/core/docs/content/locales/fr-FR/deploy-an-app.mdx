# Déployer une application

Consultez le [guide complet en anglais pour déployer une application](/docs/deploy-an-app) pour les étapes et les commandes de chaque fournisseur.

Avant le déploiement, configurez une base SQL persistante et un `BETTER_AUTH_SECRET` stable. Choisissez [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) ou [Render](/docs/render).

Pour plusieurs applications sous une même origine, utilisez [Déployer un workspace](/docs/workspace-deployment).
