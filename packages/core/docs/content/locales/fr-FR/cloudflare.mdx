# Cloudflare

## Cloudflare Workers {#cloudflare-workers}

Utilisez la sortie native en module de Nitro pour un Cloudflare Worker. Cela garde
le SSR activé et émet le point d'entrée du Worker plus les assets statiques sous
`.output/server` et `.output/public` :

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Construisez et déployez le Worker généré avec Wrangler :

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

Vous pouvez aussi sélectionner le préréglage explicitement avec
`NITRO_PRESET=cloudflare_module`. Configurez une base de données PostgreSQL externe
durable avant de déployer. Un système de fichiers de Worker n'est pas un magasin
d'application persistant.
