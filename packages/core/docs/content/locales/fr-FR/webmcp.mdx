# WebMCP

WebMCP est une API expérimentale du navigateur qui permet aux pages
d'enregistrer des outils qu'un agent autorisé peut découvrir et exécuter.
Consultez le [guide WebMCP en anglais](/docs/webmcp) pour l'enregistrement,
la consommation, les sessions du navigateur et les limites de sécurité.
Chaque exécution nécessite une approbation humaine et la liste active est vérifiée avant l'appel.
