# Chat

Chat est un modèle de départ pour développeurs qui veulent créer leur propre agent. Créez l'application et vous obtenez un écran de conversation fonctionnel, un historique de chats enregistré et une connexion, avec une seule action d'exemple que l'agent peut déjà utiliser. Il remplace les semaines passées à brancher à la main une interface de chat, le stockage des conversations et la connexion sur un modèle, si bien que vous démarrez avec une application déployable et consacrez votre temps à ce que votre agent fait réellement.

Chat n'est pas un produit fini pour une tâche précise. Si vous n'êtes pas développeur, ou si vous voulez quelque chose de prêt à l'emploi dès aujourd'hui, commencez par [Clips](/docs/template-clips) pour les enregistrements d'écran, [Diapositives](/docs/template-slides) pour les présentations, ou [Design](/docs/template-design) pour les prototypes interactifs.

## Ce que vous obtenez

Quand vous ouvrez Chat pour la première fois, vous voyez une seule zone de message et la question « Comment puis-je vous aider ? » Posez n'importe quelle question et l'agent répond directement ici. Le reste de ce qui est inclus est volontairement réduit.

- **Un chat en pleine page.** Les conversations occupent tout l'écran, avec la zone de message centrée jusqu'à l'envoi de votre premier message.
- **Une liste de conversations.** La barre latérale liste vos chats pour que vous puissiez en démarrer un nouveau, rouvrir un ancien, le renommer, l'épingler ou l'archiver.
- **Une page Premiers pas.** Une courte page d'accueil avec des liens vers les guides pour ajouter votre première action et votre premier écran. Vous pouvez la modifier ou la remplacer.
- **Connexion et équipes.** La connexion, l'inscription et les organisations fonctionnent dès le départ.
- **Une action d'exemple.** L'agent peut déjà exécuter un exemple simple, pour que vous voyiez comment fonctionne une action avant d'écrire la vôtre.
- **Des pages d'administration.** Un visualiseur de base de données et un tableau de bord d'observabilité sont inclus, que vous les ouvriez un jour ou non.
- **De la place pour des mini-apps.** Des routes pour de petits outils isolés appelés Extensions sont incluses, mais désactivées. Un développeur peut les activer.

Chat ne contient rien de spécifique à une entreprise : pas de données prêtes à l'emploi, de tableaux de bord, de formulaires ni de connexions à des services externes. Vous les ajoutez.

## Chat dans un espace de travail multi-apps

Si vous utilisez Chat avec d'autres applications sous [Dispatch](/docs/template-dispatch), il peut servir de porte d'entrée à votre espace de travail. Une seule conversation peut atteindre les applications qui l'entourent au lieu de vivre isolément. Consultez [Chat dans un espace de travail multi-apps](/docs/template-chat-integrations) pour savoir comment fonctionne la connexion.
