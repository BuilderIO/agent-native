# Guide développeur

Cette page s'adresse à toute personne qui personnalise le modèle Clips ou l'étend : le démarrage rapide, chaque action, le modèle de données, la surface des routes, et comment y ajouter des éléments. Consultez [Clips](/docs/template-clips) pour ce que fait l'application.

## Démarrage rapide

<Steps>

### Créer l'application

```bash
npx @agent-native/core@latest create my-clips --standalone --template clips
cd my-clips
pnpm install
```

Cela nécessite [Node.js](https://nodejs.org) 22.22 ou une version ultérieure et [pnpm](https://pnpm.io) installés au préalable. Consultez [Bien démarrer](/docs/getting-started) si vous n'avez encore installé aucun des deux, ou si vous n'avez pas configuré de connexion LLM (Builder.io, une clé Anthropic/OpenAI, ou Ollama en local).

### Démarrer le serveur de développement

```bash
pnpm dev
```

L'application s'ouvre automatiquement dans votre navigateur. L'enregistrement fonctionne sans configuration supplémentaire, puisque le navigateur ou l'application de bureau capture localement. Vous ne rencontrerez une erreur que sur une action qui nécessite le stockage de fichiers ou des crédits IA avant que l'un ou l'autre soit configuré.

</Steps>

<Callout tone="info">

L'enregistrement, la transcription, et les titres/résumés IA nécessitent que le stockage de fichiers et les crédits IA soient configurés avant de fonctionner de bout en bout. Connectez Builder.io depuis **Paramètres** pour les deux à la fois (son niveau gratuit inclut des crédits IA gérés), ou connectez un stockage compatible S3 séparément et apportez votre propre clé Groq pour la transcription. Consultez [Transcription et métadonnées IA](/docs/template-clips-features#transcription-and-ai-metadata).

</Callout>

## Inventaire des actions

Chaque opération est un fichier TypeScript dans `templates/clips/actions/`, monté automatiquement sur `POST /_agent-native/actions/:name`.

### Bibliothèque et enregistrements

| Action                                                                                    | Ce qu'elle fait                                                                      |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `list-recordings`, `search-recordings`                                                    | Listing de la bibliothèque, partagé avec moi, corbeille, et limité à un espace       |
| `create-recording`, `finalize-recording`                                                  | Créer la ligne ; terminer le téléversement                                           |
| `import-loom-recording`                                                                   | Importer une vidéo Loom ou une URL MP4/WebM directe                                  |
| `update-recording`                                                                        | Titre, description, mot de passe, expiration, visibilité                             |
| `move-recording`                                                                          | Déplacer un ou plusieurs enregistrements vers un dossier ou la racine                |
| `archive-recording`, `trash-recording`, `restore-recording`, `delete-recording-permanent` | Cycle de vie : masquer, suppression réversible, annuler, ou supprimer définitivement |
| `reprocess-recording`                                                                     | Réparer un média non navigable ou figé                                               |
| `generate-filmstrip`                                                                      | Sprite d'images pour la timeline de l'éditeur                                        |
| `tag-recording`, `set-thumbnail`                                                          | Étiquetage et une image de vignette choisie manuellement                             |

### Dossiers et espaces

| Action                                            | Ce qu'elle fait                                                                   |
| ------------------------------------------------- | --------------------------------------------------------------------------------- |
| `create-folder`, `rename-folder`, `delete-folder` | Dossiers imbriqués ; en supprimer un déplace son contenu vers le niveau supérieur |

## Modèle de données

Défini dans `templates/clips/server/db/schema.ts`.

<Callout tone="warning">

Les lignes d'équipe, de membre, et d'invitation vivent dans les propres tables du framework `organizations`, `org_members`, et `org_invitations`, pas dans une table spécifique à Clips. `organization_settings` est le complément propre à Clips : couleur de marque, logo, et visibilité par défaut, une ligne par organisation. Une ancienne paire `workspaces`/`workspace_members` existe encore uniquement pour qu'une migration de démarrage unique puisse rétro-remplir les tables du framework sur un déploiement existant. Ne construisez pas de nouvelles fonctionnalités sur elles.

</Callout>

## Analyse d'une action

`create-recording-agent-link` montre des schémas qu'il vaut la peine de réutiliser dans toute action qui crée un identifiant limité : vérifier l'état réel de la ressource avant de délivrer quoi que ce soit, déléguer la création du jeton à un utilitaire partagé du framework plutôt que d'en écrire un soi-même, et dériver chaque URL dont un appelant a besoin à partir de cette même autorisation.

Recorded against every read the link produces, so the owner sees a name instead of an unidentified agent.",\n      ),\n    ttlSeconds: z\n      .number()\n      .int()\n      .positive()\n      .max(BUG_REPORT_AGENT_ACCESS_TTL_SECONDS)\n      .optional()\n      .describe(\n        "Optional scoped-link lifetime in seconds, capped at seven days. Defaults to two hours.",\n      ),\n  }),\n  readOnly: true,\n  run: async (args) => {\n    const access = await resolveAccess("recording", args.recordingId);\n    if (!access) {\n      throw new ForbiddenError(`No access to recording ${args.recordingId}`);\n    }\n\n    const recording = access.resource as {\n      id: string;\n      archivedAt?: string | null;\n      trashedAt?: string | null;\n    };\n    if (recording.archivedAt || recording.trashedAt) {\n      throw new ForbiddenError(\n        `Recording ${args.recordingId} is not shareable`,\n      );\n    }\n\n    const grant = createScopedAgentAccessGrant({\n      resourceKind: CLIP_AGENT_ACCESS_TOKEN_PREFIX,\n      resourceId: recording.id,\n      viewerEmail: getRequestUserEmail() || undefined,\n      agentLabel: args.agentLabel,\n      ttlSeconds: args.ttlSeconds ?? ## Le personnaliser

Chaque partie de l'application est du code source modifiable. Commencez ici :

- `templates/clips/actions/` — ajoutez un nouveau fichier avec `defineAction` pour exposer une nouvelle fonctionnalité à la fois à l'agent et au frontend.
- `templates/clips/app/routes/` — l'interface, listée ci-dessus.
- `templates/clips/server/db/schema.ts` — ajoutez des colonnes ou des tables avec Drizzle. Gardez le schéma compatible PostgreSQL pour que le modèle fonctionne avec PGlite en local et Postgres hébergé.
- `templates/clips/server/lib/` — les intégrations de fournisseurs : `google-calendar-client.ts`, `s3-upload-provider.ts`, `slack-oauth.ts`, `video-remux.ts`, `video-filmstrip-sprite.ts`.
- `templates/clips/AGENTS.md` — les instructions de l'agent. Mettez ce fichier à jour quand vous enseignez à l'agent de nouvelles capacités ou conventions.
- `templates/clips/.agents/skills/` — les schémas détaillés que suit l'agent. Compétences pertinentes : `recording`, `ai-video-tools`, `video-editing`, `video-sharing`, `screen-memory`.
- `templates/clips/shared/api.ts` — les types TypeScript partagés utilisés à la fois par le serveur et le client.
- `templates/clips/desktop/` et `templates/clips/chrome-extension/` — des paquets séparés pour les surfaces de capture natives, chacun avec son propre `package.json` et sa propre compilation.

Si vous ajoutez une fonctionnalité, n'oubliez pas de mettre à jour les quatre domaines : l'interface, l'action, la compétence ou l'entrée AGENTS.md, et tout état d'application dont l'agent a besoin. C'est ce qui maintient l'agent et l'interface à parité.
