# Portal

Portal associe un ordinateur pour exécuter le travail entre appareils. Ouvrez **Paramètres → Espace de travail → Associer ou réparer** et conservez le jeton de l’appareil dans `~/.agent-native/remote-device.json` sur l’ordinateur.

Les modes d’exécution sont **Local**, **Computer** et **Cloud**. **Cloud** est en liste d’attente et ne démarre aucune exécution avant l’activation de l’accès.
