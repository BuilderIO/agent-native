# Collecte anonyme Clips

Ce flux permet à un visiteur d'envoyer un enregistrement privé sans se connecter à Clips. Le produit de confiance crée le lien de collecte. Ce lien reste séparé des liens de lecture de l'agent.

Si la réponse de création est perdue, la même requête signée peut être réessayée en toute sécurité après l'association de l'enregistrement ; aucun second enregistrement n'est créé.

Après l'envoi, le message de fin contient seulement l'identifiant de l'enregistrement et n'accorde pas au visiteur l'accès de lecture de l'agent. L'hôte de confiance doit ensuite utiliser `create-intake-agent-link` après authentification.

Consultez le [guide complet en anglais](/docs/template-clips-anonymous-intake) pour l'intégration, les limites de sécurité et l'auto-hébergement.
