# Collecte anonyme Clips

Ce flux permet à un visiteur d'envoyer un enregistrement privé sans se connecter à Clips. Le produit de confiance crée le lien de collecte. Ce lien reste séparé des liens de lecture de l'agent.

Consultez le [guide complet en anglais](/docs/template-clips-anonymous-intake) pour l'intégration, les limites de sécurité et l'auto-hébergement.
