# フォーム

フォームは、コードを書かずに情報を集めたい人のためのフォームビルダーです。サインアップ、フィードバック、登録、アンケートなどに使えます。欲しいフォームをエージェントに説明し、より直接的な制御をしたいときはビジュアルエディターで微調整し、誰でも記入できるリンクを公開しましょう。

## 置き換えるもの

<Comparison>

### 導入前

- 回答を集めるために Typeform、Google Forms、または自作のフォームを使う
- 新しい送信を手作業で Slack やスプレッドシートにコピーする
- 届いた内容を要約するためだけの別のツール
- Sheets や webhook に回答を送るために Zapier の自動化を設定する

### 導入後

- エージェントとビジュアルエディターの両方が更新する 1 つのフォーム
- 新しい回答は届いた瞬間に Slack、Discord、Sheets、または webhook へ送られる
- 要約を頼めば、別のツールなしでチャートやテーブル、あるいはその両方が返ってくる
- 条件付きフィールド、スパム保護、匿名モードはすべて同じビルダーに組み込まれている

</Comparison>

## マルチアプリ ワークスペースでのフォーム

[Dispatch](/docs/template-dispatch) のもとで他のアプリと一緒にフォームを動かしている場合、フォームは単に手作業で開くページではなくなります。フォームのエージェントは他のアプリに関する質問を引き継ぐことができ、他のアプリはフレームワーク自体のフィードバックボタンと同じ方法で、あなたのフォームに直接回答を送信できます。この仕組みについては [マルチアプリ ワークスペースでのフォームのクロスアプリ利用](/docs/template-forms-integrations) を参照してください。

## それを使って何ができるか

- **会話形式でフォームを作成する。** 「連絡先フォームを作成して」「NPS スコアの質問を追加して」「メールフィールドを必須にして」のようなプロンプトを試してみてください。[利用できるフィールドタイプ](/docs/template-forms-features#field-types) も参照してください。
- **視覚的に微調整する。** より直接的な制御をしたいときは、フォームビルダーでラベル、プレースホルダー、必須項目、選択肢、フィールドの順序を直接編集できます。
- **公開フォームを公開して保護する。** 公開リンクを共有し、必要に応じてスパム保護や完全な匿名回答をオンにできます。[機能](/docs/template-forms-features) を参照してください。
- **回答を確認し、分析を依頼する。** 「今週の送信を要約して」「送信を日別にチャートにして」のようなプロンプトを試してみてください。[機能](/docs/template-forms-features#response-insights) を参照してください。
- **送信を自動的にルーティングする。** Slack、Discord、Google Sheets、または汎用の webhook の URL を貼り付ければ、新しい回答は届いた瞬間にそこへ送られます。
