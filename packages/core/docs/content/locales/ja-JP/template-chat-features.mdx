# 機能

Chat に付属するすべての機能について、その仕組みと設定方法を説明します。概要は
[Chat](/docs/template-chat) を、試せるプロンプトは
[Agent との対話](/docs/template-chat-agent) を参照してください。

## 会話

サインインすると、Chat はメッセージ ボックスといくつかのリンクがある **はじめに** ページで開きます。そこでメッセージを送ると、会話が全画面で開きます。**新しいチャット** は、「どのようにお手伝いできますか？」という見出しの下で新しい会話を始めます。ボックスは最初のメッセージを送るまで中央にあり、会話が長くなるにつれて下に移動します。

サイドバーには、会話が 2 つのグループで並びます。**ピン留め** したチャットは上部に
残り、**最近** にはそれ以外がすべて新しい順に表示されます。まだ処理中のチャットは
タイトルの横にスピナーが表示されるので、最初の会話を見失わずに別の会話を始められます。

- **新しいチャットを始める** には、サイドバー上部の **新しいチャット** を使います。
- **開き直す** には、一覧からチャットを選択します。
- **名前の変更、ピン留め、アーカイブ** は、その行のオプション メニューから行います。
  アーカイブすると一覧から消えます。
- **サイドバーを折りたたむ** と、会話により多くの余裕ができます。

<Steps>

### チャットの名前を変更する

チャットの行でオプション メニューを開き、**チャット名を変更** を選びます。新しい
タイトルを入力して Enter キーを押します。タイトルは最大 160 文字です。

### よく戻るチャットをピン留めする

同じメニューから **チャットをピン留め** を選びます。**チャットのピン留めを解除** を
選ぶまで、そのチャットは **ピン留め** に移動します。

### 終わったチャットをアーカイブする

**チャットをアーカイブ** を選びます。アーカイブに失敗した場合はメッセージが表示され、
チャットはそのままの場所に残ります。

</Steps>

## モデルを接続する

エージェントが答えるにはモデルが必要です。接続されるまで、メッセージ ボックスには
「AI に接続してチャットを開始...」と表示されます。無料クレジットを使うには
**Builder.io を使用** を、お持ちのプロバイダー キーを使うには **独自のキーを追加** を
選択します。すると、エージェントはすぐに答えられるようになります。

後からモデルを変更するには、**設定** を開いて **モデル** を選びます。そのページで、
既定のモデルと、アプリが使えるプロバイダーを設定します。

<Callout tone="info">

Chat はモデルを代わりに選ぶことはありません。選べるモデルは、接続したプロバイダー
によって異なります。

</Callout>

## 音声入力

メッセージ ボックスにはマイクのボタンがあります。選択すると、入力する代わりに
メッセージを音声で口述でき、ほかのメッセージと同じように送信できます。言語と口述の
オプションは **設定 → 環境設定** にあります。

## サンプル action

Chat には、**hello** というサンプル action が 1 つ含まれています。action とは、
誰かにあいさつする、メモを作成する、レコードを調べるなど、アプリができる 1 つの
ことです。各 action には、名前、何をするかの説明、実行に必要な詳細があります。
エージェントはそれらの説明を読んで、あなたのリクエストにどの action を使うかを
決めます。

「Alex に対して hello action を呼び出して」のように、エージェントに誰かへのあいさつを
頼むと、その名前で hello を実行し、結果を表示します。これは、自分で action を書く前に、
あなたのメッセージから、エージェントが action を実行して返ってきたものを表示するまでの
全体のループを一度見られるようにするためのものです。

actions は、Agent-Native アプリの共有サーフェスです。エージェントが使い、
アプリ自身の画面からも使えるので、新しい action は追加の設定なしに両方の場所で
動作します。アプリが成長するにつれて、開発者が独自の actions を追加します。仕組みは
[Actions](/docs/actions-overview) を、書き方は [Actions の定義](/docs/actions-defining)
を参照してください。

## 設定でエージェントを調整する

**設定** を開き、**エージェント** グループを見てください。これらのページが、すべての
チャットでエージェントがどのように振る舞うかを制御します。

| ページ               | 制御するもの                                                                  |
| -------------------- | ----------------------------------------------------------------------------- |
| **モデル**           | 既定のモデルとプロバイダー キー。                                             |
| **指示**             | すべてのチャットでエージェントが従う常設のガイダンス。                        |
| **パーソナライズ**   | あなた自身のカスタム指示とメモリの設定。                                      |
| **メモリ**           | エージェントが学習し、チャットをまたいで覚えていること。                      |
| **スキル**           | ある種類のタスクのためにエージェントが読み込める再利用可能なハウツー ガイド。 |
| **ファイル**         | エージェントが読める参照ファイル。                                            |
| **サブエージェント** | メインのエージェントが作業を引き渡せるヘルパー エージェント。                 |

**接続** グループには **連携** と **API キー** があり、**アカウント** グループには
**プロフィール**、**環境設定**、**セキュリティ** があります。

<Steps>

### 設定を開く

サイドバー下部の検索ボタンを選択し、**設定** を選びます。

### ページを選ぶ

左側の一覧からページを選びます。変更は次のメッセージから適用されます。

</Steps>

## サインインとチーム

Chat ではサインインが必要です。ログイン、サインアップ、セッションは最初の実行から
設定されており、サインイン方法、メンバー、ロールは設定の **組織** グループで管理します。

サイドバー下部の組織スイッチャーには、現在作業している組織が表示され、切り替えも
できます。ワークスペースごとに組織は 1 つにして、人はメンバーとしてそこに追加して
ください。接続した認証情報は組織ごとに保存されるため、2 つ目の組織からは、最初の
組織で接続したキーは見えません。

## データベースと可観測性

Chat には 2 つの管理ページが付属しています。サイドバーからはリンクされていないため、
アドレスを指定して開きます。

- `/database` の **Database** は、アプリのテーブルを表示し、エージェントとアプリが
  保存した行を閲覧できます。
- `/observability` の **Observability** は、エージェントがこれまでに行ってきたことを、
  概要、会話、評価、実験、フィードバックのタブで表示します。

どちらもアプリを運用する人向けです。開くかどうかにかかわらずマウントされています。

## ミニアプリ

Chat は、計算機やチェックリストのような、サンドボックス化された小さなツールである
**拡張機能** を実行できます。Chat ではオフになっています。設定に拡張機能のページはなく、
エージェントもそれらを作成できません。開発者は 2 か所でオンにします。それが何で、
どう有効にするかは [拡張機能](/docs/extensions) を参照してください。
