# Agent との対話

フォームのすべての機能は、UI が使うのと同じ actions を通じてエージェントも利用できるので、クリックできることは何でも、平易な言葉で頼むこともできます。このページでは、エージェントがあなたの画面をどう見ているかと、タスク別の便利なプロンプトを説明します。概要は [フォーム](/docs/template-forms) を参照してください。

## エージェントがあなたの画面をどう見ているか

エージェントは常に、ブラウザのタブ単位で、どのフォームやビューを開いているかを把握しています。あるタブで 1 つのフォームを開き、別のタブで回答一覧を開いていれば、エージェントはそれらを区別して扱います。だからこそ、フォームを名指ししなくても「このフォームに必須の NPS 質問を追加して」や「これには何件回答がありますか」と頼めます。エージェントはすでにどれのことか分かっています。フォームの回答を見ているときは、エージェントはあなたが見ることを許可されている範囲で、その回答のプレビューも見ることができます。

## タスク別の便利なプロンプト

以下のプロンプトはすべて、UI が読み書きしているのと同じ、あなたの実際のフォームに対する本物の action になります。まずは 1 つの実例を見てみましょう。

<Comparison>

### :blue: あなたが尋ねる

「役割、チームの規模、優先ユースケースを含むベータ登録フォームを作成して。」

### :green: 何が起こるか

これは新しいものを作成します。エージェントはそれらのフィールドをすでに備えたフォームを作成し、すぐにあなたのフォーム一覧に表示されます。微調整や公開の準備が整った状態です。ページの再読み込みは不要です。新しいフォームはそこにあるだけです。

</Comparison>

<Cards columns={2}>

### 作成

- **「役割、チームの規模、優先ユースケースを含むベータ登録フォームを作成して。」** 新しいフォームはすぐにあなたのフォーム一覧に表示され、微調整の準備が整います。
- **「必須の NPS 質問と自由記述のフォローアップを追加して。」** フィールドはすぐにフォームに表示されます。
- **「ルーティングに必要なフィールドを失わずに、このフォームを短くして。」** エージェントは、送信先が依存しているフィールドを残しながらフォームを削っていきます。

### 公開と保護

- **「これを公開してリンクをください。」** フォームが公開され、すぐに公開 URL が渡されます。
- **「匿名のカスタマーフィードバックフォームを作成して、公開リンクをください。」** フォームは最初から匿名で公開されるので、送信者情報は一切記録されません。
- **「このフォームの送信を https://example.com からだけ許可して。」** フォームはそれ以外からの送信を拒否し始めます。これは今日時点ではエージェントに頼むしかできません。ビルダーにはこのためのトグルがありません。

### 回答と分析

- 「ベータ登録フォームの回答は何件ありますか?」
- 「今日誰が送信しましたか?」
- 「今週の送信を要約して、顧客セグメントごとにグループ化して。」
- 「送信を日別にチャートにして。」
- 「今月、すべてのフォームで送信はどう推移していますか?」
- 「これを CSV にエクスポートして。」

### ルーティング

- **「新しい回答をすべてプロダクト Slack チャンネルに投稿して。」** 送信先が接続されると、新しい回答は届いた瞬間に Slack に表示され始めます。
- 「ベータ登録フォームの設定はどうなっていますか?」
