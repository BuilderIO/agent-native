# エントリーポイント

`app/entry.client.tsx` はサーバーでレンダリングされた HTML をブラウザでハイドレートし、`app/entry.server.tsx` はその HTML をサーバー上でレンダリングします。どちらも React Router によって生成される薄いラッパーです。これらを編集する必要はほとんどありません。

```ts filename="app/entry.server.tsx"
import {
  createDocumentRequestHandler,
  streamTimeout,
} from "@agent-native/core/server/entry-server";
import { ServerRouter } from "react-router";

export default createDocumentRequestHandler(ServerRouter);
export { streamTimeout };
```

これらに手を伸ばすのは、ストリーミングの振る舞いの変更など、高度な SSR のカスタマイズのためだけにしてください。通常のページ、レイアウト、データにはここでの変更は不要です。ページを追加する場合は、代わりに [Routing](/docs/client-routing) を参照してください。
