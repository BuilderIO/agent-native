# コンテンツ

コンテンツはオープンソースの Obsidian for MDX です。ローカルファイルに親和性の高いドキュメントワークスペースで、エージェントがあなたに代わってページを読み取り、書き込み、再編成し、公開できます。ドキュメントを開いて「この段落をもっと簡潔に書き直して」と頼んだり、「目標、指標、リスクのサブページを持つ『第 4 四半期計画』というページを作成して」と頼んだりできます。自分で行っても、エージェントに頼んでも、結果は同じです。

## 置き換えるもの

<Comparison>

### Before

- 個人的なメモのための Obsidian、またはローカルの Markdown ファイルフォルダー
- チームで閲覧できるドキュメントのための、独立した Notion ワークスペース
- 本番サイトに公開するものすべてのためのヘッドレス CMS
- いずれかが古くなるたびに、3 つの間でコンテンツを手作業でコピーする作業

### After

- 個人用ページ、チームドキュメント、公開済みコンテンツをまとめて扱える 1 つのワークスペース
- 同じドキュメントをローカルファイル、Notion、Builder CMS のいずれにも同期でき、それぞれに書き直す必要がない
- エージェントは、あなたと同じアクション、同じページを通じて読み書きする
- 外部ソースからの変更は、無断で上書きされることなく、レビュー可能な変更セットとして反映される

</Comparison>

ドキュメントはデフォルトで非公開で、閲覧者 / 編集者 / 管理者による共有と、外部に公開したいときのための公開読み取り専用モードを備えています。複数の人(とエージェント)が、互いの変更を上書きすることなく同時に同じページを編集できます。それぞれの詳細については、[ドキュメントの作成と整理](/docs/template-content-editing)、[データベース、プロパティ、フォーム](/docs/template-content-databases)、[ローカルファイル、Notion、Builder CMS の同期](/docs/template-content-sync)を参照してください。

## はじめる {#get-started}

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

インストール、初回起動、LLM との接続については、[開発者ガイド](/docs/template-content-developers#quick-start) を参照してください。

アプリを開いたら、サイドバーの **+ 新しいページ** をクリックしてタイトルを付けて書き始めるか、エージェントに直接頼んでみましょう。

- 「オンボーディングというページを作成して、その下に 3 つのサブページを追加して」
- 「この段落をもっと簡潔に書き直して」(ページを開いた状態で)
- 「Notion から最新の内容を取得して」(Notion ページをリンクした後)

テキストを選択して Cmd+I を押すと、その選択内容があらかじめ読み込まれた状態でエージェントにフォーカスが移ります。そこで「もっとインパクトのある文章にして」と頼めば、ハイライトした部分だけに対して処理が行われます。
