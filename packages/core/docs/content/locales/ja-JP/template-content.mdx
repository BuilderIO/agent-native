# コンテンツ

コンテンツはオープンソースの Obsidian for MDX です。ローカルファイルに親和性の高いドキュメントワークスペースで、エージェントがあなたに代わってページを読み取り、書き込み、再編成し、公開できます。ドキュメントを開いて「この段落をもっと簡潔に書き直して」と頼んだり、「目標、指標、リスクのサブページを持つ『第 4 四半期計画』というページを作成して」と頼んだりできます。自分で行っても、エージェントに頼んでも、結果は同じです。

## それを使って何ができるか

- **ドキュメントを作成し、整理する。** リッチテキスト編集、無限にネストできるページツリー、お気に入り、コメント、バージョン履歴、共有に対応しています。詳しくは[ドキュメントの作成と整理](/docs/template-content-editing)を参照してください。
- **Notion スタイルのデータベースを構築する。** 各行がそれぞれ独立したドキュメントになっているテーブルで、型付きプロパティとテーブル/リスト/ギャラリー/ボード/カレンダー/タイムライン/フォームの各ビューに対応しています。詳しくは[データベース、プロパティ、フォーム](/docs/template-content-databases)を参照してください。
- **構造化された送信内容を収集する。** データベースを、エージェントや Slack、他のアプリから安全に送信できるインテークフォームに変えられます。詳しくは[データベース、プロパティ、フォーム](/docs/template-content-databases)を参照してください。
- **Obsidian のようにディスク上のファイルを編集し**、Notion や Builder CMS とドキュメントを同期させ続けられます。詳しくは[ローカルファイル、Notion、Builder CMS の同期](/docs/template-content-sync)を参照してください。
- **リアルタイムで共同編集する。** 複数の人(とエージェント)が、互いの変更を上書きすることなく同時に同じドキュメントを編集できます。
- **ドキュメントを共有する**。チームメイトと共有したり、公開したりできます。デフォルトでは非公開で、閲覧者 / 編集者 / 管理者のロールを設定できます。
- **エージェントに何でも頼んでみましょう**。「この段落を書き直して」「先頭に TL;DR を追加して」「先週のミーティングメモを全部探して」「Slack から送信できるベータ登録用のデータベースを作成して」など。

## はじめに

ライブデモ: [content.agent-native.com](https://content.agent-native.com)。

アプリを開いたら、サイドバーの **+ 新しいページ** をクリックしてタイトルを付け、書き始めましょう。エージェントを使うには、サイドバーに次のように入力します。

- 「オンボーディングというページを作成して、その下に 3 つのサブページを追加して」
- 「この段落をもっと簡潔に書き直して」(ページを開いた状態で)
- 「料金についてのセクションを、3 つの箇条書きで追加して」
- 「このドキュメントを先頭の TL;DR にまとめて」
- 「Notion から最新の内容を取得して」(Notion ページをリンクした後)

テキストを選択して Cmd+I を押すと、その選択内容があらかじめ読み込まれた状態でエージェントにフォーカスが移ります。そこで「もっとインパクトのある文章にして」と頼めば、ハイライトした部分だけに対して処理が行われます。

自分用のコンテンツのコピーを作成するには:

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

残りのセットアップ手順(`cd`、`pnpm install`、`pnpm dev`)とフレームワークの基礎については、[はじめに](/docs/getting-started) を参照してください。
