# チャット

チャットは、最もプレーンなエージェントネイティブの出発点です。中央にチャット、スレッドリスト、認証、そして 1 つのサンプル action を備えた ChatGPT スタイルのシェルで、ドメイン固有の要素は何もありません。特定の業務向けの完成したプロダクトではなく、独自のエージェントと画面をその上に構築するための、実際にデプロイ可能なアプリを求める開発者向けです。

完成したドメイン プロダクトの形が必要な場合は、[カレンダー](/docs/template-calendar)、[メール](/docs/template-mail)、[Content](/docs/template-content)、[Forms](/docs/template-forms)、[Analytics](/docs/template-analytics)、または他のドメイン テンプレートから始めてください。ブラウザ UI がまだ本当に不要な場合は、[Automation-First Apps](/docs/pure-agent-apps) を参照してください。

## 同梱内容 {#what-ships}

<Comparison>

### :green: 含まれるもの

- フレームワークのチャット サーフェスと耐久性のあるチャットスレッドを使った、
  `/` 上のフルページチャット
- チャットの作成、再開、名前変更、固定、アーカイブができる、アプリ サイドバーの
  スレッドリスト
- チャット プラグイン用に事前設定された、組み込みのアプリエージェント ループ
- Better Auth による認証: ログイン、サインアップ、セッション、組織
- 1 つの例 (`actions/hello.ts`) と標準の `view-screen` および `navigate`
  action を含む actions ディレクトリ
- チャットスレッド、アプリケーションの状態、設定、セッション、リソース、実行
  履歴のためのフレームワークのコアテーブル。加えて、開くかどうかにかかわらず
  マウントされる Database 管理ページと Observability ダッシュボード
- エージェントが SQL に書き込むと UI が更新されるように、すでに接続されている
  ライブ同期 (`useDbSync`)
- ユーザーが後でチャット内に構築する、サンドボックス化されたミニアプリのために、
  既定でマウントされている拡張機能ルート
- action、ルート、skill、アプリケーションの状態を追加するための、
  チャットファーストのガイダンスを含む AGENTS.md

### :red: 含まれないもの

- ドメインテーブルやシードデータ
- ダッシュボード、リスト、グラフ、フォーム、プロバイダー統合
- サンプルのスタブを超えるドメイン固有の action

</Comparison>

## いつ選択するか {#when-to-pick}

- **ユーザーがすぐに話しかけられる基本的なアプリが欲しい**。その後 action と
  UI で拡張していきます。
- **Agent-Native の既定のオンランプが欲しい**: まずチャット、その後 action、
  ネイティブな結果、そしてアプリ ページへと進みます。
- **使い慣れたチャット UI に独自のエージェント バックエンドを組み込みたい**。
  一方で、Agent-Native の action、状態、認証、デプロイの形は維持したい。
- **ドメイン テンプレートに当てはまらないカスタムの社内ツール**を
  プロトタイピングしている。

## 使い始める {#get-started}

```bash
npx @agent-native/core@latest create my-chat-app --standalone --template chat
```

インストール、初回起動、LLM への接続については
[チャット: 開発者ガイド](/docs/template-chat-developers#quick-start) を
参照してください。ブラウザ UI を一切使わないオートメーション優先の作業には、
代わりに `--headless` でスキャフォールドしてください。

```bash
npx @agent-native/core@latest create my-agent --headless
```

チャットやアプリ ページがまだ役に立たない、スケジュールされたジョブ、キュー、
CLI ループ、外部エージェント ワークフローに使ってください。重要な不変条件は
変わりません。action は チャット、UI、HTTP、MCP、A2A、CLI の共有サーフェスです。
このパスの詳細については [Automation-First Apps](/docs/pure-agent-apps) を
参照してください。

## 次は何ですか

- [**チャットで最初の機能を追加する**](/docs/template-chat-first-edits) —
  注釈付きのスターター チャット ルートと、実際の機能を追加する完全な
  ウォークスルー
- [**チャット: 開発者ガイド**](/docs/template-chat-developers) —
  クイックスタート、action、コアテーブル、認証、そして既定で同梱される管理ページ
- [**はじめに**](/docs/getting-started) — action からインライン結果、アプリ
  ページへと進む、チャットファーストのパスを構築します
- [**テンプレート**](/docs/cloneable-saas) — Cloneable SaaS モデルと、代わりに
  始められるすべてのドメイン テンプレート
- [**エージェント サーフェス**](/docs/agent-surfaces) — チャット、インライン
  UI、アプリ ページ、埋め込み、オートメーション、外部エージェントのパターン
- [**Actions**](/docs/actions-overview) — チャットと UI の両方が呼び出す
  action システム
- [**Native チャット UI**](/docs/native-chat-ui) — チャット サーフェスの
  プリミティブとランタイム オプション
- [**Automation-First Apps**](/docs/pure-agent-apps) — ジョブ、キュー、
  スクリプト、外部エージェント向けの、ブラウザを使わないワークフロー
