# Chat

Chat は、独自のエージェントを作るための開発者向けスターターです。アプリを作成すると、動作する会話画面、保存されるチャット履歴、サインインが手に入り、エージェントがすでに使えるサンプル action が 1 つ付いています。チャット インターフェース、会話の保存、ログインを手作業でモデルに結び付けるのに何週間もかかる作業を省けるので、デプロイ可能なアプリから始めて、エージェントが実際に何をするかに時間を使えます。

Chat は特定の仕事向けの完成品ではありません。開発者ではない場合や、今日すぐ使えるものが欲しい場合は、画面録画なら [Clips](/docs/template-clips)、スライド資料なら [Slides](/docs/template-slides)、インタラクティブなプロトタイプなら [Design](/docs/template-design) から始めてください。

## 付属するもの

サインインすると、Chat はメッセージ ボックスのある「はじめに」ページで開きます。何を聞いても、エージェントが全画面の会話で答えます。そのほかに含まれるものは、意図的に最小限です。

- **フルページのチャット。** 会話は画面全体を使い、最初のメッセージを送るまでメッセージ ボックスは中央に表示されます。
- **会話の一覧。** サイドバーにチャットが並び、新しく始めたり、古いものを開き直したり、名前を変更したり、ピン留めしたり、アーカイブしたりできます。
- **Get started ページ。** 最初の action と最初の画面を追加するためのガイドへのリンクがある、短いランディング ページです。編集することも、置き換えることもできます。
- **サインインとチーム。** ログイン、サインアップ、組織が最初から動作します。
- **サンプル action が 1 つ。** エージェントはすでに簡単なサンプルを実行できるので、自分で書く前に action の仕組みを確認できます。
- **管理ページ。** データベース ビューアーと可観測性ダッシュボードが含まれており、開くかどうかにかかわらず利用できます。
- **ミニアプリのための余地。** 拡張機能と呼ばれる、サンドボックス化された小さなツール用のルートが含まれていますが、オフになっています。開発者はそれらをオンにできます。

Chat には、ビジネス固有のものは含まれていません。用意されたデータ、ダッシュボード、フォーム、外部サービスへの接続はありません。それらは自分で追加します。

## マルチアプリ ワークスペースでの Chat

[Dispatch](/docs/template-dispatch) のもとで他のアプリと一緒に Chat を動かしている場合、Chat はワークスペースの玄関口として機能できます。1 つの会話が単独で完結するのではなく、周囲のアプリに手を伸ばせます。この連携がどのように機能するかについては、[マルチアプリ ワークスペースでの Chat](/docs/template-chat-integrations) を参照してください。
