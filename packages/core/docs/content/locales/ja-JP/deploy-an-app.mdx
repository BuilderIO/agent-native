# アプリをデプロイ

手順とプロバイダーごとのコマンドは、[英語の完全なアプリデプロイガイド](/docs/deploy-an-app)を参照してください。

デプロイ前に永続 SQL データベースと安定した `BETTER_AUTH_SECRET` を設定します。[Node.js と Docker](/docs/node-docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare](/docs/cloudflare) からターゲットを選択できます。

複数のアプリを 1 つのオリジンで実行する場合は、[ワークスペースのデプロイ](/docs/workspace-deployment)を使用してください。
