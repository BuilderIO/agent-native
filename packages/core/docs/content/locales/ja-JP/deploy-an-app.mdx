# アプリをデプロイ

手順とプロバイダーごとのコマンドは、[英語の完全なアプリデプロイガイド](/docs/deploy-an-app)を参照してください。

[はじめに](/docs/getting-started)から始めます。デプロイ前に`DATABASE_URL`をローカル`.env`だけでなく、ホスティングプロバイダーの環境設定に保存してください。`openssl rand -hex 32`で安定した`BETTER_AUTH_SECRET`を生成し、同じ場所に保存します。**Continue as local dev**はローカル専用です。デプロイ済みアプリではサインアップとサインインを使います。[Node.js](/docs/node-js)、[Docker](/docs/docker)、[Vercel](/docs/vercel)、[Netlify](/docs/netlify)、[Cloudflare Pages](/docs/cloudflare#cloudflare-pages)、[Cloudflare Workers](/docs/cloudflare#cloudflare-workers)、[AWS Amplify](/docs/aws-amplify)、[AWS Lambda](/docs/aws-lambda)、[Deno Deploy](/docs/deno-deploy)、[Azure Static Web Apps](/docs/azure-static-web-apps)、[Koyeb](/docs/koyeb)、[Render](/docs/render)から選択できます。

複数のアプリを 1 つのオリジンで実行する場合は、[ワークスペースのデプロイ](/docs/workspace-deployment)を使用してください。
