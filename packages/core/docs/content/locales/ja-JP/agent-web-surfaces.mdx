# 公的エージェントのウェブ

パブリック エージェント Web により、エージェントがパブリック Agent-Native ルートを簡単にクロール、読み取り、引用、呼び出しできるようになります。目標は、すべてのアプリのエンドポイントを公開することではありません。目標は、明示的な制御の背後でプライベート データとツールへのアクセスを維持しながら、すでに公開されているページのクリーンな公開面を公開することです。

ドキュメント サイトはリファレンス実装です。本日発送します:

- デフォルトで取得は許可するがトレーニングを禁止するクローラー ポリシーを備えた `/robots.txt`。
- ロケールごとに 1 つの `/sitemap-<locale>.xml` を指すサイトマップ インデックスとしての `/sitemap.xml`。ソース ファイルが公開する場合、絶対正規 URL および `lastmod` を含みます。
- エージェントフレンドリーなコンテンツ検出のための `/llms.txt` および `/llms-full.txt`。
- Markdown ミラー (`/docs/getting-started.md` など)。
- 実稼働ビルド後のパブリック ドキュメント ページに対する `Accept: text/markdown` 応答。
- 基本組織、Web サイト、ページのメタデータ用の JSON-LD。
- 上記のすべてをチェックする監査 CLI (`npx @agent-native/core@latest audit-agent-web`)。

これらのファイルを公開しても、アクションが公開されることはありません。アクションが外部エージェントに届くのは、そのアクション自身の `publicAgent` オプトインを通じてだけです。[公開エージェントに公開する](/docs/actions-access-control#public-agent)を参照してください。

## 構成 {#config}

`@agent-native/core/vite` の `createAgentWebVitePlugin` は、本番ビルド中にこれらのファイルを書き出します。エージェントに読ませたいページを指定して、Vite の設定に追加します。

```ts
// vite.config.ts
import { createAgentWebVitePlugin } from "@agent-native/core/vite";

export default defineConfig({
  plugins: [
    // ...your existing plugins
    createAgentWebVitePlugin({
      siteName: "My Agent-Native App",
      siteUrl: "https://example.com",
      pages: [
        {
          path: "/pricing",
          title: "Pricing",
          description: "Plans and limits.",
          markdown: "Plans and limits.\n",
        },
      ],
      agentWeb: { crawlerPolicy: "discoverable-no-training" },
    }),
  ],
});
```

プラグインが公開するのは、指定したページだけです。ルートのアクセス設定は読まず、`package.json` の `agentWeb` も渡さない限り読みません。設定を `package.json` の `agent-native.workspaceApp.agentWeb` に置いておくには、`@agent-native/core/agent-web` からインポートした `agentWebConfigFromPackageJson(pkg)` を `agentWeb` に渡します。

| オプション      | デフォルト                   | 動作                                                                                                                                                                      |
| --------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `discoverable`  | `pages` が空でなければオン   | `false` にするとファイルを一切書き出しません。                                                                                                                            |
| `llmsTxt`       | `true`                       | `/llms.txt` と `/llms-full.txt` を書き出します。                                                                                                                          |
| `markdownTwins` | `true`                       | `markdown` を持つ各ページの `.md` コピーを書き出します。                                                                                                                  |
| `crawlerPolicy` | `"discoverable-no-training"` | `robots.txt` のルールを設定します。`"discoverable-no-training"`、`"allow-all"`、`"disallow-all"` のいずれかです。                                                         |
| `crawlers`      | なし                         | クローラーのカテゴリを個別に上書きします。`training`、`search`、`userTriggered`、`codingAgents`、`autonomousAgents` のそれぞれに `"allow"` か `"disallow"` を指定します。 |

デフォルトのクローラーポリシーは「発見可能、学習不可」です。検索、ユーザーが起動した取得、コーディングエージェント、自律ブラウジングエージェントは許可され、学習用クローラーは拒否されます。

`jsonLd`、`publicAgentCard`、`publicMcp` は受け付けますが、今のところ何も読みません。JSON-LD が必要な場合は、`@agent-native/core/agent-web` の `buildBaseJsonLd` と `buildPageJsonLd` を自分でページに描画してください。

## 信頼できる情報源のルート {#route-source}

ページリストが唯一の情報源です。エージェントが受け取るのは渡したページだけです。すでに公開されているページからリストを作ります。

- 公開アプリでは、`protectedPaths` を除くすべてのルート。
- 内部アプリでは、`publicPaths` のみ。
- エージェントに読ませたい公開の共有ページとフォームページ。
- 送信されたプライベートデータ、認証済みダッシュボード、ユーザーや組織の状態は、近くのページが公開されていても決して含めません。

アクセス設定から始めるには、`@agent-native/core/agent-web` の `deriveAgentWebPublicRoutes` にアプリの `audience`、`publicPaths`、`protectedPaths`、`routes` を渡すと、それらの設定で公開になるルートが返ります。各ページには引き続き独自のタイトルと Markdown が必要です。

これにより、混合アプリが自然に保たれます。フォーム アプリはパブリック フォーム ページを公開し、送信内容を非公開に保つことができます。コンテンツ アプリは、公開された投稿を公開し、エディターを非公開に保つことができます。ドキュメント サイトでは、管理ツール以外のすべてを公開できます。

## 公開ページは公開ツールではありません {#public-tools}

公開ページへのアクセスと公開ツールへのアクセスは別のものです。ルートがパブリックであるということは、エージェントがそのルートを HTML、Markdown、サイトマップ エントリ、llms エントリ、および構造化データとして読み取ることができることを意味するだけです。

<Callout id="doc-block-s50w8y" tone="warning">

**公開ページは公開ツールではありません。** ルートをクロール可能にしても、アクションが公開されることはありません。ツールへのアクセスには、アクションでの明示的な `publicAgent.expose` オプトインが必要です。

</Callout>

パブリック エージェント プロトコルを通じてアクションを公開するには、アクションをオプトインする必要があります。

`agentWeb` のどの設定もアクションを公開せず、`publicMcp` は現在何の効果もありません。`publicAgent` がアクションを何に公開し、どのチェックが引き続き適用されるかは、[公開エージェントに公開する](/docs/actions-access-control#public-agent)を参照してください。

## ビルド時ファイル {#build-time}

`@agent-native/core/agent-web` のフレームワーク ユーティリティは、1 つのページ リストから共通ファイルを生成します。

```ts
import {
  buildAgentWebStaticFiles,
  normalizeAgentWebConfig,
} from "@agent-native/core/agent-web";

const config = normalizeAgentWebConfig(
  { crawlerPolicy: "discoverable-no-training" },
  { hasPublicRoutes: true },
);

const files = buildAgentWebStaticFiles({
  siteName: "My Agent-Native App",
  siteUrl: "https://example.com",
  description: "Public docs for my app.",
  config,
  pages: [
    {
      path: "/docs",
      title: "Docs",
      description: "Start here.",
      markdown: "# ドキュメント\n\nここから始めてください。\n",
      markdownPath: "/docs/getting-started.md",
      lastmod: new Date(),
    },
  ],
});
```

`createAgentWebVitePlugin` は `buildAgentWebStaticFiles` を代わりに呼び出し、`public`、`dist`、`dist/client`、`dist/server/public`、`build/client` のうち存在するフォルダーにファイルを書き出します。別のビルドツールでは、ユーティリティを直接呼び出してください。

どちらも、ページ自身の URL で `Accept: text/markdown` に応答しません。Markdown のコピーはその `.md` URL にしかありません。このヘッダーに応答するには、ドキュメントサイトと同じように、`buildMarkdownResponseHeaders` のヘッダーを付けてページの Markdown を返すサーバールートを追加します。そのルートがないと、下の監査の `Accept: text/markdown` チェックは失敗します。

大きなサイトマップを分割するには、`buildAgentWebStaticFiles` または `createAgentWebVitePlugin` に `sitemapGroup` を渡します。各ページをロケールなどのグループ キーに対応付けると、`sitemap.xml` はグループごとに 1 つの `sitemap-<group>.xml` を持つサイトマップ インデックスになります。

## サイトを監査する {#audit}

展開されたサイトまたはローカル実稼働サーバーに対して CLI 監査を使用します。

```bash
npx @agent-native/core@latest audit-agent-web --url https://www.agent-native.com
```

監査では以下がチェックされます:

- SSR - 可視 HTML。
- 正規の URL。
- JSON-LD。
- `robots.txt` ポリシーと絶対サイトマップ URL。
- 絶対サイトマップ エントリ。
- `/llms.txt` および `/llms-full.txt`。
- Markdown ミラー。
- `Accept: text/markdown`.
- 共通エージェント取得ユーザー エージェントに対して偶発的な 401/403 ブロックが発生することはありません。

必要なパブリック サーフェスが欠落している場合、監査はゼロ以外で終了します。
