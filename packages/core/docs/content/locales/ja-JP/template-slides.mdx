# スライド

スライドはエージェント主導のデッキ エディターです。エージェントにデッキを頼むと、プロンプトからデッキを生成し、組み立てながらスライドをエディターにストリーミングします。その後は、平易な言葉で頼むことも、クリックすることもでき、頼むたびにデッキを編集、再スタイル、エクスポートします。Google Slides、Pitch、PowerPoint を 1 つのアプリに置き換えるので、デッキの生成、編集、プレゼン、エクスポートが、切り替えなければならない別々のツールになることはありません。

## 置き換えるもの

<Comparison>

### 導入前

- デッキ自体の作成に Google Slides、Pitch、または PowerPoint
- 編集やプレゼンを続けるためだけの、ユーザー単位のサブスクリプション
- 新しいデッキごとに、ブランドカラー、フォント、ロゴを手作業でコピー&ペースト
- 別のツールを使っている相手とデッキを共有するための、手作業によるファイル変換

### 導入後

- 1 つのエディターで、プロンプトからの生成、視覚的な編集、プレゼンをすべて同じデッキの中で
- サブスクリプションなしで、スタック全体をエンドツーエンドで所有
- 保存したデザイン システムが、新しいデッキすべてに自動的にブランドを適用
- PPTX、DOCX、PDF、Google ドキュメントをインポートし、いつでも PPTX、Google Slides、HTML にエクスポートし直せる

</Comparison>

## マルチアプリ ワークスペースでのスライド

[Dispatch](/docs/template-dispatch) のもとで他のアプリと一緒にスライドを動かしている場合、デッキは単に手動で開くだけのページではなくなります。エージェントは、他のアプリが再利用できるライブラリにデッキを提出したり、姉妹アプリからの平易な英語のリクエストに、チャットで答えるのと同じように応答したりできます。この連携が実際にどう機能するのか、その裏にある本当の仕組みについては [マルチアプリ ワークスペースでのスライドのクロスアプリ利用](/docs/template-slides-integrations) を参照してください。

## それを使って何ができるか

- **プロンプトからデッキを生成する。** 「コーヒーのサブスクリプション サービス向けに 10 枚のスライドのピッチデッキを生成して。対象は投資家です。」[機能](/docs/template-slides-features) を参照してください。
- **スライドを視覚的に編集する。** テキストをダブルクリックして編集し、ブロックをクリックしてバブル メニューを開き、`/` でスラッシュ メニューを使ってブロックを挿入します。[機能](/docs/template-slides-features) を参照してください。
- **全画面でプレゼンし**、コメント、リアルタイムでの共同作業、特定のチームメイトや公開範囲を指定したデッキの共有ができます。[機能](/docs/template-slides-features) を参照してください。
- **既存のコンテンツを取り込む。** 出発点として PPTX、DOCX、PDF、Google ドキュメントをインポートします。PPTX、Google Slides、またはスタンドアロンの HTML ファイルにエクスポートします。[機能](/docs/template-slides-features) を参照してください。
- **ブランドから作られたデザイン システムを適用する。** カラー、タイポグラフィ、ロゴを一度保存すれば、新しいデッキすべてで再利用できます。Figma ファイル、接続したコードベース、または Web サイトから設定できます。[機能](/docs/template-slides-features) を参照してください。
- **以前のバージョンを復元する。** すべての変更はスナップショットされます。以前のバージョンを一覧表示したり、復元したりできます。[機能](/docs/template-slides-features) を参照してください。

## はじめに

アプリを開いたら:

1. **新しいデッキ** をクリックします。
2. エージェントに次のように頼みます。「コーヒーのサブスクリプション サービス向けに 10 枚のスライドのピッチデッキを生成して。対象は投資家です。」
3. スライドがストリーミングされていく様子を確認します。どのスライドもクリックして編集できますし、エージェントに調整を頼み続けることもできます。テキストを選択してバブル メニューの **AI で修正** をクリックすると、選択した内容をそのままエージェントに渡せます。

### 便利なプロンプト

- 「コーヒーのサブスクリプション サービス向けに 10 枚のスライドのピッチデッキを生成して。対象は投資家です。」
- 「スライド 3 の後に価格スライドを追加して。」
- 「このスライドのタイトルを大きくして、アクセントカラーを緑に変更して。」
- 「この PDF を 6 スライドのデッキとして要約して。」(PDF を添付してください)

自分用のスライドのコピーを作成するには:

```bash
npx --yes @agent-native/core@latest create my-slides --standalone --template slides
```

残りのセットアップ (`cd`、`pnpm install`、`pnpm dev`) とフレームワークの基礎については、[はじめに](/docs/getting-started) を参照してください。
