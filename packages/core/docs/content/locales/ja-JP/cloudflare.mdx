# Cloudflare

## Cloudflare Workers {#cloudflare-workers}

Cloudflare Worker には Nitro のネイティブなモジュール出力を使用します。これにより SSR
が有効なまま、Worker のエントリポイントと静的アセットが `.output/server` と
`.output/public` 配下に出力されます:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

生成された Worker を Wrangler でビルド・デプロイします。

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

`NITRO_PRESET=cloudflare_module` でプリセットを明示的に選択することもできます。
デプロイ前に、耐久性のある外部 PostgreSQL データベースを構成してください。Worker
のファイルシステムは永続的なアプリケーションストアではありません。
