# Agent との対話

スライドのエージェントは、UI が使うのと同じ actions を通じてデッキを作成、編集、インポート、エクスポート、スタイル設定します。そのため、クリックできることは何でも、頼むこともできます。このページでは、エージェントが自動的に見ているものと、タスク別に整理されたプロンプトを扱います。日常的なユーザーであっても、スライドの上に構築する開発者であっても役立ちます。

## エージェントがあなたの画面をどう見ているか

エージェントは常に、どのデッキが開いているか、どのスライドを見ているか、そのデッキ内のスライドの全リストを把握しています。「スライド 4」と言わなくても、そこに何があるかはすでに分かっています。視覚エディターで編集中は、アクティブな選択内容、つまりクリックした具体的な要素、使用中のツール、計算されたスタイルの詳細も見えています。そのため、「これを大きくして」は、推測ではなく実際に選択したものに対して作用します。

チャットはサイドバーにあり、素早いやり取りに向いています。スライドには、長めのセッションで作業スペースを広く使える、フルページの Agent ビューもあります。

### 選択内容を認識した編集

スライド上のテキストを選択してバブル メニューの **AI で修正** ボタンをクリックするか、ラバーバンド選択で 1 つ以上の要素を選んでフローティング チップの **エージェントに送信** をクリックすると、ハイライトした内容をそのままエージェントに渡せます。「もっとインパクトを出して」や「これだけ翻訳して」は、スライド全体ではなく選択部分だけに作用します。

## タスク別の便利なプロンプト

以下のプロンプトはすべて、UI が読み書きしているのと同じ、あなたの実際のデッキに対する本物の action になります。まずは 1 つの実例を見てみましょう。

<Comparison>

### :blue: あなたが尋ねる

「コーヒーのサブスクリプション サービス向けに 10 枚のスライドのピッチデッキを生成して。対象は投資家です。」

### :green: 何が起こるか

エージェントは最初にアウトラインを計画し、その後スライドが組み立てられるたびにライブでエディターにストリーミングします。そのため、全体が一度に出来上がるのを待つのではなく、デッキが形になっていく様子を見ることができます。

</Comparison>

<Cards columns={2}>

### 生成

- **「この PDF を 6 スライドのデッキとして要約して。」** PDF を添付すると、エージェントがそれを編集可能なデッキに変えます。
- **「この Google ドキュメントをデッキにして。」** 考え方は同じで、代わりに Google ドキュメントから始まります。

### 編集と再スタイル

_スライドを開いていれば、「このスライド」は自動的に解決されます。_

- **「スライド 3 の後に価格スライドを追加して。」** 新しいスライドがすぐにフィルムストリップに表示されます。
- **「このスライドのタイトルを大きくして、アクセントカラーを緑に変更して。」** 変更は開いているスライドにライブで適用されます。
- **「このデッキ内の『顧客』という言葉をすべて『メンバー』に置き換えて。」** すべてのスライドが一度に更新されます。

### インポートとエクスポート

- 「この PPTX をインポートして、各スライドをここで編集可能なスライドにして。」
- 「このデッキを PowerPoint としてエクスポートして。」
- 「これを Google Slides で開けるように準備して。」

</Cards>
