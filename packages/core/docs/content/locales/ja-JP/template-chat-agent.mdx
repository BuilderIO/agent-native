# Agent との対話

Chat では、会話がアプリを使う主な方法です。エージェントは、アプリの actions を実行し、情報を調べ、あなたが伝えたことを覚え、他のページへ案内できます。このページでは、エージェントがあなたの画面について知っていること、タスク別の便利なプロンプト、そして組み込みの actions を超えて動く場面について説明します。概要は [Chat](/docs/template-chat) を参照してください。

## エージェントがあなたの画面をどう見ているか

エージェントは常に、あなたがどのページにいて、どの会話が開いているかを把握しています。そのため、「ホームに戻って」や「今どのページにいる?」と言うだけで、説明なしに通じます。アプリはページが変わるたびにそれをエージェントに伝えるので、エージェントが推測する必要はありません。

Chat には、選択中のイベントや開いているドキュメントのような、指し示すビジネス データがありません。エージェントが知っているそれ以外のことは、すべて会話の中であなたが話したことから来ます。

## タスク別の便利なプロンプト

以下のプロンプトはすべて、実際のアプリに対して実行されます。まずは 1 つの実例を見てみましょう。

<Comparison>

### :blue: あなたが尋ねる

「Alex に対して hello action を呼び出して。」

### :green: 何が起こるか

エージェントは、サンプルの **hello** action を Alex という名前で実行します。action は
「Hello, Alex!」を返し、エージェントがそれをチャットに表示します。アプリの他の部分は
何も変わりません。

</Comparison>

<Cards columns={2}>

### アプリでできることを知る

- **「このアプリでは何ができる?」** エージェントが、持っている actions と、それぞれが
  何をするかを一覧にします。
- **「利用可能な actions を見せて。」** 同じ内容を、名前だけの単純なリストで返します。
- **「使い始めを手伝って。」** エージェントが、最初に試すことを提案します。

### 移動する

- **「設定を開いて。」** アプリがそのページを開きます。
- **「Database ページを開いて。」** エージェントは、サイドバーからリンクされていない
  `/database` を開きます。
- **「ホームに戻って。」** Get started ページが開きます。

### エージェントに教える

- **「私は短い答えが好みだと覚えておいて。」** エージェントはそれをメモリに保存し、
  以降のチャットで使います。
- **「今後は、答える前に必ず理由を説明して。」** エージェントはこれを常設の指示として
  保存できます。
- **「私について何を覚えてる?」** エージェントが、メモリの内容を読み返します。

### データを見る

- **「このアプリのデータベースにはどんなテーブルがある?」** エージェントは
  データベースの構造を読み取り、テーブルを一覧にします。
- **「チャットはいくつある?」** エージェントはデータベースに対して読み取り専用の
  問い合わせを実行し、チャットで答えます。

### フレームワークを学ぶ

- **「このアプリに新しい action を追加するにはどうする?」** エージェントは Agent-Native の
  ドキュメントを検索し、手順を説明します。
- **「action と skill の違いは?」** 同様に、ドキュメントから答えます。

</Cards>

<Callout tone="info">

エージェントはデータベースを読み取りますが、直接変更はしません。新しい情報を保存する
ときは、action を使います。そうすることで、すべての変更が、アプリ自身の画面が使うのと
同じ経路を通ります。開発者はアプリの設定でこれを変更できます。

</Callout>
