# カレンダー

カレンダーは、エージェントが動かすスケジューリング アプリです。Google Calendar
を接続すると、エージェントはあなたのスケジュールを読み取り、空き時間を見つけ、
イベントを作成し、Calendly スタイルの予約リンクを管理できます。平易な言葉で頼むことも、
クリックすることもできます。Google Calendar と Calendly の組み合わせを 1 つのアプリに
置き換えるので、実際のスケジュールと公開の予約ページを手作業で同期させる必要はもう
ありません。

## 置き換えるもの

<Comparison>

### 導入前

- 実際のスケジュール管理には Google Calendar
- 公開予約リンクには Calendly (または類似ツール) を使い、手作業で同期
- 誰かのメールアドレスが必要なときは別の連絡先検索
- すべての招待に Zoom リンクをコピー&ペースト

### 導入後

- 1 つのビューに、実際のカレンダーと予約リンクがまとまっている
- 予約リンクとエージェントの両方が参照する、1 つの空き状況モデル
- スケジューリングと同じプロンプトに組み込まれた人物検索
- 誰かが予約すると Zoom または Google Meet が自動的に付加される

</Comparison>

## マルチアプリ ワークスペースでのカレンダー

[Dispatch](/docs/template-dispatch) のもとで他のアプリと一緒にカレンダーを動かしている
場合、あなたのカレンダーは単に開くだけのページではなくなります。新しい予約を
きっかけに動く自動化から、スケジューリングのリクエストを直接カレンダーに渡す
姉妹アプリまで、他のチャンネルやアプリが働きかけられる対象になります。この連携が
実際にどう機能するのか、その裏にある本当の仕組みについては
[マルチアプリ ワークスペースでのカレンダーのクロスアプリ利用](/docs/template-calendar-integrations)
を参照してください。
