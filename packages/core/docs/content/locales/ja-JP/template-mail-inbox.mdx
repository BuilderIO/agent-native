# 受信トレイ、検索、自動化

このページでは、[メール](/docs/template-mail) での日常的な受信トレイ作業について説明します。メッセージの読み取りとトリアージ、接続されているすべてのアカウントを横断した検索、一括クリーンアップ、そして定型的なトリアージを自動化する 2 つの方法です。開発者だけでなく、メールを使うすべての人向けに書かれています。

## 読み取りとトリアージ

マウスに触れずに受信トレイを操作できます。優先度による並べ替えは、Builder へのアクセス権または保存済みの個人キーがある場合にのみ利用できます。次のキーボード ショートカットを使用します。

| 鍵        | アクション                           |
| --------- | ------------------------------------ |
| `J`       | 次のメール                           |
| `K`       | 前のメール                           |
| `Up/Down` | J/K と同じ                           |
| `Enter`   | 焦点を絞った電子メールを開く         |
| `E`       | メールまたはスレッドをアーカイブする |
| `D`       | メールまたはスレッドをゴミ箱に入れる |
| `S`       | スターを付けるか外す                 |
| `R`       | 返信                                 |
| `U`       | 既読/未読を切り替える                |
| `C`       | 新しいメールを作成                   |
| `/`       | フォーカス検索バー                   |
| `Cmd+K`   | コマンド パレットを開く              |
| `G I`     | 受信トレイに移動                     |
| `G S`     | スター付きに移動                     |
| `G T`     | 送信済みに移動                       |
| `G D`     | 下書きに移動                         |
| `G A`     | アーカイブに移動                     |
| `Esc`     | スレッドを閉じる / 検索をクリア      |

ショートカットでできることはすべて、頼むこともできます。「1 週間以上前の Netlify ボットのメールをすべてアーカイブして」「プリヤからのメールにすべてスターを付けて」「このスレッドのすべてを既読にして」。

## 接続されているすべての受信トレイを横断して検索する

検索バーに入力するか、エージェントに尋ねます。1 回のクエリで、たまたま開いているタブだけでなく、接続されているすべての Gmail アカウントを一度に検索します。個人用と仕事用の両方のアカウントを接続している場合、「Acme からの請求書を見つけて」は両方をチェックします。

## 受信トレイのクリーンアップのための一括操作

アーカイブ、スター付け、既読マークは、いずれも実際に接続されている Gmail アカウントに対して一括で動作します。複数のメッセージを選択する (またはエージェントに「これら全部」を対象に操作するよう頼む) と、メールはメッセージごとに 1 回呼び出す代わりに、アカウントごとにリクエストをまとめて処理します。日付ベースの別のクリーンアップ (「30 日以上前のものをすべてアーカイブして」) と、あるビューの JSON エクスポートも利用できますが、どちらも現在は接続された Gmail アカウントではなく、ローカルのデモ メールボックスに対して動作します。Gmail の変更後、メールは古い応答やキャンセルされた応答が新しい結果を上書きしないようにします。

1 つのアカウントにたまった大量の未読メールを片付けるには、エージェントに 1 件ずつ会話を開いてマークするよう頼むのではなく、「未読のものをすべて既読にして」を使ってください。メールはこれを検証済みの単一の一括操作として実行し、実際に変更されたメッセージ数を報告します。

## 自動トリアージ ルール vs. Gmail 純正フィルター

メールには、受信メールに対して何が起こるかを自動化する、明確に異なる 2 つの方法があります。意図的に選んでください。

<Callout tone="info">

**自動化ルール** は、あなたが書いた平易な英語の条件 (「ニュースレターから」「件名に invoice を含む」) に対して新着メールを AI で照合し、action (ラベル付け、アーカイブ、既読マーク、スター、ゴミ箱) を適用します。メール内部で約 1 分ごとに自動的に実行されます。

**Gmail フィルター** は Gmail 自体のネイティブな仕組みです。自動化ルールがメッセージを目にするより前に、Gmail 自体の内部で実行され、Gmail の正確な検索構文 (`from:`、`older_than:`、添付ファイルの有無、サイズなど) を使用します。メールを開いていないときでも動作し続けます。

ルールが Gmail 自身の条件で表現できる場合は Gmail フィルターを使い、条件に判断が必要な場合 (「これが営業の売り込みのように見えたら」など) は自動化ルールを使ってください。

</Callout>

## スレッド上の CRM コンテキスト

スレッドを開くと、メールの連絡先サイドバーに送信者の CRM コンテキストを表示できます。現在エンドツーエンドで接続されているのは HubSpot だけです。エージェントに「これは誰で、どんな案件が進行中ですか」と尋ねると、設定済みの HubSpot アカウントから連絡先、最大 5 件の関連案件、最大 5 件の関連チケットを検索します。

Gong、Pylon、Apollo も同じサイドバー パネルに表示されますが、それは設定で API キーを追加した場合に限られ、しかも読み取り専用のサイドバー表示としてのみです。現在、エージェントが Gong の通話や Pylon のチケットをチャットに取り込むことはできず、それができるのは HubSpot だけです。
