## デプロイ前に: 永続データベースを選択 {#persistent-database}

デプロイするすべてのアプリには永続 SQL データベースが必要です。最初の本番デプロイ前に、デプロイ環境へ `DATABASE_URL` を設定してください。プロバイダーが別のトークンを必要とする場合は `DATABASE_AUTH_TOKEN` も設定します。

スタンドアロンアプリには安定した `BETTER_AUTH_SECRET` が必要です。署名付きのアプリ間リクエストを使うワークスペースには `A2A_SECRET` が必要です。

## サポートされるターゲット

Agent-Native は Node.js、Vercel、Netlify、Cloudflare、AWS Lambda、Deno Deploy をサポートします。

高度な設定、シークレット、本番値については [デプロイ環境変数リファレンス](/docs/deployment-environment-variables) を参照してください。
