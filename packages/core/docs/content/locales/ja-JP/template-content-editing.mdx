# ドキュメントの作成と整理

このページでは、Content の日常的な操作について説明します。ページの作成と書式設定、ページをツリー状に配置すること、チームメイトとのコメントのやり取り、以前のバージョンへのロールバック、ドキュメントを閲覧できる人の制御です。開発者だけでなく、アプリを使うすべての人向けに書かれています。

## 作成と書式設定

空の行で `/` と入力するとスラッシュメニューが開き、見出し、箇条書きや番号付きリスト、表、画像、区切り線、コールアウトを挿入できます。高度なコード、レイアウト、ビジュアル、開発者向けドキュメントブロックは、挿入する前に **設定 → Labs** から有効にしてください。任意のテキストを選択すると、太字、斜体、リンク、インラインコード用の書式設定ツールバーがポップアップ表示されます。

- 画像はドラッグ＆ドロップまたは貼り付けができ、Content が設定済みのファイルストレージへ自動的にアップロードします。
- 数式は実際の数式としてレンダリングされます — `` $` `` マークの間にインライン数式を、`$$` 行の間にブロック数式を入力すると、エディターは元の記法をドキュメント内に保持しながら書式設定された結果を表示します。
- 手動で書式設定する代わりにエージェントに頼みましょう。「非推奨のエンドポイントについて警告するコールアウトを追加して」「このリストを表に変換して」「この見出しをレベル2にして」などです。編集を保存すると、Content はそのバージョンを保持します。後から届く復旧用ドラフトが保存済みの変更を置き換えたり、外部編集として表示したりすることはありません。

## ページの整理

サイドバーがどちらの状態であっても、最上部の **+** メニューから **ページ** または **コレクション** を選択します。キャンセルするには Escape を押します。別のワークスペースの行からアイテムを作成する場合は、まずそのワークスペースの読み込みを待ってください。すべてのページはサイドバーのツリーに存在します。ページをドラッグして並べ替えたり、別のページの下にサブページとしてネストしたりできます。ページにスターを付けると、サイドバー上部の **お気に入り** に固定されます。

検索ボックスを使う（またはエージェントに「先週のミーティングメモを見つけて」と頼む）ことで、閲覧可能なすべてのページのタイトルと内容を検索でき、各一致箇所にプレビュースニペットが表示されます。結果は関連性の高い順に並べられるため、強いタイトル一致は、検索語を本文にしか含んでいない最近のドキュメントより先に表示されます。

## コメント

Notion や Google Docs と同じ要領で、一節を選択してコメントを残せます。コメント対象のテキストはドキュメント本文への変更ではなくハイライト表示になるため、その後もページは全く同じように読めます。コメントはチームメイトへの @メンション、スレッド形式の返信、解決/再オープンの切り替えに対応しています。解決済みのスレッドはサイドバーの「解決済み」セクションに折りたたまれ、進行中のレビューを邪魔しません。

<Callout tone="info">

コメント対象の一節が後で編集されると、ハイライトは固定位置に留まるのではなく、周囲のテキストに追従します。該当のテキストが削除された場合でも、コメントスレッドは消えることなくサイドバーから引き続きアクセスできます。

</Callout>

## バージョン履歴

Content はページが大きく変更されるたびにスナップショットを保存します。ページのバージョン履歴を開くと、以前のスナップショットを確認して復元できます。

<Callout tone="warning">

復元すると、現在のコンテンツはそのバージョンの内容にまるごと置き換わります。行単位の差分表示や部分的な復元はできないため、復元する前にスナップショットを確認してください。

</Callout>

## 共有と公開範囲

ドキュメントは**デフォルトで非公開**です — 自分が作成したページは自分だけが見られます。共有するには共有ダイアログを開くか、エージェントに「このドキュメントをチームに編集者として共有して」と頼みます。

<Steps>

### 誰が閲覧できるかを設定する

公開範囲を **組織** に変更すると組織内の誰でも開けるようになり、**公開** に変更するとリンクを持つ誰もが読み取り専用の公開URLで開けるようになります。

### ロールを付与する

特定の人、または組織全体に、**閲覧者**、**編集者**、**管理者**のいずれかのロールを付与します。

### 必要に応じて検索から除外する

組織に公開されているページを discoverable-off（検索対象外）にできます。リンクを持つ誰でも引き続き開けますが、組織全体の検索やサイドバーの一覧からは外れます。参照用に存在するものの、日常的な閲覧には表示させたくないページに使用します。

</Steps>

公開ページには訪問者向けの読み取り専用チャットが付属します。訪問者はページの内容について質問できますが、それを通じて何かを作成、編集、コメント、共有することはできません。
