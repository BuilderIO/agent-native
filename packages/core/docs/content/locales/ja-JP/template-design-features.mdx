# 機能

Design のすべての中核機能について、その仕組みと設定方法を説明します。概要は
[Design](/docs/template-design) を、プロンプトの全リストは [Agent との対話]
(/docs/template-design-agent) を参照してください。機能は、アプリの実際の画面
ごとにグループ化されています: **デザイン**、**デザインを編集する**、
**テンプレート**、**デザイン システム**。

## デザイン {#designs}

`/home` の一覧ページです。アクセスできるすべてのデザインがここにあり、新しい
デザインを始めるのもここです。

### デザインを表示する {#view-designs}

デザインはカードのグリッドとして表示されます。ライブのサムネイル、タイトル、
最終更新日です。(**自分のもの** の代わりに) **すべて** フィルタに切り替えると、
それぞれの所有者も表示されます。

- **検索** は、入力するたびにタイトルでグリッドを絞り込みます。
- グリッドは 1 ページあたり 11 件のデザインでページングされ、「新しいデザイン」
  タイルが常に先頭に表示されます。
- 1 つ以上のカードを選択する (ホバーするとチェックボックスが表示されます) と、
  一括操作ツールバーが表示されます。表示中のものをすべて選択/解除する、
  creative context に追加する、選択項目を削除するといった操作ができます。
- 空のアカウントでは、空のグリッドの代わりにクリックできる 4 つのスターター
  プロンプトが表示されます (SaaS ページ、ダッシュボード、モバイルアプリ、
  価格ページ)。

### デザインを作成する {#create-a-design}

「新しいデザイン」への 2 つの入り口、ヘッダーのボタンとグリッドの破線タイルは、
どちらも同じポップオーバーを開きます。エディターを開く前に、プロンプトを入力し、
開始用のテンプレート、デザイン システム、creative context を選べます。代わりに
**スキップ** をクリックすると、AI 生成なしで、空のデザイン (または選んだ
テンプレートのプロンプトなしのコピー) が作成されます。

送信すると、生成がバックグラウンドで完了する間、「デザインを開いています」と
いうオーバーレイとともに、新しいデザインのエディターへ直接移動します。

### デザインを管理する {#manage-a-design}

デザイン カードの「⋯」メニューには 4 つの項目があります。

- **名前を変更**: テキスト フィールドを持つ小さなダイアログ。
- **複製**: 確認なしですぐにコピーを作成して開きます。
- **コンテキストに追加**: デザインを creative context に添付します。
- **削除**: 先に確認を求めます。

## デザインを編集する {#edit-a-design}

以下はすべて、デザインをクリックして開いた後に当てはまります。

### ファイル設定 {#file-settings}

画面とレイヤーは、2 つの別々のパネルではなく、1 つの統合されたツリーに存在
します。デザイン内のすべての画面 (それぞれが独自の HTML ファイルです) は
最上位のエントリで、その画面のレイヤーはその下にネストされます。

- **追加、名前変更、複製、削除、並べ替え** は、画面とレイヤーのどちらに対しても
  同じように機能します。
- レイヤーを **ロック** すると固定されます。これは、テンプレートやテンプレートの
  コピーが保持するのと同じ「ロックされたレイヤー」の概念です。
- 削除せずに任意のレイヤーを **表示または非表示** にできます。

### エージェント {#agent-in-editor}

すべての Agent-Native アプリが持つのと同じエージェント チャットが、エディターの
中にもあります。Design 専用のチャット画面ではありません。画面の生成、バリアント
の比較、細部の調整、品質とアクセシビリティの確認を、他のどんな変更を頼むときとも
同じように依頼できます。エージェントはまた、デザインを完成と呼ぶ前に、あなたが
何もしなくても自動的に品質とアクセシビリティのチェックを実行します。タスク別の
プロンプトについては [Agent との対話](/docs/template-design-agent) を参照して
ください。

#### モード

ツールの隣にある、独立した 3 段階の切り替えです。

- **編集**: 通常のモード。移動、フレーム、図形、ペン、テキストはすべて
  このモードで動作します。
- **注釈**: 描画とコメントの固定がアクティブである必要があるモード。
- **操作**: キャンバス用の別個のモードで、編集と注釈からは切り離されています。

### Design タブ {#design-tab}

選択しているものに対応する、メインのプロパティ パネルです。セクションは
現在の選択に当てはまる場合にのみ表示されます。

- **塗り** と **線**: 色、グラデーション、または画像による塗りと、既存の色を
  再利用できるドキュメント カラー パレット。
- **エフェクト**: ドロップ シャドウ、レイヤー ぼかし、背景ぼかし、そして
  名前付きスライダー (速度、色、中心点) とロー GLSL 用のコード パネルを持つ、
  コードに基づいたシェーダー エフェクト。
- **位置とレイアウト**、**タイポグラフィ**、**外観** (角の丸み、ブレンド モード、
  表示/非表示): 要素ごとの標準的なプロパティ グループ。
- **レイアウト** と **オートレイアウト**: フレームの子要素に対する flex 形式の
  配置。
- **レイアウト グリッド**: フレームに対するレイアウト ガイドのオーバーレイ。
- **コンポーネント**: 要素がコンポーネント インスタンスになると、このセクション
  にそのバリアントと props が表示されます。props を変更するとすぐにプレビュー
  され、そのインスタンス 1 つだけに適用されます。個別に保存されたコンポーネント
  定義は存在せず、すべてのインスタンスはマークアップの独立したコピーです。
  そのため「メイン コンポーネントへ移動」は、正規のテンプレートとしてではなく、
  参照点として最も古いインスタンスへ戻ります。

### コメント タブ {#comments-tab}

Design タブの隣にある本物のタブで、未読件数のバッジが付きます。アクセス権を
持つ誰もが、一般的なメモを残す代わりに、特定の要素にコメントを固定できます。
コメントは単なるメモのままにしておくことも、そのままエージェントに送ることも
できます。エージェントがコメントに取り組むときは、コメントが指し示すデザインの
正確な部分を編集し、変更が実際に反映されたことを確認したうえで、何が変わったか
を 1 行のメモにしてスレッドを解決するか、エージェント自身が判断すべきでない
事柄については本人に判断を仰ぐ返信をします。

### コードと計測タブ {#code-tab}

選択しているものについて、ピクセル単位の正確な位置とサイズ、算出済みの
スタイル (display、position、フォント、色)、そして裏側にある HTML をワンクリック
の **コピー** ボタンとともに表示します。これは読み取り専用のインスペクターで
あり、エディターではありません。

### デザイン プレビュー {#design-preview}

ヘッダーの再生ボタン メニューです。**デザイン プレビュー** は、現在の画面の
実際にレンダリングされた HTML を、エディターの外側で見えるとおりに新しい
ブラウザ タブで開きます。画面にコンテンツがあるまでは無効化されています。

### エクスポート {#export}

Agent-Native のマークが使われ、「デザイン一覧に戻る」「テンプレートとして保存」
「バージョン履歴」の隣にあります)。**エクスポート** は、そのメニューの下部
付近にあるサブメニューです。

### バージョン履歴 {#version-history}

同じ左側のレール メニューの中で、**バージョン履歴** は、デザインの保存済み
スナップショットを相対的なタイムスタンプ (「たった今」「5 分前」など) とともに
一覧表示するパネルを開きます。1 つを選択するとその画面のプレビューが表示され、
**このバージョンを復元** はデザインをその正確な状態に戻します。

## テンプレート {#templates}

空のキャンバスより速く始める、2 つの方法です。

### テンプレートを表示する {#view-templates}

テンプレート ページには 2 つのセクション、**自分のテンプレート** と
**組み込みテンプレート** があり、さらにタイトル、説明、カテゴリで絞り込める
検索ボックスがあります。各テンプレート カードには、ライブ プレビュー、
カテゴリ (広告、1 ページ資料、ランディング ページ、ソーシャル、
プレゼンテーション、その他)、寸法、そしてロックされているレイヤーの数が
表示されます。(組み込みではなく) 自分自身のテンプレートには、**共有**
(閲覧者/編集者/管理者アクセス) と **削除** を含む「⋯」メニューが付きます。

### テンプレートを使う {#use-a-template}

**テンプレートを使う** をクリックすると、小さなダイアログが開きます。任意の
プロンプト、適用するデザイン システム (または新規作成へのリンク)、そして
プロンプトなしでそのままコピーへ進む **そのまま使う** ボタンです。どちらの
場合も、新しいデザインが作成され、そのエディターへ直接移動します。

### テンプレートとして保存する {#save-as-template}

これはテンプレート ページ自体にはありません。デザインを編集中に、エクスポート
やバージョン履歴で使うのと同じ左側のレール メニューを開き、**テンプレートとして
保存** を選びます。その寸法、ファイル、ロックされたレイヤーは、組み込み
テンプレートと同じように引き継がれます。

<Callout tone="info">

現時点では、テンプレートとして保存できるのはインラインの Design プロジェクト
からのみです。`/visual-edit` や Full App Building に裏付けられたデザインは、
テンプレートとして保存できません。

</Callout>

### デザインを開く {#open-a-design}

独立した「開く」という手順はありません。テンプレートを使うことも、プロンプト
から新しいデザインを生成することと同様に、常にそのデザインのエディターを
自動的に開くところで終わります。

## デザイン システム {#design-systems}

デザイン システムとは、色、フォント、間隔、ロゴといったブランド アイデンティティ
のことで、Design はそれをリンクされたすべてのプロトタイプに適用します。

### デザイン システムを表示・共有する {#view-and-share}

デザイン システム ページはグリッドです。最初に「新しいデザイン システム」
カードがあり、その後にシステムごとに 1 枚のカードが続き、カラー スウォッチの
プレビュー、既定になっているものへの **既定** バッジ、そして可視性バッジ
(非公開、組織、または公開) が表示されます。すべてのカードには、テンプレートと
同じ共有モデルによる、閲覧者/編集者/管理者ロールの本物の **共有** ボタンが
あります。ヘッダーの **選択** トグルで複数選択と一括削除ができます。

### 新しいデザイン システム {#new-design-system}

作成は、ソースの選択から始まります。

- **Figma**: `.fig` ファイルをアップロードします。
- **会社/ブランド**: Web サイトの URL。
- **コード**: 接続された GitHub リポジトリ。
- **Design.md**: 文章によるデザイン ガイダンス ドキュメント。
- **デザイン ファイル**: ファイルを直接アップロードします。
- **既存のものをインポート**: すでに持っているデザイン システムやプロジェクト
  を再利用します。
- **メモ**: ブランドを一から説明するか、記憶から作り直す代わりに、
  Material 3、Carbon、Primer のような、実在するメンテナンスされている公開
  システムから始めます。

<Callout tone="info">

それぞれの公開システムには、本物のセマンティック トークン、タイプ スケール、
間隔、そしてクレジット表記が備わっています。Design は、プロンプトによって
それが裏側の違うデータを持つ模倣品へこっそり変えられてしまうことを許しません。
すべてのデザイン システムには、任意設定のカスタム指示と、説明済みの画像
スタイルも備わっているので、生成される写真やイラストは、ブランドの他の部分と
同じビジュアル言語を保ちます。

</Callout>
