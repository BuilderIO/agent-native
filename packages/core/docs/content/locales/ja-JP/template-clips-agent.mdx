# Agent との対話

クリップのすべての機能は、UI が使うのと同じ actions を通じてエージェントも利用できるので、クリックできることは何でも、平易な言葉で頼むこともできます。このページでは、エージェントがあなたの画面をどう見ているか、タスク別の便利なプロンプト、そしてあまり一般的でない actions に手を伸ばす場面について説明します。概要は [クリップ](/docs/template-clips) を参照してください。

## エージェントがあなたの画面をどう見ているか

録画を開いている間、エージェントはどの録画かを正確に把握しており、見ているサイド パネル (コメント、トランスクリプト、インサイトのいずれか) や、一時停止しているタイムスタンプまで分かっています。そのため、「ここにコメントを追加して」や「これを良い部分だけトリムして」と言うだけで、録画名や時刻を挙げなくても正しく解決されます。

ライブラリを閲覧している場合も、エージェントはそこで何を見ているかを把握しています。現在のフォルダ、検索内容、そして選択モードであればどの録画を選択しているかです。

エージェントがあなたに代わってできないことが 1 つあります。それは録画を開始することです。ブラウザは、人がクリックした後にしかマイクと画面へのアクセスを許可しないため、「画面を録画して」と頼むと、バックグラウンドで見えない形でキャプチャを始めるのではなく、レコーダーへ直接移動します。

## タスク別の便利なプロンプト

以下のプロンプトはすべて、UI が読み書きしているのと同じ、あなたの実際のライブラリに対する本物の action になります。まずは 1 つの実例を見てみましょう。

<Comparison>

### :blue: あなたが尋ねる

「プロダクト アップデート用にこのクリップを要約して。」

### :green: 何が起こるか

これは読み取り専用の質問です。エージェントは開いている録画のトランスクリプトを読み、チャット内で直接返答します。何も作成・移動されないため、画面上には何も変化がありません。

</Comparison>

### キャプチャとインポート

- **「画面を録画して。」** エージェントがレコーダーを開いてくれます。キャプチャの開始自体は、ブラウザが求めるため、依然としてあなたのクリックが必要です。
- **「この Loom リンクをインポートして。」** URL を貼り付けると、インポートが完了した時点でその録画がライブラリに加わります。

### クリーンアップと整理

- **「タイトルと概要を作り直して。」** エージェントは現在のトランスクリプトから両方を書き直します。
- **「チャプターを追加して。これは長いから。」** チャプター マーカーがすぐにタイムラインに表示されます。
- **「1:42 の誤って文字起こしされた単語を直して。」** エージェントがトランスクリプトをその場で修正します。
- **「ロールアウト計画について話し合ったクリップを見つけて。」** 読み取り専用の質問です。エージェントはライブラリ内のすべてのトランスクリプトを横断して検索し、チャット内で回答します。

### 編集

_録画を開いていれば、「これ」は自動的に見ているクリップに解決されます。_

- **「最初の 10 秒をトリムして。」** カットはすぐにタイムラインに表示され、書き出すまで再エンコードは行われません。
- **「えーとあーを削除して、つなぎ直して。」** エージェントがトランスクリプト内のつなぎ言葉を見つけ、同じ種類のトリムを適用します。
- **「この 3 つのクリップを、この順番で 1 つに結合して。」** エージェントはトランスクリプトとチャプターを保ったまま、それらをつなぎ合わせます。

### 共有とレビュー

- **「このクリップを誰が見ている?」** 読み取り専用の質問です。エージェントは、人間とトランスクリプトを読み取る他のエージェントを分けた視聴回数で回答します。
- **「これをデザインチームに閲覧のみで共有して。」** 録画の公開範囲とアクセス権がすぐに更新されます。

</Cards>

## あまり一般的でない actions

クリップのすべての機能が、エージェントにあらかじめ組み込まれた第一級の action というわけではありません。Rewind のスクリーンメモリの actions はその良い例で、Rewind をオンにしたときだけ意味を持つものです。こうした action のいずれかが必要なリクエストが来ると、エージェントはすべてのショートカットを記憶する代わりにコマンド パレットを検索するのと同じように、呼び出す前に名前で正しいツールを検索します。日常のライブラリ操作や編集タスクを超えるリクエストでは、これが短い一時停止として表れることに気づくはずです。
