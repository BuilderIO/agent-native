# はじめに

Agent-Nativeアプリでは、エージェントとUIが同じ[アクション](/docs/actions)、SQLデータ、アプリケーション状態を利用します。このガイドはChatから始めます。Chatはチャット履歴をすでにSQLに保存します。アプリでドメインデータを永続化する必要がある場合だけ、独自のテーブルを追加してください。

<Steps>

### チャットアプリを作成してエージェントを設定する

Chatテンプレートをスキャフォールドし、依存関係をインストールして、開発サーバーを起動し、エージェントを設定します。拡張できる動作中のチャットアプリが完成します。
**現在ここです。**

### アクションを追加する

型付きのテキスト分析を定義し、その結果をチャット内のグラフとして表示します。

### ページを追加する

トランスクリプトの外で同じアクションを呼び出すReactルートを作成します。

</Steps>

## 1. チャットアプリを作成する {#create-your-app}

[Node.js 22+](https://nodejs.org)と[pnpm](https://pnpm.io)が必要です。

ターミナルを開き、Agent Nativeアプリを作成したいディレクトリに移動して、次のコマンドを実行します。

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

アプリは`http://localhost:8080`で開きます。ログイン画面が表示されたら、実在しないログイン情報でサインアップしてください。ローカル開発ではメール認証は必要ありません。

Chatテンプレートには、永続的なチャットスレッド、認証、ライブ同期、`actions/`ディレクトリ、標準の`view-screen`および`navigate`アクションが含まれています。

### 別の開始点を選ぶ

Chatが適切な開始点でない場合は、`--template`なしで`create`を実行し、CLIで別の選択肢を選びます。他の方法については[テンプレートを作成する](/docs/creating-templates)を参照してください。

## 2. エージェントを設定する {#connect-ai}

Chatテンプレートはチャット画面を直接開きます。エージェントが応答できる状態になっていない場合は、**Settings > Manage agent**を開くか、**Cmd/Ctrl+K > Manage agent**を使用してモデルとプロバイダーを設定します。

エージェントが応答したら、[アクションを追加する](/docs/getting-started-actions)に進みます。
