# はじめに

Agent-Nativeは、直感的なUIを備えた自律型エージェントを構築するための
オープンソースTypeScriptフレームワークです。各機能を一度だけ
[アクション](/docs/actions-overview)として定義します。アクションは、エージェントが
ツールとして使用し、UIがコードから呼び出す型付き関数です。

このガイドでは、チャットUIを備えたエージェントを作成し、付属の`hello`アクションをエージェントとUIから呼び出します。

<GettingStartedPaths />

## 前提条件

- [Node.js](https://nodejs.org) 22以降
- [pnpm](https://pnpm.io)
- エージェント用のLLM接続: Builder.io、AnthropicまたはOpenAIのAPIキー、またはローカルのOllamaモデル

## エージェントを作成する

新しいディレクトリでChatテンプレートから始めます。

```bash
npx @agent-native/core@latest create my-app --standalone --template chat
cd my-app
pnpm install
```

テンプレートには、エージェント用のブラウザUI、認証、永続的な会話、
ライブ同期、アプリケーションコンテキスト、`actions/`ディレクトリが含まれます。
このガイドで使う小さな`hello`アクションも含まれています。

## 開発サーバーを起動する

開発サーバーを起動します。

```bash
pnpm dev
```

ブラウザUIは`http://localhost:8080`で開きます。自動で開かない場合は、ブラウザでそのURLにアクセスしてください。

<Callout tone="info">

Welcome画面で**Continue as local dev**を選択します。ローカル開発ではメールアドレスやパスワードを入力する必要はありません。

</Callout>

次にLLMを接続します。無料クレジットを使うには**Connect Builder.io**を選択します。あるいは、**Custom keys**を選択してプロバイダーを選び、必要な接続情報を入力します。

## エージェントからアクションを実行する

アクションは、React UIがコードから呼び出せ、エージェントがツールとして使える型付き関数です。Chatテンプレートにはシンプルな`hello`アクションが含まれているため、自分で書く前にこのパターンを試せます。

エージェントパネルで次のように依頼します。

> Call the hello action for Alex.

エージェントは説明と入力スキーマから`hello`を見つけ、`Alex`を`name`入力として渡し、次のように応答します。

```text
Hello, Alex!
```

## アクションを確認する

`actions/hello.ts`を開きます。

```ts filename="actions/hello.ts"
import { defineAction } from "@agent-native/core/action";
import { z } from "zod";

export default defineAction({
  description: "Return a friendly greeting.",
  schema: z.object({
    name: z.string().default("world").describe("Name to greet"),
  }),
  http: { method: "GET" },
  run: async ({ name }) => {
    return { message: `Hello, ${name}!` };
  },
});
```

まずは次の4つに注目してください。

- `description`は、エージェントにアクションを使うタイミングを伝えます。
- `schema`は入力を検証し、エージェントに型付きツール定義を提供します。
- `http`は、この読み取り専用アクションを`GET`で公開し、`useActionQuery`からReactで呼び出せるようにします。
- `run`には、エージェントとUIで共有されるアプリケーションロジックが含まれます。

完全なAPIは[アクションを定義する](/docs/actions-defining)を参照してください。

## Reactからアクションを呼び出す

`app/routes/hello.tsx`にルートを追加します。

```tsx filename="app/routes/hello.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";
import { useState } from "react";

import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function HelloRoute() {
  const [name, setName] = useState("Alex");
  const { data } = useActionQuery("hello", { name });

  return (
    <main className="mx-auto grid w-full max-w-xl gap-6 p-6">
      <h1 className="text-2xl font-semibold">Hello action</h1>
      <div className="grid gap-2">
        <Label htmlFor="name">Name</Label>
        <Input
          id="name"
          value={name}
          onChange={(event) => setName(event.target.value)}
        />
      </div>
      <p className="text-xl font-medium">{data?.message}</p>
    </main>
  );
}
```

<Callout tone="warning">

新しいルートを検出できるように開発サーバーを再起動してから、`http://localhost:8080/hello`を開いてください。

</Callout>

名前を入力すると、`useActionQuery`が`hello`を呼び出して結果を表示します。アクションの入力型と結果型を推論するため、このページにカスタムAPIルートや挨拶の2つ目の実装は必要ありません。

## アクションを変更する

`actions/hello.ts`で戻り値を変更します。

```ts
return { message: `Welcome, ${name}.` };
```

`/hello`を更新してから、エージェントにもう一度`hello`を呼び出すよう依頼します。同じアクションを呼び出しているため、どちらも更新後の挨拶を返します。

## ほかの方法でアクションを呼び出す

同じアクションをエージェントとUIから呼び出しました。このアクションは次からも呼び出せます。

| 呼び出し元                              | 用途                                                               |
| --------------------------------------- | ------------------------------------------------------------------ |
| [HTTP API](/docs/http-api)              | スクリプト、バックエンド、連携からアクションを呼び出す。           |
| [CLI](/docs/actions-other-surfaces#cli) | ターミナルからアクションを実行またはテストする。                   |
| [MCP](/docs/actions-other-surfaces#mcp) | 外部AIクライアントにアクションをツールとして検出・呼び出しさせる。 |
| [A2A](/docs/actions-other-surfaces#a2a) | 別のエージェントから自分のエージェントに作業を委任する。           |

すべての呼び出し元が同じアクション定義を使います。呼び出し元ごとに別の実装は不要です。この共有アクションモデルはAgent-Nativeの中心です。機能を追加しても、UI、エージェント、連携の間で動作、検証、権限が揃ったままになります。

## 作成したもの

チャットUIを備えたエージェントを作成し、同じ`hello`アクションをエージェントとReact UIから呼び出し、挨拶を一度変更して両方が更新されることを確認しました。これから書くすべてのアクションも同じパターンに従います。
