# WebMCP

WebMCP は実験的なブラウザ API です。ページがツールを登録し、許可された
エージェントがそれを検出して実行できます。登録、利用、ブラウザ セッション、
セキュリティ制限については[英語の WebMCP ガイド](/docs/webmcp)をご覧ください。
認証済みページでは、既存のアクション レジストリから対象のバックエンド
アクションが自動登録されます。承認が必要なアクションは除外され、実行前に
現在のツール一覧を再確認します。
MCP 埋め込みルートなど、認証済みの `sessionBypass` サーフェスでもバックエンド
アクション ツールが登録されます。公開ページや未サインインのページでは登録されません。

ブラウザに利用可能なネイティブ WebMCP サーフェスがない場合、Agent-Native コアは `@mcp-b/webmcp-polyfill` を初期化します。このポリフィルはページ内に限定され、ネットワーク MCP 接続は作成しません。

認証済みページはブラウザ エージェント向けに `window.__agentNativeWebMcp` も公開しており、`ready()`、`tools()`、`describe()`、`call()`、`result(id)` を利用できます。`call()` はアクティブなホストの入力契約、最新のツール記述子、再試行、短いエバリュエーターより長く続く呼び出しを処理します。詳細は英語のガイドを参照してください。

## HTTP 検出と fetch フォールバック

ブラウザを実行しないエージェント向けに、Agent-Native は
`GET /.well-known/mcp.json` で取得できる HTTP 互換ドキュメントも提供します。
アクションのエンドポイント、JSON スキーマ、読み取り専用かどうか、認証が
必要かどうかを記述します。これは Agent-Native の相互運用規約であり、WebMCP
仕様の一部でも、標準 MCP の代替でもありません。

ツールは `fetch` または `curl` で `POST /mcp/tool/:name` に呼び出せます。
認証、認可、検証、テナントのスコープは引き続きサーバー側で処理されます。
ドキュメントには `/mcp`、認証済み WebMCP マニフェスト、A2A エージェントカード
へのリンクも含まれます。

ページローカルのツールには、引き続き WebMCP 対応ブラウザを開いておく必要が
あります。リソースページは独自の JSON 検出リンクも公開できます。Clips は
`agentContextUrl` から完全なトランスクリプトと JPEG フレームの URL を提供する
ため、プレーヤーを開かずに HTTP でアクセスできます。
