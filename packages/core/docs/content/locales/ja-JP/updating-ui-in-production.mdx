# 本番環境での UI 更新

通常デプロイされたアプリのエージェントは、アプリのソースコードへの環境的なアクセスを受け取るのではなく、アプリのツール（アクション、データベース、MCP、構成済みの統合）を通じて動作します。ソースコードの変更はリポジトリの開発ワークフローに属します。埋め込み、ローカル、または Builder フレームは、そのフレームに意図的にワークスペースと書き込みツールが与えられている場合に限り、リポジトリを編集できます。

[本番コード実行](/docs/actions-agent-tools#production-code-execution) をオフにした標準的な本番デプロイでは、エージェントはアプリのツール（アクション、データベース、MCP）にアクセスできますが、ファイルシステムにはアクセスできません。つまり、エージェントはデータの読み書き、アクションの実行、外部サービスとのやり取りは行えますが、デプロイされたインスタンス上で React コンポーネントを編集したり、新しいルートを追加したりすることはできません。

## Builder.io: 本番環境でのビジュアル編集 {#builderio}

[Builder.io](https://www.builder.io?utm_source=agent-native&utm_medium=docs&utm_campaign=framework&utm_content=deployment) は、エージェントが本番環境でアプリの UI を変更できる、コード対応の別個のマネージドワークフローです。リポジトリを Builder.io に接続し（無料プランあり）、UI の変更を直接プロンプトするだけです。再デプロイは不要です。

**Connect Builder** in Settings uses Builder OAuth (`builder:ai:invoke`) with a same-origin HTTPS callback under `/_agent-native/builder/callback`, so hosted origins such as Railway work without a domain allowlist. Legacy `BUILDER_*` private keys remain a runtime fallback for existing connections.

**仕組み:**

1. agent-native のリポジトリを Builder.io に接続する（無料プランあり）
2. Builder.io がエージェント、ビジュアル編集、リアルタイムコラボレーションを備えたクラウドフレームを提供する
3. エージェントに UI の変更をプロンプトする。コンポーネント、ルート、スタイルをライブで編集する
4. 変更はリポジトリにコミットされる

埋め込みエージェントパネルとクラウドフレームの選択肢の詳細は [フレーム](/docs/frames) を参照してください。
