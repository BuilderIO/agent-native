# Clips 匿名インテーク

このフローでは、訪問者が Clips にログインせず非公開録画を1件送信できます。信頼されたプロダクトがインテーク URL を作成し、エージェントの読み取り専用リンクとは分離されます。

作成レスポンスが失われた場合、録画の紐付け後に同じ署名付きリクエストを安全に再試行できます。2件目の録画は作成されません。

連携方法、セキュリティ境界、セルフホスティング要件は[英語の完全ガイド](/docs/template-clips-anonymous-intake)を参照してください。
