# Portal

Portal はデバイス間の実行用にコンピューターをペアリングします。**設定 → ワークスペース → ペアリングまたは修復**を開き、デバイストークンをコンピューターの非公開ファイル `~/.agent-native/remote-device.json` に保存します。

実行モードは **Local**、**Computer**、**Cloud** です。**Cloud** はウェイトリストで、アクセスが有効になるまで実行を開始しません。
