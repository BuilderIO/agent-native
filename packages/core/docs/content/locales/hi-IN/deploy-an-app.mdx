# ऐप deploy करें

Steps और provider commands के लिए [पूरा English app deployment guide](/docs/deploy-an-app) देखें।

Deploy करने से पहले persistent SQL database और stable `BETTER_AUTH_SECRET` सेट करें। [Node.js और Docker](/docs/node-docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify) या [Cloudflare](/docs/cloudflare) चुनें।

एक origin के पीछे कई apps के लिए [Workspace Deployment](/docs/workspace-deployment) देखें।
