# ऐप deploy करें

Steps और provider commands के लिए [पूरा English app deployment guide](/docs/deploy-an-app) देखें।

Deploy करने से पहले persistent SQL database और stable `BETTER_AUTH_SECRET` सेट करें। [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) या [Render](/docs/render) चुनें।

एक origin के पीछे कई apps के लिए [Workspace Deployment](/docs/workspace-deployment) देखें।
