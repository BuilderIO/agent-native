# चैट

चैट सबसे सीधा एजेंट-नेटिव शुरुआती बिंदु है: केंद्र में चैट के साथ एक
ChatGPT-शैली शेल, एक थ्रेड सूची, ऑथ, और एक उदाहरण action, कुछ भी
डोमेन-विशिष्ट नहीं। यह उन डेवलपर्स के लिए है जो एक असली, डिप्लॉय करने योग्य
ऐप चाहते हैं जिस पर वे अपना खुद का एजेंट और स्क्रीन बना सकें, किसी खास काम के
लिए बना हुआ तैयार प्रोडक्ट नहीं।

अगर आप एक तैयार डोमेन प्रोडक्ट शेप चाहते हैं, तो
[कैलेंडर](/docs/template-calendar), [मेल](/docs/template-mail),
[Content](/docs/template-content), [Forms](/docs/template-forms),
[Analytics](/docs/template-analytics), या किसी अन्य डोमेन टेम्पलेट से शुरू
करें। अगर आपको सच में अभी ब्राउज़र UI की ज़रूरत नहीं है, तो
[Automation-First Apps](/docs/pure-agent-apps) देखें।

## क्या शामिल है {#what-ships}

<Comparison>

### :green: शामिल

- फ़्रेमवर्क चैट सतह और टिकाऊ चैट थ्रेड्स का उपयोग करके `/` पर पूर्ण-पृष्ठ
  चैट
- ऐप साइडबार में थ्रेड सूची, ताकि चैट बनाई, फिर से खोली, नाम बदली, पिन की,
  और आर्काइव की जा सकें
- बिल्ट-इन app-agent लूप, चैट प्लगइन के लिए पहले से कॉन्फ़िगर किया गया
- Better Auth के ज़रिए ऑथ: लॉगिन, साइनअप, सत्र, संगठन
- एक actions डायरेक्टरी, एक उदाहरण (`actions/hello.ts`) के साथ, प्लस मानक
  `view-screen` और `navigate` actions
- चैट थ्रेड्स, एप्लिकेशन स्थिति, सेटिंग्स, सत्र, संसाधन, और रन इतिहास के
  लिए फ़्रेमवर्क की मुख्य तालिकाएं, साथ ही एक Database एडमिन पेज और एक
  Observability डैशबोर्ड, जो माउंटेड रहते हैं चाहे आप उन्हें कभी खोलें या
  नहीं
- लाइव सिंक (`useDbSync`) पहले से वायर्ड है, ताकि जब एजेंट SQL में लिखे तो
  UI रीफ़्रेश हो जाए
- Extensions रूट्स डिफ़ॉल्ट रूप से माउंटेड, उन सैंडबॉक्स्ड मिनी-ऐप्स के
  लिए जिन्हें आपके यूज़र बाद में चैट के भीतर बनाते हैं
- AGENTS.md, actions, रूट्स, skills, और एप्लिकेशन स्थिति जोड़ने के लिए
  चैट-फर्स्ट मार्गदर्शन के साथ

### :red: शामिल नहीं

- डोमेन तालिकाएं या सीड डेटा
- डैशबोर्ड, सूचियां, चार्ट, फ़ॉर्म, या प्रोवाइडर इंटीग्रेशन
- उदाहरण स्टब से आगे कोई डोमेन-विशिष्ट actions

</Comparison>

## इसे कब चुनें {#when-to-pick}

- **आप एक बुनियादी ऐप चाहते हैं जिससे यूज़र तुरंत बात कर सकें** और फिर
  actions और UI के साथ इसे एक्सटेंड करें।
- **आप डिफ़ॉल्ट Agent-Native ऑन-रैंप चाहते हैं**: पहले चैट, फिर actions,
  नेटिव नतीजे, और ऐप पेज।
- **आप अपने खुद के एजेंट बैकएंड को एक जाने-पहचाने चैट UI में प्लग करना
  चाहते हैं**, जबकि Agent-Native के actions, स्थिति, ऑथ, और डिप्लॉयमेंट
  शेप को बनाए रखते हैं।
- **आप एक कस्टम इंटरनल टूल प्रोटोटाइप कर रहे हैं** जो किसी डोमेन टेम्पलेट
  से मेल नहीं खाता।

## शुरुआत करें {#get-started}

```bash
npx @agent-native/core@latest create my-chat-app --standalone --template chat
```

install, पहला रन, और एक LLM कनेक्ट करने के लिए
[चैट: डेवलपर गाइड](/docs/template-chat-developers#quick-start) देखें। बिना
किसी browser UI वाले automation-first काम के लिए, इसके बजाय `--headless`
के साथ स्कैफ़ोल्ड करें:

```bash
npx @agent-native/core@latest create my-agent --headless
```

इसका उपयोग scheduled jobs, queues, CLI loops, या external-agent workflows
के लिए करें जहां चैट और ऐप पेज अभी उपयोगी नहीं हैं। मुख्य invariant वही
रहता है: actions चैट, UI, HTTP, MCP, A2A, और CLI के लिए साझा सतह हैं। उस
पाथ को गहराई से समझने के लिए [Automation-First Apps](/docs/pure-agent-apps)
देखें।
