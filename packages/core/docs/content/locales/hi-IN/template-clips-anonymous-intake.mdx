# Clips अनाम इनटेक

इस प्रवाह में विज़िटर Clips में साइन इन किए बिना एक निजी रिकॉर्डिंग भेज सकता है। भरोसेमंद प्रोडक्ट इनटेक लिंक बनाता है। यह लिंक एजेंट के रीड-ओनली लिंक से अलग रहता है।

इंटीग्रेशन, सुरक्षा सीमाओं और सेल्फ-होस्टिंग के लिए [पूरा अंग्रेज़ी गाइड](/docs/template-clips-anonymous-intake) देखें।
