# WebMCP

WebMCP एक प्रयोगात्मक browser API है, जिससे pages ऐसे tools register कर सकते
हैं जिन्हें अधिकृत agent खोज और चला सकता है। Registration, consumption,
browser sessions और security limits के लिए [अंग्रेज़ी WebMCP guide](/docs/webmcp)
देखें।
Authenticated pages मौजूदा action registry से eligible backend actions को अपने-आप
register करते हैं। Approval माँगने वाले actions शामिल नहीं होते और चलाने से पहले
live tool list फिर जाँची जाती है।
