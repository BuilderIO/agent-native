# अपने एजेंट में UI जोड़ें

Agent-Native आपके मौजूदा एजेंट को chat, approvals, workflow state और permissions वाला workspace देता है। Provider reasoning, tools, context और लंबे execution संभालता रहता है।

यह पेज **Microsoft Foundry, Gemini Enterprise, Anthropic Managed Agents या OpenAI एजेंट में UI जोड़ने** का तरीका बताता है।

## कनेक्शन चुनें {#choose-a-connection-path}

| Backend                  | Agent-Native कनेक्शन | कॉन्फ़िगरेशन                           |
| ------------------------ | -------------------- | -------------------------------------- |
| Microsoft Foundry        | A2A 1.0              | Agent Card URL और Entra secret         |
| Gemini Enterprise        | A2A                  | Agent Card URL और Google secret        |
| Anthropic Managed Agents | Managed Agents API   | Agent ID, environment ID और vault key  |
| OpenAI Agents API        | Custom A2A endpoint  | Agent Card URL और provider credential  |
| कोई भी A2A एजेंट         | A2A                  | Agent Card URL और वैकल्पिक credentials |

**Settings → Agent → Sub-agents** खोलें और **Connect agent** चुनें (owners और admins)। Connect बटन सही प्रदाता के साथ कनेक्ट फॉर्म खोलते हैं। Secrets workspace vault में रहते हैं।

## Microsoft Foundry {#microsoft-foundry}

A2A v1.0 Agent Card URL डालें और Entra credential चुनें। Service-to-service के लिए `https://ai.azure.com/.default` scope और **Foundry Agent Consumer** role दें।

## Gemini Enterprise {#gemini-enterprise}

Custom A2A card URL डालें और vault से bearer secret चुनें। Save से पहले Agent-Native card और JSON-RPC interface की जाँच करता है।

## Anthropic Managed Agents {#anthropic-managed-agents}

**Anthropic Managed Agents** चुनें, agent और environment ID डालें और API key चुनें। Sessions और approvals Anthropic में रहते हैं और Agent-Native chat में दिखते हैं।

## Custom A2A agent {#custom-a2a}

Internal या self-hosted agent के लिए **Add by URL** इस्तेमाल करें। A2A 0.3 और 1.0 cards validate होते हैं और errors स्पष्ट status के रूप में दिखते हैं।

Streaming उपलब्ध न होने पर कनेक्शन `message/send` का उपयोग करता है।

## Registries {#registries}

[Global A2A Registry](https://www.a2a-registry.org) browse करें। Agent जोड़ने और secret इस्तेमाल करने से पहले card, host और auth verify करें।

## UI layer {#ui-layer}

[A2A](/docs/a2a-protocol) delegated task ले जाता है और Agent-Native workspace user state रखता है। [Connected agents](/docs/agent-mentions#mentioning-agents) और [External agents](/docs/external-agents) देखें।
