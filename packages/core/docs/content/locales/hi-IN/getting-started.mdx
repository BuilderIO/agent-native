# शुरुआत करें

Agent-Native ऐप agent और UI को समान [actions](/docs/actions), SQL data और
application state देते हैं। यह रास्ता Chat से शुरू होता है, जो chat history को
SQL में पहले से store करता है। अपनी tables केवल तब जोड़ें जब आपके app को domain
data persist करना हो।

<Steps>

### Chat ऐप बनाएं और agent कॉन्फ़िगर करें

Chat template को scaffold करें, dependencies install करें, dev server शुरू करें
और एक agent कॉन्फ़िगर करें। आपके पास विस्तार करने के लिए एक काम करने वाला chat ऐप
होगा। **आप यहाँ हैं।**

### एक action जोड़ें

एक typed text analyzer define करें और chat में उसके result को chart के रूप में render करें।

### एक page जोड़ें

एक React route बनाएं जो transcript के बाहर उसी action को call करे।

</Steps>

## 1. Chat ऐप बनाएं {#create-your-app}

आपको [Node.js 22+](https://nodejs.org) और [pnpm](https://pnpm.io) चाहिए।

एक terminal खोलें, उस directory में जाएं जहाँ आप अपना Agent Native ऐप रखना चाहते
हैं, और चलाएं:

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

ऐप `http://localhost:8080` पर खुलेगा। अगर login screen दिखाई दे, तो किसी नकली
login से sign up करें। Local development में email verification की आवश्यकता नहीं है।

Chat template में durable chat threads, auth, live sync, एक `actions/` directory,
और standard `view-screen` तथा `navigate` actions शामिल हैं।

### कोई दूसरा starting point चुनें

अगर Chat सही starting point नहीं है, तो `--template` के बिना `create` चलाएं और
CLI में कोई दूसरा विकल्प चुनें। दूसरे रास्तों के लिए [टेम्प्लेट बनाना](/docs/creating-templates)
देखें।

## 2. Agent कॉन्फ़िगर करें {#connect-ai}

Chat template सीधे chat surface पर खुलता है। अगर agent जवाब देने के लिए तैयार नहीं
है, तो model और provider कॉन्फ़िगर करने के लिए **Settings > Manage agent** खोलें या
**Cmd/Ctrl+K > Manage agent** का उपयोग करें।

Agent के जवाब देने के बाद [एक action जोड़ें](/docs/getting-started-actions) पर आगे बढ़ें।
