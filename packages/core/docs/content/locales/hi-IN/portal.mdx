# Portal

Portal डिवाइसों के बीच execution के लिए कंप्यूटर को pair करता है। **Settings → Workspace → Pair or repair** खोलें और device token को कंप्यूटर की निजी `~/.agent-native/remote-device.json` फ़ाइल में रखें।

Execution modes **Local**, **Computer** और **Cloud** हैं। **Cloud** waitlist पर है और access सक्षम होने तक कोई run शुरू नहीं करता।
