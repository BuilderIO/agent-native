# Deployment

<a id="self-host-quickstart"></a>
<a id="skip-ensure-tables"></a>

Agent-Native apps Nitro पर चलती हैं। अपने deployment के अनुसार रास्ता चुनें:

<Cards columns={2}>

### [ऐप deploy करें](/docs/deploy-an-app)

एक standalone app बनाएं और अपने domain पर चलाएं।

### [वर्कस्पेस deploy करें](/docs/workspace-deployment)

Shared login के साथ कई apps को एक origin के पीछे चलाएं।

</Cards>

## Deploy करने से पहले: persistent database चुनें {#persistent-database}

हर deployed app को persistent SQL database चाहिए। पहले production deploy से पहले deployment environment में `DATABASE_URL` सेट करें। अगर provider अलग token मांगता है, तो `DATABASE_AUTH_TOKEN` भी सेट करें।

Standalone app को stable `BETTER_AUTH_SECRET` चाहिए। Signed cross-app requests वाले workspace को `A2A_SECRET` चाहिए।

## Supported targets

Agent-Native Node.js, Vercel, Netlify, Cloudflare, AWS Lambda और Deno Deploy को support करता है।

Advanced settings, secrets और production values के लिए [Deployment environment variables reference](/docs/deployment-environment-variables) देखें।
