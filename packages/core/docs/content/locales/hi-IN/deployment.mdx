## Deploy करने से पहले: persistent database चुनें {#persistent-database}

Hosted production deployments के लिए यह पेज PostgreSQL की सलाह देता है। पहले production deploy से पहले deployment environment में `DATABASE_URL` सेट करें। लोकप्रिय PostgreSQL providers में Neon, Supabase, Railway, Render, Amazon RDS for PostgreSQL, Cloud SQL for PostgreSQL और Azure Database for PostgreSQL शामिल हैं। अन्य SQL backends अभी भी समर्थित हैं; configuration विवरण के लिए [database guide](/docs/server-database) देखें।

Standalone app को stable `BETTER_AUTH_SECRET` चाहिए। Signed cross-app requests वाले workspace को `A2A_SECRET` चाहिए।

## ईमेल डिलीवरी वैकल्पिक है, लेकिन इसकी सलाह दी जाती है {#email-provider}

ईमेल और पासवर्ड वाले authentication के लिए ईमेल provider आवश्यक नहीं है। इसके बिना deployed apps ईमेल और पासवर्ड से signup और login करती हैं, signup email verification छोड़ देती हैं और magic-link authentication उपलब्ध नहीं कराती हैं।

अगर आपको magic links, email verification, password resets, invitations या share notifications चाहिए, तो deploy से पहले Resend या SendGrid connect करें। Deployment environment में `RESEND_API_KEY` या `SENDGRID_API_KEY` सेट करें; SendGrid के लिए `EMAIL_FROM` भी चाहिए। Authentication modes के लिए [Authentication](/docs/authentication) देखें।

## Supported targets

Agent-Native [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Amplify](/docs/aws-amplify), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) और [Render](/docs/render) को support करता है।

Advanced settings, secrets और production values के लिए [Deployment environment variables reference](/docs/deployment-environment-variables) देखें।
