# Azure Static Web Apps

Read the [English Azure Static Web Apps guide](/docs/azure-static-web-apps) for the build steps and
provider-specific production configuration.

The deployment must use a persistent SQL database. Configure `DATABASE_URL`
and `BETTER_AUTH_SECRET` in the provider environment. The Nitro preset is
`azure-swa`.
