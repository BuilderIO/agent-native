# Vercel

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "vercel" } })],
});
```

Vercel CLI या git push के ज़रिए तैनात करें:

```bash
vercel deploy
```

एक कार्यस्थान के लिए, हर ऐप को एक Vercel Build Output API bundle में build करें:

```bash
npx @agent-native/core@latest deploy --preset vercel
```

Vercel Git deployments के लिए, build command को इस पर सेट करें:

```bash
npx @agent-native/core@latest deploy --preset vercel --build-only
```

कार्यस्थान build हर ऐप के Nitro `vercel` output को root `.vercel/output` में copy करता है, हर function को अपना खुद का mount-path environment देता है, और वह route config लिखता है जो ऐप्स को `/<app-id>` पर serve करता है।
