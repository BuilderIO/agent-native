# Cloudflare

## Cloudflare Workers {#cloudflare-workers}

Cloudflare Worker के लिए Nitro का native module output उपयोग करें। यह SSR
सक्षम रखता है और Worker entry point के साथ static assets `.output/server` और
`.output/public` के अंतर्गत emit करता है:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Wrangler के साथ generated Worker को build और deploy करें:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

आप `NITRO_PRESET=cloudflare_module` के साथ preset को स्पष्ट रूप से भी चुन सकते हैं।
Deploy करने से पहले एक durable external PostgreSQL database configure करें। Worker
filesystem persistent application store नहीं है।

## शेड्यूल किया गया काम {#cloudflare-scheduled-work}

Scheduled automations, queued event automations, और बाधित runs की सफ़ाई, ये सब
हर मिनट एक बार चलने वाले sweep पर होते हैं। Build generated `wrangler.json` में
एक `* * * * *`
[Cron Trigger](https://developers.cloudflare.com/workers/configuration/cron-triggers/)
जोड़ता है और आपके पहले से declare किए गए Cron Triggers को बनाए रखता है। जब यह
फायर होता है, तो Worker का `scheduled` handler `A2A_SECRET` से signed एक
short-lived token के साथ sweep को सीधे call करता है, इसलिए deploy करने से पहले
वह secret सेट करें:

```bash
npx wrangler secret put A2A_SECRET --config .output/server/wrangler.json
```

- **CPU time।** Workers Free plan पर हर Cron Trigger invocation को 10 ms CPU
  time मिलता है, और agent jobs चलाने वाले sweep को इससे अधिक चाहिए। Scheduled
  काम के लिए Workers Paid plan उपयोग करें।
- **Timing।** Cron Triggers UTC पर चलते हैं, और किसी नए या बदले गए trigger को
  deploy के बाद फायर होना शुरू करने में 15 मिनट तक लग सकते हैं।
- **लोकल testing।** Built Worker को
  `npx wrangler dev --test-scheduled --config .output/server/wrangler.json` से
  चलाएँ, फिर sweep को एक बार फायर करने के लिए
  `/cdn-cgi/handler/scheduled?cron=*+*+*+*+*` पर request भेजें।

दूसरे hosts के लिए [शेड्यूलर कैसे चलता है](/docs/recurring-jobs#how-scheduler-runs)
देखें।
