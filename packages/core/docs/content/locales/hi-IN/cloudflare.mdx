# Cloudflare

Cloudflare Worker के लिए Nitro का native module output उपयोग करें। यह SSR
सक्षम रखता है और Worker entry point के साथ static assets `.output/server` और
`.output/public` के अंतर्गत emit करता है:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Build and deploy the generated Worker with Wrangler:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

आप `NITRO_PRESET=cloudflare_module` के साथ preset को स्पष्ट रूप से भी चुन सकते हैं।
Deploy करने से पहले एक durable external PostgreSQL database configure करें। Worker
filesystem persistent application store नहीं है।
