# मौजूदा ऐप्स को Core 0.198.0 पर अपग्रेड करें

मौजूदा ऐप को Core 0.198.0 पर लाने के लिए यह निर्देश अपनाएँ। कमांड ऐप या
workspace के root से चलाएँ और शुरू करने से पहले ऐसा source-control diff रखें
जिसकी समीक्षा की जा सके। दूरस्थ deployment settings अलग से जाँचें: CLI स्थानीय
environment files पढ़ सकती है, लेकिन remote environments या database में रखी
feature settings नहीं देख सकती।

## 1. Upgrade और import codemods का preview देखें

Core 0.198.0 के साथ आने वाली CLI चलाएँ, ताकि उसी release का migration manifest
लोड हो:

    npx @agent-native/core@0.198.0 upgrade --codemods --dry-run

ऐप में Core 0.198.0 इंस्टॉल होने के बाद यही preview स्थानीय CLI binary से भी उपलब्ध है:

    npx agent-native upgrade --codemods --dry-run

`--codemods` कमांड `ts-morph` का उपयोग करती है। अगर ऐप से यह पैकेज पहले से resolve नहीं होता, तो पहले इसे development dependency के रूप में इंस्टॉल करें: `pnpm add -D ts-morph`।

`--codemods` समर्थित import बदलाव डिफ़ॉल्ट रूप से लागू करती है। आगे बढ़ने से पहले प्रस्तावित
dependency बदलाव, file diff और warnings देखने के लिए `--dry-run` जोड़ें। अब `--yes` की ज़रूरत नहीं है।

Codemod सक्रिय Core और Toolkit migration manifests का उपयोग करता है। यह केवल .ts
और .tsx files देखता है (declaration files, generated files और dependency
directories छोड़कर) और समर्थित import तथा re-export specifiers बदलता है।
अलग-अलग modules में जाने वाले named exports के लिए यह declaration को symbol के
अनुसार बाँट सकता है और aliases तथा type-only imports बनाए रखता है। यह सरल CSS
@import paths भी बदलता है और resolved rewrite से package सीमा पार होने पर missing
dependency जोड़ता है।

डायग्नोस्टिक CommonJS `require()` और dynamic `import()` forms भी detect करता है, लेकिन codemod इन call expressions को rewrite नहीं करता। रिपोर्ट में दिए गए नए destination का उपयोग करके इन्हें बदलें, फिर Vite या `agent-native doctor` दोबारा चलाएँ। CSS `@import url(...)` paths पर codemod quoted और unquoted दोनों रूपों में काम करता है।

यह call sites नहीं बदलता और files नहीं ले जाता। Unresolved और planned moves
warnings के साथ वैसे ही रहते हैं। यह default, namespace, side-effect या star
imports/exports को विभाजित नहीं कर सकता; symbol-level CSS imports नहीं बाँटे जा सकते। इन मामलों की manual review करें।
Removed exports के लिए code change चाहिए हो सकता है; CLI warning में दिए गए
migration guide का पालन करें।

Preview पूरे upgrade plan को भी दिखाता है: upgrade रोकने वाले framework
overrides या patches, लंबित @agent-native/\* version bumps, local config से
पहचाने गए feature dependencies, package-manager install, scaffold skills refresh
और root package में typecheck script होने पर typecheck। Command package specs को
registry के मौजूदा latest पर ले जाता है और install द्वारा resolve किए गए
versions को pin करता है। इसे तभी चलाएँ जब 0.198.0 आपका इच्छित current release
हो; बाद में exact version चाहिए तो resolved pins जाँचें।

## 2. Toolkit और वैकल्पिक पैकेज की पुष्टि करें

`@agent-native/toolkit/*` में स्थानांतरित imports के लिए `@agent-native/toolkit` चाहिए। समर्थित और resolved import या export को Toolkit में ले जाने पर codemod Toolkit जोड़ता है। यदि ऐप Toolkit export का उपयोग करता है और dependency नहीं जोड़ी गई, तो Core 0.198.0 से मेल खाने वाला Toolkit संस्करण इंस्टॉल करें:

    pnpm add @agent-native/toolkit@0.198.0
    # npm install @agent-native/toolkit@0.198.0
    # yarn add @agent-native/toolkit@0.198.0

## 3. Upgrade लागू करें

Preview देखने और feature packages की पुष्टि के बाद योजना लागू करें:

    npx agent-native upgrade --codemods

यह एक command योग्य @agent-native/\* dependency specs अपडेट करता है, पहचानी गई
feature dependencies align करता है, package manager चलाता है, resolved
Agent-Native versions pin करता है, समर्थित codemods लागू करता है, scaffold skills
refresh करता है और root typecheck script मौजूद होने पर चलाता है। केवल codemods
लागू करने के लिए दूसरी upgrade command न चलाएँ। Warnings और app-level errors
app code में ठीक करें; framework overrides या patches न जोड़ें।

## 4. परिणाम की जाँच करें

पूरा diff देखें, खासकर छोड़ी गई codemod warnings और dependency versions, फिर
चलाएँ:

    npx @agent-native/core@0.198.0 upgrade check
    pnpm typecheck

npm या Yarn के लिए समकक्ष typecheck command चलाएँ और ऐप के संबंधित tests तथा
build भी चलाएँ। वैकल्पिक peer table में local और deployed feature settings
शामिल होने की पुष्टि करें। नीचे की table में पुराने imports खोजें; बचे हुए
results intentional होने चाहिए, manifest द्वारा unsupported होने चाहिए, या
warning से स्पष्ट होने चाहिए।
