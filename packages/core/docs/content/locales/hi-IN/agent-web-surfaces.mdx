# सार्वजनिक एजेंट वेब

सार्वजनिक एजेंट वेब एजेंटों के लिए सार्वजनिक Agent-Native मार्गों को क्रॉल करना, पढ़ना, उद्धृत करना और कॉल करना आसान बनाता है। लक्ष्य प्रत्येक ऐप एंडपॉइंट को सार्वजनिक करना नहीं है। लक्ष्य उन पृष्ठों के लिए एक स्वच्छ सार्वजनिक सतह प्रकाशित करना है जो पहले से ही सार्वजनिक हैं, जबकि निजी डेटा और टूल एक्सेस को स्पष्ट नियंत्रण के पीछे रखना है।

दस्तावेज़ साइट संदर्भ कार्यान्वयन है। आज यह शिप करता है:

- `/robots.txt` एक क्रॉलर नीति के साथ जो पुनर्प्राप्ति की अनुमति देता है लेकिन डिफ़ॉल्ट रूप से प्रशिक्षण की अनुमति नहीं देता है।
- `/sitemap.xml` एक साइटमैप इंडेक्स के रूप में, जो हर भाषा के लिए एक `/sitemap-<locale>.xml` की ओर इशारा करता है, पूर्ण विहित URLs और `lastmod` के साथ जब स्रोत फ़ाइल इसे उजागर करती है।
- एजेंट-अनुकूल सामग्री खोज के लिए `/llms.txt` और `/llms-full.txt`।
- Markdown दर्पण जैसे `/docs/getting-started.md`।
- उत्पादन निर्माण के बाद सार्वजनिक दस्तावेज़ पृष्ठों के लिए `Accept: text/markdown` प्रतिक्रियाएँ।
- आधार संगठन, वेबसाइट और पेज मेटाडेटा के लिए JSON-LD।
- एक ऑडिट CLI (`npx @agent-native/core@latest audit-agent-web`) जो उपरोक्त सभी की जांच करता है।

इन फ़ाइलों को प्रकाशित करने से कोई action कभी उजागर नहीं होता। कोई action बाहरी एजेंट्स तक सिर्फ़ अपने `publicAgent` ऑप्ट-इन से पहुँचता है; देखें [Public एजेंट्स के लिए एक्सपोज़ करें](/docs/actions-access-control#public-agent)।

## कॉन्फ़िगरेशन {#config}

`@agent-native/core/vite` का `createAgentWebVitePlugin` प्रोडक्शन बिल्ड के दौरान ये फ़ाइलें लिखता है। इसे उन पेजों के साथ अपने Vite कॉन्फ़िग में जोड़ें जिन्हें एजेंट्स को पढ़ना चाहिए:

```ts
// vite.config.ts
import { defineConfig } from "vite";
import { createAgentWebVitePlugin } from "@agent-native/core/vite";

export default defineConfig({
  plugins: [
    // ...your existing plugins
    createAgentWebVitePlugin({
      siteName: "My Agent-Native App",
      siteUrl: "https://example.com",
      pages: [
        {
          path: "/pricing",
          title: "Pricing",
          description: "Plans and limits.",
          markdown: "Plans and limits.\n",
        },
      ],
      agentWeb: { crawlerPolicy: "discoverable-no-training" },
    }),
  ],
});
```

प्लगइन सिर्फ़ वही पेज प्रकाशित करता है जो आप सूची में देते हैं, और कुछ नहीं। यह आपकी रूट एक्सेस सेटिंग्स नहीं पढ़ता, और जब तक आप इसे पास न करें, `package.json` से `agentWeb` भी नहीं पढ़ता। सेटिंग्स को `package.json` में `agent-native.workspaceApp.agentWeb` के तहत रखने के लिए `@agent-native/core/agent-web` से इम्पोर्ट किया गया `agentWeb: agentWebConfigFromPackageJson(pkg)` पास करें।

| विकल्प          | डिफ़ॉल्ट                     | क्या करता है                                                                                                                                               |
| --------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `discoverable`  | `pages` खाली न हो तो चालू    | `false` होने पर कोई फ़ाइल नहीं लिखता।                                                                                                                      |
| `llmsTxt`       | `true`                       | `/llms.txt` और `/llms-full.txt` लिखता है।                                                                                                                  |
| `markdownTwins` | `true`                       | जिस भी पेज में `markdown` है, उसकी एक `.md` कॉपी लिखता है।                                                                                                 |
| `crawlerPolicy` | `"discoverable-no-training"` | `robots.txt` के नियम तय करता है: `"discoverable-no-training"`, `"allow-all"` या `"disallow-all"`।                                                          |
| `crawlers`      | कोई नहीं                     | अलग-अलग क्रॉलर श्रेणियों को ओवरराइड करता है: `training`, `search`, `userTriggered`, `codingAgents` या `autonomousAgents`, हर एक `"allow"` या `"disallow"`। |

डिफ़ॉल्ट क्रॉलर नीति "खोजने योग्य, प्रशिक्षण योग्य नहीं" है: सर्च, उपयोगकर्ता द्वारा शुरू की गई पुनर्प्राप्ति, कोडिंग एजेंट्स और स्वायत्त ब्राउज़िंग एजेंट्स की अनुमति है; प्रशिक्षण क्रॉलर्स की अनुमति नहीं है।

`jsonLd`, `publicAgentCard` और `publicMcp` स्वीकार किए जाते हैं, लेकिन अभी इन्हें कुछ भी नहीं पढ़ता। JSON-LD के लिए `@agent-native/core/agent-web` के `buildBaseJsonLd` और `buildPageJsonLd` को खुद अपने पेजों में रेंडर करें।

## सत्य का मार्ग स्रोत {#route-source}

पेज सूची ही सत्य का स्रोत है: एजेंट्स को वही पेज मिलते हैं जो आप पास करते हैं, सिर्फ़ वही। इसे उन पेजों से बनाएँ जो पहले से सार्वजनिक हैं:

- सार्वजनिक ऐप में, `protectedPaths` को छोड़कर हर रूट।
- आंतरिक ऐप में, सिर्फ़ `publicPaths`।
- सार्वजनिक शेयर और फ़ॉर्म पेज जिन्हें एजेंट्स को पढ़ पाना चाहिए।
- सबमिट किया गया निजी डेटा, प्रमाणित डैशबोर्ड, या उपयोगकर्ता या संगठन की स्थिति कभी नहीं, भले ही पास का कोई पेज सार्वजनिक हो।

अपनी एक्सेस सेटिंग्स से शुरू करने के लिए, `@agent-native/core/agent-web` का `deriveAgentWebPublicRoutes` आपके ऐप के `audience`, `publicPaths`, `protectedPaths` और `routes` लेता है और वे रूट लौटाता है जिन्हें ये सेटिंग्स सार्वजनिक बनाती हैं। हर पेज को फिर भी अपना शीर्षक और अपना Markdown चाहिए।

यह मिश्रित ऐप्स को स्वाभाविक रखता है। एक फॉर्म ऐप एक सार्वजनिक फॉर्म पेज को उजागर कर सकता है और सबमिशन को निजी रख सकता है। एक सामग्री ऐप प्रकाशित पोस्ट को उजागर कर सकता है और संपादक को निजी रख सकता है। एक डॉक्स साइट एडमिन टूल्स को छोड़कर बाकी सब कुछ उजागर कर सकती है।

## सार्वजनिक पृष्ठ सार्वजनिक उपकरण नहीं हैं {#public-tools}

सार्वजनिक पेज एक्सेस और सार्वजनिक टूल एक्सेस अलग-अलग हैं। किसी रूट के सार्वजनिक होने का मतलब केवल यह है कि एजेंट उस रूट को HTML, Markdown, साइटमैप प्रविष्टियों, एलएलएमएस प्रविष्टियों और संरचित डेटा के रूप में पढ़ सकते हैं।

<Callout id="doc-block-s50w8y" tone="warning">

**सार्वजनिक पेज सार्वजनिक टूल नहीं है।** किसी रूट को क्रॉल करने योग्य बनाने से कोई action कभी उजागर नहीं होता। टूल एक्सेस के लिए action पर स्पष्ट `publicAgent.expose` ऑप्ट-इन ज़रूरी है।

</Callout>

## बिल्ड-टाइम फ़ाइलें {#build-time}

`@agent-native/core/agent-web` में फ्रेमवर्क उपयोगिताएँ एक पृष्ठ सूची से सामान्य फ़ाइलें उत्पन्न करती हैं:

```ts
import {
  buildAgentWebStaticFiles,
  normalizeAgentWebConfig,
} from "@agent-native/core/agent-web";

const config = normalizeAgentWebConfig(
  { crawlerPolicy: "discoverable-no-training" },
  { hasPublicRoutes: true },
);

const files = buildAgentWebStaticFiles({
  siteName: "My Agent-Native App",
  siteUrl: "https://example.com",
  description: "Public docs for my app.",
  config,
  pages: [
    {
      path: "/docs",
      title: "Docs",
      description: "Start here.",
      markdown: "# दस्तावेज़\n\nयहां प्रारंभ करें.\n",
      markdownPath: "/docs/getting-started.md",
      lastmod: new Date(),
    },
  ],
});
```

`createAgentWebVitePlugin` आपके लिए `buildAgentWebStaticFiles` को कॉल करता है और फ़ाइलें `public`, `dist`, `dist/client`, `dist/server/public` और `build/client` में से उन फ़ोल्डरों में लिखता है जो मौजूद हैं। किसी दूसरे बिल्ड टूल के साथ, यूटिलिटीज़ को सीधे कॉल करें।

इनमें से कोई भी पेज के अपने URL पर `Accept: text/markdown` का जवाब नहीं देता: Markdown कॉपी सिर्फ़ उसके `.md` URL पर होती है। उस हेडर का जवाब देने के लिए, एक सर्वर रूट जोड़ें जो `buildMarkdownResponseHeaders` के हेडर्स के साथ पेज का Markdown लौटाए, जैसा डॉक्स साइट करती है। उस रूट के बिना, नीचे दिया गया ऑडिट अपनी `Accept: text/markdown` जाँच में फ़ेल होता है।

बड़े साइटमैप को बाँटने के लिए `buildAgentWebStaticFiles` या `createAgentWebVitePlugin` को `sitemapGroup` पास करें। यह हर पेज को एक समूह कुंजी, जैसे उसकी भाषा, से जोड़ता है, और `sitemap.xml` एक साइटमैप इंडेक्स बन जाता है जिसमें हर समूह के लिए एक `sitemap-<group>.xml` होता है।

## किसी साइट का ऑडिट करें {#audit}

किसी तैनात साइट या स्थानीय उत्पादन सर्वर के विरुद्ध CLI ऑडिट का उपयोग करें:

```bash
npx @agent-native/core@latest audit-agent-web --url https://www.agent-native.com
```

ऑडिट इसकी जाँच करता है:

- SSR-दृश्यमान HTML.
- कैनोनिकल URLs.
- JSON-LD.
- `robots.txt` नीति और संपूर्ण साइटमैप URL.
- पूर्ण साइटमैप प्रविष्टियाँ।
- `/llms.txt` और `/llms-full.txt`.
- Markdown दर्पण।
- `Accept: text/markdown`.
- सामान्य एजेंट पुनर्प्राप्ति उपयोगकर्ता एजेंटों के लिए कोई आकस्मिक 401/403 ब्लॉक नहीं।

यदि आवश्यक सार्वजनिक सतह गायब है तो ऑडिट गैर-शून्य से बाहर हो जाता है।
