# Doctor

Generated apps और workspaces में source code होता है जिसे repository development workflow के माध्यम से बदला जा सकता है, जिसमें वह agent frame भी शामिल है जिसे जानबूझकर workspace और write tooling दी गई हो। `agent-native doctor` source में security-critical code invariants जाँचता है। यह read-only है: doctor code edit नहीं करता, केवल report करता है।

`agent-native doctor` security और migration समस्याएँ जाँचता है। `migration-manifest` installed `migration-manifest.json` में listed imports ढूँढता है और इसे disable नहीं किया जा सकता। `feature-dependencies` configured features की उन missing optional peer packages को बताता है जिन्हें resolve नहीं किया जा सकता।

Migration preflight चलाएँ:

```bash
agent-native doctor --only migration-manifest
```

Files लिखे बिना upgrade और codemod diff का preview देखें:

```bash
npx agent-native upgrade --codemods --dry-run
```

Supported import rewrites लागू करें:

```bash
npx agent-native upgrade --codemods
```

`--codemods` supported rewrites को default रूप से apply करता है। केवल preview देखने और files न लिखने के लिए `--dry-run` जोड़ें। Apply करने से पहले diff और warnings देखें। `--yes` compatibility के लिए स्वीकार है और behavior नहीं बदलता। `migration-manifest` को disable नहीं किया जा सकता। `planned` entries केवल warnings हैं और rewrite नहीं होतीं। Active entries findings हैं; codemod उन्हें तभी rewrite करता है जब destination export installed हो। हटाए गए exports के लिए manual migration चाहिए। Finding में दिए गए guide या [Core 0.198.0 migration guide](/docs/upgrading-core-ui) का पालन करें। इसमें `ts-morph` और optional feature packages सूचीबद्ध हैं। JSON `guardsRun` में वास्तव में चलाए गए guards सूचीबद्ध होते हैं।

CLI हर नए app और workspace में `pnpm doctor` तथा `pnpm agent-native:doctor` commands जोड़ता है। Workspace root से चलाने पर `apps/<name>` के हर app की जाँच होती है। Findings मिलने पर builds डिफ़ॉल्ट रूप से fail होती हैं; `failOnBuild: false` केवल reviewed exception के रूप में उपयोग करें।

`planned` चिह्नित entries केवल warnings के रूप में दिखती हैं और rewrite नहीं होतीं। Active entries findings होती हैं; codemod उन्हें तभी rewrite करता है जब destination export installed हो।
