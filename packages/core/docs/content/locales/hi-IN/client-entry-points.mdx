# एंट्री पॉइंट्स

`app/entry.client.tsx` सर्वर-रेंडर किए गए HTML को ब्राउज़र में हाइड्रेट करता है, और `app/entry.server.tsx` वह HTML सर्वर पर रेंडर करता है। दोनों React Router द्वारा जनरेट किए गए पतले रैपर हैं। आपको इन्हें एडिट करने की शायद ही कभी आवश्यकता होती है।

```ts filename="app/entry.server.tsx"
import {
  createDocumentRequestHandler,
  streamTimeout,
} from "@agent-native/core/server/entry-server";
import { ServerRouter } from "react-router";

export default createDocumentRequestHandler(ServerRouter);
export { streamTimeout };
```

इन्हें केवल एडवांस्ड SSR कस्टमाइज़ेशन के लिए एक्सेस करें, उदाहरण के लिए स्ट्रीमिंग बिहेवियर बदलने के लिए। सामान्य पेज, लेआउट, और डेटा को यहां किसी बदलाव की आवश्यकता नहीं है। इसके बजाय पेज जोड़ने के लिए [रूटिंग](/docs/client-routing) देखें।

## आगे क्या
