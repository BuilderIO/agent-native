# Mit dem Agent sprechen

Der Agent von Folien erstellt, bearbeitet, importiert, exportiert und gestaltet Decks über dieselben Aktionen, die auch die Oberfläche verwendet, sodass Sie alles, was Sie anklicken können, auch erfragen können. Diese Seite behandelt, was er automatisch sieht, und Eingabeaufforderungen, organisiert nach Aufgabe. Sie ist nützlich, egal ob Sie Folien im Alltag nutzen oder darauf aufbauen.

## Wie der Agent Ihren Bildschirm sieht

Der Agent weiß immer, welches Deck gerade geöffnet ist, auf welcher Folie Sie sich befinden, und die vollständige Liste der Folien in diesem Deck. Sie müssen nicht „Folie 4“ sagen, er weiß bereits, was dort ist. Wenn Sie mitten in einer Bearbeitung im visuellen Editor sind, sieht er auch Ihre aktive Auswahl: das konkrete Element, auf das Sie geklickt haben, das Werkzeug, das Sie verwenden, und berechnete Stildetails, sodass „mach das größer“ auf das wirkt, was Sie tatsächlich ausgewählt haben, statt zu raten.

Der Chat befindet sich in der Seitenleiste für schnellen Hin-und-her-Austausch. Folien verfügt außerdem über eine Vollbild-Agent-Ansicht für längere Sitzungen mit mehr Arbeitsraum.

### Auswahlbewusste Bearbeitungen

Wählen Sie Text auf einer Folie aus und klicken Sie im Blasenmenü auf die Schaltfläche **Mit KI überarbeiten**, oder markieren Sie per Rahmenauswahl ein oder mehrere Elemente und klicken Sie im schwebenden Chip auf **An Agent senden**, um dem Agenten genau das zu übergeben, was Sie markiert haben. „Mach das prägnanter“ oder „übersetze nur das“ wirkt dann nur auf Ihre Auswahl, nicht auf die gesamte Folie.

## Nützliche Eingabeaufforderungen nach Aufgabe

Jede Eingabeaufforderung unten wird zu einer echten Aktion gegen Ihr tatsächliches Deck, dasselbe, aus dem auch die Oberfläche liest und in das sie schreibt. Hier ist ein durchgerechnetes Beispiel:

<Comparison>

### :blue: Sie fragen

„Erstellen Sie ein 10-Folien-Pitch-Deck für einen Kaffee-Abonnementdienst, Zielgruppe sind Investoren.“

### :green: Was passiert

Der Agent plant zuerst die Gliederung und streamt dann jede Folie live in den Editor, während sie erstellt wird, sodass Sie zusehen können, wie das Deck Gestalt annimmt, statt darauf zu warten, dass alles auf einmal erscheint.

</Comparison>

<Cards columns={2}>

### Generieren

- **„Fassen Sie dieses PDF als 6-Folien-Deck zusammen.“** Hängen Sie das PDF an, und der Agent verwandelt es in ein bearbeitbares Deck.
- **„Verwandeln Sie dieses Google Doc in ein Deck.“** Dieselbe Idee, nur ausgehend von einem Google Doc.

### Bearbeiten und neu gestalten

_Bei einer geöffneten Folie löst sich „diese Folie“ von selbst auf._

- **„Fügen Sie nach Folie 3 eine Preisfolie hinzu.“** Die neue Folie erscheint sofort im Filmstreifen.
- **„Vergrößern Sie den Titel dieser Folie und ändern Sie die Akzentfarbe in Grün.“** Die Änderung wird live auf die geöffnete Folie angewendet.
- **„Ersetzen Sie überall in diesem Deck das Wort ‚Kunden‘ durch ‚Mitglieder‘.“** Alle Folien werden gleichzeitig aktualisiert.

### Importieren und exportieren

- „Importieren Sie dieses PPTX und verwandeln Sie jede Folie hier in eine bearbeitbare Folie.“
- „Exportieren Sie dieses Deck als PowerPoint.“
- „Machen Sie dieses Deck bereit, um es in Google Slides zu öffnen.“

</Cards>
