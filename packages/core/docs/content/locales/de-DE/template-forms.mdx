# Formulare

Forms ist ein Formular-Builder für alle, die Informationen sammeln möchten, ohne dafür Code zu schreiben. Nutzen Sie ihn für Anmeldungen, Feedback, Registrierungen oder Umfragen. Beschreiben Sie dem Agenten das gewünschte Formular, feilen Sie bei Bedarf visuell für mehr direkte Kontrolle daran, und veröffentlichen Sie einen Link, den jeder ausfüllen kann.

Jede neue Sitzung öffnet sich mit **Ask Forms**, einem Chat, in dem Sie beschreiben, was Sie möchten. Der Agent erstellt das Formular für Sie. Sie können jederzeit in den visuellen Editor wechseln, um Felder, Validierung oder Veröffentlichungseinstellungen von Hand anzupassen. Beide Bearbeitungswege aktualisieren dasselbe Formular, sodass nichts aus dem Gleichgewicht gerät.

## Was ersetzt wird

<Comparison>

### Vorher

- Typeform, Google Forms oder ein selbstgebautes Formular zum Sammeln von Antworten
- Neue Einreichungen von Hand in Slack oder eine Tabelle kopieren
- Ein separates Tool nur zum Zusammenfassen der Ergebnisse
- Eine Zapier-Automatisierung einrichten, um Antworten in Sheets oder einen Webhook zu bekommen

### Nachher

- Ein Formular, das der Agent und der visuelle Editor gemeinsam aktualisieren
- Neue Antworten werden in dem Moment, in dem sie eintreffen, an Slack, Discord, Sheets oder einen Webhook gesendet
- Fragen Sie nach einer Zusammenfassung und erhalten Sie ein Diagramm, eine Tabelle oder beides, ohne ein separates Tool
- Bedingte Felder, Spam-Schutz und anonymer Modus sind alle in denselben Builder integriert

</Comparison>

## Forms in einem Multi-App-Arbeitsbereich

Wenn Sie Forms zusammen mit anderen Apps in [Dispatch](/docs/template-dispatch) betreiben, ist ein Formular nicht mehr nur eine Seite, die Sie von Hand öffnen. Der Agent von Forms kann Fragen weiterleiten, die zu einer anderen App gehören, und andere Apps können Antworten direkt in Ihr Formular senden, genau wie es auch der Feedback-Button des Frameworks selbst tut. Unter [Forms in einem Multi-App-Arbeitsbereich](/docs/template-forms-integrations) erfahren Sie, wie das funktioniert.

## Was Sie damit machen können

- **Formulare im Dialog erstellen.** Probieren Sie Eingabeaufforderungen wie „Erstelle ein Kontaktformular“, „füge eine NPS-Bewertungsfrage hinzu“ oder „mache das E-Mail-Feld zu einem Pflichtfeld.“ Siehe [die verfügbaren Feldtypen](/docs/template-forms-features#field-types).
- **Visuell feinabstimmen.** Bearbeiten Sie Beschriftungen, Platzhalter, Pflichtfelder, Optionen und Feldreihenfolge direkt im Formular-Builder, wenn Sie mehr direkte Kontrolle möchten.
- **Ein öffentliches Formular veröffentlichen und schützen.** Teilen Sie einen öffentlichen Link, und aktivieren Sie bei Bedarf Spam-Schutz oder vollständig anonyme Antworten. Siehe [Funktionen](/docs/template-forms-features).
- **Antworten prüfen und um Einblicke bitten.** Probieren Sie Eingabeaufforderungen wie „Fasse die Einreichungen dieser Woche zusammen“ oder „Stelle Einreichungen nach Tag als Diagramm dar.“ Siehe [Funktionen](/docs/template-forms-features#response-insights).
- **Einreichungen automatisch weiterleiten.** Fügen Sie eine Slack-, Discord-, Google-Sheets- oder allgemeine Webhook-URL ein, und neue Antworten werden in dem Moment, in dem sie eintreffen, dorthin gesendet.
