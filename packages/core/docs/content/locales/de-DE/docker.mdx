# Docker

Lesen Sie den [englischen Docker-Leitfaden](/docs/docker). Das Gerüst erzeugt
keine `Dockerfile`; kopieren Sie das dort gezeigte Beispiel vor `docker build`.

The deployment must use a persistent PostgreSQL database. Configure `DATABASE_URL`
and `BETTER_AUTH_SECRET` in the provider environment. The Nitro preset is
`node`.
