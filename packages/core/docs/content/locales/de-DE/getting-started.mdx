# Erste Schritte

Agent-Native ist ein Open-Source-TypeScript-Framework zum Entwickeln autonomer
Agenten mit intuitiven Benutzeroberflächen. Sie definieren jede Fähigkeit einmal
als [Aktion](/docs/actions-overview) – eine typisierte Funktion, die der Agent als
Tool verwendet und die UI aus Code aufruft.

In diesem Leitfaden erstellen Sie einen Agenten mit einer Chat-UI und rufen
dessen enthaltene `hello`-Action über den Agenten und die UI auf.

<GettingStartedPaths />

## Voraussetzungen

- [Node.js](https://nodejs.org) 22 oder höher
- [pnpm](https://pnpm.io)
- Eine LLM-Verbindung für den Agenten: Builder.io, ein Anthropic- oder
  OpenAI-API-Schlüssel oder ein lokales Ollama-Modell

## Einen Agenten erstellen

Beginnen Sie in einem neuen Verzeichnis mit dem Chat-Template:

```bash
npx @agent-native/core@latest create my-app --standalone --template chat
cd my-app
pnpm install
```

Das Template gibt Ihrem Agenten eine Browser-UI, Authentifizierung, dauerhafte
Unterhaltungen, Live-Synchronisierung, Anwendungskontext und ein
`actions/`-Verzeichnis. Außerdem enthält es eine kleine `hello`-Action, die Sie
in diesem Leitfaden verwenden werden.

## Den Entwicklungsserver starten

Starten Sie den Entwicklungsserver:

```bash
pnpm dev
```

Die Browser-UI wird unter `http://localhost:8080` geöffnet. Falls sie nicht
automatisch geöffnet wird, rufen Sie diese URL im Browser auf.

<Callout tone="info">

Wählen Sie auf dem Begrüßungsbildschirm **Continue as local dev**. Für die
lokale Entwicklung müssen Sie keine E-Mail-Adresse und kein Passwort eingeben.

</Callout>

Verbinden Sie als Nächstes ein LLM. Wählen Sie **Connect Builder.io**, um
kostenlose Credits zu verwenden, oder **Custom keys**, wählen Sie einen Anbieter
aus und geben Sie die abgefragten Verbindungsdaten ein.

## Die Action über den Agenten ausführen

Eine Action ist eine typisierte Funktion, die Ihre React-UI aus Code aufrufen
kann und die Agenten als Tool verwenden können. Das Chat-Template enthält eine
einfache `hello`-Action, damit Sie dieses Muster ausprobieren können, bevor Sie
selbst eine schreiben.

Geben Sie im Agenten-Panel ein:

> Call the hello action for Alex.

Der Agent findet `hello` anhand seiner Beschreibung und seines Eingabeschemas,
übergibt `Alex` als Eingabe für `name` und antwortet:

```text
Hello, Alex!
```

## Die Action ansehen

Öffnen Sie `actions/hello.ts`:

```ts filename="actions/hello.ts"
import { defineAction } from "@agent-native/core/action";
import { z } from "zod";

export default defineAction({
  description: "Return a friendly greeting.",
  schema: z.object({
    name: z.string().default("world").describe("Name to greet"),
  }),
  http: { method: "GET" },
  run: async ({ name }) => {
    return { message: `Hello, ${name}!` };
  },
});
```

Konzentrieren Sie sich zunächst auf vier Teile:

- `description` erklärt dem Agenten, wann er die Action verwenden soll.
- `schema` validiert die Eingabe und gibt dem Agenten eine typisierte
  Tool-Definition.
- `http` stellt diese schreibgeschützte Action über `GET` bereit, damit
  `useActionQuery` sie aus React aufrufen kann.
- `run` enthält die Anwendungslogik, die Agent und UI gemeinsam nutzen.

Die vollständige API finden Sie unter [Actions definieren](/docs/actions-defining).

## Die Action über React aufrufen

Fügen Sie eine Route unter `app/routes/hello.tsx` hinzu:

```tsx filename="app/routes/hello.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";
import { useState } from "react";

import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function HelloRoute() {
  const [name, setName] = useState("Alex");
  const { data } = useActionQuery("hello", { name });

  return (
    <main className="mx-auto grid w-full max-w-xl gap-6 p-6">
      <h1 className="text-2xl font-semibold">Hello action</h1>
      <div className="grid gap-2">
        <Label htmlFor="name">Name</Label>
        <Input
          id="name"
          value={name}
          onChange={(event) => setName(event.target.value)}
        />
      </div>
      <p className="text-xl font-medium">{data?.message}</p>
    </main>
  );
}
```

<Callout tone="warning">

Starten Sie den Entwicklungsserver neu, damit er die neue Route erkennt, und
öffnen Sie anschließend `http://localhost:8080/hello`.

</Callout>

Während Sie einen Namen eingeben, ruft `useActionQuery` `hello` auf und zeigt
das Ergebnis an. Die Eingabe- und Ergebnistypen der Action werden abgeleitet;
die Seite benötigt daher weder eine eigene API-Route noch eine zweite
Implementierung der Begrüßung.

## Die Action ändern

Ändern Sie in `actions/hello.ts` den Rückgabewert:

```ts
return { message: `Welcome, ${name}.` };
```

Aktualisieren Sie `/hello` und bitten Sie dann den Agenten erneut, `hello`
aufzurufen. Beide geben die aktualisierte Begrüßung zurück, weil sie dieselbe
Action aufrufen.

## Actions auf andere Arten aufrufen

Sie haben dieselbe Action über den Agenten und die UI aufgerufen. Dieselbe
Action lässt sich außerdem aufrufen über:

| Aufruf über                             | Verwenden Sie es, um                                                         |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| [HTTP API](/docs/http-api)              | eine Action aus einem Skript, Backend oder einer Integration aufzurufen.     |
| [CLI](/docs/actions-other-surfaces#cli) | eine Action über das Terminal auszuführen oder zu testen.                    |
| [MCP](/docs/actions-other-surfaces#mcp) | einen externen KI-Client Actions als Tools entdecken und aufrufen zu lassen. |
| [A2A](/docs/actions-other-surfaces#a2a) | einen anderen Agenten Arbeit an Ihren delegieren zu lassen.                   |

Jeder Aufrufer verwendet dieselbe Action-Definition. Sie benötigen keine
separate Implementierung für jeden einzelnen. Dieses gemeinsame Action-Modell
steht im Zentrum von Agent-Native: Verhalten, Validierung und Berechtigungen
bleiben in UI, Agenten und Integrationen abgestimmt, wenn Sie Fähigkeiten hinzufügen.

## Was Sie erstellt haben

Sie haben einen Agenten mit einer Chat-UI erstellt, dieselbe `hello`-Action über
den Agenten und eine React-UI aufgerufen und die Begrüßung einmal geändert,
woraufhin sich beide aktualisiert haben. Jede Action, die Sie von nun an
schreiben, folgt demselben Muster.
