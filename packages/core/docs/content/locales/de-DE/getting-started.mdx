# Erste Schritte

Agent-Native-Apps geben dem Agenten und der UI dieselben [Aktionen](/docs/actions),
SQL-Daten und den Anwendungszustand. Dieser Pfad beginnt mit Chat, das den
Chatverlauf bereits in SQL speichert. Fügen Sie eigene Tabellen nur hinzu, wenn
Ihre App Fachdaten dauerhaft speichern muss.

<Steps>

### Eine Chat-App erstellen und einen Agenten konfigurieren

Erstellen Sie das Chat-Template, installieren Sie die Abhängigkeiten, starten Sie
den Entwicklungsserver und konfigurieren Sie einen Agenten. Sie erhalten eine
funktionierende Chat-App, die Sie erweitern können.
**Hier sind Sie.**

### Eine Aktion hinzufügen

Definieren Sie einen typisierten Textanalysator und rendern Sie sein Ergebnis im
Chat als Diagramm.

### Eine Seite hinzufügen

Erstellen Sie eine React-Route, die dieselbe Aktion außerhalb des Transkripts aufruft.

</Steps>

## 1. Eine Chat-App erstellen {#create-your-app}

Sie benötigen [Node.js 22+](https://nodejs.org) und [pnpm](https://pnpm.io).

Öffnen Sie ein Terminal, wechseln Sie in das Verzeichnis, in dem Ihre
Agent-Native-App erstellt werden soll, und führen Sie Folgendes aus:

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

Die App wird unter `http://localhost:8080` geöffnet. Wenn der Anmeldebildschirm
erscheint, registrieren Sie sich mit einem erfundenen Login. Für die lokale
Entwicklung ist keine E-Mail-Verifizierung erforderlich.

Das Chat-Template umfasst dauerhafte Chat-Threads, Authentifizierung,
Live-Synchronisierung, ein `actions/`-Verzeichnis sowie die Standardaktionen
`view-screen` und `navigate`.

### Einen anderen Ausgangspunkt wählen

Wenn Chat nicht der richtige Ausgangspunkt ist, führen Sie `create` ohne
`--template` aus und wählen Sie eine andere Option in der CLI. Weitere Wege
finden Sie unter [Vorlagen erstellen](/docs/creating-templates).

## 2. Einen Agenten konfigurieren {#connect-ai}

Das Chat-Template öffnet direkt die Chat-Oberfläche. Wenn der Agent noch nicht
antwortet, öffnen Sie **Einstellungen > Agent verwalten** oder verwenden Sie
**Cmd/Ctrl+K > Agent verwalten**, um ein Modell und einen Anbieter zu
konfigurieren.

Sobald der Agent antwortet, fahren Sie mit [Eine Aktion hinzufügen](/docs/getting-started-actions)
fort.
