# Einstiegspunkte

`app/entry.client.tsx` hydratisiert das serverseitig gerenderte HTML im Browser, und `app/entry.server.tsx` rendert dieses HTML auf dem Server. Beide sind dünne, von React Router generierte Wrapper. Sie müssen sie selten bearbeiten.

```ts filename="app/entry.server.tsx"
import {
  createDocumentRequestHandler,
  streamTimeout,
} from "@agent-native/core/server/entry-server";
import { ServerRouter } from "react-router";

export default createDocumentRequestHandler(ServerRouter);
export { streamTimeout };
```

Greifen Sie hierauf nur für fortgeschrittene SSR-Anpassungen zu, etwa das Ändern des Streaming-Verhaltens. Gewöhnliche Seiten, Layout und Daten benötigen hier keine Änderungen. Siehe [Routing](/docs/client-routing), um stattdessen Seiten hinzuzufügen.
