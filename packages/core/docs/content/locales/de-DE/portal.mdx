# Portal

Portal koppelt einen Computer für geräteübergreifende Ausführung. Öffne **Einstellungen → Arbeitsbereich → Koppeln oder reparieren** und speichere das Gerätetoken in `~/.agent-native/remote-device.json` auf dem Computer.

Die Ausführungsmodi sind **Local**, **Computer** und **Cloud**. **Cloud** steht auf einer Warteliste und startet bis zur Freischaltung keinen Lauf.
