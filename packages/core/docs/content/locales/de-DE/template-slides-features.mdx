# Funktionen

Alle wichtigen Folien-Funktionen: wie sie funktionieren und wie Sie sie einrichten. Einen Überblick finden Sie unter
[Folien](/docs/template-slides), die vollständige Liste der Eingabeaufforderungen unter [Mit dem
Agent sprechen](/docs/template-slides-agent).

## Decks

Alles rund um das Erstellen, Bearbeiten, Präsentieren und Teilen eines einzelnen Decks.

### Ein Deck aus einer Eingabeaufforderung generieren

<Steps>

### Den Agenten briefen wie eine Person

„Erstellen Sie ein 10-Folien-Pitch-Deck für einen Kaffee-Abonnementdienst, Zielgruppe sind Investoren.“ Geben Sie ihm ein Thema, eine Länge und eine Zielgruppe, und er baut die Gliederung darum herum auf.

### Beim Aufbau Folie für Folie zusehen

Der Agent plant zuerst die Gliederung und baut das Deck dann Folie für Folie auf, sodass Sie zusehen können, wie es im Editor entsteht, statt darauf zu warten, dass alles auf einmal erscheint.

### In derselben Konversation weiter verfeinern

„Fügen Sie nach Folie 3 eine Preisfolie hinzu.“ „Machen Sie diesen Abschnitt kürzer.“ Nur die Folien, um die Sie gebeten haben, ändern sich.

</Steps>

Jedes neue Deck verwendet standardmäßig eine 16:9-Breitbild-Leinwand. Bitten Sie den Agenten, sie auf 1:1 (quadratisch), 9:16 (vertikal, im Stories-Stil) oder 4:5 (Hochformat) umzustellen, wenn Sie ein anderes Format brauchen. Eine Änderung aktualisiert die Editor-Leinwand, den Präsentationsmodus und den PDF-/PPTX-Export gemeinsam, sodass Sie nie mit einem Export enden, der nicht zu dem passt, was Sie erstellt haben.

### Folien visuell bearbeiten

- **Inline-Textbearbeitung.** Doppelklicken Sie auf beliebigen Text, um ihn direkt auf der Folie zu bearbeiten.
- **Das Blasenmenü.** Klicken Sie auf einen Block, eine Überschrift, eine Aufzählungsliste, ein Bild, um schnelle Formatierungsoptionen nur für diesen Block zu erhalten.
- **Das Schrägstrichmenü.** Tippen Sie `/`, um einen neuen Block einzufügen, eine Überschrift, Aufzählungspunkte, eine Tabelle, einen Codeblock, einen Bildplatzhalter, ohne die Tastatur zu verlassen.
- **Neu ordnen.** Ziehen Sie Folien im Filmstreifen, um sie neu zu ordnen; Rückgängig und Wiederholen funktionieren wie erwartet.
- **Umfangreiche Einbettungen.** Eine Folie kann neben Ihrem Text und Ihren Bildern auch ein handgezeichnetes Diagramm oder eine live gerenderte Grafik enthalten, nicht nur statisches HTML.
- **Generierte Inhalte verschieben und in der Größe ändern.** Ziehen Sie ein Objekt, um es zu verschieben, oder ziehen Sie seine Größenanpassungspunkte, um seine Größe zu ändern. Um einen umrandeten Abschnitt zu verschieben, ziehen Sie dessen Text.

Wählen Sie Text auf einer Folie aus und klicken Sie im Blasenmenü auf die Schaltfläche **Mit KI überarbeiten**, um dem Agenten genau diese Auswahl zu übergeben. Oder wählen Sie mehrere Elemente auf Ihrer Folie aus und klicken Sie auf **An Agent senden**. Geben Sie dann eine Eingabeaufforderung im Chatfenster rechts ein. Wie auswahlbewusste Bearbeitungen funktionieren, erfahren Sie unter [Mit dem Agent sprechen](/docs/template-slides-agent).

### Im Vollbildmodus präsentieren

Klicken Sie auf **Präsentieren**, um das Deck im Vollbildmodus zu öffnen. Die Steuerelemente blenden aus, bis Sie die Maus bewegen, und Ihre Sprechernotizen bleiben nur für Sie sichtbar. Während der Präsentation gelten diese Tastenkürzel:

| Taste                     | Aktion                                            |
| ------------------------- | ------------------------------------------------- |
| `→`, `↓` oder `Leertaste` | Nächste Folie                                     |
| `←` oder `↑`              | Vorherige Folie                                   |
| `F`                       | Vollbildmodus umschalten                          |
| `S`                       | Sprechernotizen in einem separaten Fenster öffnen |
| `Esc`                     | Präsentationsmodus verlassen                      |

### Kommentieren und in Echtzeit zusammenarbeiten

Öffnen Sie das Panel **Kommentare** über die Symbolleiste, um Kommentare für die Folie, die Sie gerade betrachten, zu sehen und hinzuzufügen. Das Panel ist auf diese Folie beschränkt: Wechseln Sie zu einer anderen Folie, passt sich sein Inhalt entsprechend an, sodass es nie die Kommentare des gesamten Decks auf einmal zeigt. Wählen Sie zuerst Text aus, um ihn in einem neuen Kommentar zu zitieren, oder verwenden Sie das Werkzeug **Kommentare anpinnen** in der Symbolleiste, um einen dauerhaften Pin direkt auf einem Element abzulegen.

Jeder mit Bearbeitungszugriff kann kommentieren und in einem Thread antworten. Lösen Sie einen Thread auf, sobald er bearbeitet wurde. Mehrere Personen (und der Agent) können dasselbe Deck gleichzeitig bearbeiten, ohne sich gegenseitig die Änderungen zu überschreiben. Wie das im Hintergrund funktioniert, erfahren Sie unter [Echtzeit-Zusammenarbeit](/docs/real-time-collaboration).

### Ein Deck teilen

Teilen Sie ein Deck genauso, wie Sie jede Agent-Native-Ressource teilen würden: behalten Sie es privat, teilen Sie es mit bestimmten Teamkollegen als Betrachter oder Bearbeiter, oder generieren Sie einen öffentlichen, schreibgeschützten Link, den jeder ohne Konto öffnen kann. Das vollständige Modell finden Sie unter [Freigabe](/docs/sharing).

### Eine frühere Version wiederherstellen

Jede bedeutende Änderung, ob von Ihnen oder vom Agenten, sichert das Deck zuerst als Snapshot, sodass nie etwas unbemerkt verloren geht. Öffnen Sie den Versionsverlauf, um eine Zeitleiste vergangener Snapshots zu sehen und einen davon wiederherzustellen. Auch eine Wiederherstellung erstellt zuerst ihren eigenen Snapshot, sodass eine Wiederherstellung nie eine Einbahnstraße ist.

### Decks in andere Formate umwandeln und zurück

| Richtung | Formate                      | Was passiert                                                                                                                                                                        |
| -------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Import   | PPTX, DOCX, PDF, Google Docs | Wird in bearbeitbare Folien umgewandelt — ein PDF oder DOCX wird zu einer Folie pro Seite oder Abschnitt, ein PPTX behält seine ursprüngliche Foliengliederung und Sprechernotizen. |
| Export   | PPTX                         | Nativer, bearbeitbarer Text, Formen und Bilder — kein abgeflachtes Bild jeder Folie.                                                                                                |
| Export   | Google Slides                | Folien generiert dasselbe PPTX und gibt Ihnen einen fertigen Import-Link, da Google Slides keinen direkten „diese URL öffnen“-Import bietet.                                        |
| Export   | Eigenständiges HTML          | Eine einzelne, in sich geschlossene Datei mit integrierter Tastaturnavigation, die Sie überall hosten oder per E-Mail versenden können — keine App zum Betrachten erforderlich.     |

Das Einbinden eines GitHub-Repos, einer Codebasis oder einer Website-URL ist eine andere Funktion als das Importieren des Inhalts eines Decks: Diese drei speisen die im Abschnitt [Designsysteme](#design-systems) beschriebene Designsystem-Indizierung, nicht den folienweisen Inhaltsimport.

## Designsysteme {#design-systems}

Ein Designsystem ist ein wiederverwendbares Bündel an Markenidentität: primäre/akzentuierte/Hintergrundfarben, Überschriften- und Fließtextschriften, Abstände, Logos und frei formulierte benutzerdefinierte Anweisungen („Abschnittsbeschriftungen immer klein schreiben“, „niemals Stockfotos verwenden“). Es ist eine eigene Ressource, unabhängig von einem einzelnen Deck. Speichern Sie eines, und jedes neue Deck kann es anstelle generischer Standardwerte verwenden.

### Ein Designsystem hinzufügen

<Steps>

### Designsysteme öffnen

Öffnen Sie in der Seitenleiste **Designsysteme** und klicken Sie auf **Neues Designsystem**.

### Ihr Markenmaterial hinzufügen

Geben Sie ein, was immer Sie haben: einen Firmennamen und eine Website, ein GitHub-Repo, Code-Dateien, Dokumente, Referenzbilder oder Logos, Notizen oder benutzerdefinierte Anweisungen.

### Auf „Weiter zur Generierung“ klicken

Dies startet den Aufbau Ihres Designsystems. Was genau als Nächstes passiert, hängt davon ab, was Sie angegeben haben.

</Steps>

#### Was als Nächstes passiert, hängt von der Quelle ab

Das Hochladen einer Figma-Datei oder die alleinige Angabe eines GitHub-Repos baut das Designsystem sofort auf. Alles andere öffnet stattdessen den Agenten in der Seitenleiste, um es dort fertigzustellen. Es gibt keinen Farbwähler oder Schriftwähler: Markenfarben und -schriften stammen immer aus einer Quelle, die der Agent interpretiert, oder aus dem, was Sie in den Notizen und benutzerdefinierten Anweisungen eingeben.

#### Einen Standard festlegen

Markieren Sie ein Designsystem als Standard, damit jedes neue Deck es automatisch übernimmt, oder wählen Sie beim Erstellen eines neuen Decks explizit eines aus.

### Builder-Integration

Eine Figma-Datei, eine verbundene Codebasis oder ein GitHub-Repo, oder eine `design.md`, benötigt eine echte Analyse, sodass diese über Builder Design System Intelligence laufen, statt über eine einmalige lokale Schätzung.

#### Builder verbinden

Dies erfordert ein verbundenes Builder.io-Konto (eine kostenlose Stufe ist verfügbar). Wenn Sie noch keines verbunden haben, fordert der Agent Sie dazu auf, sobald er es braucht.

#### Builder bleibt die Quelle der Wahrheit

Builder indiziert die Quelle und besitzt die daraus entstehenden Dokumente, extrahierten Tokens und Nutzungshinweise, nicht Folien. Folien behält lokal nur einen leichtgewichtigen Verweis auf das Ergebnis, sodass der Agent die aktuellen Dokumente jedes Mal von Builder abruft, wenn er das Designsystem anwendet.

### Figma-Dateien

Eine `.fig`-Datei ist die einzige Quelle, deren Indizierung in dem Moment beginnt, in dem Sie sie ablegen, ohne dass ein Agenten-Chat-Schritt nötig ist. Ziehen Sie eine Datei auf das Figma-Panel im Einrichtungsdialog, oder klicken Sie, um eine auszuwählen. Folien lädt sie hoch und startet sofort einen Builder-Design-System-Intelligence-Indizierungsjob, und das Ergebnis wird zu einem Designsystem, das Sie auf jedes Deck anwenden können, sobald die Indizierung abgeschlossen ist.

### Pro Deck anwenden und anpassen

Sobald ein Designsystem mit einem Deck verknüpft ist, bietet Ihnen das Panel **Anpassungen** schnelle Live-Überschreibungen, ein Muster für die Akzentfarbe, Titel-Schreibweise, Hintergrundwärme, ohne das gespeicherte System direkt zu bearbeiten. Eine Änderung, die Sie beibehalten, wird in das Designsystem zurückgeschrieben.
