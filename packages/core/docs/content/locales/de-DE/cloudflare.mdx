# Cloudflare

Verwenden Sie Nitros native Modulausgabe für einen Cloudflare Worker. Das hält
SSR aktiviert und erzeugt den Worker-Einstiegspunkt plus statische Assets
unter `.output/server` und `.output/public`:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Build and deploy the generated Worker with Wrangler:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

Sie können die Voreinstellung auch explizit mit `NITRO_PRESET=cloudflare_module`
wählen. Konfigurieren Sie vor dem Deployment eine dauerhafte externe
PostgreSQL-Datenbank. Ein Worker-Dateisystem ist kein persistenter App-Speicher.
