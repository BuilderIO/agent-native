# Chat

Chat ist ein Entwickler-Starter zum Bauen Ihres eigenen Agenten. Sobald Sie die App erstellen, haben Sie einen funktionierenden Konversationsbildschirm, einen gespeicherten Chatverlauf und die Anmeldung, dazu eine einzelne Beispielaktion, die der Agent bereits nutzen kann. Das erspart Ihnen die wochenlange Arbeit, eine Chatoberfläche, die Speicherung von Konversationen und eine Anmeldung von Hand an ein Modell anzubinden. So starten Sie mit einer bereitstellbaren App und verbringen Ihre Zeit mit dem, was Ihr Agent tatsächlich tut.

Chat ist kein fertiges Produkt für eine bestimmte Aufgabe. Wenn Sie kein Entwickler sind oder etwas suchen, das Sie sofort nutzen können, beginnen Sie mit [Clips](/docs/template-clips) für Bildschirmaufnahmen, [Slides](/docs/template-slides) für Präsentationen oder [Design](/docs/template-design) für interaktive Prototypen.

## Was Sie bekommen

Wenn Sie Chat zum ersten Mal öffnen, sehen Sie ein einzelnes Nachrichtenfeld und die Frage „Wie kann ich helfen?“ Fragen Sie, was Sie möchten, und der Agent antwortet direkt dort. Der Rest des Lieferumfangs ist bewusst klein gehalten.

- **Ein Vollseiten-Chat.** Konversationen nehmen den ganzen Bildschirm ein, wobei das Nachrichtenfeld zentriert bleibt, bis Sie Ihre erste Nachricht senden.
- **Eine Konversationsliste.** Die Seitenleiste listet Ihre Chats auf, sodass Sie einen neuen starten, einen alten wieder öffnen, ihn umbenennen, anheften oder archivieren können.
- **Eine Loslegen-Seite.** Eine kurze Startseite mit Links zu den Anleitungen, wie Sie Ihre erste Aktion und Ihren ersten Bildschirm hinzufügen. Sie können sie bearbeiten oder ersetzen.
- **Anmeldung und Teams.** Login, Registrierung und Organisationen funktionieren von Anfang an.
- **Eine Beispielaktion.** Der Agent kann bereits ein einfaches Beispiel ausführen, sodass Sie sehen, wie eine Aktion funktioniert, bevor Sie Ihre eigene schreiben.
- **Admin-Seiten.** Ein Datenbank-Viewer und ein Dashboard für Beobachtbarkeit sind enthalten, ob Sie sie je öffnen oder nicht.
- **Platz für Mini-Apps.** Eine Seite für kleine, isolierte Werkzeuge namens Erweiterungen ist enthalten. Ein Entwickler kann die Fähigkeit des Agenten aktivieren, sie zu bauen.

Chat lässt alles weg, was spezifisch für ein Unternehmen ist: keine vorgefertigten Daten, Dashboards, Formulare oder Verbindungen zu externen Diensten. Diese fügen Sie selbst hinzu.

## Chat in einem Multi-App-Arbeitsbereich

Wenn Sie Chat zusammen mit anderen Apps unter [Dispatch](/docs/template-dispatch) betreiben, kann es als Eingangstür zu Ihrem Arbeitsbereich dienen. Eine einzelne Konversation kann auf die umliegenden Apps zugreifen, statt für sich allein zu stehen. Unter [Chat in einem Multi-App-Arbeitsbereich](/docs/template-chat-integrations) erfahren Sie, wie die Verbindung funktioniert.
