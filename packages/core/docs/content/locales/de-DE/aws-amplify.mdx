# AWS Amplify

Read the [English AWS Amplify guide](/docs/aws-amplify) for build steps,
persistent database configuration, and CloudFront caching.

The deployment must use a persistent SQL database. Configure `DATABASE_URL`
and `BETTER_AUTH_SECRET` in the provider environment. The Nitro preset is
`aws_amplify`.

The framework uses Nitro's Node.js 24 compute runtime and
`AMPLIFY_MONOREPO_APP_ROOT=templates/calendar` for the calendar monorepo build.

The English guide also documents generated runtime environment handling, safe
CLI map merging, AWS CLI commands, the optional response-streaming Lambda
origin, and streaming keepalive behavior.
