# Folien

Folien ist ein von einem Agenten betriebener Deck-Editor. Bitten Sie den Agenten um ein Deck, und er generiert eines aus einer Eingabeaufforderung, streamt die Folien beim Erstellen in den Editor und bearbeitet, gestaltet neu oder exportiert das Deck, sobald Sie es verlangen, in einfacher Sprache oder mit einem Klick. Es ersetzt Google Slides, Pitch und PowerPoint durch eine einzige App, sodass Generieren, Bearbeiten, Präsentieren und Exportieren eines Decks nie getrennte Werkzeuge sind, zwischen denen Sie wechseln müssen.

## Was ersetzt wird

<Comparison>

### Vorher

- Google Slides, Pitch oder PowerPoint, um das Deck selbst zu erstellen
- Ein Abonnement pro Nutzer, nur um weiter bearbeiten und präsentieren zu können
- Ihre Markenfarben, Schriften und Ihr Logo von Hand in jedes neue Deck kopieren
- Dateien manuell konvertieren, um ein Deck mit Personen zu teilen, die ein anderes Tool nutzen

### Nachher

- Ein Editor: aus einer Eingabeaufforderung generieren, visuell bearbeiten und präsentieren, alles im selben Deck
- Den gesamten Stack durchgängig selbst besitzen, ohne Abonnement
- Ein gespeichertes Designsystem wendet Ihre Marke automatisch auf jedes neue Deck an
- PPTX, DOCX, PDF oder Google Docs importieren und jederzeit zurück nach PPTX, Google Slides oder HTML exportieren

</Comparison>

## Folien in einem Multi-App-Arbeitsbereich

Wenn Sie Folien zusammen mit anderen Apps unter [Dispatch](/docs/template-dispatch) betreiben, ist ein Deck nicht mehr nur eine Seite, die Sie von Hand öffnen. Der Agent kann ein Deck an eine Library übermitteln, die andere Apps wiederverwenden können, oder eine Anfrage in einfacher Sprache von einer Schwester-App genauso beantworten, wie er Ihnen im Chat antwortet. Unter [Folien in einem Multi-App-Arbeitsbereich](/docs/template-slides-integrations) erfahren Sie, wie die Verbindung tatsächlich funktioniert und welche Mechanismen wirklich dahinterstecken.

## Was Sie damit machen können

- **Decks aus einer Eingabeaufforderung generieren.** „Erstellen Sie ein 10-Folien-Pitch-Deck für einen Kaffee-Abonnementdienst, Zielgruppe sind Investoren.“ Siehe [Funktionen](/docs/template-slides-features).
- **Folien visuell bearbeiten.** Doppelklicken Sie auf Text, um ihn zu bearbeiten, klicken Sie auf einen Block für das Blasenmenü, verwenden Sie `/` für das Schrägstrichmenü, um Blöcke einzufügen. Siehe [Funktionen](/docs/template-slides-features).
- **Im Vollbildmodus präsentieren**, kommentieren, in Echtzeit zusammenarbeiten und ein Deck mit bestimmten Teamkollegen oder öffentlich teilen. Siehe [Funktionen](/docs/template-slides-features).
- **Vorhandene Inhalte einbringen.** Importieren Sie ein PPTX, DOCX, PDF oder Google Doc als Ausgangspunkt. Exportieren Sie nach PPTX, Google Slides oder in eine eigenständige HTML-Datei. Siehe [Funktionen](/docs/template-slides-features).
- **Ein aus Ihrer Marke aufgebautes Designsystem anwenden.** Speichern Sie Farben, Schrift und Logos einmal und verwenden Sie sie in jedem neuen Deck wieder. Richten Sie eines aus einer Figma-Datei, einer verbundenen Codebasis oder einer Website ein. Siehe [Funktionen](/docs/template-slides-features).
- **Frühere Versionen wiederherstellen.** Jede Änderung wird als Snapshot gesichert. Listen Sie jede frühere Version auf oder stellen Sie sie wieder her. Siehe [Funktionen](/docs/template-slides-features).

## Erste Schritte

Wenn Sie die App öffnen:

1. Klicken Sie auf **Neues Deck**.
2. Fragen Sie den Agenten: „Erstellen Sie ein 10-Folien-Pitch-Deck für einen Kaffee-Abonnementdienst, Zielgruppe sind Investoren.“
3. Sehen Sie zu, wie die Folien eingehen. Klicken Sie auf eine beliebige Folie, um sie zu bearbeiten, oder bitten Sie den Agenten weiterhin um Verfeinerungen. Wählen Sie Text aus und klicken Sie im Blasenmenü auf **Mit KI überarbeiten**, um dem Agenten genau diese Auswahl zu übergeben.

### Nützliche Eingabeaufforderungen

- „Erstellen Sie ein 10-Folien-Pitch-Deck für einen Kaffee-Abonnementdienst, Zielgruppe sind Investoren.“
- „Fügen Sie nach Folie 3 eine Preisfolie hinzu.“
- „Vergrößern Sie den Titel dieser Folie und ändern Sie die Akzentfarbe in Grün.“
- „Fassen Sie dieses PDF als 6-Folien-Deck zusammen.“ (PDF anhängen)

Um Ihre eigene Kopie von Folien zu erstellen:

```bash
npx --yes @agent-native/core@latest create my-slides --standalone --template slides
```

Den Rest der Einrichtung (`cd`, `pnpm install`, `pnpm dev`) und die Grundlagen des Frameworks finden Sie unter [Erste Schritte](/docs/getting-started).
