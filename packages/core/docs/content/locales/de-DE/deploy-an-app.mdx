# Eine App bereitstellen

Folge dem [vollständigen englischen Leitfaden zum Bereitstellen einer App](/docs/deploy-an-app) für die Schritte und Anbieterbefehle.

Setze vor dem Deployment eine dauerhafte SQL-Datenbank und ein stabiles `BETTER_AUTH_SECRET`. Wähle [Node.js und Docker](/docs/node-docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify) oder [Cloudflare](/docs/cloudflare).

Für mehrere Apps unter einer Origin nutze [Workspace-Deployment](/docs/workspace-deployment).
