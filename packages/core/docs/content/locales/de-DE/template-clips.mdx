# Clips

Clips ist eine agentennative Bildschirmaufnahme-App. Nehmen Sie Ihren Bildschirm auf, und der Agent transkribiert, betitelt, fasst zusammen und indiziert die Aufnahme in einer durchsuchbaren Bibliothek, sodass Sie fragen können „finde den Clip, in dem wir den Einführungsplan besprochen haben“, und über jede Aufnahme suchen können, die Sie je gemacht haben. Sie ersetzt Loom durch eine einzige App, sodass jede Aufnahme, die Sie machen, an einem durchsuchbaren Ort liegt, den Sie besitzen, statt in einem separaten Tool mit eigenem Transkript.

Der Agent ist ein erstklassiger Editor für jede Aufnahme, und alles, was Sie aufnehmen, gehört Ihnen, nicht einem SaaS-Anbieter. Clips macht eine freigegebene Aufnahme außerdem für jeden Agenten lesbar, nicht nur für den eigenen. Wenn Sie den Freigabelink eines Clips in Claude, ChatGPT oder einen anderen Assistenten einfügen, kann dieser das Transkript lesen und mit Zeitstempeln versehene Bildschirmframes sehen, ohne das Rohvideo herunterzuladen. Wie das funktioniert, erfahren Sie unter [Clips in einem Multi-App-Arbeitsbereich](/docs/template-clips-integrations).

## Was ersetzt wird

<Comparison>

### Vorher

- Loom für Bildschirmaufnahmen
- Ein separates Tool, oder Handarbeit, für Transkripte, Titel und Zusammenfassungen
- Einen Clip neu aufnehmen oder erneut hochladen, nur um eine KI-Bereinigung dafür zu bekommen
- Kein Weg für einen externen Agenten, tatsächlich zu verstehen, was in einer Aufnahme steckt

### Nachher

- Ein Rekorder, mit Loom-Import für alles, was Sie dort bereits haben
- Der Agent betitelt, fasst zusammen und gliedert jede Aufnahme automatisch in Kapitel
- Zuschneiden, Füllwörter entfernen oder Clips kombinieren, einfach durch Fragen
- Freigabelinks, die jeder Agent lesen kann, nicht nur der von Clips selbst

</Comparison>

## Clips in einem Multi-App-Arbeitsbereich

Wenn Sie Clips zusammen mit anderen Apps unter [Dispatch](/docs/template-dispatch) betreiben, ist eine Aufnahme nicht mehr etwas, das Sie nur von Hand ansehen. Andere Apps können fertige Transkripte in Brain übernehmen, einer CRM-Automatisierung einen dauerhaften Anruf-Nachweislink übergeben oder dem Agenten von Clips direkt eine Frage stellen, genau wie Sie es im Chat tun würden. Wie das funktioniert, erfahren Sie unter [Clips in einem Multi-App-Arbeitsbereich](/docs/template-clips-integrations).

## Was Sie damit machen können

- **Nehmen Sie Ihren Bildschirm auf oder importieren Sie aus Loom.** Probieren Sie „nimm meinen Bildschirm auf“ oder fügen Sie einen öffentlichen Loom-Link ein, um ihn in Ihre Bibliothek zu holen. Siehe [Einen Clip erstellen](/docs/template-clips-features#create-a-clip).
- **Bearbeiten Sie zerstörungsfrei über den Chat.** Probieren Sie „entferne die Ähs und Ähms“ oder „schneide die ersten 10 Sekunden ab“. Siehe [Zerstörungsfreie Bearbeitung](/docs/template-clips-features#non-destructive-editing).
- **Teilen und schützen Sie, was Sie aufnehmen.** Legen Sie Sichtbarkeit, ein Passwort oder ein Ablaufdatum fest, und lassen Sie jeden Agenten das Transkript eines freigegebenen Clips lesen. Siehe [Teilen](/docs/template-clips-features#share).
