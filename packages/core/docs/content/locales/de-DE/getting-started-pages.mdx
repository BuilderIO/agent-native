# Eine Seite hinzufügen

Dies ist der dritte Teil der Reihe „Erste Schritte“. In [Eine Aktion hinzufügen](/docs/getting-started-actions)
haben Sie `analyze-text` erstellt. Hier rufen Sie dieselbe Aktion aus einer Route
auf. Für dieses Beispiel ist keine neue Datenbanktabelle erforderlich. Chat
speichert den Chatverlauf bereits in SQL; fügen Sie eigene Tabellen hinzu, wenn
Sie Fachdaten speichern müssen.

## Die Route erstellen {#add-a-page}

Der Entwicklungsserver liest Routendateien beim Start. Erstellen Sie
`app/routes/text-analyses.tsx` und starten Sie `pnpm dev` neu, falls es bereits
läuft. Die Route ist dann unter
`http://localhost:8080/text-analyses` verfügbar.

```tsx filename="app/routes/text-analyses.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";

type TextAnalysis = {
  summary: {
    characters: number;
    words: number;
    sentences: number;
    paragraphs: number;
  };
};

export default function TextAnalysesRoute() {
  const { data: analysis, isLoading } = useActionQuery<TextAnalysis>(
    "analyze-text",
    { text: "Hello world. How are you today?" },
  );

  return (
    <main className="mx-auto flex max-w-3xl flex-col gap-6 p-6">
      <header>
        <h1 className="text-2xl font-semibold">Text analyses</h1>
        <p className="text-muted-foreground">The same action, on a page.</p>
      </header>
      <section className="grid gap-3 sm:grid-cols-2">
        {isLoading && <p className="text-muted-foreground">Analyzing...</p>}
        {analysis &&
          Object.entries(analysis.summary).map(([label, value]) => (
            <article key={label} className="rounded-lg border p-4">
              <p className="text-sm capitalize text-muted-foreground">
                {label}
              </p>
              <p className="text-2xl font-semibold">{value}</p>
            </article>
          ))}
      </section>
    </main>
  );
}
```

`useActionQuery` ruft dieselbe schreibgeschützte Aktion auf, die auch der Agent
verwendet. Die Seite benötigt weder eine benutzerdefinierte API-Route noch eine
zweite Datenschicht oder SQL.

Öffnen Sie `http://localhost:8080/text-analyses` oder bitten Sie den Agenten:

> Navigate to `/text-analyses`.

Für dieses Tutorial reicht die Route aus. Fügen Sie später einen Eintrag in der
Seitenleiste hinzu, wenn dies zu einem zentralen Workflow wird. Die vollständigen
Muster für `view-screen`, `navigate` und den Anwendungszustand finden Sie unter
[Kontextbewusstsein](/docs/context-awareness).
