# WebMCP

WebMCP ist eine experimentelle Browser-API, mit der Seiten Tools registrieren
können, die ein berechtigter Agent entdecken und ausführen darf. Der
[englische WebMCP-Leitfaden](/docs/webmcp) beschreibt Registrierung, Nutzung,
Browsersitzungen und Sicherheitsgrenzen.
Authentifizierte Seiten registrieren geeignete Backend-Aktionen automatisch aus
dem bestehenden Aktionsregister. Genehmigungspflichtige Aktionen bleiben ausgeschlossen;
vor der Ausführung wird die aktuelle Tool-Liste erneut geprüft.
