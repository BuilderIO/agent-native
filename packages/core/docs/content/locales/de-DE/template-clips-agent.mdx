# Mit dem Agent sprechen

Alles in Clips steht dem Agenten über dieselben Aktionen zur Verfügung, die auch die Oberfläche verwendet. Alles, was Sie anklicken können, können Sie also auch in einfacher Sprache erfragen. Diese Seite behandelt, wie der Agent Ihren Bildschirm sieht, nützliche Eingabeaufforderungen nach Aufgabe, und wo er über die integrierten Aktionen hinausgeht. Einen Überblick finden Sie unter [Clips](/docs/template-clips).

## Wie der Agent Ihren Bildschirm sieht

Wenn eine Aufnahme geöffnet ist, weiß der Agent genau, welche es ist, bis hin zu dem Seitenpanel, das Sie sich ansehen (Kommentare, Transkript oder Einblicke), und dem Zeitstempel, bei dem Sie pausiert haben. Deshalb löst sich „füge hier einen Kommentar hinzu“ oder „schneide das auf den guten Teil zu“ korrekt auf, ohne dass Sie die Aufnahme oder die Zeit benennen müssen.

Durchsuchen Sie stattdessen die Bibliothek, weiß der Agent auch dort, was Sie sich ansehen: den aktuellen Ordner, Ihre Suche und welche Aufnahmen Sie ausgewählt haben, wenn Sie sich im Auswahlmodus befinden.

Eine Sache, die der Agent nicht für Sie erledigen kann: eine Aufnahme starten. Browser gewähren Mikrofon- und Bildschirmzugriff erst, nachdem eine Person auf etwas geklickt hat, daher bringt „nimm meinen Bildschirm auf“ Sie direkt zum Rekorder, statt die Aufnahme unsichtbar im Hintergrund zu starten.

## Nützliche Eingabeaufforderungen nach Aufgabe

Jede Eingabeaufforderung unten wird zu einer echten Aktion gegen Ihre tatsächliche Bibliothek, dieselbe, aus der auch die Oberfläche liest und in die sie schreibt. Hier ist ein durchgerechnetes Beispiel:

<Comparison>

### :blue: Sie fragen

„Fasse diesen Clip für ein Produktupdate zusammen.“

### :green: Was passiert

Das ist eine reine Leseabfrage. Der Agent liest das Transkript der Aufnahme, die Sie geöffnet haben, und antwortet direkt im Chat. Auf Ihrem Bildschirm ändert sich nichts, da nichts erstellt oder verschoben wurde.

</Comparison>

<Cards columns={2}>

### Aufnehmen und importieren

- **„Nimm meinen Bildschirm auf.“** Der Agent öffnet den Rekorder für Sie. Die Aufnahme selbst zu starten bleibt weiterhin Ihr Klick, da der Browser das erfordert.
- **„Importiere diesen Loom-Link.“** Fügen Sie die URL ein, und die Aufnahme wird Ihrer Bibliothek hinzugefügt, sobald der Import abgeschlossen ist.

### Bereinigen und organisieren

- **„Generiere Titel und Zusammenfassung neu.“** Der Agent schreibt beide aus dem aktuellen Transkript neu.
- **„Füge Kapitel hinzu. Der ist lang.“** Kapitelmarkierungen erscheinen sofort auf der Timeline.
- **„Korrigiere das falsch transkribierte Wort bei 1:42.“** Der Agent korrigiert das Transkript direkt.
- **„Finde den Clip, in dem wir den Einführungsplan besprochen haben.“** Eine reine Leseabfrage. Der Agent durchsucht jedes Transkript in Ihrer Bibliothek und antwortet im Chat.

### Bearbeiten

_Bei einer geöffneten Aufnahme löst sich „das“ zu dem Clip auf, den Sie sich ansehen._

- **„Schneide die ersten 10 Sekunden ab.“** Der Schnitt erscheint sofort auf der Timeline, und nichts wird neu codiert, bis Sie exportieren.
- **„Entferne die Ähs und Ähms und füge alles neu zusammen.“** Der Agent findet die Füllwörter im Transkript und wendet dieselbe Art von Zuschnitt an.
- **„Kombiniere diese drei Clips in dieser Reihenfolge zu einem.“** Der Agent fügt sie zusammen und erhält dabei Transkript und Kapitel.

### Teilen und überprüfen

- **„Wer sieht sich diesen Clip an?“** Eine reine Leseabfrage. Der Agent antwortet mit Aufrufzahlen, aufgeteilt nach Menschen und anderen Agenten, die das Transkript lesen.
- **„Teile das mit dem Design-Team, nur zum Ansehen.“** Sichtbarkeit und Zugriff der Aufnahme werden sofort aktualisiert.

</Cards>

## Weniger gängige Aktionen

Nicht jede Clips-Fähigkeit ist eine erstklassige Aktion, die der Agent vorgeladen hat. Die Bildschirmgedächtnis-Aktionen von Rewind sind ein gutes Beispiel dafür, da sie erst zählen, sobald Sie Rewind aktiviert haben. Wenn eine Anfrage eine davon benötigt, sucht der Agent das richtige Werkzeug nach Namen, bevor er es aufruft, ähnlich wie Sie eine Befehlspalette durchsuchen könnten, statt sich jede Tastenkombination zu merken. Das bemerken Sie in der Regel als kurze Pause bei Anfragen, die über alltägliche Bibliotheks- und Bearbeitungsaufgaben hinausgehen.
