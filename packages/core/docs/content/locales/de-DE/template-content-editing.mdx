# Dokumente schreiben und organisieren

Diese Seite behandelt die alltäglichen Teile von Content: eine Seite schreiben und formatieren, Ihre Seiten in einem Baum anordnen, mit Teammitgliedern kommentieren, zu einer früheren Version zurückkehren und steuern, wer ein Dokument sehen kann. Sie richtet sich an alle, die die App nutzen, nicht nur an Entwickler.

## Schreiben und Formatieren

Geben Sie `/` in einer leeren Zeile ein, um das Slash-Menü zu öffnen und Überschriften, Aufzählungs- oder nummerierte Listen, Tabellen, Bilder, Trennlinien und Callouts einzufügen. Aktivieren Sie erweiterte Code-, Layout-, Visual- oder Entwicklerdokumentations-Blöcke unter **Einstellungen → Labs**, bevor Sie sie einfügen. Markieren Sie beliebigen Text, um eine Formatierungsleiste für Fett, Kursiv, Links und Inline-Code einzublenden.

- Bilder können hineingezogen oder eingefügt werden; Content lädt sie automatisch in Ihren konfigurierten Dateispeicher hoch.
- Mathematik wird als echte Gleichungen dargestellt – geben Sie Inline-Mathematik zwischen `` $` `` -Zeichen oder eine Blockgleichung zwischen `$$`-Zeilen ein, und der Editor zeigt das formatierte Ergebnis an, während die ursprüngliche Notation im Dokument erhalten bleibt.
- Fragen Sie den Agenten, statt von Hand zu formatieren: „Füge einen Callout-Hinweis zum veralteten Endpunkt hinzu“, „Verwandle diese Liste in eine Tabelle“ oder „Mach diese Überschrift zu einer Ebene 2“. Nachdem Sie eine Bearbeitung gespeichert haben, behält Content diese Version bei. Ein später eintreffender Wiederherstellungsentwurf ersetzt die gespeicherte Änderung nicht und zeigt sie auch nicht als externe Bearbeitung an.

## Ihre Seiten organisieren

Wählen Sie **Seite** oder **Sammlung** aus dem obersten **+**-Menü in beiden Seitenleistenzuständen. Drücken Sie Escape zum Abbrechen. Wenn Sie ein Element aus einer Zeile in einem anderen Arbeitsbereich erstellen, warten Sie zunächst, bis dieser Arbeitsbereich geladen ist. Jede Seite lebt in einem Seitenleisten-Baum. Ziehen Sie eine Seite, um sie neu anzuordnen oder als Unterseite unter eine andere Seite zu verschachteln. Markieren Sie eine Seite mit einem Stern, um sie oben in der Seitenleiste unter **Favoriten** anzuheften.

Verwenden Sie das Suchfeld (oder bitten Sie den Agenten, „meine Meeting-Notizen von letzter Woche zu finden“), um Titel und Inhalte über jede Seite zu durchsuchen, die Sie sehen können, mit einem Vorschau-Ausschnitt für jeden Treffer. Die Ergebnisse werden nach Relevanz sortiert, sodass eine starke Titelübereinstimmung vor einem aktuellen Dokument erscheint, das die Suchbegriffe nur im Text erwähnt.

## Kommentare

Markieren Sie eine Textpassage und hinterlassen Sie einen Kommentar, so wie Sie es in Notion oder Google Docs tun würden. Der kommentierte Text erhält eine Hervorhebung statt einer Änderung am Dokumentinhalt, sodass die Seite danach genau gleich aussieht. Kommentare unterstützen @-Erwähnungen von Teammitgliedern, verschachtelte Antworten und einen Auflösen/Wiedereröffnen-Schalter. Aufgelöste Threads werden in einen „Aufgelöst“-Bereich in der Seitenleiste eingeklappt, damit sie eine aktive Überprüfung nicht überladen.

<Callout tone="info">

Wenn eine kommentierte Passage später bearbeitet wird, folgt die Hervorhebung dem umgebenden Text, statt an eine feste Position zu springen. Wird der genaue Text jemals gelöscht, bleibt der Kommentar-Thread trotzdem über die Seitenleiste erreichbar, statt zu verschwinden.

</Callout>

## Versionsverlauf

Content erstellt jedes Mal, wenn sich eine Seite wesentlich ändert, einen Schnappschuss. Öffnen Sie den Versionsverlauf einer Seite, um frühere Schnappschüsse anzuzeigen und einen davon wiederherzustellen.

<Callout tone="warning">

Beim Wiederherstellen wird der aktuelle Inhalt vollständig durch den Inhalt dieser Version ersetzt. Es gibt keinen zeilenweisen Diff oder eine Teilwiederherstellung, prüfen Sie den Schnappschuss also, bevor Sie ihn wiederherstellen.

</Callout>

## Freigabe und Sichtbarkeit

Dokumente sind **standardmäßig privat** – nur Sie können eine von Ihnen erstellte Seite sehen. Um eine Seite freizugeben, öffnen Sie den Freigabedialog oder bitten Sie den Agenten, „dieses Dokument mit dem Team als Editor zu teilen“:

<Steps>

### Legen Sie fest, wer es sehen kann

Ändern Sie die Sichtbarkeit auf **Organisation**, damit jeder in Ihrer Organisation die Seite öffnen kann, oder auf **öffentlich**, damit jeder mit dem Link sie über eine schreibgeschützte öffentliche URL öffnen kann.

### Rolle vergeben

Vergeben Sie an bestimmte Personen oder Ihre gesamte Organisation die Rolle **Betrachter**, **Editor** oder **Administrator**.

### Optional aus der Suche ausblenden

Machen Sie eine für die Organisation sichtbare Seite nicht auffindbar: Sie bleibt für jeden mit dem Link offen, fällt aber aus der organisationsweiten Suche und der Seitenleistenliste heraus. Verwenden Sie dies für Seiten, die als Referenz existieren, aber nicht im alltäglichen Durchstöbern auftauchen sollen.

</Steps>

Öffentliche Seiten bieten Besuchern einen schreibgeschützten Chat. Sie können Fragen zum Seiteninhalt stellen, aber darüber nichts erstellen, bearbeiten, kommentieren oder freigeben.
