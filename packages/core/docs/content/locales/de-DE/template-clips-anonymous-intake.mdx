# Anonyme Clips-Aufnahme

Dieser Ablauf ermöglicht einem Besucher, eine private Aufzeichnung ohne Clips-Anmeldung zu senden. Das vertrauenswürdige Produkt erstellt den Aufnahme-Link. Der Link bleibt von schreibgeschützten Agenten-Links getrennt.

Geht die Antwort auf die Erstellung verloren, kann dieselbe signierte Anfrage nach der Zuordnung sicher wiederholt werden. Dabei wird keine zweite Aufzeichnung erstellt.

Weitere Informationen zu Integration, Sicherheitsgrenzen und Self-Hosting enthält der [vollständige englische Leitfaden](/docs/template-clips-anonymous-intake).
