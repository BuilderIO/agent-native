# المكون API

يشحن Agent-Native شريطًا جانبيًا كاملاً، لكن الشريط الجانبي ليس العقد.
العقد هو وقت التشغيل: تدفق الدردشة، وحالة سلسلة المحادثات، actions، والسياق،
المرفقات واختيار النموذج وعمليات التشغيل والمزامنة المدعومة بـ SQL. استخدم المخزون
المكونات عندما تستطيع ذلك، وقم بإسقاط الطبقة عندما تحتاج إلى منتج مخصص UI.

استيراد المتصفح UI من مسارات العميل الفرعية المركزة:

```tsx
import { AgentSidebar } from "@agent-native/core/client/agent-chat";
import { PromptComposer } from "@agent-native/core/client/composer";
import { AgentConversation } from "@agent-native/core/client/conversation";
import { usePresence } from "@agent-native/core/client/collab";
import { SharedRichEditor } from "@agent-native/core/client/editor";
import { ResourcesPanel } from "@agent-native/core/client/resources";
```

تجنب استيراد مكونات UI من حزمة `@agent-native/core` العارية. استخدم
`@agent-native/core/client` أو مسار فرعي `@agent-native/core/client/*` مركّز
لذلك يختار القائمون على التجميع الإدخال الآمن للمتصفح.

استخدم `@agent-native/toolkit` للقطع القابلة لإعادة الاستخدام في بناء التطبيقات التي ليست جزءا من عقد وقت التشغيل الأساسي: عناصر UI بأسلوب shadcn، hooks المشتركة، مساعدات هيكل التطبيق البسيطة، ووحدات تركيب القوالب. يحتفظ Core بإعادة تصدير توافقية أثناء الانتقال.

يمكن للحزم القابلة لإعادة الاستخدام استيراد وحدات Toolkit مباشرة:

```tsx
import { Button } from "@agent-native/toolkit/ui/button";
import { Toaster } from "@agent-native/toolkit/ui/sonner";
import { useToast } from "@agent-native/toolkit/hooks/use-toast";
import { useSetHeaderActions } from "@agent-native/toolkit/app-shell";
```

داخل تطبيقات القوالب، فضّل adapters محلية للتطبيق حتى تتمكن الفرق من استبدال primitives مرة واحدة وتستخدم كل أسطح Toolkit المعاد استخدامها التنفيذ المحلي:

```tsx
import { Button } from "@/components/ui/button";
import { useToast } from "@/hooks/use-toast";
```

## الوكيل والدردشة UI {#agent-chat-ui}

| API                                  | مسار الاستيراد                                | استخدم عندما                                                                             |
| ------------------------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `<AgentSidebar>`                     | `@agent-native/core/client` أو `/client/chat` | تريد الشريط الجانبي الكامل حول تطبيقك.                                                   |
| `<AgentToggleButton>`                | `@agent-native/core/client` أو `/client/chat` | يمكنك عرض زر الرأس الخاص بك للشريط الجانبي.                                              |
| `<AgentPanel>`                       | `@agent-native/core/client` أو `/client/chat` | تريد اللوحة الكاملة في التخطيط أو المسار أو مربع الحوار أو العمود الجانبي الخاص بك.      |
| `<AgentChatSurface>`                 | `@agent-native/core/client` أو `/client/chat` | تريد الدردشة في وضع اللوحة أو الصفحة بدون غلاف الشريط الجانبي.                           |
| `<AssistantChat>`                    | `@agent-native/core/client` أو `/client/chat` | تريد امتلاك Chrome المحيط مع الاحتفاظ بالمحادثة القياسية ووقت تشغيل الملحن.              |
| `<MultiTabAssistantChat>`            | `@agent-native/core/client` أو `/client/chat` | تريد علامات تبويب مؤشر ترابط إطار العمل بدون `AgentPanel` chrome.                        |
| `createHttpAgentChatRuntime()`       | `@agent-native/core/client` أو `/client/chat` | لديك نقطة نهاية وكيل BYO تعمل على بث أحداث الدردشة الطبيعية.                             |
| `createOpenAIAgentsChatRuntime()`    | `@agent-native/core/client` أو `/client/chat` | لديك ساحة بث OpenAI Agents SDK وتريد الدردشة القياسية UI حوله.                           |
| `createOpenAIResponsesChatRuntime()` | `@agent-native/core/client` أو `/client/chat` | لديك تدفق أحداث ردود OpenAI وتريد تطبيعه في الدردشة UI.                                  |
| `createAgUiChatRuntime()`            | `@agent-native/core/client` أو `/client/chat` | لديك تدفق أحداث AG-UI وتريد تطبيعه في الدردشة UI.                                        |
| `createClaudeAgentChatRuntime()`     | `@agent-native/core/client` أو `/client/chat` | لديك بث Claude Agent SDK وتريد تطبيعه في الدردشة UI.                                     |
| `createVercelAiChatRuntime()`        | `@agent-native/core/client` أو `/client/chat` | لديك بث Vercel AI SDK وتريد تطبيعه في الدردشة UI.                                        |
| `createAgentChatRuntimeAdapter()`    | `@agent-native/core/client` أو `/client/chat` | تحتاج إلى تكييف `AgentChatRuntime` مع واجهة المستخدم المساعدة بنفسك.                     |
| `createAgentChatAdapter()`           | `@agent-native/core/client` أو `/client/chat` | تحتاج إلى وسيلة نقل Agent-Native SSE المدمجة كمحول مساعد لواجهة المستخدم منخفضة المستوى. |
| `useChatThreads()`                   | `@agent-native/core/client` أو `/client/chat` | تحتاج إلى قائمة سلاسل محادثات مخصصة، أو منتقي السجل، أو دردشة محددة النطاق UI.           |
| `sendToAgentChat()`                  | `@agent-native/core/client` أو `/client/chat` | يجب أن يؤدي إجراء المنتج إلى تسليم العمل إلى دردشة الوكيل.                               |

`AgentChatRuntime` هو عقد وكيل BYO لقشرة الدردشة القياسية. تمرير
من `runtime` إلى `<AssistantChat>` عندما يتعين على وكيل خارجي تشغيل
المحادثة بينما يحتفظ Agent-Native بالملحن والنص وبطاقات الأدوات و
عرض القطعة الأصلية. الموصلات أعلاه هي سطح API؛ وقت التشغيل
يتم تدريس أشكال العقود والأحداث في
[Native واجهة الدردشة — BYO agent runtimes](/docs/native-chat-ui#byo-agent-runtimes).
إذا كنت تختار بين الوكلاء مقطوعي الرأس، والدردشة الغنية، والعربة الجانبية المضمنة، و
أشكال التطبيق الكاملة، راجع [Agent Surfaces](/docs/agent-surfaces).

لا يزال أقصر مسار مخصص سطحًا مزودًا بأسلاك مسبقًا:

```tsx
import { AgentChatSurface } from "@agent-native/core/client/chat";

export default function ChatRoute() {
  return <AgentChatSurface mode="page" className="h-screen" />;
}
```

بالنسبة إلى Chrome المخصص في وقت التشغيل القياسي:

```tsx
import { AssistantChat, useChatThreads } from "@agent-native/core/client/chat";

function CustomChat({ projectSlug }: { projectSlug: string }) {
  const threads = useChatThreads(undefined, projectSlug);
  const threadId = threads.activeThreadId ?? undefined;

  return (
    <section className="grid h-full grid-cols-[260px_1fr]">
      <ThreadList
        threads={threads.threads}
        activeThreadId={threadId}
        onSelect={threads.switchThread}
      />
      <AssistantChat threadId={threadId} />
    </section>
  );
}
```

للحصول على نقطة نهاية إحضار الوكيل الخاص بك، أنشئ `AgentChatRuntime` باستخدام أحد
الموصلات أعلاه وتمريرها إلى `<AssistantChat runtime={...} />`. انظر
[Native واجهة الدردشة — BYO agent runtimes](/docs/native-chat-ui#byo-agent-runtimes)
لاستخدام الموصل، ودفق الأحداث الذي تمت تسويته، ومتى يجب الوصول إليه
`createHttpAgentChatRuntime()` مقابل موصل خاص بالبروتوكول.

## حقل الدردشة والملحن {#composer}

استخدم `@agent-native/core/client/composer` عندما تحتاج إلى حقل الدردشة نفسه
الذي يستخدمه الشريط الجانبي داخل UI مخصص. توفّر `@agent-native/toolkit/composer`
واجهة Tiptap ومكوّنات UI المحمولة المجردة؛ وعند استخدامها مع خدمات إطار العمل، غلّفها
بـ `ComposerRuntimeAdaptersProvider` وقدّم الخدمات. Core هو الغلاف الموصّل للمرفقات والإشارات والمهارات والصوت واختيار النموذج.

| API                               | استخدم عندما                                                                                                                                                     |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<PromptComposer>`                | تحتاج إلى حقل دردشة جاهز للإرسال يحتوي على المرفقات، وأوامر الشرطة المائلة، والمراجع، ومعالجة النص الملصق، واستمرارية المسودة، والإدخال الصوتي، ودلالات الإرسال. |
| `<AgentComposerFrame>`            | تريد الغلاف المرئي القياسي حول نص الملحن المخصص.                                                                                                                 |
| `<TiptapComposer>`                | أنت بحاجة إلى حقل الدردشة الغنية ذي المستوى الأدنى. ويجب أن يتم عرضه داخل واجهة المستخدم المساعدة `ThreadPrimitive.Root` / وقت تشغيل الملحن.                     |
| `buildPromptComposerSubmission()` | تحتاج إلى نفس المرفقات وتسوية النص الملصق قبل استدعاء معالج الإرسال الخاص بك.                                                                                    |
| `formatPromptWithAttachments()`   | تحتاج إلى عرض بيانات تعريف المرفقات المخفية في سلسلة مطالبة.                                                                                                     |

يجب أن تبدأ معظم UI المخصصة بـ `PromptComposer`:

```tsx
import { PromptComposer } from "@agent-native/core/client/composer";

<PromptComposer
  placeholder="Ask the agent..."
  onSubmit={async (text, files, references, options) => {
    await sendMessageToYourRuntime({ text, files, references, options });
  }}
/>;
```

استخدم `TiptapComposer` فقط إذا كنت تقوم بالفعل بتوصيل عناصر واجهة المستخدم المساعدة
نفسك. إنه الحقل، وليس وقت تشغيل الدردشة بالكامل.

### السياق المُجهّز في المحرر {#composer-context}

تقبل `PromptComposer` و`TiptapComposer` الخاصية `submissionDisabled` لمنع الإرسال مع إبقاء إعداد المسودة والملفات والسياق متاحًا. عدم إعداد المزوّد يمنع الإرسال فقط. تظل `disabled` تعطل المحرر بالكامل.

تقبل `PromptComposer` و`TiptapComposer` و`AgentKitComposer` الخاصيتين `contextItems` و`contextMenuItems`. تتولى التطبيقات قراءة المصادر وتسميات القوائم المترجمة.

يتضمن كل `AgentChatContextItem` الحقول `key` و`title` و`context`. قيمة `status` الاختيارية هي `ready` أو `pending` أو `error`. يوضح `statusMessage` سبب الفشل. تستقبل `onRemoveContextItem` و`onInspectContextItem` و`onRetryContextItem` مفتاح العنصر. تخفي `removable: false` الإزالة. تمنع العناصر المعلقة أو الفاشلة الإرسال ما لم تجعلها `blocksSubmission: false` معلوماتية صراحةً.

يمكن للمضيف تجهيز سياق مصرح بالوصول إليه واستلام لقطة ثابتة عند الإرسال:

```tsx
<PromptComposer
  contextItems={contextItems}
  onRemoveContextItem={removeContext}
  onSubmit={(text, files, references, options) =>
    submitPrompt({
      text,
      files,
      references,
      contextItems: options.contextItems,
    })
  }
/>
```

تسجّل مصادر السياق `picker` ضمن `ComposerContextMenuItem`. تدير `ComposerContextMenu` قوائم فرعية متصلة ومتسلسلة من shadcn/Radix، لا لوحات تحلّ محل بعضها: تعرض القائمة الرئيسية رفع الملفات ثم إضافة سياق → فئات المضيف → منتقيات المصادر. تُحذف إضافة سياق عند غياب عناصر المضيف. تتنقل مفاتيح الأسهم وEscape بين مستويات القائمة. أما الرجوع داخل منتقي الروابط فيعيد فقط من النتائج إلى إدخال الرابط في القائمة الفرعية نفسها. يدير المنتقي المشترك البحث وصفوف القائمة وحالات التحميل والفراغ والخطأ وإعادة المحاولة وترقيم الصفحات وإدخال الروابط. توفّر التطبيقات بيانات مصرحًا بها ودوال اختيار بدلًا من JSX خاص بالمنتقي.

تقبل تهيئة المنتقي ما يلي:

- `searchPlaceholder` و`emptyMessage` الاختياري كنصوص مترجمة للتطبيق. تحدد `selectedIds` الصفوف المختارة. تتضمن العناصر `id` و`title` وحقلي `disabled` و`url` الاختياريين.
- إما `items` محلية مع `loading` و`error` و`onRetry()` اختيارية، أو `load(request)` للتحميل عن بُعد. لا يمكن الجمع بين النمطين.
- تستقبل `load(request)` كلًا من `search` و`page` التي تبدأ من واحد و`cursor` و`url` الاختياريين و`AbortSignal`. وتعيد `{ items, hasMore?, nextCursor? }`. يجب أن ترفض حالات الفشل الوعد بدلًا من إعادة نتيجة فارغة.
- تجهّز `onSelect(item, request)` المصدر ويمكن أن تعمل بشكل غير متزامن. تبقي إعادة `false` المنتقي مفتوحًا. يؤدي رمي خطأ إلى عرض خطأ مع إعادة المحاولة. توفّر `clearSelection` الاختيارية `label` مترجمًا ودالة `onSelect()`.
- توفّر `link` الاختيارية نصّي `placeholder` و`submitLabel` المترجمين. يمكن أن تعيد `validate(url)` رسالة خطأ. يتولى النموذج المشترك إدخال الرابط والتنقل.
- تعيد `scopeKey` ضبط جميع حالات المنتقي عند تغيّر الهوية أو نطاق الوصول. تبطل `refreshKey` الاستعلام الحالي عند تغيّر رمز المصدر أو الإصدار دون إعادة ضبط الرابط. يعيد تغيّر البحث الانتقال إلى الصفحة الأولى. تمرّر التطبيقات رموزًا محدثة عندما تغيّر كتابات الوكيل بيانات المصدر.

يمكن للتطبيق تسجيل خيارات مصرح بها مسبقًا. تحتوي `labels` هنا على نصوص التطبيق المترجمة، وتحدّث `stageReference` السياق المجهّز لدى المضيف:

```tsx
import type { ComposerContextMenuItem } from "@agent-native/core/client/composer";
import { Link } from "react-router";

const contextMenuItems: ComposerContextMenuItem[] = [
  {
    id: "references",
    label: labels.references,
    picker: {
      searchPlaceholder: labels.searchReferences,
      items: authorizedReferences,
      selectedIds,
      onSelect: stageReference,
      footerAction: {
        label: labels.createReference,
        renderLink: (children) => (
          <Link to={createReferenceHref}>{children}</Link>
        ),
      },
    },
  },
];
```

لمصدر قابل للبحث أو يعتمد على رابط، يوفّر التطبيق دالة تحميل مصادقًا عليها. تطبّق `loadAuthorizedReferences` عقد الطلب والنتيجة أعلاه، وتحافظ على فحوص الوصول، وتمرّر إشارة الإلغاء إلى دالة العميل المساعدة:

```tsx
const contextMenuItems: ComposerContextMenuItem[] = [
  {
    id: "references",
    label: labels.references,
    picker: {
      searchPlaceholder: labels.searchReferences,
      scopeKey: accessScope,
      refreshKey: sourceVersion,
      load: loadAuthorizedReferences,
      presentation: {
        type: "dialog",
        mode: "multiple",
        onAttach: stageReferences,
      },
      link: {
        label: labels.referenceUrl,
        placeholder: labels.referenceLink,
        submitLabel: labels.findReferences,
        validate: validateReferenceLink,
      },
    },
  },
];
```

القيمة الافتراضية لـ `presentation` هي `"submenu"`. مع `{ type: "dialog", mode: "multiple", onAttach }`، يفتح عنصر قائمة عادي حوارًا مشتركًا بعنوان العنصر. يحدد `link.label` تسمية حقل URL. يتحقق زر المتابعة من عنوان HTTP(S) بلا بيانات اعتماد قبل تحميل النتائج. لا يستدعي الإدخال الفارغ أو غير الصالح المزوّد. يمكن لـ `link.validate()` فرض قواعد خاصة بالمزوّد. تستخدم أزرار الحوار تسميات مشتركة مترجمة، وليس `link.submitLabel`.

تستقبل `presentation.onAttach(items, request)` دفعة مجمّدة واحدة من العناصر المحددة حديثًا. لا يسمح هذا الوضع بـ `onSelect`. تُحفظ الاختيارات أثناء البحث والتنقل بين الصفحات، وتظهر عناصر `selectedIds` محددة ومعطّلة وتُستبعد من الدفعة. يجب أن تميّز المعرّفات بين ملفات المصادر المختلفة. يبقي إرجاع `false` الحوار مفتوحًا. يعرض الرفض خطأً مع إمكانية إعادة المحاولة. يؤدي الإلغاء أو تغيير `scopeKey` إلى إلغاء العمل المعلّق وتجاهل النتائج المتأخرة. تبدأ إعادة الفتح بعنوان URL جديد. يجب على المضيف مراعاة `request.signal` قبل تثبيت تغييرات الاستدعاءات غير المتزامنة. يبقى `footerAction` و`clearSelection` ضمن عناصر تحكم القائمة الفرعية.

يستخدم `{ type: "dialog", mode: "url" }` الإرفاق مباشرةً دون تحميل قائمة نتائج. تستقبل `onSelect(item, request)` القيمة `{ id: url, title: url, url }` و`request.url`:

```tsx
const websiteContextItem: ComposerContextMenuItem = {
  id: "website",
  label: labels.attachWebsite,
  picker: {
    searchPlaceholder: labels.searchReferences,
    scopeKey: accessScope,
    presentation: { type: "dialog", mode: "url" },
    link: {
      label: labels.websiteUrl,
      placeholder: labels.websiteUrl,
      submitLabel: labels.attach,
      validate: validateWebsiteUrl,
    },
    onSelect: stageWebsiteReference,
  },
};
```

تبني `readComposerWebsiteSource(url, extractCallback)` من `@agent-native/core/server` مراجع المواقع عبر مستخرج المضيف الحالي المحمي من SSRF. تقبل `composerSourceRequestSchema` من `@agent-native/core/shared` القيمة `source: "website"` فقط مع `operation: "read"` وعنوان `url` ببروتوكول HTTP(S) بلا بيانات اعتماد، بطول أقصاه 2,048 محرفًا. تعيد الدالة `{ id, title, url, context }` بمعرّف ثابت مشتق من تجزئة العنوان وسياق لا يتجاوز 20,000 محرف. تبقى حالة الاستخراج والتحذيرات وبيانات التصيير وأي علامة `[truncated]` ضمن نص السياق. يظل الاستخراج الجزئي واضحًا. يؤدي فشل الاستخراج أو غياب `designMd` صالح للاستخدام إلى خطأ ذي نوع محدد. يبقى التفويض مسؤولية [إجراء](/docs/actions-overview) المضيف.

لا تعرّف عناصر المنتقي أيضًا `render` أو `onSelect` على مستوى العنصر. تستخدم الفئات `children`. تحتفظ القائمة الرئيسية وكل فئة بحقل بحث في رأسها. يمكن للفئات توفير `searchPlaceholder` مترجم؛ وإلا تستخدم النص المشترك للبحث في السياق. يحدد `picker.searchPlaceholder` نص حقل البحث في قائمة المصادر. لا يمنح التسجيل وصولًا إلى المصدر. يتجاهل المنتقي المشترك استجابات التحميل التي حلّت محلها طلبات أحدث.

يبقى `footerAction` الاختياري أسفل النتائج حتى أثناء التحميل أو الخطأ أو فراغ القائمة. يقبل `label` مترجمًا و`icon` و`disabled` اختياريين، وإما `onSelect()` أو `renderLink(children)`. استخدم دالة لفتح نافذة حوار أو مسار آخر ذي حالة: تُبقي `false` القائمة مفتوحة، وتغلقها `true` أو `void`، ويعرض رفض الوعد خطأ مع إعادة المحاولة. للتنقل فقط، أعد من `renderLink` عنصر `Link` حقيقيًا من React Router أو رابط HTML؛ توفّر القائمة المشتركة الصف عبر `asChild` وتحافظ على `href` وسلوك تنقل المتصفح. اربط مسارات موجودة ومصرحًا بها، لا إجراءات شكلية.

تؤدي إضافة `addAttachment` إلى `ComposerContextMenu` إلى وضع إجراء الرفع القياسي أولًا مع الحفاظ على دالة معالجة ملفات المضيف.

تقبل `PromptComposer` و`AgentKitComposer` الخاصية `attachmentAdapter` بالنوع العام `AttachmentAdapter` من `@assistant-ui/react`. قدّم عبر هذا المحوّل سياسة المضيف لقبول الملفات والتحقق من الحجم وتجهيز المرفقات؛ واحذفه للإبقاء على المحوّلات الافتراضية. يظل المحرر المشترك مسؤولًا عن أداة الرفع ومنتقي الملفات ومنتقي السياق وشرائح المرفقات. لا تستبدل هذه الأدوات لتخصيص تجهيز الملفات.

تكون `inlineTextAttachments` مساوية لـ`true` افتراضيًا في `PromptComposer` و`AgentKitComposer`. اضبطها على `false` عندما يستخرج المضيف الملفات النصية العادية بالفعل: يمرّر المحرر الملفات الأصلية إلى المضيف دون قراءة محتواها وإلحاقه بالطلب النصي. تظل المرفقات المصطنعة الناتجة عن النص الملصق جزءًا من نص الطلب. لا يغيّر هذا الخيار قبول المرفقات أو الأدوات المشتركة.

```tsx
<PromptComposer
  contextItems={contextItems}
  contextMenuItems={contextMenuItems}
  attachmentAdapter={hostAttachmentAdapter}
  onRetryContextItem={retryContext}
  onSubmit={submitPrompt}
/>
```

تميّز اللقطة بين `undefined` والمصفوفة الفارغة الصريحة. ترفض أكثر من 32 عنصرًا أو 64 KiB من بيانات UTF-8 المسلسلة دون اقتطاع. يُنتظر `AgentKitComposer.beforeSend(submission)` قبل الإرسال أو الإدراج في الطابور، ويتلقى السياق والمراجع والمرفقات المرفوعة وخيارات التشغيل الثابتة. يحافظ الرفض على المسودة. يُدرج السياق في نص الرسالة وبياناتها الوصفية.

تستخدم `composerRef.current.submitWithText(text)` مسار الإرسال نفسه بالملفات وإعدادات النموذج الحالية دون استبدال نص المحرر أولًا. تُرجع `true` بعد القبول أو `false` عند المنع أو الرفض. اختيار السياق ليس منحًا للوصول. يجب أن تعيد التطبيقات التحقق من وصول المصادر عبر إجراءاتها الموثقة.

## موارد مساحة العمل {#resources}

استخدم `@agent-native/core/client/resources` عندما تريد الكشف عن نفسه
نموذج مورد مساحة العمل الذي يعمل على تشغيل علامة تبويب مساحة العمل في لوحة الوكيل.

| API                                                                   | استخدم عندما                                                            |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `<ResourcesPanel>`                                                    | تريد علامة تبويب مساحة العمل الكاملة كصفحة أو درج أو لوحة مخصصة.        |
| `<ResourceTree>`                                                      | تريد عرض متصفح الموارد الخاص بك حول بيانات إطار العمل.                  |
| `<ResourceEditor>`                                                    | تريد محرر إطار العمل لمورد محدد.                                        |
| `useResourceTree()`                                                   | تحتاج إلى شجرة محددة النطاق للموارد الشخصية أو المشتركة أو مساحة العمل. |
| `useResource()`                                                       | أنت بحاجة إلى المحتوى والبيانات الوصفية لمورد واحد محدد.                |
| `useCreateResource()` / `useUpdateResource()` / `useDeleteResource()` | تحتاج إلى عناصر تحكم مخصصة حول دورة حياة المورد.                        |
| `useUploadResource()`                                                 | تحتاج إلى تحميل الملف إلى مخزن موارد إطار العمل.                        |

لا تحتاج اللوحة الكاملة إلى أي دعائم:

```tsx
import { ResourcesPanel } from "@agent-native/core/client/resources";

<ResourcesPanel />;
```

بالنسبة لمورد Chrome المخصص، احتفظ بالخطافات والعناصر الأولية معًا:

```tsx
import { useState } from "react";
import {
  ResourceEditor,
  ResourceTree,
  useResource,
  useResourceTree,
  useUpdateResource,
} from "@agent-native/core/client/resources";

function WorkspaceResources() {
  const tree = useResourceTree("workspace");
  const updateResource = useUpdateResource();
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const resource = useResource(selectedId);

  return (
    <div className="grid h-full grid-cols-[260px_1fr]">
      <ResourceTree
        tree={tree.data ?? []}
        selectedId={selectedId}
        onSelect={(item) => setSelectedId(item.id)}
        onCreateFile={() => {}}
        onCreateFolder={() => {}}
        onDelete={() => {}}
        onRename={() => {}}
        onDrop={() => {}}
      />
      {resource.data ? (
        <ResourceEditor
          resource={resource.data}
          onSave={(content) =>
            updateResource.mutate({ id: resource.data.id, content })
          }
        />
      ) : null}
    </div>
  );
}
```

## إكمال النص لمرة واحدة {#one-off-text-completion}

إذا كنت تحتاج حقًا إلى نص خام/نص خارج، فاحتفظ به من جانب الخادم واستخدمه
`completeText()` من `@agent-native/core/server`. لف الاستخدام الذي يواجه المستخدم في
إجراء بحيث يتشارك UI والوكيل في نفس الإمكانية.

<Callout id="doc-block-11d6llv" tone="warning">

`completeText()` is the escape hatch, not the default. Reach for it only for true text-in/text-out (a label, a one-line rewrite). Anything needing tools, state, auditability, or steering belongs in an action plus `sendToAgentChat({ background: true })`.

</Callout>

```ts
import { defineAction } from "@agent-native/core/action";
import { completeText } from "@agent-native/core/server";
import { z } from "zod";

export default defineAction({
  description: "Classify a short message",
  schema: z.object({ body: z.string() }),
  run: async ({ body }) => {
    const result = await completeText({
      systemPrompt: "Return exactly one label.",
      input: body,
      maxOutputTokens: 12,
      temperature: 0,
    });
    return { label: result.text.trim() };
  },
});
```

استخدم `sendToAgentChat({ background: true, openSidebar: false })` بدلاً من ذلك عندما
يحتاج العمل إلى أدوات، أو حالة، أو إمكانية التدقيق، أو توجيه المستخدم، أو الخطوات المتعددة
الاستدلال.
