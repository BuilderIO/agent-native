# تضمين المقاطع

استخدم المقاطع المستضافة كخلفية تسجيل لمنتجك. يمكن لشخص التسجيل من iframe
دون تسجيل الدخول إلى المقاطع. يستخدم الخادم الخلفي لديك رمز خدمة للمؤسسة
لإنشاء عنوان URL لاستقبال قصير العمر، ويخزّن المقاطع التسجيل الناتج في
التخزين المُهيّأ لتلك المؤسسة.

يغطي هذا الدليل تدفق التضمين المستضاف. لا يتطلب أن يكون لدى الشخص الذي يسجّل
حساب في المقاطع.

## كيف يعمل التكامل

يتكون التكامل من أربعة أجزاء:

1. يُهيّئ مشرف المؤسسة تخزين الفيديو في المقاطع.
2. يخزّن الخادم الخلفي لديك رمز خدمة المؤسسة ويطلب عنوان URL لاستقبال.
3. يمرّر منتجك فقط عنوان URL لاستقبال قصير العمر إلى iframe.
4. يرفع المقاطع التسجيل إلى تخزين المؤسسة وينشر رسالة اكتمال إلى منتجك.

لا ينتمي رمز خدمة المؤسسة إلى iframe أبدًا. فهو مرتبط بالمؤسسة التي سكّته،
بحيث يوفّر الرمز نفسه سياق المؤسسة. معرّف المؤسسة مفيد لتخطيط المستأجرين
الخاص بك، لكنه ليس بيانات اعتماد بمفرده.

## تهيئة مؤسسة المقاطع

أنشئ أو اختر مؤسسة المقاطع التي يجب أن تملك التسجيلات. يُهيّئ مشرف المؤسسة
بعد ذلك تخزين الفيديو من خلال تأهيل المقاطع أو إعدادات المقاطع:

- يوفّر **Builder.io Connect** تخزين فيديو مُدارًا ورصيد ذكاء اصطناعي.
- يستخدم **التخزين المتوافق مع S3** نقطة النهاية والحاوية ومفتاح الوصول
  والمفتاح السري المُهيّأة للمؤسسة، والمنطقة أو عنوان URL الأساسي العام
  الاختياريين. يستخدم Cloudflare R2 وDigitalOcean Spaces إعدادات التخزين
  نفسها بأسماء خاصة بكل مزوّد.

إعداد التخزين محدد النطاق بالمؤسسة. يستخدم كل تسجيل يُنشأ من خلال رمز خدمة
تلك المؤسسة التخزين المرتبط بها مسبقًا. لا يحتاج المنتج المضمِّن إلى بيانات
اعتماد Builder.io أو S3.

يُخزَّن الفيديو في تخزين الكائنات المُهيّأ. يخزّن المقاطع البيانات الوصفية
للتسجيل، والملكية، وحالة المعالجة، والمرجع إلى التخزين في قاعدة بياناته.

## إنشاء رمز خدمة للمؤسسة

شغّل أمر `connect` الحالي بصفتك مالك المؤسسة أو مشرفها. يفتح الأمر تسجيل
دخول في المتصفح، وينشئ رمز خدمة مسمّى للمؤسسة النشطة، ويطبع الرمز مرة واحدة:

```bash
npx @agent-native/core@latest connect https://clips.agent-native.com \
  --service-token support-desk --ttl-days 365
```

انسخ الرمز المطبوع مباشرة إلى مدير الأسرار من جانب الخادم في منتجك. الرمز
مملوك للمؤسسة، لذا يستمر في العمل إذا ترك الشخص الذي سكّه المؤسسة أو أبطل
رموزه الشخصية. لا يُكتب أبدًا في تهيئة عميل محلية. استخدم اسم خدمة مختلفًا
لكل تكامل حتى يمكن إبطال مستدعٍ واحد دون كسر آخر.

يقبل `--ttl-days` من 1 إلى 365 يومًا ويكون 365 افتراضيًا. يتصرف الرمز كعضو
في المؤسسة. لا يمكنه إنشاء أو إبطال رموز خدمة أخرى أو تغيير إعدادات المؤسسة.

## طلب عنوان URL للاستقبال

يستدعي الخادم الخلفي الموثوق لديك إجراء الاستقبال في المقاطع. استخدم مصدر
المقاطع المستضاف للحسابات المستضافة، أو مصدر المقاطع الخاص بك عند الاستضافة
الذاتية.

```ts
const clipsBaseUrl = "https://clips.agent-native.com";
const clipsServiceToken = process.env.CLIPS_SERVICE_TOKEN;

const response = await fetch(
  `${clipsBaseUrl}/_agent-native/actions/create-recording-intake-link`,
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${clipsServiceToken}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      ttlSeconds: 3600,
    }),
  },
);

if (!response.ok) {
  throw new Error("Could not create a Clips intake URL");
}

const intake = await response.json();
// intake.url is safe to pass to the recording iframe.
```

يحدد سياق المؤسسة الموقَّع الخاص برمز الخدمة أي مؤسسة تملك الاستقبال. استجابة
الإجراء هي كائن الاستقبال على المستوى الأعلى. مدة الاستقبال الافتراضية هي
ساعة واحدة. الحد الأقصى أربع ساعات. يمكن لكل عنوان URL للاستقبال إنشاء تسجيل
واحد.

لا تقم بهذا الطلب من متصفح مجهول. لا تُرجع رمز الخدمة، أو بيانات اعتماد
التخزين، أو جلسة المقاطع طويلة الأمد إلى المتصفح.

## تضمين المسجّل

مرّر عنوان URL المُرجَع مباشرة إلى iframe. يحتوي عنوان URL على القدرة الضيقة
والموقَّعة التي تتيح للزائر إنشاء ورفع تسجيل خاص واحد.

```tsx
<iframe
  data-clips-recorder
  src={intake.url}
  allow="display-capture; camera; microphone"
  title="Report a problem"
  style={{ width: 420, height: 560, border: 0 }}
/>
```

يمكنك إضافة قيم سياق صغيرة وغير حساسة إلى عنوان URL للاستقبال قبل عرضه، مثل
معرّف مشروع، أو عنوان صفحة، أو إصدار تطبيق، أو بيئة. لا تضع كلمات مرور، أو
مفاتيح API، أو سجلات عملاء، أو قيمًا حساسة أخرى في عنوان URL. يمكن أن تظهر
عناوين URL في سجل تصفح المتصفح، والسجلات، والتحليلات، والمُحيلات.

يفتح المسجّل نافذة منبثقة من المستوى الأعلى عندما يبدأ الزائر الالتقاط.
تتطلب أذونات الوسائط في المتصفح والتقاط الشاشة إشارة من المستخدم في سياق
تصفح من المستوى الأعلى. اسمح بالنوافذ المنبثقة للمنتج المضيف أثناء الاختبار.

## استقبال رسالة الاكتمال

عندما يُحفظ التسجيل، تنشر صفحة الانتهاء
`agent-native.clips.bug-report.submitted` إلى النافذة الأصل المضمِّنة. تحقق
من مصدر المقاطع ومصدر الرسالة قبل استخدام الحمولة.

```ts
const clipsOrigin = new URL(clipsBaseUrl).origin;
const recorderFrame = document.querySelector<HTMLIFrameElement>(
  "iframe[data-clips-recorder]",
);

window.addEventListener("message", (event) => {
  if (event.origin !== clipsOrigin) return;
  if (recorderFrame && event.source !== recorderFrame.contentWindow) return;
  if (event.data?.type !== "agent-native.clips.bug-report.submitted") return;

  const { recordingId, recordingUrl, embedUrl, agentAccessStatus } = event.data;
  if (!recordingId) return;

  // Send recordingId to your trusted backend and attach it to the support case.
  console.log({ recordingId, recordingUrl, embedUrl, agentAccessStatus });
});
```

يمكن أن تشمل حمولة الاكتمال `recordingId`، و`recordingUrl`، و`embedUrl`،
و`agentShareUrl`، و`agentContextUrl`، و`agentAccessExpiresAt`،
و`agentAccessStatus`. عامل `recordingId` كمعرّف دائم لحالة الدعم. قد يُقدّم
استقبال للكتابة فقط `agentAccessStatus: "unavailable"` حتى ينشئ الخادم
الخلفي الموثّق لديك رابط وكيل منفصل ومحدد النطاق. لا تعني هذه الحالة أن
التسجيل خالٍ.

رسالة المتصفح إشعار، لا منح تفويض. يجب أن يستخدم الخادم الخلفي لديك اتصاله
الموثَّق الخاص بالمقاطع عندما يحتاج إلى قراءة أو مشاركة التسجيل المكتمل.

## أين تُخزَّن التسجيلات

تُمتلك التسجيلات التي تُنشأ من خلال رمز الخدمة بواسطة المؤسسة المرتبطة بذلك
الرمز. يرسل المقاطع الوسائط عبر خط أنابيب الرفع والإنهاء العادي الخاص به.
يستخدم خط الأنابيب تخزين Builder.io أو التخزين المتوافق مع S3 المُهيّأ لتلك
المؤسسة.

لا يرفع iframe مباشرة إلى حاويتك (bucket)، ولا يحتاج إلى بيانات اعتماد
الحاوية. يستقبل منتجك معرّفات تسجيل وعناوين URL محددة النطاق من المقاطع.
خزّن فقط المعرّفات أو عناوين URL التي تحتاجها في نظام الدعم الخاص بك.

## الاستضافة الذاتية للمقاطع

تستخدم الاستضافة الذاتية عقد المؤسسة نفسه:

1. انشر المقاطع بقاعدة بيانات دائمة و`BETTER_AUTH_URL` عام.
2. أنشئ المؤسسة التي ستملك التسجيلات المضمَّنة.
3. هيّئ Builder.io Connect أو التخزين المتوافق مع S3 مرة واحدة في تلك
   المؤسسة.
4. شغّل `connect` تجاه مصدر المقاطع المستضاف ذاتيًا لإنشاء رمز خدمة المؤسسة.
5. قدّم ذلك الرمز مرة واحدة إلى الخادم الخلفي المضمِّن لديك كقيمة نشر أو
   مدير أسرار.
6. استخدم مصدر المقاطع المستضاف ذاتيًا عندما يطلب الخادم الخلفي لديك عناوين
   URL للاستقبال.

```bash
npx @agent-native/core@latest connect https://clips.example.com \
  --service-token support-desk --ttl-days 365
```

على سبيل المثال، يمكن للخادم الخلفي المضمِّن الاحتفاظ بهذه القيم في تهيئته
من جانب الخادم:

```text
CLIPS_BASE_URL=https://clips.example.com
CLIPS_SERVICE_TOKEN=<secret>
```

يُقدَّم الرمز مرة واحدة إلى الخادم الخلفي. لا يزال كل زائر يحصل على عنوان
URL جديد للاستقبال قصير العمر. لا يُضاف أي رمز أو بيانات اعتماد تخزين إلى
iframe، ولا حاجة إلى تغيير كود iframe عند تدوير الرمز.

راجع [النشر](/docs/deployment) لمتطلبات الاستضافة الذاتية العامة.

## قائمة تحقق الأمان

- احفظ رمز خدمة المؤسسة في مدير أسرار من جانب الخادم.
- استخدم HTTPS لكل من المنتج المضيف والمقاطع.
- عامل كل عنوان URL للاستقبال كبيانات اعتماد حاملة. احفظه بعيدًا عن السجلات
  وبيانات المُحيلات.
- استخدم أقصر مدة صلاحية مفيدة للاستقبال.
- تحقق من `event.origin` و`event.source` كلاهما في مستمع الاكتمال.
- لا تكشف أبدًا نقاط نهاية الرفع الخاصة بمالك المقاطع مباشرة للمستخدمين
  المجهولين.
- دوّر رمز الخدمة بإنشاء رمز بديل باستخدام `connect`، ونشره، والتحقق من
  التدفق، ثم إبطال الرمز القديم باستخدام `revoke-org-service-token`.
- احفظ معرّف المؤسسة ومعرّف الاستقبال لدى الخادم الخلفي الموثوق بدلاً من
  الوثوق بالقيم التي يوفّرها الزائر.

## استكشاف الأخطاء وإصلاحها

**طلب الاستقبال غير مُصرَّح به.** تأكد من أن الخادم الخلفي يستخدم رمز خدمة
غير منتهي الصلاحية وغير مُبطَل، مسكوكًا لمصدر المقاطع المقصود. يحدد ربط
الرمز بالمؤسسة مكان إنشاء الاستقبال.

**يفتح iframe صفحة تسجيل دخول.** تأكد من أن iframe يستخدم عنوان URL قصير
العمر المُرجَع من `create-recording-intake-link`. لا تُضمّن `/record` أو
عنوان URL عادي لمكتبة المقاطع بالنسبة لزائر مجهول.

**لا ينتهي التسجيل.** تحقق من أن المؤسسة لديها Builder.io أو تخزين متوافق
مع S3 مُهيّأ. لا يمكن لزائر مجهول تهيئة التخزين من iframe.

**لا يحتوي الاكتمال على رابط وكيل.** هذا متوقع لاستقبال للكتابة فقط. اجعل
الخادم الخلفي الموثّق لديك ينشئ رابط وكيل منفصلاً ومحدد النطاق إذا احتاج
سير عمل الدعم إلى بيانات نص وإطار قابلة للقراءة من قبل الوكيل.
