# ترقية التطبيقات الحالية إلى Core 0.198.0

استخدم هذا الدليل لترقية تطبيق موجود إلى إصدار Core 0.198.0. نفّذ الأوامر من
جذر التطبيق أو مساحة العمل، واحتفظ بفروق التغييرات لمراجعتها قبل البدء. افحص
إعدادات النشر عن بُعد بشكل منفصل: يمكن للأداة قراءة ملفات البيئة المحلية، لكنها
لا تستطيع فحص البيئات البعيدة أو إعدادات الميزات المخزنة في قاعدة البيانات.

## 1. معاينة الترقية وتحويلات الاستيراد

استخدم واجهة الأوامر المرفقة بإصدار Core 0.198.0 لتحميل بيان الترحيل الخاص به:

    npx @agent-native/core@0.198.0 upgrade --codemods --dry-run

بعد تثبيت Core 0.198.0 في التطبيق، تتوفر المعاينة نفسها عبر ملف CLI التنفيذي المحلي:

    npx agent-native upgrade --codemods --dry-run

يستخدم الأمر `--codemods` الحزمة `ts-morph`. إذا لم يكن التطبيق قادرًا على حلّ الحزمة بالفعل، فثبّتها أولًا كتبعية تطوير: `pnpm add -D ts-morph`.

يطبّق `--codemods` تلقائيًا تعديلات الاستيراد المدعومة. أضف `--dry-run` لمعاينة تغييرات
التبعيات المخطط لها وفروق الملفات والتحذيرات قبل المتابعة. لم يعد الخيار `--yes` مطلوبًا.

تستخدم التحويلات بياني الترحيل النشطين لـ Core وToolkit. تفحص ملفات .ts و .tsx فقط،
مع استثناء ملفات التعريف والملفات المولدة ومجلدات التبعيات، ثم تعيد كتابة
مسارات الاستيراد والتصدير المدعومة. عند انتقال أسماء تصدير إلى وحدات مختلفة،
يمكنها تقسيم التصريح حسب الرمز مع الحفاظ على الأسماء البديلة والاستيرادات
النوعية. كما تعيد كتابة مسارات CSS @import البسيطة وتضيف تبعية حزمة مفقودة إذا
انتقل مسار محلول إلى حزمة أخرى.

كما يكتشف التشخيص صيغ CommonJS باستخدام `require()` وصيغ `import()` الديناميكية، لكن codemod لا يعيد كتابة استدعاءات الدوال هذه. استبدلها باستخدام المسار الجديد المذكور في التقرير، ثم أعد تشغيل Vite أو `agent-native doctor`. تُعدّل codemod مسارات CSS `@import url(...)` سواء كانت بين علامتي اقتباس أم لا.

لا تغيّر مواقع الاستدعاء ولا تنقل ملفاتك. تترك التحويلات غير المحلولة أو
المخططة كما هي وتصدر تحذيراً. لا يمكنها تقسيم استيرادات أو صادرات default أو
namespace أو side-effect أو star، ولا تقسّم استيرادات CSS
على مستوى الرمز. راجع هذه الحالات يدوياً. قد تحتاج الصادرات المحذوفة إلى تعديل
في الشيفرة؛ اتبع دليل الترحيل المذكور في تحذير CLI.

تعرض المعاينة خطة الترقية كاملة أيضاً: تعارضات overrides أو patches التي تمنع
الترقية، وتحديثات إصدارات @agent-native/\* المعلقة، وحزم الميزات المستنتجة من
الإعدادات المحلية، والتثبيت، وتحديث مهارات scaffold، وفحص typecheck عند وجود
هذا البرنامج النصي في الحزمة الجذرية. يحدّث الأمر مواصفات الحزم إلى latest
الحالية في السجل ثم يثبت الإصدارات التي حلّها التثبيت. شغّله عندما يكون
0.198.0 هو الإصدار الحالي المقصود، وتحقق من الإصدارات المثبتة إذا كنت تحتاج
إلى إصدار محدد.

## 2. تأكيد Toolkit والحزم الاختيارية

تتطلب الاستيرادات المنقولة إلى `@agent-native/toolkit/*` تثبيت `@agent-native/toolkit`. تضيف التحويلات Toolkit عند نقل استيراد أو تصدير مدعوم ومحلول إليها. إذا كان التطبيق يستخدم تصديراً من Toolkit ولم تُضف تبعية، ثبّت إصدار Toolkit المطابق لـ Core 0.198.0:

    pnpm add @agent-native/toolkit@0.198.0
    # npm install @agent-native/toolkit@0.198.0
    # yarn add @agent-native/toolkit@0.198.0

### التبعيات التي يختارها CLI تلقائياً

يضيف CLI هذه التبعيات عندما تتطابق فحوصات البيئة المحلية. بالنسبة إلى PGlite، يفحص `${APP_NAME}_DATABASE_URL` بعد توحيد اسم التطبيق أولاً، ثم `DATABASE_URL`؛ ويختار PGlite عندما لا يوجد عنوان أو يبدأ بـ `pglite:`. لا يستطيع فحص البيئات البعيدة أو إعدادات الميزات المخزنة في قاعدة البيانات، لذا تحقّق من الإنتاج والمعاينة بنفسك.

للبحث في مصدر القوالب المضمّنة، أضف حزمة corpus المطابقة كتَبعية تطوير: `pnpm add -D @agent-native/core-corpus@0.198.0`.

## 3. تطبيق الترقية

بعد مراجعة المعاينة والتأكد من حزم الميزات، طبّق الخطة:

    npx agent-native upgrade --codemods

يحدّث هذا الأمر الواحد مواصفات تبعيات @agent-native/\* المؤهلة، ويوائم حزم
الميزات المكتشفة، ويشغّل مدير الحزم، ويثبت إصدارات Agent-Native المحلولة،
ويطبق التحويلات المدعومة، ويحدّث مهارات scaffold، ويشغّل برنامج typecheck في
الجذر إذا كان موجوداً. لا تشغّل أمراً ثانياً للترقية لمجرد تطبيق التحويلات.
عالج التحذيرات والأخطاء في شيفرة التطبيق؛ لا تضف overrides أو patches لإطار
العمل.

## 4. التحقق من النتيجة

راجع كامل الفرق، خصوصاً تحذيرات التحويلات المتروكة وإصدارات التبعيات، ثم شغّل:

    npx @agent-native/core@0.198.0 upgrade check
    pnpm typecheck

استخدم أمر typecheck المكافئ لـ npm أو Yarn، وشغّل الاختبارات والبناء المناسبين
للتطبيق. تأكد من تغطية إعدادات الميزات المحلية والمنشورة في جدول الحزم
الاختيارية. ابحث عن الاستيرادات القديمة في الجدول التالي؛ يجب أن تكون النتائج
المتبقية مقصودة أو غير مدعومة في البيان أو مشمولة بتحذير.
