# الخطوات الأولى

تمنح تطبيقات Agent-Native الوكيل وواجهة المستخدم نفس [الإجراءات](/docs/actions)
وبيانات SQL وحالة التطبيق. يبدأ هذا المسار بـ Chat، الذي يخزّن سجل المحادثات في
SQL بالفعل. أضف جداولك الخاصة فقط عندما يحتاج تطبيقك إلى حفظ بيانات المجال.

<Steps>

### إنشاء تطبيق Chat وضبط وكيل

أنشئ هيكل قالب Chat، وثبّت التبعيات، وشغّل خادم التطوير، واضبط وكيلاً. ستحصل
على تطبيق محادثة يعمل ويمكنك توسيعه. **أنت هنا.**

### إضافة إجراء

عرّف محلّل نصوص محدد الأنواع واعرض نتيجته كمخطط في المحادثة.

### إضافة صفحة

أنشئ مسار React يستدعي الإجراء نفسه خارج سجل المحادثة.

</Steps>

## 1. إنشاء تطبيق Chat {#create-your-app}

ستحتاج إلى [Node.js 22+](https://nodejs.org) و[pnpm](https://pnpm.io).

افتح طرفية، وانتقل إلى الدليل الذي تريد وضع تطبيق Agent Native فيه، ثم شغّل:

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

يفتح التطبيق على `http://localhost:8080`. إذا ظهرت شاشة تسجيل الدخول، سجّل
بمعلومات دخول وهمية. لا تتطلب بيئة التطوير المحلية التحقق من البريد الإلكتروني.

يتضمن قالب Chat خيوط محادثة دائمة، ومصادقة، ومزامنة مباشرة، ودليل `actions/`،
وإجرائي `view-screen` و`navigate` القياسيين.

### اختيار نقطة بداية مختلفة

إذا لم يكن Chat نقطة البداية المناسبة، شغّل `create` من دون `--template` واختر
خياراً آخر في CLI. راجع [إنشاء النماذج](/docs/creating-templates) للمسارات الأخرى.

## 2. ضبط وكيل {#connect-ai}

يفتح قالب Chat مباشرة على سطح المحادثة. إذا لم يكن الوكيل جاهزاً للرد، افتح
**Settings > Manage agent** أو استخدم **Cmd/Ctrl+K > Manage agent** لضبط نموذج وموفّر.

بعد أن يرد الوكيل، تابع إلى [إضافة إجراء](/docs/getting-started-actions).
