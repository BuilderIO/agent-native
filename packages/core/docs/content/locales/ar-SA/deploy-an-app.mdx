# نشر تطبيق

اتبع [دليل نشر التطبيق الكامل باللغة الإنجليزية](/docs/deploy-an-app) للخطوات والأوامر الخاصة بكل موفر.

قبل النشر، اضبط قاعدة بيانات SQL دائمة و`BETTER_AUTH_SECRET` ثابتًا. اختر هدفًا من [Node.js](/docs/node-js) أو [Docker](/docs/docker) أو [Vercel](/docs/vercel) أو [Netlify](/docs/netlify) أو [Cloudflare Pages](/docs/cloudflare#cloudflare-pages) أو [Cloudflare Workers](/docs/cloudflare#cloudflare-workers) أو [AWS Lambda](/docs/aws-lambda) أو [Deno Deploy](/docs/deno-deploy) أو [Azure Static Web Apps](/docs/azure-static-web-apps) أو [Koyeb](/docs/koyeb) أو [Render](/docs/render).

لعدة تطبيقات خلف أصل واحد، استخدم [نشر مساحة عمل](/docs/workspace-deployment).
