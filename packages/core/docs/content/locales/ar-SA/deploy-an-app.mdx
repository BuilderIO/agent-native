# نشر تطبيق

اتبع [دليل نشر التطبيق الكامل باللغة الإنجليزية](/docs/deploy-an-app) للخطوات والأوامر الخاصة بكل موفر.

قبل النشر، اضبط قاعدة بيانات SQL دائمة و`BETTER_AUTH_SECRET` ثابتًا. اختر هدفًا من [Node.js وDocker](/docs/node-docker) أو [Vercel](/docs/vercel) أو [Netlify](/docs/netlify) أو [Cloudflare](/docs/cloudflare).

لعدة تطبيقات خلف أصل واحد، استخدم [نشر مساحة عمل](/docs/workspace-deployment).
