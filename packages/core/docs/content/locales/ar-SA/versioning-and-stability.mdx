# الإصدارات والاستقرار

حزم Agent-Native قبل الإصدار 1.0. يوفر مسار الإصدار لقطات nightly وإصدارات مستقرة وأدوات ترحيل وفحوص doctor. الإصدار التجريبي لا يمثل ضمان دعم إنتاجي.

## قنوات الإصدار

تنشر عمليات الدمج إلى `main` لقطات nightly تحت وسم npm `nightly` ولا تحرّك وسم `latest`. تُنسق الإصدارات المستقرة عبر Changesets. تعد الجداول الزمنية لإصدار patch من الاثنين إلى الخميس عند الظهر بتوقيت المحيط الهادئ. لا يضمن كل تشغيل إصداراً.

## التوافق قبل 1.0

تهدف إصدارات patch إلى إصلاح الأخطاء والتحسينات المتوافقة. قد تضيف إصدارات minor ميزات وتغيّر سلوكاً أو واجهات ما زالت في alpha أو beta. تُخصّص إصدارات major للتغييرات الواسعة غير المتوافقة. راجع ملاحظات الإصدار وخطوات الترحيل قبل التحديث.

يسجل `migration-manifest.json` عمليات نقل الاستيراد وإعادة تسمية الرموز عند توفر مسار ترحيل مدعوم. اعرض التغيير أولاً ثم طبّقه:

```bash
npx @agent-native/core@latest upgrade --codemods
npx @agent-native/core@latest upgrade --codemods --yes
agent-native doctor --only migration-manifest
```

قد تبقى مسارات محذوفة مؤقتاً كوحدات tombstone تعرض بديلها وأمر الترحيل. لا توجد مدة احتفاظ ثابتة.

## إصدارات القوالب والأهداف

تثبت CLI إصدار `@agent-native/core` المطابق تماماً للقالب عند إنشائه. استخدم أدوات الترحيل للتحديث ولا تغيّر الإصدار يدوياً إلى `latest`.

الهدف هو إصدار beta في منتصف أكتوبر 2026 و1.0 بنهاية 2026. هذه أهداف وليست وعوداً. أرسل البلاغات القابلة لإعادة الإنتاج مع رقم الحزمة ومزود قاعدة البيانات ونتيجة الترحيل.
