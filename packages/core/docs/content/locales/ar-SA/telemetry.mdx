# القياس عن بُعد

تجمع أداتا سطر الأوامر `@agent-native/core` و`@agent-native/skills` بيانات استخدام مجهولة الهوية. تُظهر لنا هذه البيانات أجزاء CLI التي تعمل والمواضع التي يتعثر فيها المستخدمون، فنعرف ما يجب إصلاحه.

لا شيء هنا يحدد هويتك أو مشروعك أو شيفرتك، ويمكنك إيقافه بأمر واحد. تتناول هذه الصفحة الأداتين وتسرد كل ما يمكنهما إرساله. أما التحليلات داخل تطبيق تبنيه فهي خيار منفصل تضبطه بنفسك؛ راجع [التتبع](/docs/tracking).

## إيقافه {#turn-it-off}

```bash
npx @agent-native/core telemetry disable
```

يشمل هذا الأداتين على هذا الجهاز، كما يوقف تقارير الأعطال.

| الأمر                                      | ما يفعله                                                     |
| ------------------------------------------ | ------------------------------------------------------------ |
| `npx @agent-native/core telemetry status`  | يعرض ما إذا كان القياس عن بُعد مفعّلًا، والإعداد الذي أوقفه. |
| `npx @agent-native/core telemetry disable` | يوقف القياس عن بُعد على هذا الجهاز.                          |
| `npx @agent-native/core telemetry enable`  | يعيد تشغيله.                                                 |
| `npx @agent-native/core telemetry reset`   | يستبدل المعرّف العشوائي لهذا الجهاز بمعرّف جديد.             |

يُخزَّن الإعداد في `~/.agent-native/telemetry.json`، بجوار المعرّف العشوائي في `~/.agent-native/installation-id`.

يمكنك أيضًا إيقافه بأيٍّ من متغيري البيئة التاليين، وهما يتقدمان على الإعداد. استخدمهما في CI أو في ملف تعريف مشترك للطرفية:

```bash
DO_NOT_TRACK=1
AGENT_NATIVE_TELEMETRY_DISABLED=1
```

## معاينة ما سيرسله الأمر {#see-what-a-command-would-send}

اضبط `AGENT_NATIVE_TELEMETRY_DEBUG=1` لطباعة كل حدث إلى stderr، كلٌّ في سطر يبدأ بـ `[telemetry]`، من دون إرسال أي شيء. يعمل هذا أيضًا عندما يكون القياس عن بُعد متوقفًا، ولا يُنشئ معرّفًا للجهاز.

```bash
AGENT_NATIVE_TELEMETRY_DEBUG=1 npx @agent-native/core --version
```

## الإشعار {#the-notice}

في أول مرة يكون فيها أمر ما على وشك إرسال أي شيء من جهاز ما، يطبع هذا النص إلى stderr:

```text
▶ Agent-Native collects anonymous usage data.
  It shows us which parts of the CLI work and where people get stuck.
  Run "npx @agent-native/core telemetry disable" to opt out.
  https://www.agent-native.com/docs/telemetry
```

يظهر مرة واحدة لكل جهاز، ولا يظهر في CI أو عندما يكون القياس عن بُعد متوقفًا. تواصل عمليات CI إرسال الأحداث ما لم يُضبط أحد المتغيرين أعلاه، وتُعلَّم بالخاصية `ci`.

## ما يُرسَل {#what-is-sent}

تذهب الأحداث إلى خدمة التحليلات الخاصة بـ Agent-Native على `analytics.agent-native.com`، باستخدام مفتاح للكتابة فقط وهو علني في شيفرة CLI المصدرية. يمكن أن يؤخّر الإرسال الأمر لمدة 1.5 ثانية على الأكثر، ثم يتوقف إذا كانت الشبكة بطيئة.

يحمل كل حدث اسمًا وطابعًا زمنيًا ومعرّف الجهاز ومعرّف التشغيل، إضافة إلى هذه الخصائص. يفشل الاختبار في `packages/core/src/cli/telemetry.spec.ts` إذا غابت عن النسخة الإنجليزية من هذه الصفحة خاصية يمكن لـ CLI إرسالها.

### في كل حدث {#on-every-event}

| الخاصية       | ما هي                                                                                   |
| ------------- | --------------------------------------------------------------------------------------- |
| `cli`         | الأداة التي أرسلته: `core` أو `skills-installer`.                                       |
| `cliVersion`  | إصدار CLI.                                                                              |
| `command`     | اسم الأمر، مثل `dev`. أي شيء ليس أمرًا، كخطأ مطبعي أو طلب نصي، يُرسل على أنه `unknown`. |
| `node`        | إصدار Node.js.                                                                          |
| `platform`    | نظام التشغيل: `darwin` أو `linux` أو `win32`.                                           |
| `ci`          | ما إذا كان الأمر يعمل في CI.                                                            |
| `interactive` | ما إذا كان الأمر يعمل في طرفية.                                                         |
| `installId`   | معرّف الجهاز: قيمة عشوائية تُنشأ على هذا الجهاز ولا ترتبط بأي شيء آخر.                  |
| `runId`       | قيمة عشوائية لهذا التشغيل الواحد من الأمر.                                              |

تُرسل بعض الأحداث أيضًا باسم ثانٍ أحدث، مع تسجيل الاسمين في `canonical_event_name` و`legacy_event_name`.

### الأوامر {#commands}

| الحدث                       | متى                        | الخصائص |
| --------------------------- | -------------------------- | ------- |
| `cli.run`                   | يبدأ أمر.                  | لا شيء. |
| `cli.crash`                 | يتعطل أمر.                 | `error` |
| `cli.scaffold.import_error` | يتعذر تحميل مولّد المشروع. | `error` |

`error` هو تلميح الرسالة القصير الموضح في [تقارير الأعطال](#crash-reports).

### تثبيت المهارات {#installing-skills}

تتتبع هذه الأحداث `skills add` و`npx @agent-native/skills`، لنرى أين يتوقف التثبيت. تُرسل المهارات من فهرس Agent-Native بأسمائها. أما المهارة من أي مصدر آخر، مثل ملف بيان محلي أو مستودع آخر، فتُرسل على أنها `custom`.

| الحدث                                                        | متى                                         | الخصائص                                                   |
| ------------------------------------------------------------ | ------------------------------------------- | --------------------------------------------------------- |
| `skills_cli started`                                         | يبدأ الأمر.                                 | لا شيء.                                                   |
| `skills_cli skills listed`, `skills_cli skills prompted`     | تُعرض المهارات المتاحة.                     | `available`, `availableCount`                             |
| `skills_cli skills selected`                                 | تُختار المهارات.                            | `selected`, `selectedCount`, `selectedAll`, `preselected` |
| `skills_cli plan mode selected`                              | يُختار وضع الخطة.                           | `mode`                                                    |
| `skills_cli clients selected`                                | يُختار وكلاء البرمجة.                       | `clients`, `clientCount`                                  |
| `skills_cli scope selected`                                  | يُختار التثبيت على مستوى المشروع أو عامًّا. | `scope`                                                   |
| `skills_cli install completed`                               | تُكتب ملفات المهارات.                       | `skills`, `clients`, `scope`, `dryRun`, `writtenCount`    |
| `skills_cli instructions updated`                            | تُحدَّث ملفات التعليمات.                    | `fileCount`                                               |
| `skills_cli mcp registered`                                  | يُسجَّل موصل MCP.                           | `skills`, `serverName`, `clients`, `authenticated`        |
| `skills_cli github action added`                             | يُضاف سير عمل PR Visual Recap.              | لا شيء.                                                   |
| `skills_cli connect started`, `skills_cli connect completed` | يبدأ تسجيل الدخول إلى تطبيق أو ينتهي.       | لا شيء.                                                   |
| `skills_cli connect failed`                                  | يفشل تسجيل الدخول إلى تطبيق.                | `error`                                                   |
| `skills_cli cancelled`                                       | يُلغى التثبيت.                              | `step`                                                    |
| `skills_cli completed`                                       | ينتهي الأمر.                                | `skills`, `clients`, `scope`, `dryRun`, `durationMs`      |
| `skills_cli failed`                                          | يفشل الأمر.                                 | `command`, `error`, `durationMs`                          |

### تقارير الأعطال {#crash-reports}

عندما يفشل أمر، يبلّغ الحدث `$exception` عمّا تعطل في شيفرة Agent-Native، ولا شيء عن شيفرتك:

| الخاصية            | ما هي                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `exceptionType`    | نوع الخطأ إذا كان نوعًا قياسيًا، مثل `TypeError`. أما أي نوع آخر، مثل فئة خطأ مخصصة، فيُرسل باسم `Error`.                                                                                                           |
| `exceptionCode`    | رمز الخطأ إذا كان رمزًا قياسيًا، مثل `ENOENT`.                                                                                                                                                                      |
| `exceptionMessage` | تلميح قصير. ترسل الأخطاء المعروفة الخاصة بـ Agent-Native نصها الثابت. وترسل أي رسالة أخرى كلماتها الأولى فقط، بحد أقصى 20 حرفًا، وتتوقف عند أول كلمة تحتوي على أي شيء غير الحروف، أو مباشرة بعد كلمة تنتهي بنقطتين. |
| `exceptionStack`   | إطارات المكدّس في ملفات Agent-Native فقط، بمسارات نسبية إلى الحزمة. تُحذف كل الإطارات الأخرى.                                                                                                                       |
| `handled`          | `false` عندما يوقف الخطأ الأمر.                                                                                                                                                                                     |
| `level`            | درجة الخطورة.                                                                                                                                                                                                       |
| `occurredAt`       | وقت حدوثه.                                                                                                                                                                                                          |
| `release`          | إصدار CLI.                                                                                                                                                                                                          |
| `app`              | دائمًا `agent-native-cli`.                                                                                                                                                                                          |
| `template`         | دائمًا `cli`.                                                                                                                                                                                                       |
| `runtime`          | دائمًا `cli`.                                                                                                                                                                                                       |
| `source`           | دائمًا `cli`.                                                                                                                                                                                                       |
| `exceptionTags`    | مكان حدوث الفشل؛ انظر أدناه.                                                                                                                                                                                        |
| `exceptionExtra`   | كيف انتهى الفشل؛ انظر أدناه.                                                                                                                                                                                        |

لا يحمل هذان الحقلان سوى هذه القيم:

- `exceptionTags`: `source` (جزء CLI الذي فشل)، و`buildStep` (أحد أسماء خطوات البناء لدينا)، و`template` (أحد أسماء قوالبنا فقط)، و`command`، و`handled` (تسمية للفحص الذي أبلغ عنه).
- `exceptionExtra`: `exitCode` و`signal` (كيف انتهت خطوة البناء)، و`stage` و`durationMs`.

التلميح هو بداية الرسالة، لذا قد تحمل رسالة تبدأ بكلمات عادية تخصك، مثل اسم مشروع، تلك الكلمات. وينتهي التلميح عند أي رقم أو شرطة سفلية أو شرطة مائلة أو رمز آخر، وكذلك عند كلمة أطول من أن تتسع له، لذا لا يمكن أن تمر المسارات أو الروابط أو عناوين البريد الإلكتروني أو معظم الرموز المميزة.

### Sentry {#sentry}

إذا كانت `@sentry/node` مثبتة إلى جانب `@agent-native/core`، فإن الأعطال وعمليات البناء الفاشلة تذهب أيضًا إلى مشروع Sentry الخاص بـ Agent-Native، وكذلك تحذيران من خادم تطوير مساحة العمل. أما أوامر المهارات الفاشلة فلا تذهب إليه. تتبع هذه التقارير كل إعداد في هذه الصفحة وتحمل نوع الخطأ والتلميح وإطارات المكدّس وحقول `exceptionExtra` نفسها، مع هذه الوسوم: حقول `exceptionTags` أعلاه، و`code` الخاص بالخطأ، واسم `command`، و`nodeVersion`، و`platform`. البيئة دائمًا `production`. وتحمل التقارير أيضًا ما يضيفه Sentry عادةً: معرّف الحدث والطابع الزمني ودرجة الخطورة وإصدار CLI واسم Sentry SDK وإصداره. لا يرسل CLI اسم المضيف أو أسطر الشيفرة المصدرية أو مخرجات وحدة التحكم أو قائمة تبعياتك.

## ما لا يُرسَل أبدًا {#what-is-never-sent}

- متغيرات البيئة
- مسارات الملفات أو محتوياتها أو الشيفرة المصدرية
- أسماء المشاريع أو المستودعات أو التطبيقات، وعناوين git البعيدة
- السجلات أو مخرجات الأوامر
- وسائط سطر الأوامر أو الطلبات النصية
- عناوين البريد الإلكتروني أو أسماء المستخدمين أو أسماء المضيفين
- رسائل الخطأ الخام، أو إطارات المكدّس من شيفرتك
- أي معرّف لمشروعك

الاستثناء الوحيد في هذه القائمة هو تلميح العطل الموضح أعلاه، إذ قد يحمل الكلمات الأولى من رسالة الخطأ.

يمكن للخدمة التي تستقبل الحدث رؤية عنوان IP للطلب، كما هو الحال مع أي خادم ويب. لا يضعه CLI في أي حدث.
