# القرارات

تصدّر الحزمة `@agent-native/core/decisions` الدالة `decide({ ownerEmail, input, questions, options? }): Promise<DecisionResult>`، وهي مصنّف ومقيّم يراعي قدرات المزوّد للأسئلة المنظّمة. تعيد نتيجة ليفحصها المستدعي. ولا تنفّذ إجراءً لاحقًا ولا تمنح الإذن به.

## المدخلات والأسئلة

تقبل decide() عنوان البريد الإلكتروني للمالك ومصفوفة من أجزاء الإدخال وأسئلة مسمّاة وإعدادات تنفيذ اختيارية. يمكن أن تحتوي أجزاء الإدخال على نص أو JSON منظّم أو رابط صورة:

يمكن تمرير سلسلة نصية مباشرةً بوصفها الإدخال أيضًا.

```ts
const input = [
  { type: "text", text: "Please cancel Friday's lunch reservation." },
  { type: "json", value: { reservationId: "reservation-123" } },
  { type: "image", url: "https://example.com/reservation.png" },
];
```

لكل سؤال اسم وتعليمات. ويحدّد نوع السؤال الحقول الإضافية:

| النوع | الحقول الإضافية | الغرض |
| --- | --- | --- |
| `predicate` | لا شيء | تقييم عبارة محددة |
| `choice` | `choices`: قيم نصية مع أوصاف | الاختيار من القيم المقدّمة |
| `score` | `levels`: من مستويين إلى 10 مستويات مرتبة مع تسميات وأوصاف | تحديد موضع الإدخال على مقياس مقدّم |

تأخذ عناصر choices الشكل `{ value: string, description: string }`. وتأخذ مستويات score الشكل `{ label: string, description: string }`.

## واجهة البرمجة

```ts
import { decide } from "@agent-native/core/decisions";

const result = await decide({
  ownerEmail: "owner@example.com",
  input: [{ type: "text", text: "Please cancel Friday's lunch reservation." }],
  questions: [
    {
      type: "predicate",
      name: "isCancellationRequest",
      instructions: "Does the message ask to cancel a reservation?",
    },
  ],
});

if (result.status === "ok") {
  const answer = result.answers["isCancellationRequest"];
} else {
  throw new Error(`Decision unavailable: ${result.status}`);
}
```

يجمع المثال التالي سؤال اختيار وسؤال تقييم في استدعاء واحد. يستخدم التقييم خمسة مستويات مرتبة، ضمن النطاق المدعوم من مستويين إلى 10.

```ts
import { decide } from "@agent-native/core/decisions";

const triage = await decide({
  ownerEmail: "owner@example.com",
  input: [
    { type: "text", text: "I have waited over a day for a refund update." },
    { type: "json", value: { daysWaiting: 2, amount: 48 } },
  ],
  questions: [
    {
      type: "choice",
      name: "queue",
      instructions: "Choose the support queue that best fits the request.",
      choices: [
        { value: "billing", description: "Payments, refunds, or invoices" },
        { value: "general", description: "Other customer questions" },
      ],
    },
    {
      type: "score",
      name: "urgency",
      instructions: "Score how soon a support agent should review the request.",
      levels: [
        { label: "low", description: "Can wait several business days" },
        { label: "normal", description: "Review in the usual queue" },
        { label: "elevated", description: "Review sooner than usual" },
        { label: "high", description: "Review as soon as practical" },
        { label: "urgent", description: "Needs immediate review" },
      ],
    },
  ],
  options: { timeoutMs: 15_000 },
});

if (triage.status !== "ok") {
  throw new Error(`Decision unavailable: ${triage.status}`);
}

const queue = triage.answers["queue"];
const urgency = triage.answers["urgency"];
```

تتضمن كائنات الوسيطات الحقول التالية:

- **ownerEmail**: عنوان بريد مالك مساحة العمل المستخدم لحل إعدادات القرارات.
- **input**: أجزاء نصية أو JSON أو روابط صور لتقييمها.
- **questions**: أسئلة مسمّاة من نوع predicate أو choice أو score.
- **options**: إعدادات اختيارية تتضمن signal أو timeoutMs أو providers أو cacheKey.

تكون قيمة result.status هي ok عند النجاح؛ وتتضمن النتيجة provider وmodel وanswers مفهرسة بأسماء الأسئلة، وقد تتضمن cached وusage اختياريًا. تتضمن حالة not_configured السبب missing_credentials وقائمة providers. وتتضمن حالة failed سببًا محدد النوع، وقد تتضمن provider وquestionNames. لا يُفعّل التخزين المؤقت إلا عند توفير cacheKey. ويشمل نطاق مفتاح التخزين المالك والمؤسسة والمزوّد والطراز وcacheKey والإدخال والأسئلة. مدة صلاحية الذاكرة المؤقتة داخل الذاكرة 60 ثانية وبحد أقصى 256 إدخالًا.


## دعم المزوّدين بحسب القدرات

قد يختلف دعم الأسئلة باختلاف المزوّد والطراز. تراعي decide() القدرات، لذلك لا تفترض أن كل مزوّد يدعم كل نوع من الأسئلة. لا تعلن عن دعم تركيبة مزوّد وطراز ونوع سؤال إلا بعد التحقق منها. تحدد النتيجة الناجحة المزوّد والطراز اللذين أجابا.

يمكن ضبط ترتيب المزوّدين لكل مساحة عمل على حدة. الترتيب الافتراضي هو Builder Jev، ثم Jev الشخصي، ثم OpenAI. إذا لم تتم تهيئة أي مزوّد، تعيد `decide()` الحالة `not_configured`. تتحكم إعدادات مساحة العمل `decisions.providerOrder` في ترتيب المزوّدين، وتحدد `decisions.timeoutMs` مهلة كل مزوّد؛ والاسمان البديلان في البيئة هما `DECISIONS_PROVIDER_ORDER` (قائمة مفصولة بفواصل) و`DECISIONS_TIMEOUT_MS`. يجب أن يتضمن مفتاح أي حد أو ذاكرة مؤقتة خاصة بمزوّد كلاً من المزوّد والطراز حتى لا يُعاد استخدام معايرة أو نتيجة طراز مع طراز آخر.

تعيد decide() تصنيفات أو درجات يفسرها المستدعي. استخدم إجراءً منفصلًا ومصرّحًا به لأي تغيير لاحق في بيانات التطبيق.
