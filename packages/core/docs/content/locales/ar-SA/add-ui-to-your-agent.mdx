# أضف واجهة إلى وكيلك

تمنح Agent-Native وكيلك الحالي مساحة عمل عملية للمحادثة والموافقات وحالة سير العمل والصلاحيات. يحتفظ المزوّد بالتفكير والأدوات والسياق والتنفيذ الطويل.

هذه الصفحة تشرح **إضافة واجهة إلى وكيل Microsoft Foundry أو Gemini Enterprise أو Anthropic Managed Agents أو OpenAI**.

## اختر مسار الاتصال {#choose-a-connection-path}

| الخلفية                  | الاتصال في Agent-Native | ما الذي تضبطه                                |
| ------------------------ | ----------------------- | -------------------------------------------- |
| Microsoft Foundry        | A2A 1.0                 | عنوان Agent Card وسر Entra                   |
| Gemini Enterprise        | A2A                     | عنوان Agent Card وسر Google                  |
| Anthropic Managed Agents | Managed Agents API      | معرّف الوكيل والبيئة ومفتاح من الخزنة        |
| OpenAI Agents API        | نقطة A2A مخصصة          | عنوان Agent Card وبيانات اعتماد المزوّد      |
| أي وكيل A2A              | A2A                     | عنوان Agent Card وبيانات الاعتماد الاختيارية |

افتح **Settings → Agent → Sub-agents** واختر **Connect agent** (للمالكين والمسؤولين) للبحث في المزوّدين. يفتح كل زر Connect نموذج الاتصال مع تحديد المزوّد الصحيح. تبقى الأسرار في خزنة مساحة العمل ولا يُحفظ سوى مرجعها.

## Microsoft Foundry {#microsoft-foundry}

الصق عنوان بطاقة A2A v1.0، واختر بيانات Entra. لخدمة إلى خدمة استخدم النطاق `https://ai.azure.com/.default` ودور **Foundry Agent Consumer**.

## Gemini Enterprise {#gemini-enterprise}

الصق عنوان بطاقة A2A المخصص واختر سر bearer من الخزنة. يتحقق Agent-Native من البطاقة وواجهة JSON-RPC قبل الحفظ.

## Anthropic Managed Agents {#anthropic-managed-agents}

اختر **Anthropic Managed Agents**، ثم أدخل معرّف الوكيل والبيئة واختر مفتاح API. تبقى الجلسات والموافقات في Anthropic وتظهر في محادثة Agent-Native.

## وكيل A2A مخصص {#custom-a2a}

استخدم **Add by URL** لوكيل داخلي أو مستضاف ذاتياً. يدعم Agent-Native بطاقات A2A 0.3 و1.0 ويعرض فشل البطاقة أو رفض المصادقة كحالة واضحة.

عند عدم توفر البث، يستخدم الاتصال `message/send`.

## السجلات {#registries}

يمكنك تصفح [Global A2A Registry](https://www.a2a-registry.org). السجل للاكتشاف فقط: راجع البطاقة والمضيف ومتطلبات المصادقة ثم أضف الوكيل صراحة قبل استخدام أي سر.

## طبقة الواجهة {#ui-layer}

يحمل [A2A](/docs/a2a-protocol) المهمة المفوضة بينما تملك مساحة عمل Agent-Native حالة المستخدم. راجع [Connected agents](/docs/agent-mentions#mentioning-agents) و[External agents](/docs/external-agents).
