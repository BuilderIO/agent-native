# المحتوى: مصادر المجلدات المحلية

يستخدم Content نموذج بيانات واحدًا: تُحفظ كل صفحة في SQL، وتنتمي إلى
**مساحة**، وتكون عنصرًا في قاعدة النظام **Files** لتلك المساحة. المجلد المحلي
من Markdown أو MDX هو مصدر متصل بـ Files، إلى جانب التعاون والمشاركة
والتعليقات والسجل والبحث وخصائص قاعدة البيانات، ونفس سطح الإجراءات الذي
تستخدمه كل صفحة أخرى.

لكل مستخدم مساحة شخصية، ولكل مؤسسة متاحة مساحة مؤسسة، ويحدد كتالوج
**Workspaces** الشخصي المساحات التي تظهر. Files قاعدة Content عادية؛ يمكن
لخصائصها وعوامل التصفية والترتيب والتجميع وطرق العرض المحفوظة أن تعرض الشريط
الجانبي أيضًا.

## ربط مجلد

<Steps>

### افتح شاشة المجلد المحلي

اختر مجلدًا عبر واجهة File System Access في المتصفح أو عبر Agent-Native
Desktop. لا يخزّن Content في SQL سوى معرف اتصال معتم، والمسارات النسبية،
والبصمات، وبيانات المصدر الوصفية. لا يخزّن أبدًا المسار المطلق أو مقبض
المتصفح أو محتوى الملفات الخام هناك.

### اختر مكان ارتباط المجلد

اربطه بقاعدة Files لمساحة شخصية أو مساحة مؤسسة موجودة، أو أنشئ مساحة خاصة
مدعومة بمجلد لها قاعدة Files خاصة بها.

### اختر سياسة المصدر الموثوق

| السياسة                  | السلوك                                                              |
| ------------------------ | -------------------------------------------------------------------- |
| `database_primary`       | Content هو المرجع الموثوق؛ تتم مراجعة تغييرات المجلد قبل استخدامها  |
| `source_primary`         | يكون المجلد هو المرجع الموثوق عند عدم وجود تعديل متزامن في Content |
| `reviewed_bidirectional` | تتطلب التغييرات في أي من الاتجاهين المراجعة عند وجود تعارضات        |

</Steps>

تُحوّل المزامنة الأولى الملفات إلى صفحات عادية مدعومة بـ SQL وتسجل هوية
مصدرها. المزامنة المتكررة متكافئة الأثر (idempotent). إذا تغير الملف وصفحته
في Content معًا، يسجّل Content مجموعة تغييرات واردة بدل الكتابة فوق أي من
الجانبين. يحافظ قطع الاتصال على صفحات SQL والملفات المحلية معًا.

## البدء من مستودع

```bash
npx @agent-native/core@latest content .
```

يشغل الأمر تطبيق Content العادي المدعوم بقاعدة البيانات، ويسجل المجلد كمصدر،
ويفتح شاشة الاتصال.

## الإعداد

```json
{
  "version": 1,
  "apps": {
    "content": {
      "roots": [
        {
          "name": "Docs",
          "path": "docs",
          "kind": "docs",
          "extensions": [".md", ".mdx"],
          "source": {
            "type": "local-folder",
            "connectionId": "local-folder:<opaque-id>",
            "truthPolicy": "source_primary"
          }
        }
      ],
      "components": "components",
      "extensions": "extensions"
    }
  }
}
```

## الترحيل من وضع الملفات المحلية

<Callout tone="info">

تخطَّ هذا القسم إذا كنت تُعِدّ مجلدًا محليًا لأول مرة. فهو ينطبق فقط على
ملف إعداد (manifest) يسبق نموذج المصدر الحالي.

</Callout>

للترحيل، احذف `mode: "local-files"` و`AGENT_NATIVE_MODE=local-files`، واحتفظ
بالجذور، وأضف `source`. تحافظ معرفات frontmatter على هوية الصفحة عند إعادة
التسمية أو النقل. وتستمر المكونات والامتدادات المحلية عبر الجسر المحلي الموثوق.
