# Cloudflare

## Cloudflare Pages {#cloudflare-pages}

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_pages" } })],
});
```

## Cloudflare Workers {#cloudflare-workers}

استخدم مخرجات الوحدة الأصلية لـ Nitro من أجل Cloudflare Worker. هذا يبقي
SSR مُفعّلًا ويُصدر نقطة دخول الـ Worker بالإضافة إلى الأصول الثابتة تحت
`.output/server` و`.output/public`:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

قم ببناء ونشر الـ Worker المُولَّد باستخدام Wrangler:

```bash
npx @agent-native/core@latest build
npx wrangler deploy --config .output/server/wrangler.json
```

يمكنك أيضًا تحديد الإعداد المسبق صراحةً باستخدام
`NITRO_PRESET=cloudflare_module`. قم بتكوين قاعدة بيانات SQL خارجية دائمة
قبل النشر. نظام ملفات الـ Worker ليس مخزنًا دائمًا للتطبيق.
