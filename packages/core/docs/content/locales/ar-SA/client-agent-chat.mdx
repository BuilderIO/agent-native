# محادثة الوكيل

يمكن لعميل تطبيقك التحدث إلى الوكيل من خلال مجموعة صغيرة من الأدوات المساعدة الخاصة بالعميل. تغطي هذه الأدوات إرسال مطالبة، وتهيئة سياق مخفي، وسؤال المستخدم سؤالاً معطِّلاً (blocking)، وفتح لوحة الوكيل.

في المثال أدناه، يطلب زر **صياغة رد** من الوكيل أن يسأل المستخدم سؤالاً. بعد أن يجيب المستخدم، يشرع الوكيل في صياغة رد يأخذ في الحسبان سياق الصفحة الحالية ورد المستخدم.

## كيف يعمل

باستخدام أساليب الأدوات المساعدة الخاصة بالعميل التي توفرها Agent-Native، يمكن لواجهة المستخدم أن تطلب من الوكيل التفاعل مع المستخدم بطرق متنوعة. يوضح الرسم البياني أدناه كيف يمكن للمستخدم النقر على زر "صياغة رد"، الذي يطلب من الوكيل بعد ذلك التفاعل مع المستخدم قبل إنشاء رد.

تجربة المستخدم هي كما يلي:

1. ينقر المستخدم على زر **صياغة رد**، الذي يُشغّل استدعاء دالة `askUserQuestion()`. تتم الإجابة على السؤال بشكل مضمّن في لوحة الوكيل.

1. يختار المستخدم **تقديم استرداد**، الذي يُشغّل `sendDraftRequest()` لإرسال المطالبة وسياق التذكرة إلى الوكيل.

1. يستدعي الوكيل [action](/docs/actions-overview) الخاص بـ `draft-ticket-reply`، ويظهر الرد المُصاغ في مؤلف الرد.

تسأل هذه الدالة المستخدم سؤالاً متعدد الاختيارات من كود التطبيق، وتعرضه بشكل مضمّن في لوحة الوكيل، وتنتظر إجابته. استخدمها عندما تحتاج واجهة المستخدم إلى قرار صغير واحد بخيارين إلى أربعة خيارات قبل بدء عمل الوكيل، بدلاً من بناء نافذة منبثقة مخصصة.

في المثال أدناه، يسأل زر "صياغة رد" في صفحة تذكرة الممثل عن كيفية رغبته في الرد قبل إرسال أي شيء إلى الوكيل:

```ts
import { askUserQuestion } from "@agent-native/core/client/agent-chat";

const answer = await askUserQuestion({
  question: "How would you like to respond to this ticket?",
  header: "Response", // optional short chip/heading (≈12 chars)
  options: [
    { label: "Offer a refund", value: "refund" },
    { label: "Offer a reprint", value: "reprint" },
  ],
});
```

يُغلّف خطاف React هذا دالة `sendToAgentChat()` بتتبع حالة التحميل.

1. المعامل الأول، `isGenerating`، يتحول إلى true عند استدعائه، ثم يُعاد ضبطه إلى false عندما ينتهي الوكيل من الإنشاء.

2. المعامل الثاني، `send()`، يُطابق دالة `sendToAgentChat()`.

لا يُعاد ضبط `isGenerating` إلا بعد أن يبدأ التشغيل فعليًا ويُعلن أنه توقف. يقوم استدعاء بـ `submit: false` بتعبئة مسودة مسبقًا دون بدء تشغيل، لذا تبقى `isGenerating` صحيحة (`true`) إلى الأبد بعد ذلك. استخدم هذا الخطاف فقط لعمليات الإرسال بـ `submit: true`؛ استدعِ `sendToAgentChat()` مباشرة لعمليات التعبئة المسبقة فقط.

## sendToAgentChat(opts) {#sendtoagentchat}

أرسل رسالة إلى محادثة الوكيل عبر `postMessage`. هذا هو البدائي (primitive) ذو المستوى الأدنى الذي تُغلّفه `useAgentChatGenerating()` أعلاه، وهو مفيد عندما لا يحتاج تفاعل واجهة المستخدم إلى تتبع حالة تحميل خاص به. مرر `context` لتفصيل إضافي ينبغي أن يراه الوكيل دون أن يراه المستخدم. يُلحَق بالرسالة المرسلة إلى الوكيل، مُغلَّفًا بوسوم `<context>`، ثم يُزال قبل عرض الرسالة في واجهة المحادثة. مرر `submit: true` للإرسال فورًا، أو `submit: false` لتعبئة مسودة يراجعها المستخدم أولًا.

```ts
import { sendToAgentChat } from "@agent-native/core/client/agent-chat";
// إرسال تلقائي لمطالبة مع سياق مخفي
sendToAgentChat({
  message: "Generate alt text for this image",
  context: "Image path: /api/projects/hero.jpg",
  submit: true,
});

// Prefill without submitting (user reviews first)
sendToAgentChat({
  message: "Rewrite this in a conversational tone",
  context: selectedText,
  submit: false,
});
```

### AgentChatMessage {#agentchatmessage}

| الخيار        | النوع      | الوصف                                                                        |
| ------------- | ---------- | ---------------------------------------------------------------------------- |
| `message`     | `string`   | المطالبة المُرسلة إلى المحادثة، وهي الجزء الوحيد الذي يظهر في واجهة المحادثة |
| `context`     | `string?`  | سياق يراه الوكيل يُلحَق بالرسالة قبل إرسالها. يُزال من عرض واجهة المحادثة    |
| `submit`      | `boolean?` | true = إرسال تلقائي، false = تعبئة مسبقة فقط                                 |
| `newTab`      | `boolean?` | إنشاء سلسلة محادثة منفصلة لهذه المطالبة                                      |
| `openSidebar` | `boolean?` | اضبطه على false للإرسال/التعبئة المسبقة دون فتح الشريط الجانبي               |

تشغيل هذا من داخل تضمين MCP App، أو تشغيل العمل في الخلفية دون فتح الشريط الجانبي، مُغطّى كلاهما في [متقدم](/docs/client-advanced#background-send).

## الاقتراحات الديناميكية {#dynamic-suggestions}

قبل بدء محادثة، تعرض `<AgentSidebar>`، و`<AgentPanel>`، و`<AssistantChat>` شرائح مطالبات على المحادثة الفارغة. لا تكون هذه افتراضيًا مجرد قائمة `suggestions` الثابتة الخاصة بك فقط: يقرأ إطار العمل `navigation`، و`selection`، و`pending-selection-context`، وعنوان URL الحالي من حالة التطبيق، ويدمج شرائح تطابق ما هو معروض فعليًا على الشاشة.

يقوم بذلك من خلال فحصين. إذا كان هناك شيء محدد، يضيف شرائح عامة مثل "تلخيص هذا التحديد". بشكل منفصل، ينظر إلى `navigation` بحثًا عن أسماء حقول شائعة تستخدمها التطبيقات الحالية، مثل `threadId`/`emailId` لسلسلة بريد إلكتروني أو `dashboardId`/`chartId` لمخطط، ويضيف شرائح مصممة خصيصًا لهذا النوع من الشاشة، مثل "صياغة رد" لسلسلة رسائل أو "البحث عن حالات شاذة في هذه البيانات" لمخطط. أي ما يخرج به يتم دمجه مع `suggestions` الثابتة الخاصة بك، وإزالة التكرار، والتقييد عند `max`.

```tsx
<AgentSidebar
  suggestions={["Summarize my inbox"]}
  dynamicSuggestions={{ max: 4 }}
>
  <App />
</AgentSidebar>
```

إذا كانت الشاشة الحالية لا تطابق أي شيء يتعرف عليه الاستدلال (heuristic) ولم يكن هناك شيء محدد، فإنها لا تضيف أي شرائح، وتعود المحادثة الفارغة إلى `suggestions` الثابتة الخاصة بك فقط. اضبط `dynamicSuggestions={false}` للاحتفاظ بالشرائح الثابتة فقط. إذا كان شكل التنقل في تطبيقك لا يطابق الاستدلال المدمج، أو كنت تريد شرائح حتمية خاصة بالتطبيق بالكامل، راجع [متقدم](/docs/client-advanced#custom-suggestions).

## openAgentSettings(section?) {#openagentsettings}

استخدم `openAgentSettings()` عندما ينبغي أن تفتح صفحة إعدادات التطبيق أو بطاقة الإعداد
علامة تبويب الإعدادات في الشريط الجانبي للوكيل. مرر معرف قسم مثل `"llm"`، أو `"secrets"`،
أو `"automations"`، أو `"voice"`، أو `"limits"` لفتح قسم معين.

```ts
import { openAgentSettings } from "@agent-native/core/client/navigation";
openAgentSettings();
openAgentSettings("secrets");
```

يُفضَّل هذا المساعد على إرسال `agent-panel:open-settings` مباشرة.

## حالة سياق محادثة الوكيل {#agent-chat-context-state}

واجهات برمجة حالة السياق هي أدوات ربط اختيارية لواجهة المستخدم التي تحتاج إلى مزامنة ثنائية الاتجاه مع شرائح السياق المرحلية: عرض العناصر المرحلية الحالية خارج المؤلف، أو إظهار ما إذا كان عنصر ما مرفقًا بالفعل، أو توفير عناصر تحكم صريحة للإزالة/المسح.

لا تتجه إلى هذه الأدوات المساعدة لتدفقات "أرسل هذا إلى الوكيل" أو "عبّئ هذه المسودة مسبقًا للمراجعة" البسيطة. استخدم [`sendToAgentChat()`](#sendtoagentchat) مع `context` و`submit` لتلك الحالات.

| API                               | استخدم عندما                                                                  |
| --------------------------------- | ----------------------------------------------------------------------------- |
| `useAgentChatContext()`           | يحتاج مكون React إلى قائمة السياق المرحلية المباشرة                           |
| `setAgentChatContextItem(item)`   | يجب أن يُهيّئ الكود الحتمي أو يستبدل عنصر سياق مفتاحي واحد                    |
| `listAgentChatContext()`          | يحتاج الكود غير الخاص بـ React إلى لقطة لمرة واحدة للسياق المرحلي             |
| `removeAgentChatContextItem(key)` | يجب أن تُزيل واجهة المستخدم عنصر سياق مرحلي واحد بواسطة `key` الثابت الخاص به |
| `clearAgentChatContext()`         | يجب أن تمسح واجهة المستخدم كل السياق المرحلي، مثل بعد إعادة ضبط عرض أو وضع    |
| `refreshAgentChatContext()`       | يجب أن يُعيد الكود الحتمي قراءة أحدث لقطة سياق مستمرة                         |

تُعيد `useAgentChatContext()` `{ items, set, remove, clear, refresh }`.

```tsx
import { useAgentChatContext } from "@agent-native/core/client/agent-chat";

function SelectedTicketContextButton({ ticket }: { ticket: { id: string } }) {
  const chatContext = useAgentChatContext();
  const contextKey = `selected-ticket:${ticket.id}`;
  const isAttached = chatContext.items.some((item) => item.key === contextKey);

  return (
    <button
      type="button"
      onClick={() => {
        if (isAttached) {
          chatContext.remove(contextKey);
          return;
        }

        chatContext.set({
          key: contextKey,
          title: "Selected Ticket",
          context: JSON.stringify(ticket, null, 2),
          openSidebar: false,
        });
      }}
    >
      {isAttached ? "Remove from prompt context" : "Add to prompt context"}
    </button>
  );
}
```

`listAgentChatContext()` مخصصة للكود الحتمي الذي يحتاج فقط إلى فحص العناصر المرحلية الحالية مرة واحدة. `clearAgentChatContext()` واسعة عمدًا. استخدم `removeAgentChatContextItem(key)` عندما يتغير اختيار واحد فقط.

### AgentChatContextSetOptions {#agentchatcontextsetoptions}

| الخيار        | النوع      | الوصف                                           |
| ------------- | ---------- | ----------------------------------------------- |
| `key`         | `string`   | معرِّف ثابت يُستخدم لاستبدال عنصر موجود         |
| `title`       | `string`   | تسمية قصيرة تظهر في شريحة المؤلف                |
| `context`     | `string`   | سياق مخفي يُضمَّن مع المطالبة التالية المُرسَلة |
| `openSidebar` | `boolean?` | الافتراضي true. مرر false لتهيئة السياق بصمت    |
