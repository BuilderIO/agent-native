# Netlify

يعمل إعداد `netlify` المسبق لـ Nitro بشكل جيد، وقد منحنا عمليًا بدايات باردة أسرع بكثير من Cloudflare Pages (حوالي 200 مللي ثانية TTFB مقابل حوالي 9 ثوانٍ) للقوالب التي تتواصل مع Postgres خارجي (Neon). إما أن تضبط الإعداد المسبق في `vite.config.ts`:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "netlify" } })],
});
```

...أو تضبط `NITRO_PRESET=netlify` عند وقت البناء.

بالنسبة لمساحة عمل، انشر كل تطبيق من موقع Netlify واحد عن طريق تشغيل:

```bash
npx @agent-native/core@latest deploy --preset netlify
```

يكتب بناء مساحة العمل الأصول الثابتة تحت `dist/_workspace_static/` ويوجّه كل تطبيق إلى دالة Netlify الخاصة به دون إعادة توجيهات أصول قسرية، بحيث تُخدَم ملفات مثل `/mail/assets/...` بشكل ثابت قبل أن تتعامل دالة الخادم مع مسارات التطبيق.

## الإبقاء دافئًا وقواعد البيانات ذات التوسع إلى صفر {#netlify-keep-warm}

عند التمكين، يُصدر بناء Netlify دالة مجدولة تطلب `/_agent-native/health` **كل دقيقة**. هذا يُبقي دالة الخادم وقاعدة بياناتها دافئتين حتى لا يدفع الزائر التالي بعد فترة خمول تكلفة بداية باردة (من 1 إلى 5 ثوانٍ على Neon).

الإبقاء دافئًا **مُعطَّل افتراضيًا** لأن الإيقاظ مرة كل دقيقة يمنع الإيقاف التلقائي على قواعد البيانات ذات التوسع إلى صفر المقاسة. على مستوى Neon المجاني، يمكن أن يستنفد هذا حصة الحوسبة، وترفض قاعدة البيانات حينها **جميع** القراءات في منتصف الجلسة. العرَض هو تطبيق ميت، وليس تطبيقًا بطيئًا. اضبط `AGENT_NATIVE_ENABLE_KEEP_WARM=1` عندما يستحق تقليل زمن انتظار الزائر التالي وقت يقظة قاعدة البيانات.

لا يُطبَّق جدول الإبقاء دافئًا ودفء دالة الخلفية إلا بعد تمكين علم الإبقاء دافئًا الرئيسي:

| المتغير                                     | التأثير                                                                                                                                                  |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AGENT_NATIVE_ENABLE_KEEP_WARM`             | ينضم إلى دفء الخادم/قاعدة البيانات المجدول. غير مضبوط افتراضيًا.                                                                                         |
| `AGENT_NATIVE_DISABLE_KEEP_WARM`            | مفتاح إيقاف للتوافق يتغلب على علم الانضمام عند ضبطه.                                                                                                     |
| `AGENT_NATIVE_KEEP_WARM_SCHEDULE`           | يتجاوز الوتيرة بتعبير cron مكون من 5 حقول، مثل `*/5 * * * *`. الوتيرة الافتراضية عند التمكين هي `* * * * *`. القيمة التي يتعذر تحليلها **تُفشل البناء**. |
| `AGENT_NATIVE_DISABLE_KEEP_WARM_BACKGROUND` | يُسقط دفء دالة الخلفية فقط، مع إبقاء الخادم دافئًا. تدفئة `server` هي طلب واحد. تدفئة `-background` تبدأ حاوية جديدة تعيد فحص المخطط.                    |

إذا كنت على مستوى قاعدة بيانات مجاني أو مقيّد الحصة بطريقة أخرى، اترك `AGENT_NATIVE_ENABLE_KEEP_WARM` غير مضبوط. إذا انضممت، استخدم وتيرة أبطأ أو اضبط `AGENT_NATIVE_DISABLE_KEEP_WARM_BACKGROUND=1` لإسقاط دفء الخلفية الأكثر تكلفة.
