# النشر: متغيرات البيئة

للحصول على المرجع الشامل للمستودع بأكمله، بما في ذلك متغيرات القالب والمزود والمحلي والتكامل المستمر (CI)، راجع [متغيرات البيئة](/docs/environment-variables). تظل الجداول
أدناه الدليل المرجعي لقيم الإنتاج وسلوك الاستضافة.

## البناء / وقت التشغيل {#env-runtime}

| المتغير                                     | الوصف                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`                                      | منفذ الخادم (Node.js فقط)                                                                                                                                                                                                                                                                                                                                                                     |
| `NITRO_PRESET`                              | تجاوز الإعداد المسبق للبناء وقت البناء                                                                                                                                                                                                                                                                                                                                                        |
| `APP_BASE_PATH`                             | ثبّت التطبيق تحت بادئة (مثل `/mail`). يُضبط تلقائيًا بواسطة `npx @agent-native/core@latest deploy`. اتركه غير مضبوط للنشر المستقل.                                                                                                                                                                                                                                                            |
| `APP_URL`                                   | مصدر عام أساسي اختياري. يُفحص قبل `BETTER_AUTH_URL` عند تحليل جمهور A2A JWT، ومصدر OAuth العام، وأهداف webhook للإرسال الذاتي، وروابط الموارد المُولَّدة. اضبطه صراحةً في عمليات نشر المعاينة/التجهيز حيث لا يمكن الاعتماد على مضيف الطلب.                                                                                                                                                    |
| `AGENT_PROD_CODE_EXECUTION`                 | وضع تنفيذ كود إنتاجي اختياري: `off` (افتراضي)، أو `sandboxed`، أو `trusted`. راجع [تنفيذ الكود في الإنتاج](/docs/actions-agent-tools#production-code-execution).                                                                                                                                                                                                                              |
| `AGENT_NATIVE_SSR_CACHE`                    | سياسة التخزين المؤقت لواجهة SSR على مستوى النشر بأكمله: غير مضبوطة/`on` تُبقي التخزين المؤقت الصارم الافتراضي، و`off` ترسل `no-store`، أو مدة زمنية مثل `30s` / `5m` تضبط نضارة أقصر. راجع [التخزين المؤقت SSR](/docs/ssr-caching).                                                                                                                                                           |
| `AGENT_NATIVE_ENABLE_KEEP_WARM`             | انضم إلى دالة الإبقاء دافئًا المجدولة لـ Netlify. غير مضبوط افتراضيًا. راجع [الإبقاء دافئًا](/docs/netlify#netlify-keep-warm).                                                                                                                                                                                                                                                                |
| `AGENT_NATIVE_DISABLE_KEEP_WARM`            | مفتاح إيقاف للتوافق لدالة الإبقاء دافئًا المجدولة لـ Netlify. راجع [الإبقاء دافئًا](/docs/netlify#netlify-keep-warm).                                                                                                                                                                                                                                                                         |
| `AGENT_NATIVE_KEEP_WARM_SCHEDULE`           | تجاوز وتيرة الإبقاء دافئًا بتعبير cron مكون من 5 حقول (الافتراضي `* * * * *` عند التمكين). القيمة التي يتعذر تحليلها تُفشل البناء. راجع [الإبقاء دافئًا](/docs/netlify#netlify-keep-warm).                                                                                                                                                                                                    |
| `AGENT_NATIVE_DISABLE_KEEP_WARM_BACKGROUND` | أسقط دفء دالة الخلفية فقط وأبقِ الخادم دافئًا. راجع [الإبقاء دافئًا](/docs/netlify#netlify-keep-warm).                                                                                                                                                                                                                                                                                        |
| `AGENT_NATIVE_DISABLE_INPROCESS_SWEEPS`     | أوقف مؤقتات المسح الاحتياطية داخل العملية (إعادة إرسال الأتمتة، ومصالحة فرق الوكلاء، واستعادة تنفيذ الصندوق المعزول). على serverless، تعمل هذه لكل حاوية دافئة، لذا يتوسع معدل استعلامها مع عدد المثيلات. اضبطه **فقط** حيث يقود جدولة دائمة بالفعل نفس الاستعادة، وإلا لن تتم إعادة محاولة العمل المُصفَّف.                                                                                  |
| `AGENT_NATIVE_SKIP_ENSURE_TABLES`           | تخطَّ DDL المخطط عند الطلب في عمليات النشر التي لا يغطيها التخطي التلقائي لـ serverless. يتطلب أن يكون مخططك مُهاجَرًا بالفعل. راجع [DDL المخطط عند الطلب](/docs/deployment#skip-ensure-tables).                                                                                                                                                                                              |
| `AGENT_NATIVE_BUILDER_RELAY_SECRET`         | سر HMAC مشترك مخصص لا يقل عن 32 حرفًا لترحيل تفويض Builder الآمن للمعاينة. اضبط نفس القيمة في عملية النشر المؤسسية المعتمدة لرد الاتصال وعمليات نشر المعاينة فقط عندما يجب أن يهبط التفويض في قاعدة بيانات معاينة معزولة.                                                                                                                                                                     |
| `AGENT_NATIVE_BUILDER_RELAY_TARGET_ORIGINS` | قائمة سماح مفصولة بفواصل خاصة برد اتصال المؤسسة فقط لمصادر معاينة موثوقة دقيقة (على سبيل المثال، `https://0123456789abcdef01234567--content.netlify.app`). اضبطها فقط في عملية نشر رد الاتصال المؤسسي. يجب أن تستخدم مصادر Netlify رابطًا دائمًا سداسي عشري ثابتًا خاصًا بالنشر مكونًا من 24 حرفًا. تُرفض أسماء مستعارة `deploy-preview-*` القابلة للتغيير، والأحرف البديلة، ولواحق النطاقات. |

تعيش متغيرات اتصال قاعدة البيانات (`DATABASE_URL`، و`DATABASE_AUTH_TOKEN`، و`<APP_NAME>_DATABASE_URL` الخاصة بكل تطبيق) في [قاعدة البيانات](/docs/server-database#production).

## التكوين الحساس للإنتاج {#env-required-prod}

تغطي هذه الإعدادات السلوك الحساس للإنتاج. يحتاج تطبيق مستقل يستخدم
مصادقة الإطار إلى `BETTER_AUTH_SECRET` ثابت وقاعدة بيانات دائمة.
يُستنتج عنوان URL العام للمصادقة من الطلب، أو القالب المعروف، أو منصة
الاستضافة عندما يكون غير مضبوط. إعدادات مساحة العمل وA2A مشروطة بتلك
الميزات. القيم المفقودة إما تفشل بشكل مغلق أو تعود إلى سلوك أضعف
مع تحذير واضح.

| المتغير                                     | الوصف                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BETTER_AUTH_SECRET`                        | سلسلة عشوائية لا تقل عن 32 حرفًا. توقّع ملفات تعريف ارتباط الجلسة وهي الاحتياطي لـ `OAUTH_STATE_SECRET` والقيم المشفَّرة المحلية للتطبيق. إنها أيضًا مرشح قراءة قديم لنص خزنة مشتركة مشفَّر موجود بالفعل. مطلوبة بشدة: يرمي الإطار خطأً عند بدء التشغيل إذا كانت مفقودة في الإنتاج.                                                                                        |
| `BETTER_AUTH_URL`                           | تجاوز اختياري لعنوان URL العام لهذا التطبيق (مثل `https://mail.example.com`). يستنتجه الإطار من الطلب، والقالب المعروف، وسياق منصة الاستضافة عندما يكون غير مضبوط.                                                                                                                                                                                                         |
| `ANTHROPIC_API_KEY`                         | مفتاح API للوكيل الإنتاجي المضمّن. **في عمليات النشر متعددة المستأجرين**، يرفض الإطار العودة إلى هذا عندما لا يملك المستخدم مفتاحًا خاصًا به. مطلوب إحضار مفتاحك الخاص. تستخدمه التثبيتات المستضافة ذاتيًا أحادية المستأجر كمفتاح عام.                                                                                                                                     |
| `OAUTH_STATE_SECRET`                        | مفتاح HMAC مخصص لأظرف حالة OAuth (Google، وAtlassian، وZoom). يعود إلى `BETTER_AUTH_SECRET` عندما يكون غير مضبوط، ولكن يُوصى بقيمة مخصصة حتى لا يُبطل تدوير أحدهما الآخر. أنشئه عبر `openssl rand -hex 32`.                                                                                                                                                                |
| `A2A_SECRET`                                | HMAC مشترك لـ JSON-RPC الخاص بـ A2A بين التطبيقات وعمليات التسليم الموقَّعة في الخلفية. مطلوب لعمليات نشر مساحة العمل المستضافة وميزات A2A. بدونه، تفشل تلك النقاط النهائية بشكل مغلق في الإنتاج. عندما لا يكون هناك مفتاح خزنة مساحة عمل مخصص مضبوط، يستخدم نص الخزنة المشترك المشفَّر مفتاحًا مشتقًا من الغرض من هذه القيمة، لذا فإن تدويرها يُدوِّر أيضًا مفتاح الخزنة. |
| `WORKSPACE_SECRETS_ENCRYPTION_KEY`          | مفتاح AES-256-GCM ثابت مفضَّل لخزنة الأسرار المشفَّرة عند الراحة المشتركة. اضبط نفس القيمة في كل تطبيق يقرأ الخزنة. إنه منفصل عن تشفير OAuth/بيانات الاعتماد المحلي للتطبيق، لذا يمكن لثقة A2A أن تدور دون ترك صفوف الخزنة معزولة. يتم ترحيل نص A2A، وBetter Auth، ومفتاح التطبيق المشفَّر الموجود بالفعل عند القراءات الناجحة.                                            |
| `WORKSPACE_SECRETS_ENCRYPTION_KEY_PREVIOUS` | مفتاح خزنة مساحة عمل سابق اختياري يُستخدم فقط أثناء نافذة التدوير. انشره جنبًا إلى جنب مع `WORKSPACE_SECRETS_ENCRYPTION_KEY` الجديد، ودع القراءات الناجحة تعيد تشفير الصفوف، ثم أزله بعد الترحيل.                                                                                                                                                                          |
| `SECRETS_ENCRYPTION_KEY`                    | مفتاح مدمج قديم للتشفير المحلي للتطبيق والخزنة المشتركة. يظل مدعومًا، ولكن يجب أن تستخدم عمليات النشر الجديدة متعددة التطبيقات `WORKSPACE_SECRETS_ENCRYPTION_KEY` للخزنة المشتركة حتى لا يؤدي تغيير تشفير مساحة العمل إلى تغيير نص OAuth المحلي المشفَّر للتطبيق.                                                                                                          |

## المصادقة والهوية {#env-auth}

بيانات اعتماد مزود OAuth (Google، وGitHub)، واحتياطيات bearer الثابتة لـ MCP (`ACCESS_TOKEN` / `ACCESS_TOKENS`)، ومفاتيح تبديل التحقق من البريد الإلكتروني موثَّقة في [المصادقة](/docs/authentication). اضبطها هناك وفقًا لوضع المصادقة الذي تختاره.

## Webhooks الواردة {#env-webhooks}

يتطلب كل تكامل مراسلة سر توقيع خاصًا به في الإنتاج (تفشل المعالجات بشكل مغلق عند الطلبات المزوَّرة عندما يكون السر مفقودًا). المتغيرات الخاصة بكل تكامل مدرجة في [المراسلة](/docs/messaging) و[الأمان](/docs/security). للتطوير المحلي فقط، يعيد `AGENT_NATIVE_ALLOW_UNVERIFIED_WEBHOOKS=1` الانضمام إلى "التحذير والقبول". لا تضبطه أبدًا في الإنتاج.

## تكوين الأمان (اختياري) {#security-config}

الإعدادات الافتراضية صارمة. حفنة من الأعلام الاختيارية تُخفف السلوك (تتبعات المكدس التصحيحية، وwebhooks غير المتحقق منها، واحتياطي المفتاح على مستوى مساحة العمل، ومحول MCP الحُبّي متعدد المؤسسات، وكتابات متغير البيئة وقت التشغيل). موثَّقة مع مقايضاتها الأمنية في [الأمان](/docs/security). لا تضبطها إلا إذا كنت تريد تحديدًا المسار المُخفَّف.

## وراثة .env لمساحة العمل {#env-inheritance}

داخل مساحة عمل، يُحمَّل ملف `.env` الجذر تلقائيًا في كل تطبيق، لذا فإن المفاتيح المشتركة مثل `ANTHROPIC_API_KEY`، و`A2A_SECRET`، و`BETTER_AUTH_SECRET`، و`OAUTH_STATE_SECRET` تحتاج إلى الضبط مرة واحدة فقط. يفوز `apps/<name>/.env` الخاص بكل تطبيق عند التعارض.

## إنشاء أسرار قوية {#env-generate-secrets}

بالنسبة لأي سر معلَّم بـ "عشوائي لا يقل عن 32 حرفًا" (`BETTER_AUTH_SECRET`، و`OAUTH_STATE_SECRET`، و`A2A_SECRET`، و`WORKSPACE_SECRETS_ENCRYPTION_KEY`، و`SECRETS_ENCRYPTION_KEY`، و`AGENT_NATIVE_BUILDER_RELAY_SECRET`)، أنشئ قيمًا جديدة باستخدام:

```bash
openssl rand -hex 32
```

دوِّر مفاتيح التوقيع/الجلسة عن طريق استبدال متغير البيئة في كل مثيل وإعادة النشر. تصبح الجلسات وأظرف حالة OAuth الموقَّعة بموجب المفتاح القديم غير صالحة، لذا قد يحتاج المستخدمون إلى تسجيل الدخول مرة أخرى. دوِّر `WORKSPACE_SECRETS_ENCRYPTION_KEY` باستخدام نافذة `..._PREVIOUS` الموصوفة أعلاه حتى تظل صفوف الخزنة المشفَّرة قابلة للقراءة أثناء ترحيلها.

## ما هي الخطوة التالية

- [**النشر**](/docs/deployment) — اختر قاعدة بيانات دائمة وإعدادًا مسبقًا قبل أول عملية نشر إنتاجي
- [**متغيرات البيئة**](/docs/environment-variables) — المرجع الشامل للمستودع بأكمله، بما في ذلك متغيرات القالب والمزود والمحلي والتكامل المستمر
- [**الأمان**](/docs/security) — قائمة التحقق الخاصة بالإنتاج والأعلام الاختيارية المشار إليها في هذه الصفحة
- [**المصادقة**](/docs/authentication) — بيانات اعتماد OAuth ومتغيرات البيئة لوضع المصادقة الذي تختاره
