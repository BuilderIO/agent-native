# دليل المطور

هذه الصفحة لأي شخص يخصص قالب المقاطع أو يوسعه: البدء السريع، وكل إجراء، ونموذج
البيانات، وسطح المسارات، وكيفية الإضافة إليه. راجع [المقاطع](/docs/template-clips)
لمعرفة ما يفعله التطبيق.

## البدء السريع

<Steps>

### إنشاء التطبيق

```bash
npx @agent-native/core@latest create my-clips --standalone --template clips
cd my-clips
pnpm install
```

يتطلب هذا تثبيت [Node.js](https://nodejs.org) بإصدار 22.22 أو أحدث
و[pnpm](https://pnpm.io) أولاً. راجع [بدء الاستخدام](/docs/getting-started)
إذا لم تكن قد ثبّت أيًا منهما بعد، أو لم يكن لديك اتصال بنموذج لغوي
(Builder.io، أو مفتاح Anthropic/OpenAI، أو Ollama محلي) مُهيّأ.

### تشغيل خادم التطوير

```bash
pnpm dev
```

يفتح التطبيق تلقائيًا في متصفحك. يعمل التسجيل دون أي إعداد إضافي، لأن
المتصفح أو تطبيق سطح المكتب يلتقط محليًا. لن تواجه خطأ إلا في إجراء يحتاج
إلى تخزين ملفات أو رصيد ذكاء اصطناعي قبل إعداد أي منهما.

</Steps>

<Callout tone="info">

يحتاج التسجيل والنسخ والعناوين/الملخصات بالذكاء الاصطناعي إلى تخزين ملفات
ورصيد ذكاء اصطناعي مُهيّأين قبل أن يعملا من طرف إلى طرف. اربط Builder.io من
**الإعدادات** لكليهما معًا (تشمل فئته المجانية رصيد ذكاء اصطناعي مُدار)، أو
اربط تخزينًا متوافقًا مع S3 بشكل منفصل وأتِ بمفتاح Groq خاص بك للنسخ. راجع
[النسخ والبيانات الوصفية للذكاء الاصطناعي](/docs/template-clips-features#transcription-and-ai-metadata).

</Callout>

## قائمة الإجراءات

كل عملية هي ملف TypeScript في `templates/clips/actions/`، مثبَّت تلقائيًا
عند `POST /_agent-native/actions/:name`.

### المكتبة والتسجيلات

| الإجراء                                                                                   | ما يفعله                                                        |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `list-recordings`, `search-recordings`                                                    | سرد المكتبة، ومشترك معي، والمهملات، والقوائم المحددة بمساحة     |
| `create-recording`, `finalize-recording`                                                  | إنشاء الصف؛ وإنهاء الرفع                                        |
| `import-loom-recording`                                                                   | استيراد فيديو Loom أو رابط MP4/WebM مباشر                       |
| `update-recording`                                                                        | العنوان، والوصف، وكلمة المرور، وانتهاء الصلاحية، والرؤية        |
| `move-recording`                                                                          | نقل تسجيل واحد أو عدة تسجيلات إلى مجلد أو الجذر                 |
| `archive-recording`, `trash-recording`, `restore-recording`, `delete-recording-permanent` | دورة الحياة: الإخفاء، والحذف المؤقت، والتراجع، أو الحذف نهائيًا |
| `reprocess-recording`                                                                     | إصلاح وسائط غير قابلة للتقديم أو متجمدة                         |
| `generate-filmstrip`                                                                      | شريط إطارات الخط الزمني في المحرر                               |
| `tag-recording`, `set-thumbnail`                                                          | الوسم واختيار إطار صورة مصغرة يدويًا                            |

### المجلدات والمساحات

| الإجراء                                           | ما يفعله                                             |
| ------------------------------------------------- | ---------------------------------------------------- |
| `create-folder`, `rename-folder`, `delete-folder` | مجلدات متداخلة؛ حذف أحدها ينقل محتوياته للأعلى       |
| `create-space`, `rename-space`, `delete-space`    | حاويات تسجيل محددة بموضوع وضمن نطاق المؤسسة          |
| `add-recording-to-space`                          | إضافة أو إزالة تسجيل من مساحة (علاقة متعددة لمتعددة) |
| `add-space-member`, `remove-space-member`         | أدوار المشاهد والمساهم والمشرف على مستوى المساحة     |

### التحرير

| الإجراء                                  | ما يفعله                                                    |
| ---------------------------------------- | ----------------------------------------------------------- |
| `trim-recording`, `split-recording`      | إضافة طبقة تعليمات قطع؛ لا تلمس الوسائط المصدر أبدًا        |
| `remove-silences`, `remove-filler-words` | يُنفَّذ من قبل الوكيل: يقرأ النص، ويطبّق الاقتطاعات من أجلك |
| `stitch-recordings`                      | دمج عدة تسجيلات في واحد، بالترتيب                           |
| `undo-edit`, `clear-edits`               | إزالة التعديل الأخير، أو إعادة الضبط إلى الأصل              |

## نموذج البيانات

معرَّف في `templates/clips/server/db/schema.ts`.

<Callout tone="warning">

تعيش صفوف الفريق والعضو والدعوة في جداول إطار العمل الخاصة `organizations`
و`org_members` و`org_invitations`، لا في جدول خاص بـ المقاطع.
`organization_settings` هو الملحق الخاص بـ المقاطع: لون العلامة التجارية،
والشعار، والرؤية الافتراضية، صف واحد لكل مؤسسة. لا يزال زوج
`workspaces`/`workspace_members` الأقدم موجودًا فقط حتى تتمكن ترحيلة بدء
تشغيل تُجرى مرة واحدة من تعبئة جداول إطار العمل بأثر رجعي على نشر قائم. لا
تبنِ ميزات جديدة عليها.

</Callout>

## شرح إجراء بالتفصيل

يُظهر `create-recording-agent-link` أنماطًا تستحق إعادة استخدامها في أي
إجراء يسكّ بيانات اعتماد محددة النطاق: التحقق من الحالة الحقيقية للمورد قبل
تسليم أي شيء، وتفويض سكّ الرمز الفعلي إلى مساعد مشترك في إطار العمل بدلاً من
ابتكار طريقة خاصة، واستخلاص كل عنوان URL يحتاجه المستدعي من ذلك المنح الواحد.

## تخصيصه

كل جزء من التطبيق مصدر قابل للتحرير. ابدأ من هنا:

- `templates/clips/actions/` — أضف ملفًا جديدًا باستخدام `defineAction`
  لكشف قدرة جديدة لكل من الوكيل والواجهة الأمامية.
- `templates/clips/app/routes/` — واجهة المستخدم، المذكورة أعلاه.
- `templates/clips/server/db/schema.ts` — أضف أعمدة أو جداول باستخدام
  Drizzle. حافظ على توافق المخطط مع PostgreSQL حتى يعمل القالب مع PGlite
  المحلي وPostgres المستضاف.
- `templates/clips/server/lib/` — تكاملات المزوّدين: `google-calendar-client.ts`،
  و`s3-upload-provider.ts`، و`slack-oauth.ts`، و`video-remux.ts`،
  و`video-filmstrip-sprite.ts`.
- `templates/clips/AGENTS.md` — تعليمات الوكيل. حدّث هذا عندما تُعلّم الوكيل
  قدرات أو اتفاقيات جديدة.
- `templates/clips/.agents/skills/` — أنماط مفصّلة يتبعها الوكيل. المهارات
  ذات الصلة: `recording`، و`ai-video-tools`، و`video-editing`،
  و`video-sharing`، و`screen-memory`.
- `templates/clips/shared/api.ts` — أنواع TypeScript المشتركة التي يستخدمها
  الخادم والعميل كلاهما.
- `templates/clips/desktop/` و`templates/clips/chrome-extension/` — حزم
  منفصلة لأسطح الالتقاط الأصلية، كل منها بملف `package.json` وبناء خاص بها.

إذا أضفت ميزة، تذكّر تحديث المجالات الأربعة كلها: واجهة المستخدم، والإجراء،
والمهارة أو إدخال AGENTS.md، وأي حالة تطبيق يحتاج الوكيل إلى رؤيتها. هذا ما
يحافظ على تكافؤ الوكيل وواجهة المستخدم.
