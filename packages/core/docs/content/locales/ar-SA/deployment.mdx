## قبل النشر: اختر قاعدة بيانات دائمة {#persistent-database}

كل تطبيق منشور يحتاج إلى قاعدة بيانات PostgreSQL دائمة. يمكن استخدام قاعدة بيانات PGlite المحلية للتطوير، لكن يجب ضبط `DATABASE_URL` قبل أول نشر إنتاجي. تشمل خيارات PostgreSQL المستضافة [Neon](/docs/neon) و[Supabase](/docs/supabase) وRailway وRender و[Amazon RDS for PostgreSQL](/docs/aws-rds) و[Cloud SQL for PostgreSQL](/docs/cloud-sql) و[Azure Database for PostgreSQL](/docs/azure-postgresql). راجع دليل [Plain Postgres](/docs/postgres) للخدمات المُدارة الأخرى وخوادم PostgreSQL ذاتية الاستضافة.

تحتاج التطبيقات المستقلة إلى `BETTER_AUTH_SECRET` ثابت. تحتاج مساحات العمل التي تستخدم الطلبات الموقعة بين التطبيقات إلى `A2A_SECRET`.

اضبط هذه القيم في إعدادات بيئة موفر الاستضافة، لا في ملف `.env` المحلي فقط. أنشئ سر المصادقة باستخدام `openssl rand -hex 32`. لا يتضمن Agent-Native حسابًا لإرسال البريد؛ يجب ربط Resend أو SendGrid بشكل منفصل.

## تسليم البريد الإلكتروني اختياري، لكنه موصى به {#email-provider}

موفر البريد الإلكتروني ليس مطلوبًا لمصادقة البريد الإلكتروني وكلمة المرور. بدونه، تستخدم التطبيقات المنشورة التسجيل وتسجيل الدخول بالبريد الإلكتروني وكلمة المرور، وتتخطى التحقق من البريد عند التسجيل، ولا تعرض مصادقة الروابط السحرية.

اربط Resend أو SendGrid قبل النشر إذا أردت الروابط السحرية أو التحقق من البريد أو إعادة تعيين كلمات المرور أو الدعوات أو إشعارات المشاركة. اضبط `RESEND_API_KEY` أو `SENDGRID_API_KEY` في بيئة النشر؛ ويحتاج SendGrid أيضًا إلى `EMAIL_FROM`. راجع [المصادقة](/docs/authentication) لأنماط المصادقة المتاحة.

### تخصيص رسائل البريد في الإطار {#email-templates}

لكل رسالة بريد يرسلها الإطار قالب افتراضي. لاستخدام تصميمك الخاص، سجّل override من إضافة خادم. يظل الإطار هو من يحدد المستلم والمرسل ويسلّم الرسالة؛ أما الـ override فيحدد محتوى الرسالة وشكلها.

```ts
// server/plugins/email-templates.ts
import {
  escapeEmailHtml,
  overrideTransactionalEmail,
} from "@agent-native/core/server";

export default function registerEmailTemplates(): void {
  overrideTransactionalEmail("core.resource-shared", (props) => ({
    subject: `${props.sender.name} shared "${props.resource.title}"`,
    html: `<p>${escapeEmailHtml(props.sender.name)} invited you to
      <a href="${escapeEmailHtml(props.resource.url)}">${escapeEmailHtml(props.resource.title)}</a>
      in ${escapeEmailHtml(props.app.name)}.</p>`,
  }));
}
```

| معرّف البريد                     | Props                                                                              |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| `core.verify-signup`             | `email`, `verifyUrl`                                                               |
| `core.reset-password`            | `email`, `resetUrl`                                                                |
| `core.magic-link`                | `email`, `magicLinkUrl`                                                            |
| `core.change-email-confirmation` | `email`, `newEmail`, `confirmationUrl`                                             |
| `core.change-email-verification` | `email`, `verifyUrl`                                                               |
| `core.organization-invite`       | `invitee`, `orgName`, `inviter`, `acceptUrl`                                       |
| `core.builder-credit-limit`      | `subject`, `heading`, `body`, `upgradeLabel`, `upgradeUrl`                         |
| `core.resource-shared`           | `recipientEmail`, `sender`, `resource` (`type`, `title`, `url`), `role`, `message` |

يتلقى كل override أيضًا `app` (`name`، `logoUrl`). يحمل الوسيط الثاني العرض الافتراضي، لتتمكن من إعادة استخدام العنوان أو النص.

- قيم الـ props خام. اهرب منها باستخدام `escapeEmailHtml` قبل وضعها في سلسلة HTML.
- أعد `react` مع عنصر React بدلًا من `html` لعرض مكوّن. يتولى React الهروب من الـ props.
- احذف `subject` للإبقاء على العنوان الافتراضي. احذف `text` لاشتقاق النص العادي من HTML الخاص بك.
- إذا رمى الـ override خطأ، يفشل الإرسال. لا يعود الإطار إلى التصميم الافتراضي. تعرض معاينة رسائل البريد المعاملاتية الـ override الخاص بك، فتحقق منه هناك.
