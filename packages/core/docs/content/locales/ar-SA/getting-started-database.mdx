# حفظ البيانات في SQL

هذا هو الجزء الاختياري الرابع من سلسلة الخطوات الأولى. في [إضافة صفحة](/docs/getting-started-pages)
استخدمت `analyze-text` مباشرة من مسار. ستضيف هنا بيانات SQL خاصة بالتطبيق عندما
تحتاج النتائج إلى الاستمرار بين المحادثات.

## إضافة جدول {#persist-data}

يتضمن قالب Chat بالفعل بيئة SQL وجداول النظام وملف SQLite محلياً بشكل افتراضي.
لا تحتاج إلى تثبيت قاعدة بيانات أو ضبط `DATABASE_URL` أو إضافة ترحيل لجداول Chat
المضمّنة. لإضافة جدول جديد خاص بالتطبيق، أضف ملفات الخادم الثلاثة التالية:

1. ينشئ `server/plugins/db.ts` الجدول من خلال ترحيل إضافي.
2. يصف `server/db/schema.ts` الجدول للاستعلامات محددة الأنواع.
3. ينشئ `server/db/index.ts` عميل قاعدة البيانات محدد الأنواع للتطبيق.

أنشئ `server/plugins/db.ts`:

```ts filename="server/plugins/db.ts"
import { runMigrations } from "@agent-native/core/db";

export default runMigrations(
  [
    {
      version: 1,
      name: "create-text-analyses",
      sql: `CREATE TABLE IF NOT EXISTS text_analyses (
        id TEXT PRIMARY KEY,
        input TEXT NOT NULL,
        char_count INTEGER NOT NULL,
        word_count INTEGER NOT NULL,
        sentence_count INTEGER NOT NULL,
        paragraph_count INTEGER NOT NULL,
        owner_email TEXT NOT NULL,
        created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
      )`,
    },
  ],
  { table: "text_analyses_migrations" },
);
```

أنشئ `server/db/schema.ts`:

```ts filename="server/db/schema.ts"
import { integer, now, table, text } from "@agent-native/core/db/schema";

export const textAnalyses = table("text_analyses", {
  id: text("id").primaryKey(),
  input: text("input").notNull(),
  charCount: integer("char_count").notNull(),
  wordCount: integer("word_count").notNull(),
  sentenceCount: integer("sentence_count").notNull(),
  paragraphCount: integer("paragraph_count").notNull(),
  ownerEmail: text("owner_email").notNull(),
  createdAt: text("created_at").notNull().default(now()),
});
```

أنشئ `server/db/index.ts`:

```ts filename="server/db/index.ts"
import { createGetDb } from "@agent-native/core/db";
import * as schema from "./schema.js";

export const getDb = createGetDb(schema);
export { schema };
```

أعد تشغيل `pnpm dev` مرة واحدة حتى يعمل الترحيل. اجعل الترحيلات المستقبلية
إضافية، وامنح كل ترحيل `version` و`name` جديدين.

## إضافة إجراءات الحفظ والقائمة

أبقِ `analyze-text` للقراءة فقط واجعل الحفظ إجراءً منفصلاً وصريحاً. أنشئ
`actions/save-text-analysis.ts`:

```ts filename="actions/save-text-analysis.ts"
import { defineAction } from "@agent-native/core/action";
import { z } from "zod";

import { getDb, schema } from "../server/db/index.js";

export default defineAction({
  description: "Save a text analysis result to the database.",
  schema: z.object({
    input: z.string().min(1),
    charCount: z.number(),
    wordCount: z.number(),
    sentenceCount: z.number(),
    paragraphCount: z.number(),
  }),
  run: async (
    { input, charCount, wordCount, sentenceCount, paragraphCount },
    ctx,
  ) => {
    const ownerEmail = ctx?.userEmail;
    if (!ownerEmail) throw new Error("Sign in before saving analyses.");

    const id = crypto.randomUUID();
    await getDb().insert(schema.textAnalyses).values({
      id,
      input,
      charCount,
      wordCount,
      sentenceCount,
      paragraphCount,
      ownerEmail,
    });

    return { id };
  },
});
```

أنشئ `actions/list-text-analyses.ts`:

```ts filename="actions/list-text-analyses.ts"
import { defineAction } from "@agent-native/core/action";
import { desc, eq } from "drizzle-orm";
import { z } from "zod";

import { getDb, schema } from "../server/db/index.js";

export default defineAction({
  description: "List the signed-in user's saved text analyses, newest first.",
  schema: z.object({}),
  http: { method: "GET" },
  readOnly: true,
  run: async (_, ctx) => {
    const ownerEmail = ctx?.userEmail;
    if (!ownerEmail) throw new Error("Sign in before listing analyses.");

    return getDb()
      .select({
        id: schema.textAnalyses.id,
        input: schema.textAnalyses.input,
        charCount: schema.textAnalyses.charCount,
        wordCount: schema.textAnalyses.wordCount,
        sentenceCount: schema.textAnalyses.sentenceCount,
        paragraphCount: schema.textAnalyses.paragraphCount,
        createdAt: schema.textAnalyses.createdAt,
      })
      .from(schema.textAnalyses)
      .where(eq(schema.textAnalyses.ownerEmail, ownerEmail))
      .orderBy(desc(schema.textAnalyses.createdAt));
  },
});
```

تستخدم الإجراءات عميل Drizzle محدد الأنواع لقراءة التطبيق والكتابة فيه. لا تحتاج
إلى SQL خام هنا إلا للترحيل الإضافي. تخطَّ هذه الصفحة حتى يحتاج إجراءك إلى
بيانات مجال دائمة.

## جرّبه

في المحادثة، اطلب من الوكيل تنفيذ التدفق كاملاً:

> Run analyze-text on "Hello world", save the result with save-text-analysis, then list my saved text analyses.

أصبح الصف المحفوظ متاحاً الآن للوكيل ولأي صفحة تقرأ من `list-text-analyses`.
