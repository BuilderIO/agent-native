# Portal

يوفر Portal إقران الكمبيوتر وتنفيذ العمل عبر الأجهزة. استخدم **الإعدادات → مساحة العمل → إقران أو إصلاح**، واحفظ رمز الجهاز في ملف `~/.agent-native/remote-device.json` الخاص بالكمبيوتر.

أوضاع التنفيذ هي **Local** و**Computer** و**Cloud**. وضع Cloud في قائمة انتظار، ولا يبدأ تشغيلًا قبل تفعيل الوصول.
