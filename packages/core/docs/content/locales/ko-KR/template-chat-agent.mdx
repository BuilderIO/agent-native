# Agent와 대화

채팅에서는 대화가 앱을 사용하는 주된 방법입니다. 에이전트는 앱의 액션을 실행하고,
정보를 찾아보고, 사용자가 알려준 것을 기억하고, 다른 페이지로 안내할 수 있습니다. 이
페이지는 에이전트가 화면에 대해 무엇을 알고 있는지, 작업별로 유용한 프롬프트가
무엇인지, 그리고 기본 제공 액션을 넘어서는 부분을 다룹니다. 전체 개요는
[채팅](/docs/template-chat) 문서를 참고하세요.

## 에이전트가 화면을 보는 방식

에이전트는 현재 어느 페이지에 있는지, 어떤 대화가 열려 있는지를 항상 알고 있습니다.
그래서 "홈으로 돌아가줘"나 "지금 무슨 페이지야?"라고만 말해도 별도의 설명 없이
동작합니다. 앱이 페이지가 바뀔 때마다 에이전트에게 알려주므로, 에이전트가 추측할
필요가 없습니다.

채팅에는 선택된 이벤트나 열려 있는 문서처럼 가리킬 만한 비즈니스 데이터가 없습니다.
에이전트가 아는 나머지는 모두 대화에서 사용자가 하는 말에서 나옵니다.

## 작업별 유용한 프롬프트

아래 프롬프트는 모두 실제 앱을 대상으로 실행됩니다. 동작하는 예시 하나를 살펴보겠습니다.

<Comparison>

### :blue: 여러분이 묻습니다

"Alex에게 인사하는 hello 액션을 호출해줘."

### :green: 일어나는 일

에이전트가 이름 Alex로 예제 **hello** 액션을 실행합니다. 액션이 "Hello, Alex!"를
반환하고 에이전트가 이를 채팅에 보여줍니다. 앱의 다른 부분은 아무것도 바뀌지
않습니다.

</Comparison>

<Cards columns={2}>

### 앱이 할 수 있는 일 알아보기

- **"이 앱으로 뭘 할 수 있어?"** 에이전트가 가지고 있는 액션과 각각이 하는 일을
  나열합니다.
- **"사용할 수 있는 액션을 보여줘."** 같은 취지로, 이름만 간단한 목록으로 보여줍니다.
- **"시작하는 걸 도와줘."** 에이전트가 처음 시도해 볼 만한 일을 제안합니다.

### 이동하기

- **"설정으로 이동해줘."** 앱이 해당 페이지를 열어줍니다.
- **"Database 페이지를 열어줘."** 에이전트가 사이드바에 연결되어 있지 않은
  `/database`를 엽니다.
- **"홈으로 돌아가줘."** 시작하기 페이지가 열립니다.

### 에이전트 가르치기

- **"나는 짧은 답변을 선호한다는 걸 기억해줘."** 에이전트가 이를 메모리에 저장하고
  이후 채팅에서도 사용합니다.
- **"앞으로는 답하기 전에 항상 추론 과정을 설명해줘."** 에이전트가 이를 상시 지침으로
  저장할 수 있습니다.
- **"나에 대해 뭘 기억하고 있어?"** 에이전트가 메모리를 읽어서 알려줍니다.

### 데이터 살펴보기

- **"이 앱의 데이터베이스에 어떤 테이블이 있어?"** 에이전트가 데이터베이스 구조를
  읽고 테이블을 나열합니다.
- **"내 채팅이 몇 개야?"** 에이전트가 데이터베이스에 읽기 전용 질의를 실행하고
  채팅에서 답합니다.

### 프레임워크 알아보기

- **"이 앱에 새 액션을 추가하려면 어떻게 해?"** 에이전트가 Agent-Native 문서를
  검색해 단계를 설명합니다.
- **"액션과 스킬의 차이가 뭐야?"** 마찬가지로 문서를 바탕으로 답합니다.

</Cards>

<Callout tone="info">

에이전트는 데이터베이스를 읽을 수는 있지만 직접 바꾸지는 않습니다. 새 정보를
저장할 때는 액션을 사용합니다. 그래야 모든 변경이 앱의 화면이 사용하는 것과 같은
경로를 거칩니다. 개발자는 앱 설정에서 이를 바꿀 수 있습니다.

</Callout>
