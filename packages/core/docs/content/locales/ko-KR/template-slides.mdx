# 슬라이드

슬라이드는 에이전트 기반 데크 편집기입니다. 에이전트에게 데크를 요청하면 프롬프트를 바탕으로 데크를 생성하며, 슬라이드를 만들어 가는 과정을 편집기에 실시간으로 스트리밍합니다. 이후 평범한 문장으로 말하거나 클릭 한 번으로 데크를 편집하고, 다시 스타일링하고, 내보낼 수 있습니다. 하나의 앱이 Google Slides, Pitch, PowerPoint를 대체하므로, 데크를 생성하고 편집하고 발표하고 내보내는 일을 서로 다른 도구로 오갈 필요가 없습니다.

## 대체하는 것

<Comparison>

### 이전에는

- 데크 자체를 만들기 위한 Google Slides, Pitch, 또는 PowerPoint
- 편집과 발표를 계속하기 위한 인당 구독료
- 새 데크마다 브랜드 색상, 폰트, 로고를 수동으로 복사해 붙여넣기
- 다른 도구를 쓰는 사람과 데크를 공유하기 위한 수동 파일 변환

### 이후에는

- 하나의 편집기: 프롬프트로 생성하고, 시각적으로 편집하고, 발표하는 과정이 모두 같은 데크 안에서 이루어짐
- 구독료 없이 전체 스택을 처음부터 끝까지 직접 소유
- 저장된 디자인 시스템이 새 데크마다 브랜드를 자동으로 적용
- PPTX, DOCX, PDF, Google Docs를 가져오고, 언제든 PPTX, Google Slides, HTML로 다시 내보내기

</Comparison>

## 다중 앱 작업 공간에서의 슬라이드

[Dispatch](/docs/template-dispatch) 아래에서 다른 앱들과 함께 슬라이드를 운영한다면, 데크는 더 이상 직접 열어보는 페이지에만 머무르지 않습니다. 에이전트는 다른 앱이 재사용할 수 있는 Library에 데크를 제출할 수 있고, 형제 앱이 보낸 평범한 문장의 요청에도 채팅에서 답하는 것과 같은 방식으로 답할 수 있습니다. 연결이 실제로 어떻게 동작하는지와 그 뒤에 있는 진짜 메커니즘은 [다중 앱 작업 공간 속 슬라이드](/docs/template-slides-integrations) 문서를 참고하세요.

## 슬라이드로 할 수 있는 일

- **프롬프트로 데크를 생성하세요.** "커피 구독 서비스를 위한 10장짜리 피치 데크를 생성해줘. 대상은 투자자야." [기능](/docs/template-slides-features) 문서를 참고하세요.
- **슬라이드를 시각적으로 편집하세요.** 텍스트를 두 번 클릭해 편집하고, 블록을 클릭해 풍선 메뉴를 열고, `/`로 슬래시 메뉴를 열어 블록을 삽입하세요. [기능](/docs/template-slides-features) 문서를 참고하세요.
- **전체 화면으로 발표**하고, 댓글을 남기고, 실시간으로 협업하고, 특정 팀원과 또는 공개적으로 데크를 공유하세요. [기능](/docs/template-slides-features) 문서를 참고하세요.
- **기존 콘텐츠를 가져오세요.** PPTX, DOCX, PDF, 또는 Google Doc을 시작점으로 가져옵니다. PPTX, Google Slides, 또는 독립 실행형 HTML 파일로 내보냅니다. [기능](/docs/template-slides-features) 문서를 참고하세요.
- **브랜드로 만든 디자인 시스템을 적용하세요.** 색상, 서체, 로고를 한 번만 저장하면 새 데크마다 재사용됩니다. Figma 파일, 연결된 코드베이스, 또는 웹사이트로부터 설정할 수 있습니다. [기능](/docs/template-slides-features) 문서를 참고하세요.
- **이전 버전을 복원하세요.** 모든 변경 사항이 스냅샷으로 기록됩니다. 이전 버전을 목록으로 확인하거나 복원하세요. [기능](/docs/template-slides-features) 문서를 참고하세요.

## 시작하기

앱을 열면:

1. **새 데크**를 클릭하세요.
2. 에이전트에게 요청하세요: "커피 구독 서비스를 위한 10장짜리 피치 데크를 생성해줘. 대상은 투자자야."
3. 슬라이드가 스트리밍되는 것을 지켜보세요. 슬라이드를 클릭해 편집하거나, 에이전트에게 계속 다듬어달라고 요청하세요. 텍스트를 선택하고 풍선 메뉴에서 **AI로 수정**을 클릭하면 선택한 부분만 정확히 에이전트에게 넘길 수 있습니다.

### 유용한 프롬프트

- "커피 구독 서비스를 위한 10장짜리 피치 데크를 생성해줘. 대상은 투자자야."
- "슬라이드 3 뒤에 가격 슬라이드를 추가해줘."
- "이 슬라이드의 제목을 더 크게 만들고 강조 색상을 초록색으로 바꿔줘."
- "이 PDF를 6장짜리 데크로 요약해줘." (PDF를 첨부하세요)

슬라이드를 직접 만들려면:

```bash
npx --yes @agent-native/core@latest create my-slides --standalone --template slides
```

나머지 설정(`cd`, `pnpm install`, `pnpm dev`)과 프레임워크 기본 원리는 [시작하기](/docs/getting-started) 문서를 참고하세요.
