# 캘린더

캘린더는 에이전트 기반 일정 관리 앱입니다. Google Calendar를 연결하면 에이전트가 일정을
읽고, 빈 시간을 찾고, 이벤트를 만들고, Calendly 스타일 예약 링크를 관리할 수 있습니다.
간단한 말로 요청하든 클릭 한 번으로 처리하든 방식은 자유입니다. Google Calendar와
Calendly의 조합을 하나의 앱으로 대체하므로, 실제 일정과 공개 예약 페이지를 수동으로
동기화해야 할 일이 없습니다.

## 대체하는 것

<Comparison>

### 이전에는

- 실제 일정 관리를 위한 Google Calendar
- 공개 예약 링크를 위한 Calendly(또는 유사 서비스), 수동으로 동기화
- 누군가의 이메일이 필요할 때 별도의 연락처 검색
- 모든 초대장에 Zoom 링크를 일일이 복사해 붙여넣기

### 이후에는

- 하나의 화면: 실제 일정과 예약 링크를 함께
- 예약 링크와 에이전트가 함께 참조하는 하나의 가용성 모델
- 일정 예약과 같은 대화 안에 내장된 사람 검색
- 누군가 예약하면 Zoom 또는 Google Meet가 자동으로 연결됨

</Comparison>

## 다중 앱 작업 공간에서의 캘린더

[Dispatch](/docs/template-dispatch) 아래에서 다른 앱들과 함께 캘린더를 운영한다면,
캘린더는 단순히 열어보는 페이지에서 벗어납니다. 새로운 예약을 처리하는 자동화부터, 다른
앱이 일정 예약 요청을 캘린더에 직접 넘기는 것까지, 다른 채널과 앱이 실제로 동작을 걸 수
있는 대상이 됩니다. 실제로 연결이 어떻게 동작하는지와 그 뒤에 있는 진짜 메커니즘은
[다중 앱 작업 공간 속 캘린더](/docs/template-calendar-integrations) 문서를 참고하세요.
