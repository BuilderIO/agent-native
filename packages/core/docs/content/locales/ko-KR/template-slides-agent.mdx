# Agent와 대화

슬라이드의 에이전트는 UI가 사용하는 것과 같은 액션을 통해 데크를 생성, 편집, 가져오기, 내보내기, 스타일링합니다. 그래서 클릭으로 할 수 있는 일은 말로도 요청할 수 있습니다. 이 페이지는 에이전트가 자동으로 보는 것과 작업별로 정리한 프롬프트를 다룹니다. 일상적으로 슬라이드를 사용하든 그 위에 무언가를 만들든 유용합니다.

## 에이전트가 화면을 보는 방식

에이전트는 어떤 데크가 열려 있는지, 지금 어느 슬라이드에 있는지, 그리고 그 데크의 전체 슬라이드 목록을 항상 알고 있습니다. "슬라이드 4"라고 굳이 말할 필요가 없습니다. 이미 무엇이 거기 있는지 알고 있기 때문입니다. 시각적 편집기에서 편집 중일 때는 현재 선택 상태, 즉 클릭한 특정 요소, 사용 중인 도구, 계산된 스타일 정보까지 파악하므로, "이거 더 크게 만들어줘"라고 하면 추측 없이 실제로 선택한 대상에 정확히 적용됩니다.

채팅은 간단히 주고받는 대화를 위해 사이드바에 있습니다. 더 긴 작업이 필요할 때는 여유 있게 작업할 수 있는 전체 화면 Agent 화면도 제공됩니다.

### 선택 인식 편집

슬라이드에서 텍스트를 선택하고 풍선 메뉴의 **AI로 수정** 버튼을 클릭하거나, 드래그로 하나 이상의 요소를 선택하고 떠 있는 칩의 **에이전트에게 보내기**를 클릭하면 강조한 부분을 정확히 에이전트에게 넘길 수 있습니다. 그러면 "이거 더 강렬하게 만들어줘"나 "이 부분만 번역해줘" 같은 요청이 슬라이드 전체가 아니라 선택한 부분에만 적용됩니다.

## 작업별 유용한 프롬프트

아래 프롬프트는 모두 실제 데크에 대한 실제 액션이 되며, UI가 읽고 쓰는 것과 동일한 데크를 대상으로 합니다. 실제로 동작하는 예시 하나를 살펴보겠습니다.

<Comparison>

### :blue: 여러분이 묻습니다

"커피 구독 서비스를 위한 10장짜리 피치 데크를 생성해줘. 대상은 투자자야."

### :green: 일어나는 일

에이전트가 먼저 개요를 계획한 다음, 슬라이드를 만들 때마다 편집기로 실시간 스트리밍합니다. 그래서 전체가 한꺼번에 완성되기를 기다리는 대신 데크가 만들어지는 과정을 지켜볼 수 있습니다.

</Comparison>

### 생성

- **"이 PDF를 6장짜리 데크로 요약해줘."** PDF를 첨부하면 에이전트가 편집 가능한 데크로 만들어줍니다.
- **"이 Google Doc을 데크로 만들어줘."** 같은 방식이지만 Google Doc에서 시작합니다.

### 편집과 재스타일링

_슬라이드가 열려 있으면 "이 슬라이드"는 자동으로 해석됩니다._

- **"슬라이드 3 뒤에 가격 슬라이드를 추가해줘."** 새 슬라이드가 곧바로 필름스트립에 나타납니다.
- **"이 슬라이드의 제목을 더 크게 만들고 강조 색상을 초록색으로 바꿔줘."** 열려 있는 슬라이드에 변경 사항이 실시간으로 적용됩니다.
- **"이 데크의 모든 곳에서 '고객'이라는 단어를 '회원'으로 바꿔줘."** 모든 슬라이드가 한꺼번에 업데이트됩니다.

### 가져오기와 내보내기

- "이 PPTX를 가져와서 각 슬라이드를 여기서 편집 가능한 슬라이드로 만들어줘."
- "이 데크를 PowerPoint로 내보내줘."
- "이걸 Google Slides에서 열 수 있게 준비해줘."
