# Design

Design은 에이전트 기반 프로토타이핑 스튜디오입니다. 계층으로 이루어진 그리기
캔버스 대신, 에이전트가 완전하고 독립적인 Alpine과 Tailwind HTML 프로토타입을
생성해 실시간 미리보기로 보여주고, 프롬프트와 조정 컨트롤을 통해 결과를
다듬습니다. 정적 목업 도구와 그 뒤에 따라오는 핸드오프 과정을 대체합니다.
미리보기에서 보이는 것이 이미 실제로 동작하는 코드이기 때문입니다.

모든 생성, 조정, 내보내기는 같은 HTML 파일을 읽고 씁니다. 그래서 미리보기와
다운로드한 결과물 사이에서 아무것도 사라지지 않습니다.

## 대체하는 것

<Comparison>

### 이전에는

- 정적 목업을 위한 Figma 같은 도구, 그리고 이를 실제 마크업으로 바꿔줄 별도의 개발자
- 실시간 브라우저 렌더링이 아니라 아트보드 크기를 조절해 가며 디자인이 어떻게 반응할지 추측하기
- 내보낸 스펙과 그것을 손으로 일일이 맞추는 사람 사이의 느린 핸드오프
- 시간이 지나면서 디자인 파일과 실제로 배포된 코드가 서로 어긋나는 문제

### 이후에는

- 에이전트가 생성하고 미리보고 다듬는 하나의 HTML 프로토타입, 별도의 빌드 단계 없이
- 어떤 브레이크포인트에서도 실시간으로 미리볼 수 있는 실제 Alpine과 Tailwind 마크업
- 에이전트에게 레이아웃, 카피, 또는 인터랙션 변경을 요청하면 같은 파일이 그대로 업데이트됨
- HTML, ZIP, PDF, 또는 코딩 핸드오프 번들로 바로 내보내, 디자인과 코드가 하나의 아티팩트로 유지됨

</Comparison>

## 다중 앱 작업 공간 속 Design

다른 앱과 함께 [Dispatch](/docs/template-dispatch)에서 Design을 운영한다면,
Design에 접근하는 방법은 그것 하나만이 아닙니다. Design은 Claude Code와 Claude
Desktop을 포함해 다른 에이전트가 직접 호출할 수 있는 호스팅된 도구로도
동작하며, 작업 공간 앱이 이미 노출하는 것과 같은 종류의 연결점을 통해
이루어집니다. 실제로 연결이 어떻게 동작하는지와 그 뒤에 있는 진짜 메커니즘은
[다중 앱 작업 공간 속 Design](/docs/template-design-integrations) 문서를
참고하세요.

## Design으로 할 수 있는 일

- **완전한 프로토타입을 생성하세요.** 필요한 화면이나 페이지를 설명하면 에이전트가 Tailwind 스타일과 Alpine 인터랙션을 갖춘 실제 동작하는 HTML 문서를 작성합니다.
- **변형을 비교하세요.** 몇 가지 다른 방향을 생성하고, 가장 강력한 것을 골라 처음부터 다시 시작하는 대신 계속 다듬으세요.
- **브랜드를 적용하세요.** 디자인 시스템을 연결하거나, 사이트나 코드베이스에서 브랜드를 가져오거나, Figma 프레임을 가져와 픽셀 단위로 정확한 출발점을 만드세요. [기능](/docs/template-design-features) 문서를 참고하세요.
- **품질을 일관되게 유지하세요.** 에이전트는 프로토타입을 준비 완료로 표시하기 전에 접근성과 시각적 검사를 실행하며, 반복되는 패턴은 재사용 가능한 컴포넌트가 될 수 있습니다. [기능](/docs/template-design-features) 문서를 참고하세요.
- **실제 파일을 내보내세요.** HTML, ZIP, PDF, 또는 진짜 벡터 Figma SVG를 내보내거나, 준비된 핸드오프 번들과 함께 프로토타입을 코딩 에이전트에게 넘기세요. [기능](/docs/template-design-features) 문서를 참고하세요.
