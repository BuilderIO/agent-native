# 양식

양식은 코드를 작성하지 않고도 정보를 수집해야 하는 모든 사람을 위한 양식 작성 도구입니다. 가입, 피드백, 등록, 설문조사에 사용하세요. 원하는 양식을 에이전트에게 설명하고, 더 직접적으로 제어하고 싶을 때는 시각적으로 세부 조정한 다음, 누구나 작성할 수 있는 링크를 게시하세요.

## 대체하는 것

<Comparison>

### 이전에는

- 응답을 수집하기 위한 Typeform, Google Forms, 또는 직접 만든 양식
- 새 제출물을 손으로 Slack이나 스프레드시트에 옮겨 적기
- 돌아온 응답을 요약하기 위한 별도의 도구
- 응답을 Sheets나 웹훅으로 보내기 위한 Zapier 자동화 설정

### 이후에는

- 에이전트와 시각적 편집기가 함께 업데이트하는 하나의 양식
- 새 응답이 도착하는 즉시 Slack, Discord, Sheets, 또는 웹훅으로 전송됨
- 별도의 도구 없이 요약을 요청하면 차트나 표, 또는 둘 다를 받아볼 수 있음
- 조건부 필드, 스팸 방지, 익명 모드가 모두 같은 빌더에 내장되어 있음

</Comparison>

## 다중 앱 작업 공간에서의 양식

[Dispatch](/docs/template-dispatch) 안에서 다른 앱들과 함께 양식을 운영한다면, 양식은 더 이상 직접 열어보는 페이지에 그치지 않습니다. 양식의 에이전트는 다른 앱에 속한 질문을 그대로 전달할 수 있고, 다른 앱들은 프레임워크 자체의 피드백 버튼이 하는 것과 같은 방식으로 여러분의 양식에 직접 응답을 보낼 수 있습니다. 이 원리가 어떻게 동작하는지는 [다중 앱 작업 공간 속 양식](/docs/template-forms-integrations) 문서를 참고하세요.

## 그것으로 무엇을 할 수 있나요

- **대화로 양식을 만드세요.** "연락처 양식 만들어줘", "NPS 점수 질문 추가해줘", "이메일 필드를 필수로 설정해줘" 같은 프롬프트를 시도해 보세요. [사용 가능한 필드 유형](/docs/template-forms-features#field-types)을 참고하세요.
- **시각적으로 세부 조정하세요.** 더 직접적으로 제어하고 싶을 때는 양식 빌더에서 바로 레이블, 자리표시자, 필수 여부, 옵션, 필드 순서를 편집하세요.
- **공개 양식을 게시하고 보호하세요.** 공개 링크를 공유하고, 필요할 때 스팸 방지나 완전 익명 응답을 켜세요. [기능](/docs/template-forms-features) 문서를 참고하세요.
- **응답을 검토하고 인사이트를 요청하세요.** "이번 주 제출물을 요약해줘"나 "일별 제출 현황을 차트로 보여줘" 같은 프롬프트를 시도해 보세요. [기능](/docs/template-forms-features#response-insights) 문서를 참고하세요.
- **제출물을 자동으로 라우팅하세요.** Slack, Discord, Google Sheets, 또는 일반 웹훅 URL을 붙여넣으면 새 응답이 도착하는 즉시 그곳으로 전송됩니다.
