# 공무원 웹

공개 에이전트 웹을 사용하면 에이전트가 공개 Agent-Native 경로를 쉽게 크롤링하고, 읽고, 인용하고, 호출할 수 있습니다. 목표는 모든 앱 엔드포인트를 공개하는 것이 아닙니다. 목표는 이미 공개된 페이지에 대해 깨끗한 공개 표면을 게시하는 동시에 개인 데이터 및 도구 액세스를 명시적인 제어로 유지하는 것입니다.

문서 사이트는 참조 구현입니다. 오늘 배송됩니다:

- 검색을 허용하지만 기본적으로 학습을 허용하지 않는 크롤러 정책이 있는 `/robots.txt`.
- 로캘마다 하나의 `/sitemap-<locale>.xml`을 가리키는 사이트맵 인덱스인 `/sitemap.xml`. 소스 파일이 노출될 때 절대 표준 URL 및 `lastmod`가 포함됩니다.
- 상담원 친화적인 콘텐츠 검색을 위한 `/llms.txt` 및 `/llms-full.txt`.
- `/docs/getting-started.md`와 같은 Markdown 미러.
- 프로덕션 빌드 후 공개 문서 페이지에 대한 `Accept: text/markdown` 응답.
- 기본 조직, 웹사이트 및 페이지 메타데이터용 JSON-LD
- 위의 사항을 모두 확인하는 감사 CLI(`npx @agent-native/core@latest audit-agent-web`)

이 파일들을 게시해도 액션이 노출되지는 않습니다. 액션은 자체 `publicAgent` 옵트인을 통해서만 외부 에이전트에 도달합니다. [공개 에이전트에 노출하기](/docs/actions-access-control#public-agent)를 참고하세요.

## 구성 {#config}

`@agent-native/core/vite`의 `createAgentWebVitePlugin`은 프로덕션 빌드 중에 이 파일들을 씁니다. 에이전트가 읽어야 할 페이지와 함께 Vite 설정에 추가하세요.

```ts
// vite.config.ts
import { defineConfig } from "vite";
import { createAgentWebVitePlugin } from "@agent-native/core/vite";

export default defineConfig({
  plugins: [
    // ...your existing plugins
    createAgentWebVitePlugin({
      siteName: "My Agent-Native App",
      siteUrl: "https://example.com",
      pages: [
        {
          path: "/pricing",
          title: "Pricing",
          description: "Plans and limits.",
          markdown: "Plans and limits.\n",
        },
      ],
      agentWeb: { crawlerPolicy: "discoverable-no-training" },
    }),
  ],
});
```

플러그인은 나열한 페이지만 게시하고 그 외에는 아무것도 게시하지 않습니다. 라우트 접근 설정을 읽지 않으며, 직접 전달하지 않는 한 `package.json`의 `agentWeb`도 읽지 않습니다. 설정을 `package.json`의 `agent-native.workspaceApp.agentWeb`에 두려면 `@agent-native/core/agent-web`에서 가져온 `agentWebConfigFromPackageJson(pkg)`를 `agentWeb`으로 전달하세요.

| 옵션            | 기본값                          | 동작                                                                                                                                                                  |
| --------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `discoverable`  | `pages`가 비어 있지 않으면 켜짐 | `false`이면 파일을 쓰지 않습니다.                                                                                                                                     |
| `llmsTxt`       | `true`                          | `/llms.txt`와 `/llms-full.txt`를 씁니다.                                                                                                                              |
| `markdownTwins` | `true`                          | `markdown`이 있는 각 페이지의 `.md` 사본을 씁니다.                                                                                                                    |
| `crawlerPolicy` | `"discoverable-no-training"`    | `robots.txt` 규칙을 정합니다: `"discoverable-no-training"`, `"allow-all"`, `"disallow-all"` 중 하나입니다.                                                            |
| `crawlers`      | 없음                            | 크롤러 카테고리를 개별적으로 재정의합니다: `training`, `search`, `userTriggered`, `codingAgents`, `autonomousAgents` 각각에 `"allow"` 또는 `"disallow"`를 지정합니다. |

기본 크롤러 정책은 "검색 가능, 학습 불가"입니다. 검색, 사용자가 시작한 검색, 코딩 에이전트, 자율 브라우징 에이전트는 허용되고, 학습용 크롤러는 허용되지 않습니다.

`jsonLd`, `publicAgentCard`, `publicMcp`는 받아들여지지만 아직 아무것도 이 값을 읽지 않습니다. JSON-LD가 필요하면 `@agent-native/core/agent-web`의 `buildBaseJsonLd`와 `buildPageJsonLd`를 직접 페이지에 렌더링하세요.

## 정보 소스 경로 {#route-source}

페이지 목록이 기준입니다. 에이전트는 전달한 페이지만 받습니다. 이미 공개된 페이지로 목록을 만드세요.

- 공개 앱에서는 `protectedPaths`를 제외한 모든 라우트.
- 내부 앱에서는 `publicPaths`만.
- 에이전트가 읽을 수 있어야 하는 공개 공유 페이지와 양식 페이지.
- 제출된 비공개 데이터, 인증된 대시보드, 사용자 또는 조직 상태는 근처 페이지가 공개되어 있더라도 절대 포함하지 않습니다.

접근 설정에서 시작하려면 `@agent-native/core/agent-web`의 `deriveAgentWebPublicRoutes`에 앱의 `audience`, `publicPaths`, `protectedPaths`, `routes`를 전달하세요. 그 설정으로 공개되는 라우트를 반환합니다. 각 페이지에는 여전히 고유한 제목과 Markdown이 필요합니다.

이렇게 하면 혼합 앱이 자연스럽게 유지됩니다. 양식 앱은 공개 양식 페이지를 노출하고 제출 내용을 비공개로 유지할 수 있습니다. 콘텐츠 앱은 게시된 게시물을 노출하고 편집자를 비공개로 유지할 수 있습니다. 문서 사이트는 관리 도구를 제외한 모든 것을 노출할 수 있습니다.

## 공개 페이지는 공개 도구가 아닙니다 {#public-tools}

공개 페이지 액세스와 공개 도구 액세스는 별개입니다. 경로가 공개된다는 것은 에이전트가 해당 경로를 HTML, Markdown, 사이트맵 항목, llms 항목 및 구조화된 데이터로 읽을 수 있다는 의미입니다.

<Callout id="doc-block-s50w8y" tone="warning">

**공개 페이지는 공개 도구가 아닙니다.** 경로를 크롤링 가능하게 만들어도 액션이 노출되지는 않습니다. 도구 액세스에는 액션에 대한 명시적인 `publicAgent.expose` 옵트인이 필요합니다.

</Callout>

공개 에이전트 프로토콜을 통해 작업을 노출하려면 작업이 옵트인되어야 합니다.

## 빌드타임 파일 {#build-time}

`@agent-native/core/agent-web`의 프레임워크 유틸리티는 하나의 페이지 목록에서 공통 파일을 생성합니다.

```ts
import {
  buildAgentWebStaticFiles,
  normalizeAgentWebConfig,
} from "@agent-native/core/agent-web";

const config = normalizeAgentWebConfig(
  { crawlerPolicy: "discoverable-no-training" },
  { hasPublicRoutes: true },
);

const files = buildAgentWebStaticFiles({
  siteName: "My Agent-Native App",
  siteUrl: "https://example.com",
  description: "Public docs for my app.",
  config,
  pages: [
    {
      path: "/docs",
      title: "Docs",
      description: "Start here.",
      markdown: "# 문서\n\n여기서 시작하세요.\n",
      markdownPath: "/docs/getting-started.md",
      lastmod: new Date(),
    },
  ],
});
```

`createAgentWebVitePlugin`은 `buildAgentWebStaticFiles`를 대신 호출하고, `public`, `dist`, `dist/client`, `dist/server/public`, `build/client` 중 존재하는 폴더에 파일을 씁니다. 다른 빌드 도구를 쓴다면 유틸리티를 직접 호출하세요.

둘 다 페이지 자체 URL에서 `Accept: text/markdown`에 응답하지 않습니다. Markdown 사본은 `.md` URL에만 있습니다. 이 헤더에 응답하려면 문서 사이트처럼 `buildMarkdownResponseHeaders`의 헤더와 함께 페이지의 Markdown을 반환하는 서버 라우트를 추가하세요. 그 라우트가 없으면 아래 감사의 `Accept: text/markdown` 검사가 실패합니다.

큰 사이트맵을 나누려면 `buildAgentWebStaticFiles` 또는 `createAgentWebVitePlugin`에 `sitemapGroup`을 전달하세요. 각 페이지를 로캘 같은 그룹 키에 매핑하면 `sitemap.xml`은 그룹마다 하나의 `sitemap-<group>.xml`을 가리키는 사이트맵 인덱스가 됩니다.

## 사이트 감사 {#audit}

배포된 사이트 또는 로컬 프로덕션 서버에 대해 CLI 감사를 사용하십시오.

```bash
npx @agent-native/core@latest audit-agent-web --url https://www.agent-native.com
```

감사에서는 다음 사항을 확인합니다:

- SSR-보이는 HTML.
- 표준 URL.
- JSON-LD.
- `robots.txt` 정책 및 절대 사이트맵 URL.
- 절대 사이트맵 항목.
- `/llms.txt` 및 `/llms-full.txt`.
- Markdown 거울.
- `Accept: text/markdown`.
- 일반 에이전트 검색 사용자 에이전트에 대해 실수로 401/403 블록이 발생하지 않습니다.

필요한 공개 표면이 누락된 경우 감사는 0이 아닌 값으로 종료됩니다.
