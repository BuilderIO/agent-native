# Portal

Portal은 기기 간 실행을 위해 컴퓨터를 페어링합니다. **설정 → 워크스페이스 → 페어링 또는 복구**를 열고 장치 토큰을 컴퓨터의 비공개 파일 `~/.agent-native/remote-device.json`에 저장하세요.

실행 모드는 **Local**, **Computer**, **Cloud**입니다. **Cloud**는 대기 목록에 있으며 액세스가 활성화될 때까지 실행을 시작하지 않습니다.
