# WebMCP

WebMCP는 페이지가 도구를 등록하면 권한이 있는 에이전트가 이를 검색하고
실행할 수 있는 실험적 브라우저 API입니다. 등록, 사용, 브라우저 세션 및
보안 제한은 [영문 WebMCP 가이드](/docs/webmcp)를 참조하세요.
인증된 페이지는 기존 작업 레지스트리에서 적합한 백엔드 작업을 자동으로
등록합니다. 승인이 필요한 작업은 제외되며 실행 전에 현재 도구 목록을 다시
확인합니다.
MCP 임베드 경로와 같은 인증된 `sessionBypass` 표면에서도 백엔드 작업 도구가
등록됩니다. 공개 페이지와 로그아웃 상태의 페이지에는 등록되지 않습니다.

## HTTP 검색과 fetch 대체 경로

브라우저를 실행하지 않는 에이전트를 위해 Agent-Native는
`GET /.well-known/mcp.json`에서 가져올 수 있는 HTTP 호환 문서도 제공합니다.
이 문서에는 작업 엔드포인트, JSON 스키마, 읽기 전용 여부와 인증 필요 여부가
포함됩니다. 이는 Agent-Native 상호 운용 규약이며 WebMCP 사양의 일부나 MCP의
대체품이 아닙니다.

도구는 `fetch` 또는 `curl`로 `POST /mcp/tool/:name`에 호출할 수 있습니다.
인증, 권한 부여, 검증 및 테넌트 범위는 계속 서버에서 처리됩니다. 문서는
`/mcp`, 인증된 WebMCP 매니페스트와 A2A 에이전트 카드도 연결합니다.

페이지 로컬 도구에는 여전히 WebMCP를 지원하는 열린 브라우저가 필요합니다.
리소스 페이지는 자체 JSON 검색 링크를 게시할 수 있습니다. Clips는
`agentContextUrl`을 통해 전체 transcript와 JPEG 프레임 URL을 제공하므로
플레이어를 열지 않아도 HTTP 접근을 사용할 수 있습니다.
