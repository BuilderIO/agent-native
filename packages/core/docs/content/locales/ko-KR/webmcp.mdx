# WebMCP

WebMCP는 페이지가 도구를 등록하면 권한이 있는 에이전트가 이를 검색하고
실행할 수 있는 실험적 브라우저 API입니다. 등록, 사용, 브라우저 세션 및
보안 제한은 [영문 WebMCP 가이드](/docs/webmcp)를 참조하세요.
인증된 페이지는 기존 작업 레지스트리에서 적합한 백엔드 작업을 자동으로
등록합니다. 승인이 필요한 작업은 제외되며 실행 전에 현재 도구 목록을 다시
확인합니다.
