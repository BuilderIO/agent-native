# 채팅

채팅은 가장 평범한 에이전트 네이티브 시작점입니다. 중앙에 채팅이 있고 스레드 목록, 인증,
예제 액션 하나를 갖춘 ChatGPT 스타일 셸이며, 도메인에 특화된 요소는 전혀 없습니다.
특정 업무를 위한 완성된 제품이 아니라, 자신만의 에이전트와 화면을 그 위에 구축하고 싶은
개발자를 위한 실제로 배포 가능한 앱입니다.

완성된 도메인 제품 형태를 원한다면 [Calendar](/docs/template-calendar),
[Mail](/docs/template-mail), [Content](/docs/template-content),
[Forms](/docs/template-forms), [Analytics](/docs/template-analytics) 또는 다른
도메인 템플릿에서 시작하세요. 아직 브라우저 UI가 전혀 필요하지 않다면
[자동화 우선 앱](/docs/pure-agent-apps) 문서를 참고하세요.

## 무엇이 제공되는가 {#what-ships}

<Comparison>

### :green: 포함됨

- 프레임워크 채팅 화면과 내구성 있는 채팅 스레드를 사용하는 `/`의 전체 페이지 채팅
- 채팅을 생성, 다시 열기, 이름 변경, 고정, 보관할 수 있는 앱 사이드바의 스레드 목록
- 채팅 플러그인에 맞게 미리 구성된 내장 앱-에이전트 루프
- Better Auth를 통한 인증: 로그인, 가입, 세션, 조직
- 예제 하나(`actions/hello.ts`)와 표준 `view-screen`, `navigate` 액션을 포함한
  액션 디렉터리
- 채팅 스레드, 애플리케이션 상태, 설정, 세션, 리소스, 실행 기록을 위한 프레임워크의
  핵심 테이블, 그리고 열어보지 않아도 마운트되어 있는 Database 관리자 페이지와
  Observability 대시보드
- 에이전트가 SQL에 기록하면 UI가 새로 고쳐지도록 이미 연결된 실시간 동기화
  (`useDbSync`)
- 사용자가 나중에 채팅 안에서 직접 만드는 샌드박스 미니 앱을 위해 기본으로 마운트된
  Extensions 라우트
- 액션, 라우트, skills, 애플리케이션 상태를 추가하는 방법에 대한 채팅 우선 지침이
  담긴 AGENTS.md

### :red: 포함되지 않음

- 도메인 테이블이나 시드 데이터
- 대시보드, 목록, 차트, 폼, 프로바이더 통합
- 예제 스텁을 넘어서는 도메인별 액션

</Comparison>

그것이 핵심입니다. 채팅은 일반적인 척하는 도메인 제품이 아니라, 여러분 자신의
에이전트를 위한 얇고 유용한 기본 셸입니다.

## 선택 시기 {#when-to-pick}

- **사용자가 즉시 대화할 수 있는 기본 앱을 원하고**, 이후 액션과 UI로 확장하려는
  경우.
- **채팅을 먼저 만들고, 그다음 액션, 네이티브 결과, 앱 페이지로 이어지는 Agent-Native의
  기본 온램프를 원하는** 경우.
- **Agent-Native의 액션, 상태, 인증, 배포 형태를 유지하면서 자신만의 에이전트
  백엔드를 익숙한 채팅 UI에 연결하고 싶은** 경우.
- **도메인 템플릿과 맞지 않는 사용자 정의 내부 도구를 프로토타이핑하는** 경우.

## 시작하기 {#get-started}

```bash
npx @agent-native/core@latest create my-chat-app --standalone --template chat
```

설치, 첫 실행, LLM 연결에 대해서는
[채팅: 개발자 가이드](/docs/template-chat-developers#quick-start) 문서를
참고하세요. 브라우저 UI가 전혀 없는 자동화 우선 작업이라면 대신 `--headless`로
스캐폴딩하세요.

```bash
npx @agent-native/core@latest create my-agent --headless
```

예약된 작업, 큐, CLI 루프, 또는 채팅과 앱 페이지가 아직 유용하지 않은 외부 에이전트
워크플로에 사용하세요. 핵심 불변성은 동일하게 유지됩니다: 액션은 채팅, UI, HTTP,
MCP, A2A, CLI가 공유하는 표면입니다. 이 경로를 자세히 다루는
[자동화 우선 앱](/docs/pure-agent-apps) 문서를 참고하세요.
