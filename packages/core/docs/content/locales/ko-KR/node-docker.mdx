# Node.js & Docker

Node.js는 기본 Nitro 프리셋입니다. 이 페이지는 이를 직접 실행하는 방법과 Docker로 컨테이너화하는 방법을 다룹니다. 먼저 데이터베이스를 선택하려면 [Deployment](/docs/deployment)를, Docker Compose로 다중 앱 작업 공간을 자체 호스팅하려면 [Workspace Deployment](/docs/workspace-deployment#workspace-docker-compose)를 참조하세요.

## 빠른 시작: Chat 앱을 로컬에서 셀프 호스팅하기 {#self-host-quickstart}

시작하는 방법은 두 가지입니다.

- **앱을 만들고 있나요?** [Getting Started](/docs/getting-started)에서 시작하고 앱을 영구적인 곳에 배포할 때 여기로 돌아오세요.
- **앱을 운영하고 있나요?** 먼저 로컬 Docker 경로를 사용하세요. 작은 서버에서 사용할 Node.js, Postgres, 인증 및 환경 변수 구성을 같은 형태로 확인할 수 있습니다.

로컬 스택은 의도적으로 예시 인증 시크릿과 로컬 Postgres 볼륨을 사용합니다. `localhost`용이며 인터넷에 공개하기 위한 것이 아닙니다. 전체 Compose 파일과 복사 가능한 단계는 [전체 빠른 시작](/docs/node-docker#self-host-quickstart)을 참조하세요. 이 빠른 시작은 PostgreSQL 18의 볼륨 레이아웃을 사용합니다. PostgreSQL 17 이하에서 만든 볼륨을 재사용하지 마세요. 이미지 또는 마운트 경로를 변경하기 전에 기존 데이터를 백업하고 마이그레이션하세요.

### 1. 앱 만들기

```bash
npx @agent-native/core@latest create my-app --standalone --template chat
cd my-app
pnpm install
```

### 2. 로컬 스택 시작하기

```bash
docker compose up --build
```

[http://localhost:3000](http://localhost:3000)을 여세요. 포함된 에이전트를 사용하려면 로컬 `.env` 파일에 `ANTHROPIC_API_KEY`를 추가하세요.

## Node.js (기본값) {#nodejs}

기본 프리셋입니다. 빌드하고 실행하세요:

```bash
npx @agent-native/core@latest build
node .output/server/index.mjs
```

리스닝 포트를 설정하려면 `PORT`를 사용하세요(기본값: `3000`).

프로덕션 배포에는 현재의 Node.js LTS 라인을 사용하세요. 2026년 5월 기준으로는
Node.js 24입니다. Node.js 20은 2026년 4월 30일에 수명 종료(end-of-life)되어
더 이상 업스트림 보안 업데이트를 받지 않습니다.

## Docker {#docker}

This Dockerfile works for the standalone app created above. Run `pnpm install` before building so `pnpm-lock.yaml` exists in the build context. Keep the dependency manifest and lockfile in sync when you update the app.

```dockerfile filename="Dockerfile"
FROM node:24-slim AS build
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN corepack enable && pnpm install --frozen-lockfile
COPY . .
RUN pnpm build

FROM node:24-slim
WORKDIR /app
COPY --from=build /app/.output .output
# data/ is a runtime-created SQLite directory. Do not copy a dev DB into prod.
# For production, set DATABASE_URL to a hosted Postgres or Turso instance.
RUN mkdir -p /app/data
ENV NODE_ENV=production
ENV PORT=3000
EXPOSE 3000
CMD ["node", ".output/server/index.mjs"]
```

Create `.dockerignore` alongside the Dockerfile:

```text filename=".dockerignore"
node_modules
.output
data
.env
.env.*
!.env.example
.git
```

이 동일한 독립형 Dockerfile을 기반으로 Docker Compose를 사용해 다중 앱
작업 공간을 자체 호스팅하는 방법은
[Workspace Deployment](/docs/workspace-deployment#workspace-docker-compose)에서 다룹니다.
