# 콘텐츠

콘텐츠는 MDX용 오픈소스 Obsidian입니다. 로컬 파일과 잘 어울리는 문서
작업 공간으로, 에이전트가 여러분을 대신해 페이지를 읽고 쓰고 재구성하고
게시할 수 있습니다. 문서를 열고 "이 문단을 더 간결하게 다시 써줘"라고
요청하거나 "목표, 지표, 리스크에 대한 하위 페이지를 포함한 Q4 Planning이라는
페이지를 만들어줘"라고 요청해 보세요. 직접 하든 에이전트에게 부탁하든
결과는 같습니다.

## 이것으로 무엇을 할 수 있나요

- **문서를 작성하고 정리하세요.** 서식 있는 텍스트 편집, 무한히 중첩되는 페이지 트리, 즐겨찾기, 댓글, 버전 기록, 공유 기능을 제공합니다. [문서 작성 및 정리](/docs/template-content-editing)를 참조하세요.
- **Notion 스타일 데이터베이스를 만드세요.** 모든 행이 각각 독립된 문서인 테이블로, 타입이 지정된 속성과 표/목록/갤러리/보드/캘린더/타임라인/폼 보기를 제공합니다. [데이터베이스, 속성 및 폼](/docs/template-content-databases)을 참조하세요.
- **구조화된 제출 내용을 수집하세요.** 데이터베이스를 인테이크 폼으로 전환하면 에이전트나 Slack, 다른 앱에서 안전하게 제출할 수 있습니다. [데이터베이스, 속성 및 폼](/docs/template-content-databases)을 참조하세요.
- **Obsidian처럼 디스크에 있는 파일을 편집**하고, 문서를 Notion 또는 Builder CMS와 동기화된 상태로 유지하세요. [로컬 파일, Notion 및 Builder CMS 동기화](/docs/template-content-sync)를 참조하세요.
- **실시간으로 공동 작업하세요.** 여러 사람(그리고 에이전트)이 서로의 작업을 덮어쓰지 않고 동시에 같은 문서를 편집할 수 있습니다.
- **문서를 공유하세요.** 팀원과 공유하거나 공개로 전환할 수 있습니다. 기본값은 비공개이며, 뷰어/편집자/관리자 역할을 사용할 수 있습니다.
- **에이전트에게 무엇이든 요청하세요**: "이 문단을 다시 써줘." "맨 위에 TL;DR을 추가해 줘." "지난주 회의 메모를 전부 찾아줘." "Slack 제출용 폼이 있는 베타 신청 데이터베이스를 만들어 줘."

## 시작하기

라이브 데모: [content.agent-native.com](https://content.agent-native.com).

앱을 열면 사이드바에서 **+ 새 페이지**를 클릭하고 제목을 지정한 다음 글쓰기를 시작하세요. 에이전트를 사용하려면 사이드바에 다음과 같이 입력하세요.

- "Onboarding이라는 페이지를 만들고 그 아래에 하위 페이지 3개를 추가해 줘."
- "이 문단을 더 간결하게 다시 써줘." (페이지를 연 상태에서)
- "요금제에 관한 섹션을 항목 3개로 추가해 줘."
- "이 문서를 맨 위에 TL;DR로 요약해 줘."
- "Notion에서 최신 내용을 가져와 줘." (Notion 페이지를 연결한 후)

텍스트를 선택하고 Cmd+I를 누르면 해당 선택 영역이 미리 로드된 채로 에이전트에 초점이 맞춰집니다. 이 상태에서 "더 임팩트 있게 만들어 줘"라고 요청하면 정확히 강조 표시한 부분에만 적용됩니다.

나만의 콘텐츠 사본을 스캐폴딩하려면:

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

나머지 설정 과정(`cd`, `pnpm install`, `pnpm dev`)과 프레임워크 기본 개념은 [시작하기](/docs/getting-started)를 참조하세요.
