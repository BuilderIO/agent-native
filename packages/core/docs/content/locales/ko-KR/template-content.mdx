# 콘텐츠

콘텐츠는 MDX용 오픈소스 Obsidian입니다. 로컬 파일과 잘 어울리는 문서
작업 공간으로, 에이전트가 여러분을 대신해 페이지를 읽고 쓰고 재구성하고
게시할 수 있습니다. 문서를 열고 "이 문단을 더 간결하게 다시 써줘"라고
요청하거나 "목표, 지표, 리스크에 대한 하위 페이지를 포함한 Q4 Planning이라는
페이지를 만들어줘"라고 요청해 보세요. 직접 하든 에이전트에게 부탁하든
결과는 같습니다.

## 무엇을 대체하나요

<Comparison>

### Before

- 비공개 노트용 Obsidian 또는 로컬 Markdown 파일 폴더
- 팀이 함께 살펴볼 수 있는 문서를 위한 별도의 Notion 워크스페이스
- 실제 사이트에 게시되는 모든 것을 위한 헤드리스 CMS
- 셋 중 하나가 뒤처질 때마다 콘텐츠를 손으로 옮겨 복사하는 작업

### After

- 비공개 페이지, 팀 문서, 게시된 콘텐츠를 위한 하나의 작업 공간
- 같은 문서를 각각 다시 입력할 필요 없이 로컬 파일, Notion, Builder CMS로 동기화할 수 있습니다
- 에이전트는 여러분과 동일한 액션과 동일한 페이지를 통해 읽고 씁니다
- 외부 소스에서 온 변경 사항은 조용히 덮어써지지 않고 검토 가능한 변경 세트로 반영됩니다

</Comparison>

문서는 기본적으로 비공개이며, 뷰어/편집자/관리자 공유 권한과 세상에 공개하고 싶을 때 사용할 수 있는 공개 읽기 전용 모드를 제공합니다. 여러 사람(그리고 에이전트)이 서로의 작업을 덮어쓰지 않고 동시에 같은 페이지를 편집할 수 있습니다. 각각에 대해 더 자세히 알아보려면 [문서 작성 및 정리](/docs/template-content-editing), [데이터베이스, 속성 및 폼](/docs/template-content-databases), [로컬 파일, Notion 및 Builder CMS 동기화](/docs/template-content-sync)를 참조하세요.

## 시작하기 {#get-started}

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

설치, 최초 실행, LLM 연결에 대해서는 [콘텐츠: 개발자 가이드](/docs/template-content-developers#quick-start)를 참조하세요.

앱을 열면 사이드바에서 **+ 새 페이지**를 클릭하고 제목을 지정한 다음 글쓰기를 시작하세요. 아니면 에이전트에게 직접 요청하세요:

- "Onboarding이라는 페이지를 만들고 그 아래에 하위 페이지 3개를 추가해 줘."
- "이 문단을 더 간결하게 다시 써줘." (페이지를 연 상태에서)
- "Notion에서 최신 내용을 가져와 줘." (Notion 페이지를 연결한 후)

텍스트를 선택하고 Cmd+I를 누르면 해당 선택 영역이 미리 로드된 채로 에이전트에 초점이 맞춰집니다. 이 상태에서 "더 임팩트 있게 만들어 줘"라고 요청하면 정확히 강조 표시한 부분에만 적용됩니다.
