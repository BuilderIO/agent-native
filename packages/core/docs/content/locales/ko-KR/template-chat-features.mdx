# 기능

채팅과 함께 제공되는 모든 기능이 어떻게 동작하고 어떻게 설정하는지 다룹니다. 전체
개요는 [채팅](/docs/template-chat) 문서를, 시도해 볼 프롬프트는
[Agent와 대화](/docs/template-chat-agent) 문서를 참고하세요.

## 대화

로그인하면 채팅은 메시지 입력창과 몇 개의 링크가 있는 **시작하기** 페이지에서 열립니다. 거기서 메시지를 보내면 대화가 전체 화면으로 열립니다. **새 채팅**은 "How can I help?"라는 제목 아래에서 새 대화를 시작합니다. 첫 메시지를 보내기 전까지 입력창은 가운데에 있다가, 대화가 길어지면 아래쪽으로 이동합니다.

사이드바는 대화를 두 그룹으로 나눠 보여줍니다. **고정됨** 채팅은 맨 위에 머무르고,
**최근**에는 나머지가 최신순으로 표시됩니다. 아직 작업 중인 채팅은 제목 옆에
스피너가 표시되므로, 첫 번째 대화를 놓치지 않으면서 다른 대화를 시작할 수 있습니다.

- 사이드바 상단의 **New Chat**으로 **새 채팅을 시작**합니다.
- 목록에서 채팅을 선택해 **다시 엽니다**.
- 해당 행의 옵션 메뉴에서 채팅의 **이름을 바꾸거나, 고정하거나, 보관**합니다.
  보관하면 목록에서 사라집니다.
- 대화에 더 많은 공간이 필요하면 **사이드바를 접습니다**.

<Steps>

### 채팅 이름 바꾸기

채팅 행의 옵션 메뉴를 열고 **Rename Chat**을 선택하세요. 새 제목을 입력하고 Enter를
누르면 됩니다. 제목은 최대 160자까지 가능합니다.

### 자주 돌아오는 채팅 고정하기

같은 메뉴에서 **Pin Chat**을 선택하세요. **Unpin Chat**을 선택하기 전까지 채팅은
**고정됨**에 머무릅니다.

### 끝난 채팅 보관하기

**Archive Chat**을 선택하세요. 보관에 실패하면 메시지가 나타나고 채팅은 원래 자리에
그대로 남습니다.

</Steps>

## 모델 연결하기

에이전트가 답하려면 모델이 필요합니다. 모델이 연결되기 전까지 메시지 입력창에는
"Connect AI to start chatting..."이라고 표시됩니다. 무료 크레딧을 받으려면 **Builder.io 사용**을,
직접 가진 프로바이더 키를 사용하려면 **직접 키 추가**를
선택하세요. 그러면 에이전트가 바로 답할 수 있습니다.

나중에 모델을 바꾸려면 **설정**을 열고 **Model**을 선택하세요. 이 페이지에서 기본
모델과 앱이 사용할 수 있는 프로바이더를 설정합니다.

<Callout tone="info">

채팅이 대신 모델을 골라주지는 않습니다. 선택할 수 있는 모델은 연결한 프로바이더에
따라 달라집니다.

</Callout>

## 음성 입력

메시지 입력창에는 마이크 버튼이 있습니다. 이를 선택하면 입력하는 대신 말로
메시지를 받아쓸 수 있고, 다른 메시지와 똑같이 보낼 수 있습니다. 언어와 받아쓰기
옵션은 **설정 → Preferences**에 있습니다.

## 예제 액션

채팅에는 **hello**라는 예제 액션이 하나 포함되어 있습니다. 액션은 누군가에게 인사하기,
메모 만들기, 레코드 조회하기처럼 앱이 할 수 있는 하나의 일입니다. 각 액션에는 이름,
무엇을 하는지에 대한 설명, 실행에 필요한 세부 정보가 있습니다. 에이전트는 이 설명을
읽고 요청에 어떤 액션을 쓸지 결정합니다.

에이전트에게 "Alex에게 인사하는 hello 액션을 호출해줘"처럼 누군가에게 인사하도록
요청하면, 해당 이름으로 hello를 실행하고 결과를 보여줍니다. 직접 액션을 만들기 전에
메시지에서 에이전트가 액션을 실행하고 그 결과를 보여주기까지의 전체 흐름을 한 번
확인해 볼 수 있도록 존재합니다.

액션은 에이전트 네이티브 앱의 공유 접점입니다. 에이전트가 사용하고, 앱의 화면도
사용할 수 있으므로, 새 액션은 추가 설정 없이 두 곳 모두에서 동작합니다. 개발자는 앱이
커지면서 자신만의 액션을 추가합니다. 동작 방식은 [액션](/docs/actions-overview)을,
작성 방법은 [액션 정의하기](/docs/actions-defining)를 참고하세요.

## 설정에서 에이전트 다듬기

**설정**을 열고 **Agent** 그룹을 확인하세요. 이 페이지들은 모든 채팅에서 에이전트가
어떻게 동작할지를 제어합니다.

| 페이지            | 제어하는 것                                               |
| ----------------- | --------------------------------------------------------- |
| **Model**         | 기본 모델과 프로바이더 키.                                |
| **Instructions**  | 모든 채팅에서 에이전트가 따르는 상시 지침.                |
| **개인화**        | 사용자 지정 지침과 메모리 환경설정.                       |
| **Memory**        | 에이전트가 배워서 채팅 사이에 기억하는 것들.              |
| **Skills**        | 에이전트가 작업 유형에 맞게 불러올 수 있는 재사용 가이드. |
| **Files**         | 에이전트가 읽을 수 있는 참조 파일.                        |
| **하위 에이전트** | 메인 에이전트가 작업을 넘길 수 있는 보조 에이전트.        |

**Connections** 그룹에는 **연동**과 **API 키**가 있고, **Account**
그룹에는 **프로필**, **Preferences**, **보안**이 있습니다.

<Steps>

### 설정 열기

사이드바 하단의 검색 버튼을 선택하고 **설정**을 선택하세요.

### 페이지 고르기

왼쪽 목록에서 페이지를 선택하세요. 변경 사항은 다음 메시지부터 적용됩니다.

</Steps>

## 로그인과 팀

채팅은 로그인이 필요합니다. 로그인, 가입, 세션은 첫 실행부터 설정되어 있으며,
로그인 방법, 구성원, 역할은 설정의 **Organization** 그룹에서 관리합니다.

사이드바 하단의 조직 전환기는 현재 어느 조직에서 작업 중인지 보여주고 전환할 수
있게 해줍니다. 작업 공간마다 조직을 하나만 유지하고 사람들을 구성원으로 추가하세요.
연결한 자격 증명은 조직별로 저장되므로, 두 번째 조직에서는 첫 번째 조직에 연결된
키를 볼 수 없습니다.

## 데이터베이스와 관측

채팅에는 두 개의 관리자 페이지가 포함되어 있습니다. 사이드바에서 연결되지 않으므로
주소로 직접 여세요.

- `/database`의 **Database**는 앱의 테이블을 보여주고, 에이전트와 앱이 저장한
  행을 탐색할 수 있게 해줍니다.
- `/observability`의 **관찰성**은 에이전트가 무엇을 해왔는지를 개요, 대화,
  평가, 실험, 피드백 탭으로 보여줍니다.

둘 다 앱을 운영하는 사람을 위한 것입니다. 열어 보지 않더라도 마운트되어 있습니다.

## 미니 앱

채팅은 계산기나 체크리스트처럼 작은 샌드박스 도구인 **확장**을 실행할 수 있습니다.
채팅에서는 꺼져 있습니다. 설정에 확장 페이지가 없고, 에이전트도 이를 만들 수 없습니다.
개발자가 두 곳에서 이를 켭니다. 확장이 무엇이고 어떻게 활성화하는지는
[확장](/docs/extensions) 문서를 참고하세요.
