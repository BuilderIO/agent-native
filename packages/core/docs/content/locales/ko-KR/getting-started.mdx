# 시작하기

Agent-Native 앱에서는 에이전트와 UI가 동일한 [액션](/docs/actions-overview), SQL 데이터, 애플리케이션 상태를 사용합니다. 이 경로는 필요한 프레임워크 테이블을 이미 만들고 채팅 기록을 기본적으로 로컬 SQLite에 저장하는 Chat에서 시작합니다. 앱에서 도메인 데이터를 저장해야 할 때만 자체 테이블을 추가하세요.

<Steps>

### 채팅 앱을 만들고 에이전트 구성하기

Chat 템플릿을 스캐폴딩하고 종속 항목을 설치한 뒤 개발 서버를 시작하고 에이전트를 구성합니다. 확장할 수 있는 작동하는 채팅 앱이 만들어집니다.
**현재 단계입니다.**

### 액션 추가하기

타입이 지정된 텍스트 분석을 정의하고 그 결과를 채팅에서 차트로 렌더링합니다.

### 페이지 추가하기

트랜스크립트 밖에서 동일한 액션을 호출하는 React 라우트를 만듭니다.

</Steps>

## 1. 채팅 앱 만들기 {#create-your-app}

[Node.js 22+](https://nodejs.org)와 [pnpm](https://pnpm.io)이 필요합니다.

터미널을 열고 Agent Native 앱을 만들 디렉터리로 이동한 다음 다음 명령을 실행하세요.

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

앱은 `http://localhost:8080`에서 열립니다. 로그인 화면이 보이면 실제로 존재하지 않는 로그인 정보로 가입하세요. 로컬 개발에서는 이메일 인증이 필요하지 않습니다.

Chat 템플릿에는 지속적인 채팅 스레드, 인증, 라이브 동기화, `actions/` 디렉터리, 표준 `view-screen` 및 `navigate` 액션이 포함되어 있습니다.

### 다른 시작점 선택하기

Chat이 적합한 시작점이 아니라면 `--template` 없이 `create`를 실행하고 CLI에서 다른 옵션을 선택하세요. 다른 경로는 [템플릿 만들기](/docs/creating-templates)에서 확인할 수 있습니다.

## 2. 에이전트 구성하기 {#connect-ai}

Chat 템플릿은 채팅 화면을 바로 엽니다. 에이전트가 응답할 준비가 되지 않았다면 **Settings > Manage agent**를 열거나 **Cmd/Ctrl+K > Manage agent**를 사용해 모델과 프로바이더를 구성하세요.

에이전트가 응답하면 [액션 추가하기](/docs/getting-started-actions)로 계속 진행하세요.
