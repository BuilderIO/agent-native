# 앱 배포

단계와 공급자 명령은 [영문 앱 배포 전체 가이드](/docs/deploy-an-app)를 참고하세요.

배포 전에 영구 SQL 데이터베이스와 안정적인 `BETTER_AUTH_SECRET`을 설정하세요. [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb), [Render](/docs/render) 중에서 대상을 선택할 수 있습니다.

여러 앱을 하나의 오리진에서 실행하려면 [워크스페이스 배포](/docs/workspace-deployment)를 사용하세요.
