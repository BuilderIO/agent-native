# 개발자 가이드

이 페이지는 클립 템플릿을 커스터마이즈하거나 확장하는 모든 사람을 위한 것입니다. 빠른 시작, 모든 액션, 데이터 모델, 라우트 구성, 그리고 여기에 추가하는 방법을 다룹니다. 앱이 무엇을 하는지는 [클립](/docs/template-clips) 문서를 참고하세요.

## 빠른 시작

<Steps>

### 앱 만들기

```bash
npx @agent-native/core@latest create my-clips --standalone --template clips
cd my-clips
pnpm install
```

먼저 [Node.js](https://nodejs.org) 22.22 이상과 [pnpm](https://pnpm.io)이 설치되어 있어야 합니다. 아직 설치하지 않았거나 LLM 연결(Builder.io, Anthropic/OpenAI 키, 또는 로컬 Ollama)이 설정되어 있지 않다면 [시작하기](/docs/getting-started) 문서를 참고하세요.

### 개발 서버 시작하기

```bash
pnpm dev
```

앱이 브라우저에서 자동으로 열립니다. 브라우저나 데스크톱 앱이 로컬에서 캡처하므로 녹화는 별도 설정 없이 동작합니다. 파일 저장소나 AI 크레딧이 필요한 액션은 둘 중 하나가 설정되기 전까지만 오류가 발생합니다.

</Steps>

<Callout tone="info">

녹화, 전사, AI 제목/요약이 처음부터 끝까지 동작하려면 파일 저장소와 AI 크레딧이 설정되어 있어야 합니다. **설정**에서 Builder.io를 연결하면 둘 다 한 번에 처리됩니다(무료 등급에 관리형 AI 크레딧이 포함됩니다). 또는 S3 호환 저장소를 따로 연결하고 전사를 위해 직접 Groq 키를 준비하세요. [전사 및 AI 메타데이터](/docs/template-clips-features#transcription-and-ai-metadata) 문서를 참고하세요.

</Callout>

## 액션 목록

모든 작업은 `templates/clips/actions/`에 있는 TypeScript 파일이며, `POST /_agent-native/actions/:name`에 자동으로 마운트됩니다.

### 라이브러리 및 녹화

| Action                                                                                    | What it does                                                    |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `list-recordings`, `search-recordings`                                                    | 라이브러리, 나와 공유된 항목, 휴지통, 스페이스 범위의 목록 조회 |
| `create-recording`, `finalize-recording`                                                  | 행 생성, 업로드 완료 처리                                       |
| `import-loom-recording`                                                                   | Loom 동영상 또는 직접 MP4/WebM URL 가져오기                     |
| `update-recording`                                                                        | 제목, 설명, 비밀번호, 만료, 공개 범위                           |
| `move-recording`                                                                          | 하나 또는 여러 녹화를 폴더나 루트로 이동                        |
| `archive-recording`, `trash-recording`, `restore-recording`, `delete-recording-permanent` | 라이프사이클: 숨기기, 소프트 삭제, 취소, 완전 삭제              |

<Callout tone="warning">

</Callout>

## 액션 살펴보기

`create-recording-agent-link`는 범위가 지정된 자격 증명을 발급하는 어떤 액션에서도 재사용할 만한 패턴을 보여줍니다. 무언가를 내주기 전에 리소스의 실제 상태를 확인하는 것, 직접 만들지 않고 실제 토큰 발급을 공유 프레임워크 헬퍼에 위임하는 것, 그리고 호출자가 필요로 하는 모든 URL을 그 하나의 부여(grant)에서 도출하는 것입니다.

## 커스터마이즈하기

앱의 모든 부분은 수정 가능한 소스입니다. 여기서부터 시작하세요.

- `templates/clips/actions/` — 새 파일을 `defineAction`으로 추가해 에이전트와 프런트엔드 양쪽에 새 기능을 노출하세요.
- `templates/clips/app/routes/` — 위에 나열한 UI입니다.
- `templates/clips/server/db/schema.ts` — Drizzle로 컬럼이나 테이블을 추가하세요. 템플릿이 로컬 PGlite와 호스팅된 Postgres 모두에서 동작하도록 스키마를 PostgreSQL과 호환되게 유지하세요.
- `templates/clips/server/lib/` — 제공자 통합: `google-calendar-client.ts`, `s3-upload-provider.ts`, `slack-oauth.ts`, `video-remux.ts`, `video-filmstrip-sprite.ts`.
- `templates/clips/AGENTS.md` — 에이전트 안내입니다. 에이전트에게 새로운 기능이나 규칙을 가르칠 때 이 파일을 업데이트하세요.
- `templates/clips/.agents/skills/` — 에이전트가 따르는 세부 패턴입니다. 관련 스킬: `recording`, `ai-video-tools`, `video-editing`, `video-sharing`, `screen-memory`.
- `templates/clips/shared/api.ts` — 서버와 클라이언트가 함께 사용하는 공유 TypeScript 타입입니다.
- `templates/clips/desktop/`와 `templates/clips/chrome-extension/` — 네이티브 캡처 화면을 위한 별도 패키지로, 각각 자체 `package.json`과 빌드를 가집니다.

기능을 추가한다면 네 가지 영역을 모두 업데이트해야 한다는 것을 기억하세요: UI, 액션, 스킬 또는 AGENTS.md 항목, 그리고 에이전트가 봐야 하는 애플리케이션 상태입니다. 이것이 에이전트와 UI를 동등하게 유지하는 방법입니다.
