# Clips 익명 인테이크

이 흐름에서는 방문자가 Clips에 로그인하지 않고 비공개 녹화 하나를 제출할 수 있습니다. 신뢰된 제품이 인테이크 URL을 만들며 에이전트의 읽기 전용 링크와 분리됩니다.

통합 방법, 보안 경계, 셀프 호스팅 요구 사항은 [영문 전체 가이드](/docs/template-clips-anonymous-intake)를 참조하세요.
