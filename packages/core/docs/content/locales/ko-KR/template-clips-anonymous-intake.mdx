# Clips 익명 인테이크

이 흐름에서는 방문자가 Clips에 로그인하지 않고 비공개 녹화 하나를 제출할 수 있습니다. 신뢰된 제품이 인테이크 URL을 만들며 에이전트의 읽기 전용 링크와 분리됩니다.

생성 응답이 유실되면 녹화가 연결된 뒤 같은 서명된 요청을 안전하게 재시도할 수 있으며, 두 번째 녹화는 생성되지 않습니다.

제출 후 완료 메시지에는 녹화 ID만 포함되며 방문자에게 에이전트 읽기 권한을 주지 않습니다. 신뢰된 호스트가 인증 후 `create-intake-agent-link`를 실행해야 합니다.

통합 방법, 보안 경계, 셀프 호스팅 요구 사항은 [영문 전체 가이드](/docs/template-clips-anonymous-intake)를 참조하세요.
