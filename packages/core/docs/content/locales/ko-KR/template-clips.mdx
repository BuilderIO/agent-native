# 클립

클립은 에이전트 기반 화면 녹화 앱입니다. 화면을 녹화하면 에이전트가 이를 전사하고, 제목을 짓고, 요약하고, 검색 가능한 하나의 라이브러리에 색인화합니다. 그래서 "출시 계획에 대해 논의한 클립을 찾아줘"라고 요청하면 지금까지 만든 모든 녹화를 검색할 수 있습니다. 클립은 하나의 앱으로 Loom을 대체하므로, 각자 자체 전사 기능을 가진 별도의 도구 대신, 만든 모든 녹화가 여러분이 소유한 하나의 검색 가능한 공간에 남습니다.

에이전트는 모든 녹화에서 일급 편집자로 동작하며, 캡처한 모든 것은 SaaS 공급업체의 것이 아니라 여러분의 것입니다. 클립은 또한 공유한 녹화를 자신뿐 아니라 어떤 에이전트든 읽을 수 있게 만듭니다. 클립의 공유 링크를 Claude, ChatGPT, 또는 다른 어시스턴트에 붙여넣으면 원본 동영상을 다운로드하지 않고도 전사를 읽고 타임스탬프가 찍힌 화면 프레임을 볼 수 있습니다. 실제로 어떻게 동작하는지는 [다중 앱 작업 공간 속 클립](/docs/template-clips-integrations) 문서를 참고하세요.

## 대체하는 것

<Comparison>

### 이전에는

- 화면 녹화를 위한 Loom
- 전사, 제목, 요약을 위한 별도의 도구 또는 수동 작업
- AI 정리를 받기 위해 클립을 다시 녹화하거나 다시 업로드하기
- 외부 에이전트가 녹화 내용을 실제로 이해할 방법이 없음

### 이후에는

- 하나의 레코더, 이미 Loom에 있는 것은 가져오기로 처리
- 에이전트가 모든 녹화의 제목을 짓고, 요약하고, 챕터를 자동으로 나눔
- 요청만 하면 자르거나, 필러 단어를 제거하거나, 클립을 합칠 수 있음
- 클립 자신뿐 아니라 어떤 에이전트든 읽을 수 있는 공유 링크

</Comparison>

## 다중 앱 작업 공간에서의 클립

[Dispatch](/docs/template-dispatch) 아래에서 다른 앱들과 함께 클립을 운영한다면, 녹화는 더 이상 손으로만 확인하는 것에 그치지 않습니다. 다른 앱이 준비된 전사를 Brain으로 가져오거나, CRM 자동화에 지속되는 통화 증거 링크를 건네거나, 여러분이 채팅에서 하는 것과 같은 방식으로 클립의 에이전트에게 직접 질문할 수 있습니다. 실제로 어떻게 동작하는지는 [다중 앱 작업 공간 속 클립](/docs/template-clips-integrations) 문서를 참고하세요.

## 할 수 있는 일

- **화면을 녹화하거나 Loom에서 가져오기.** "내 화면 녹화해줘"라고 요청하거나 공개 Loom 링크를 붙여넣어 라이브러리로 가져오세요. [클립 만들기](/docs/template-clips-features#create-a-clip) 문서를 참고하세요.
- **채팅으로 비파괴적으로 편집하기.** "음이랑 어 제거해줘" 또는 "처음 10초 잘라줘"라고 요청해 보세요. [비파괴 편집](/docs/template-clips-features#non-destructive-editing) 문서를 참고하세요.
- **녹화한 내용을 공유하고 보호하기.** 공개 범위, 비밀번호, 만료일을 설정하고, 공유한 클립의 전사를 어떤 에이전트든 읽을 수 있게 하세요. [공유](/docs/template-clips-features#share) 문서를 참고하세요.
