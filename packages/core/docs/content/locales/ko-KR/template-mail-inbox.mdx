# 받은편지함, 검색 및 자동화

이 페이지는 [메일](/docs/template-mail)에서의 일상적인 받은편지함 작업을 다룹니다: 메시지를 읽고 분류하기, 연결된 모든 계정에서 검색하기, 대량으로 정리하기, 반복되는 분류를 자동화하는 두 가지 방법입니다. 개발자뿐 아니라 메일을 사용하는 모든 사람을 위해 작성되었습니다.

## 읽기와 분류

마우스를 건드리지 않고 받은편지함을 이동하세요. 우선순위 정렬은 Builder 액세스가 있거나 저장된 개인 키가 있을 때만 사용할 수 있습니다. 다음 키보드 단축키를 사용하세요.

| 키        | 동작                      |
| --------- | ------------------------- |
| `J`       | 다음 이메일               |
| `K`       | 이전 이메일               |
| `Up/Down` | J/K와 동일                |
| `Enter`   | 초점이 맞춰진 이메일 열기 |
| `E`       | 이메일 또는 스레드 보관   |
| `D`       | 이메일 또는 스레드 휴지통 |
| `S`       | 별표 표시 또는 별표 해제  |
| `R`       | 답글                      |
| `U`       | 읽음/읽지 않음 전환       |
| `C`       | 새 이메일 작성            |
| `/`       | 검색창에 초점 맞추기      |
| `Cmd+K`   | 명령 팔레트 열기          |
| `G I`     | 받은편지함으로 이동       |
| `G S`     | 별표로 이동               |
| `G T`     | 보낸함으로 이동           |
| `G D`     | 초안으로 이동             |
| `G A`     | 보관함으로 이동           |
| `Esc`     | 스레드 닫기 / 검색 지우기 |

단축키가 하는 모든 일은 에이전트에게 요청해도 됩니다: "일주일이 지난 모든 Netlify 봇 이메일을 보관해줘", "프리야가 보낸 건 다 별표 표시해줘", "이 스레드 전체를 읽음으로 표시해줘."

## 연결된 모든 받은편지함에서 검색하기

검색창에 입력하거나 에이전트에게 물어보세요. 지금 열려 있는 탭뿐 아니라 연결된 모든 Gmail 계정에서 한 번의 검색으로 찾습니다. 개인 계정과 업무 계정을 둘 다 연결했다면 "Acme에서 온 인보이스 찾아줘"는 두 계정 모두를 확인합니다.

## 받은편지함 정리를 위한 대량 작업

보관, 별표 표시, 읽음 표시는 모두 연결된 실제 Gmail 계정을 대상으로 대량으로 동작합니다. 여러 메시지를 선택하거나(또는 에이전트에게 "이것들 전부"에 대한 작업을 요청하면) 메일은 메시지 하나당 한 번씩 호출하는 대신 계정별로 요청을 묶어 처리합니다. 날짜 기준의 별도 정리 기능("30일이 지난 건 전부 보관해줘")과 특정 보기를 JSON으로 내보내는 기능도 있지만, 두 가지 모두 현재는 연결된 Gmail 계정이 아니라 로컬 데모 편지함에서만 동작합니다. Gmail이 변경된 뒤에는 메일이 더 오래되거나 취소된 응답이 더 새로운 결과를 덮어쓰지 못하도록 막습니다.

한 계정에 쌓인 대량의 읽지 않은 메일을 한 번에 정리하려면, 에이전트에게 대화를 하나씩 열어 표시해 달라고 하는 대신 "읽지 않은 걸 전부 읽음으로 표시해줘"라고 요청하세요. 메일은 이를 하나의 검증된 대량 작업으로 실행하고 실제로 몇 건이 변경되었는지 알려줍니다.

## 자동 분류 규칙 vs. 네이티브 Gmail 필터

메일에는 들어오는 메일을 자동화하는 서로 다른 두 가지 방법이 있습니다. 신중하게 선택하세요.

<Callout tone="info">

**자동화 규칙**은 여러분이 작성한 평범한 영어 조건("뉴스레터에서 온 것", "제목에 인보이스 포함")에 AI를 이용해 새 메일을 대조하고, 일치하면 작업(라벨 지정, 보관, 읽음 표시, 별표 표시, 휴지통)을 적용합니다. 메일 안에서 약 1분마다 자동으로 실행됩니다.

**Gmail 필터**는 Gmail 자체의 네이티브 메커니즘입니다. 자동화 규칙이 메시지를 보기도 전에 Gmail 내부에서 실행되며, Gmail의 정확한 검색 문법(`from:`, `older_than:`, 첨부파일 여부, 크기 등)을 사용합니다. 메일을 열어두지 않아도 계속 동작합니다.

규칙을 Gmail 자체의 조건으로 표현할 수 있다면 Gmail 필터를 사용하고, 조건에 판단이 필요하다면("이게 영업 메일 같으면") 자동화 규칙을 사용하세요.

</Callout>

## 스레드의 CRM 컨텍스트

스레드를 열면 메일의 연락처 사이드바가 보낸 사람의 CRM 컨텍스트를 보여줄 수 있습니다. 현재 전체 연동이 완성된 것은 HubSpot뿐입니다. 에이전트에게 "이 사람이 누구고 진행 중인 거래가 뭐가 있는지 알려줘"라고 물어보면, 설정한 HubSpot 계정에서 연락처, 관련 거래(최대 5개), 관련 티켓(최대 5개)을 조회합니다.

Gong, Pylon, Apollo도 같은 사이드바 패널에 나타나지만, 설정에서 각각의 API 키를 추가한 경우에만, 그리고 읽기 전용 사이드바 보기로만 나타납니다. 현재 에이전트가 채팅으로 가져올 수 있는 것은 HubSpot뿐이며, Gong 통화나 Pylon 티켓은 가져올 수 없습니다.
