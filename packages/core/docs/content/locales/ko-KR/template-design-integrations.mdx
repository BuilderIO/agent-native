# 다중 앱 작업 공간 속 Design

Design은 [Dispatch](/docs/template-dispatch) 작업 공간에 속한 여러 앱 중
하나이며, 그 작업 공간 바깥에 있는 에이전트도 직접 접근할 수 있습니다. 이
페이지는 두 가지를 모두 다룹니다. Dispatch 연결이 어떻게 동작하는지, 그리고
외부 에이전트가 MCP를 통해 Design 자체의 액션을 어떻게 호출할 수 있는지입니다.
전체 개요는 [Design](/docs/template-design) 문서를 참고하세요.

## Design이 Dispatch와 연결되는 방식

이것이 자동으로 이루어지는지는 Design과 Dispatch를 어떻게 함께 설정했는지에
따라 달라지며, 둘 중 하나가 호스팅되어 있는지 로컬에서 실행 중인지와는
관련이 없습니다.

### 같은 작업 공간: 자동

Design과 Dispatch가 하나의 Agent-Native 작업 공간에(`create` 또는
`add-app`을 통해) 함께 생성되거나 추가되어 하나의 단위로 배포되었다면,
이미 하나의 `.env`, 하나의 `A2A_SECRET`, 하나의 작업 공간 레지스트리를
공유합니다. 검색과 인증된 A2A 호출 모두 그 작업 공간이 여러분의 컴퓨터에서
실행되든 프로덕션에서 실행되든 별도로 설정할 것 없이 그대로 동작합니다.

### 별도 배포: 수동 단계 하나

Design과 Dispatch가 독립적으로 생성된 두 개의 Agent-Native 프로젝트라면,
시크릿을 공유하지 않으므로 아직 서로를 호출할 수 없습니다. 이들을
연결하려면 양쪽 각각에서 수동 단계 하나가 필요합니다. Settings → Agent → Sub-agents(Connect agent), 또는 Dispatch → 에이전트 → 외부 에이전트
추가에서 공유 시크릿과 함께 `remote-agents/<id>.json` 리소스를 추가하세요.
전체 과정은 [A2A 프로토콜](/docs/a2a-protocol) 문서를 참고하세요.

어느 쪽 상황인지 확인하려면 두 앱 중 어느 쪽 에이전트에게든 "어떤 앱들을
볼 수 있어?"라고 물어보세요. Dispatch의 답변에 Design이 빠져 있다면 두
번째 경우에 해당합니다.

## 작업 공간 바깥에서 Design 호출하기

Design은 여러분의 Dispatch 작업 공간에 속해 있는지와 상관없이 다른
에이전트가 직접 연결할 수 있는 호스팅된 MCP 서버로도 동작합니다. Claude,
Claude Code, Claude Desktop, Codex, 그리고 그 밖의 MCP 호환 호스트는 모두
다음 주소에 연결할 수 있습니다.

```
https://design.agent-native.com/mcp
```

Claude와 Claude Desktop은 이를 커스텀 커넥터로 추가하고 로그인해 접근을
승인합니다. Claude Code는 같은 URL을 추가한 다음 `/mcp`를 실행해 인증합니다.
Codex와 그 밖의 CLI 또는 stdio 클라이언트는 대신 `npx
@agent-native/core@latest connect https://design.agent-native.com`을
실행합니다. 그러면 브라우저 탭이 열려 승인을 받고, 공유 시크릿 없이
사용자별로 발급되고 취소 가능한 토큰을 발급받습니다.

연결되면 외부 에이전트는 [Agent와 대화](/docs/template-design-agent)에서
다룬 것과 같은 핵심 작업 흐름을 사용할 수 있습니다. 디자인을 만들고, 비교할
방향을 몇 가지 생성하고, 화면의 현재 상태를 가져오고, 범위가 정해진 편집을
하고, 결과를 실제 코드로 바꿀 시점이 되면 코딩 핸드오프 번들을 내보내는
것입니다. 에이전트는 대화에 원시 HTML을 붙여넣는 대신 인라인 미리보기나
실제 편집기로 돌아가는 "디자인 열기" 링크를 보여줍니다.

<Callout tone="info">

외부 에이전트에서 Design 도구 호출이 세션 또는 인증 오류를 반환하기
시작하면 계속 재시도하지 마세요. Claude Code에서 `/mcp`를 실행해 다시
연결하거나, 어떤 터미널에서든 `npx -y @agent-native/core@latest reconnect
https://design.agent-native.com`을 실행하세요. 둘 다 아무것도 다시
설치하지 않고 재인증합니다.

</Callout>

## Dispatch를 통해 Design에 위임하기

형제 앱이 Design과 함께 동작하는 데 특별한 통합이 필요하지는 않습니다.
"이 새 기능을 위한 랜딩 페이지를 만들어줘"처럼 여러분이 채팅에서 하는 것과
같은 방식으로 Design의 에이전트에게 평범한 자연어 요청을 그대로 건네면,
Design이 직접 답하거나 처리합니다.

이 모든 과정에서 Design이 요청한 앱의 자격 증명을 알아야 할 필요는 전혀
없으며, 반대 방향도 마찬가지입니다. 실제 요청에 답하기만 하면 됩니다.
누가 묻고 있는지, 왜 묻는지는 알 필요가 없습니다.
