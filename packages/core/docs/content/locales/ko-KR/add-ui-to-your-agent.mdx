# 에이전트에 UI 추가하기

Agent-Native는 기존 에이전트에 채팅, 승인, 워크플로 상태, 권한을 위한 워크스페이스를 제공합니다. 추론, 도구, 컨텍스트, 장기 실행은 공급자에 남습니다.

이 페이지는 **Microsoft Foundry, Gemini Enterprise, Anthropic Managed Agents 또는 OpenAI 에이전트에 UI를 추가**하는 방법을 설명합니다.

## 연결 선택 {#choose-a-connection-path}

| 백엔드                   | Agent-Native 연결          | 설정                               |
| ------------------------ | -------------------------- | ---------------------------------- |
| Microsoft Foundry        | A2A 1.0                    | Agent Card URL 및 Entra 시크릿     |
| Gemini Enterprise        | A2A                        | Agent Card URL 및 Google 시크릿    |
| Anthropic Managed Agents | Managed Agents API         | 에이전트 ID, 환경 ID, Vault 키     |
| OpenAI Agents API        | 사용자 지정 A2A 엔드포인트 | Agent Card URL 및 공급자 자격 증명 |
| 모든 A2A 에이전트        | A2A                        | Agent Card URL 및 선택적 인증 정보 |

**Settings → Agent → Sub-agents**를 열고 **Connect agent**를 선택합니다(소유자와 관리자). Connect 버튼은 해당 공급자가 선택된 연결 양식을 엽니다. 시크릿은 워크스페이스 Vault에 보관됩니다.

## Microsoft Foundry {#microsoft-foundry}

A2A v1.0 Agent Card URL을 붙여 넣고 Entra 자격 증명을 선택합니다. 서비스 간 연결에는 `https://ai.azure.com/.default`와 **Foundry Agent Consumer** 역할을 사용합니다.

## Gemini Enterprise {#gemini-enterprise}

사용자 지정 A2A 카드 URL과 Vault의 bearer 시크릿을 입력합니다. 저장 전에 카드와 JSON-RPC 인터페이스를 검증합니다.

## Anthropic Managed Agents {#anthropic-managed-agents}

**Anthropic Managed Agents**를 선택하고 에이전트 및 환경 ID와 API 키를 입력합니다. 세션과 승인은 Anthropic에 남고 Agent-Native 채팅에 표시됩니다.

## 사용자 지정 A2A {#custom-a2a}

내부 또는 자체 호스팅 에이전트에는 **Add by URL**을 사용합니다. A2A 0.3 및 1.0 카드를 검증하고 실패를 명확한 상태로 표시합니다.

스트리밍을 사용할 수 없으면 연결은 `message/send`를 사용합니다.

## 레지스트리 {#registries}

[Global A2A Registry](https://www.a2a-registry.org)를 찾아볼 수 있습니다. 에이전트를 추가하고 시크릿을 사용하기 전에 카드, 호스트, 인증을 확인하세요.

## UI 계층 {#ui-layer}

[A2A](/docs/a2a-protocol)가 위임된 작업을 전달하고 Agent-Native 워크스페이스가 사용자 상태를 관리합니다. [Connected agents](/docs/agent-mentions#mentioning-agents)와 [External agents](/docs/external-agents)를 참고하세요.
