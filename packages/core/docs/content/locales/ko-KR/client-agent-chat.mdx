# Agent 채팅

여러분의 애플리케이션 클라이언트는 작은 클라이언트 헬퍼 집합을 통해 에이전트와 대화할 수 있습니다. 여기에는 프롬프트 전송, 숨겨진 컨텍스트 준비, 사용자에게 블로킹 질문하기, 에이전트 패널 열기가 포함됩니다.

아래 예시에서는 **답변 초안 작성** 버튼이 에이전트에게 사용자에게 질문을 하도록 요청합니다. 사용자가 답변하면 에이전트는 현재 페이지 컨텍스트와 사용자의 응답을 염두에 두고 답변 초안을 작성합니다.

## 작동 방식

Agent-Native가 제공하는 클라이언트 헬퍼 메서드를 사용하면 UI가 다양한 방식으로 사용자와 상호작용하도록 에이전트에게 요청할 수 있습니다. 아래 다이어그램은 사용자가 클릭한 "답변 초안 작성" 버튼이 응답을 생성하기 전에 에이전트가 사용자와 상호작용하도록 요청하는 과정을 보여줍니다.

사용자 경험은 다음과 같습니다.

1. 사용자가 **답변 초안 작성** 버튼을 클릭하면 `askUserQuestion()` 함수가 호출됩니다. 질문은 에이전트 패널 안에서 인라인으로 답변됩니다.

1. 사용자가 **환불 제공**을 선택하면 `sendDraftRequest()`가 프롬프트와 티켓 컨텍스트를 에이전트에게 전송합니다.

1. 에이전트는 `draft-ticket-reply` [action](/docs/actions-overview)을 호출하고, 작성된 답글이 답글 작성기에 나타납니다.

이 함수는 앱 코드에서 사용자에게 객관식 질문을 던지고, 이를 에이전트 패널 안에 인라인으로 렌더링한 뒤 답변을 기다립니다. UI가 에이전트 작업을 시작하기 전에 2~4개 옵션 중 작은 결정 하나가 필요할 때, 커스텀 모달을 만드는 대신 이 함수를 사용하세요.

아래 예시에서는 티켓 페이지의 "답변 초안 작성" 버튼이 에이전트에게 무언가를 보내기 전에 담당자에게 어떻게 응답하고 싶은지 묻습니다.

```ts
import { askUserQuestion } from "@agent-native/core/client/agent-chat";

const answer = await askUserQuestion({
  question: "How would you like to respond to this ticket?",
  header: "Response", // optional short chip/heading (≈12 chars)
  options: [
    { label: "Offer a refund", value: "refund" },
    { label: "Offer a reprint", value: "reprint" },
  ],
});
```

## sendToAgentChat(opts) {#sendtoagentchat}

`postMessage`를 통해 에이전트 채팅에 메시지를 보냅니다. 이는 위의 `useAgentChatGenerating()`이 감싸고 있는 더 저수준의 기본 요소로, UI 상호작용이 자체적인 로딩 상태 추적을 필요로 하지 않을 때 유용합니다. 모델은 봐야 하지만 사용자는 보지 않아야 하는 추가 세부 정보에는 `context`를 전달하세요. 이는 에이전트로 전송되는 메시지에 `<context>` 태그로 감싸여 추가되며, 채팅 UI에 메시지가 렌더링되기 전에 다시 제거됩니다. 즉시 전송하려면 `submit: true`를, 사용자가 먼저 검토할 초안을 미리 채우려면 `submit: false`를 전달하세요.

```ts
import { sendToAgentChat } from "@agent-native/core/client/agent-chat";
// 숨겨진 컨텍스트로 프롬프트 자동 전송
sendToAgentChat({
  message: "Generate alt text for this image",
  context: "Image path: /api/projects/hero.jpg",
  submit: true,
});

// Prefill without submitting (user reviews first)
sendToAgentChat({
  message: "Rewrite this in a conversational tone",
  context: selectedText,
  submit: false,
});
```

### AgentChatMessage {#agentchatmessage}

| 옵션          | 유형       | 설명                                                                                        |
| ------------- | ---------- | ------------------------------------------------------------------------------------------- |
| `message`     | `string`   | 채팅에 전송되는 프롬프트이며, 채팅 UI에 표시되는 유일한 부분입니다                          |
| `context`     | `string?`  | 전송 전에 메시지에 추가되는 모델에게만 보이는 컨텍스트입니다. 채팅 UI 표시에서는 제거됩니다 |
| `submit`      | `boolean?` | true = 자동 제출, false = 미리 채우기만                                                     |
| `newTab`      | `boolean?` | 이 프롬프트를 위한 별도의 채팅 스레드를 생성합니다                                          |
| `openSidebar` | `boolean?` | 사이드바를 열지 않고 제출/미리 채우려면 false로 설정하세요                                  |

MCP 앱 임베드 내부에서 이를 실행하는 경우, 또는 사이드바를 열지 않고 실행을 백그라운드로 보내는 경우는 모두 [고급](/docs/client-advanced#background-send)에서 다룹니다.

## 동적 제안 {#dynamic-suggestions}

대화가 시작되기 전, `<AgentSidebar>`, `<AgentPanel>`, `<AssistantChat>`은 빈 채팅에 프롬프트 칩을 보여줍니다. 기본적으로 이는 여러분이 고정한 `suggestions` 목록만이 아닙니다. 프레임워크는 애플리케이션 상태에서 `navigation`, `selection`, `pending-selection-context`, 그리고 현재 URL을 읽어, 실제 화면에 있는 내용과 일치하는 칩을 병합합니다.

이는 두 가지 검사를 통해 이루어집니다. 무언가가 선택되어 있으면 "이 선택 항목 요약"과 같은 일반적인 칩을 추가합니다. 별도로, `navigation`에서 이메일 스레드의 `threadId`/`emailId`나 차트의 `dashboardId`/`chartId`처럼 이미 여러 앱이 사용하는 흔한 필드 이름을 찾아, 스레드에는 "답장 초안 작성", 차트에는 "이 데이터에서 이상치 찾기"처럼 그 화면 종류에 맞는 칩을 추가합니다. 그 결과는 여러분의 고정 `suggestions`와 병합되고, 중복이 제거되며, `max`로 상한이 설정됩니다.

```tsx
<AgentSidebar
  suggestions={["Summarize my inbox"]}
  dynamicSuggestions={{ max: 4 }}
>
  <App />
</AgentSidebar>
```

현재 화면이 이 휴리스틱이 인식하는 어떤 것과도 일치하지 않고 아무것도 선택되어 있지 않다면, 이는 아무 칩도 제공하지 않고 빈 채팅은 여러분의 고정 `suggestions`만으로 되돌아갑니다. 고정 칩만 유지하려면 `dynamicSuggestions={false}`를 설정하세요. 앱의 내비게이션 형태가 내장 휴리스틱과 맞지 않거나, 완전히 결정론적인 앱 전용 칩을 원한다면 [고급](/docs/client-advanced#custom-suggestions)을 참조하세요.

## openAgentSettings(section?) {#openagentsettings}

앱 설정 페이지나 설정 카드가 에이전트 사이드바의 설정 탭을 열어야 할 때
`openAgentSettings()`를 사용하세요. 특정 섹션을 열려면 `"llm"`, `"secrets"`,
`"automations"`, `"voice"`, `"limits"`와 같은 섹션 id를 전달하세요.

```ts
import { openAgentSettings } from "@agent-native/core/client/navigation";
openAgentSettings();
openAgentSettings("secrets");
```

`agent-panel:open-settings`를 직접 디스패치하는 것보다 이 헬퍼를 사용하는 것을 우선하세요.

## Agent 채팅 컨텍스트 상태 {#agent-chat-context-state}

컨텍스트 상태 API는 단계적으로 준비된 컨텍스트 칩과 양방향 동기화가 필요한 UI를 위한 선택적 배관입니다: 현재 준비된 항목을 작성기 밖에서 렌더링하거나, 어떤 항목이 이미 첨부되어 있는지 반영하거나, 명시적인 제거/삭제 컨트롤을 제공하는 경우입니다.

단순한 "이것을 에이전트에게 보내기"나 "이 초안을 검토용으로 미리 채우기" 흐름에는 이 헬퍼들을 사용하지 마세요. 그런 경우에는 [`sendToAgentChat()`](#sendtoagentchat)을 `context`와 `submit`과 함께 사용하세요.

| API                               | 사용 시점                                                                |
| --------------------------------- | ------------------------------------------------------------------------ |
| `useAgentChatContext()`           | React 컴포넌트가 현재 준비된 컨텍스트 목록을 실시간으로 필요로 할 때     |
| `setAgentChatContextItem(item)`   | 명령형 코드가 키를 가진 컨텍스트 항목 하나를 준비하거나 대체해야 할 때   |
| `listAgentChatContext()`          | React가 아닌 코드가 준비된 컨텍스트의 일회성 스냅샷이 필요할 때          |
| `removeAgentChatContextItem(key)` | UI가 안정적인 `key`로 준비된 컨텍스트 항목 하나를 제거해야 할 때         |
| `clearAgentChatContext()`         | 화면이나 모드가 재설정된 뒤처럼 UI가 준비된 컨텍스트를 전부 지워야 할 때 |
| `refreshAgentChatContext()`       | 명령형 코드가 최신으로 저장된 컨텍스트 스냅샷을 다시 읽어야 할 때        |

`useAgentChatContext()`는 `{ items, set, remove, clear, refresh }`를 반환합니다.

```tsx
import { useAgentChatContext } from "@agent-native/core/client/agent-chat";

function SelectedTicketContextButton({ ticket }: { ticket: { id: string } }) {
  const chatContext = useAgentChatContext();
  const contextKey = `selected-ticket:${ticket.id}`;
  const isAttached = chatContext.items.some((item) => item.key === contextKey);

  return (
    <button
      type="button"
      onClick={() => {
        if (isAttached) {
          chatContext.remove(contextKey);
          return;
        }

        chatContext.set({
          key: contextKey,
          title: "Selected Ticket",
          context: JSON.stringify(ticket, null, 2),
          openSidebar: false,
        });
      }}
    >
      {isAttached ? "Remove from prompt context" : "Add to prompt context"}
    </button>
  );
}
```

`listAgentChatContext()`는 현재 준비된 항목을 한 번만 검사하면 되는 명령형 코드를 위한 것입니다. `clearAgentChatContext()`는 의도적으로 광범위합니다. 선택 항목 하나만 바뀌었다면 `removeAgentChatContextItem(key)`를 사용하세요.

### AgentChatContextSetOptions {#agentchatcontextsetoptions}

| 옵션          | 유형       | 설명                                                                 |
| ------------- | ---------- | -------------------------------------------------------------------- |
| `key`         | `string`   | 기존 항목을 대체하는 데 사용되는 안정적인 식별자                     |
| `title`       | `string`   | 작성기 칩에 표시되는 짧은 레이블                                     |
| `context`     | `string`   | 다음에 제출되는 프롬프트에 포함되는 숨겨진 컨텍스트                  |
| `openSidebar` | `boolean?` | 기본값은 true입니다. 조용히 컨텍스트를 준비하려면 false를 전달하세요 |
