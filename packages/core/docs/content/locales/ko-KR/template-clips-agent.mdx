# Agent와 대화

클립의 모든 기능은 UI가 사용하는 것과 같은 액션을 통해 에이전트에게도 그대로 제공되므로, 클릭으로 할 수 있는 일은 말로도 요청할 수 있습니다. 이 페이지는 에이전트가 화면을 어떻게 보는지, 작업별로 유용한 프롬프트가 무엇인지, 그리고 흔치 않은 액션에는 어떻게 접근하는지를 다룹니다. 전체 개요는 [클립](/docs/template-clips) 문서를 참고하세요.

## 에이전트가 화면을 보는 방식

녹화를 열어둔 상태라면 에이전트는 어떤 녹화인지, 지금 보고 있는 사이드 패널(댓글, 전사, 인사이트)과 일시정지한 타임스탬프까지 정확히 알고 있습니다. 그래서 녹화 이름이나 시간을 굳이 말하지 않아도 "여기에 댓글 남겨줘"나 "이거 좋은 부분만 잘라줘" 같은 말이 정확히 처리됩니다.

대신 라이브러리를 둘러보고 있다면 에이전트는 그곳에서 무엇을 보고 있는지도 알고 있습니다. 현재 폴더, 검색어, 선택 모드라면 선택한 녹화까지 알고 있습니다.

에이전트가 대신 할 수 없는 한 가지는 녹화를 시작하는 것입니다. 브라우저는 사람이 무언가를 클릭한 뒤에만 마이크와 화면 접근 권한을 부여하므로, "내 화면 녹화해줘"라고 하면 백그라운드에서 보이지 않게 캡처를 시작하는 대신 곧바로 레코더로 이동시킵니다.

## 작업별 유용한 프롬프트

아래 프롬프트는 모두 실제 라이브러리에 대한 실제 액션이 되며, UI가 읽고 쓰는 것과 동일한 라이브러리를 대상으로 합니다. 실제로 동작하는 예시 하나를 살펴보겠습니다.

<Comparison>

### :blue: 여러분이 묻습니다

"제품 업데이트를 위해 이 클립을 요약해줘."

### :green: 일어나는 일

읽기만 하는 질문입니다. 에이전트가 열려 있는 녹화의 전사를 읽고 채팅에서 바로 답합니다. 아무것도 만들거나 옮기지 않았으므로 화면에는 아무 변화가 없습니다.

</Comparison>

<Cards columns={2}>

### 캡처와 가져오기

- **"내 화면 녹화해줘."** 에이전트가 레코더를 열어줍니다. 브라우저가 요구하기 때문에 캡처를 시작하는 것 자체는 여전히 여러분의 클릭이 필요합니다.
- **"이 Loom 링크 가져와줘."** URL을 붙여넣으면 가져오기가 끝나는 즉시 녹화가 라이브러리에 추가됩니다.

### 정리하기

- **"제목과 요약을 다시 생성해줘."** 에이전트가 현재 전사를 바탕으로 둘 다 다시 작성합니다.
- **"챕터를 추가해줘. 이건 길어."** 챕터 마커가 타임라인에 즉시 나타납니다.
- **"1:42에 잘못 전사된 단어를 고쳐줘."** 에이전트가 전사를 그 자리에서 수정합니다.
- **"출시 계획에 대해 논의한 클립을 찾아줘."** 읽기만 하는 질문입니다. 에이전트가 라이브러리의 모든 전사를 검색해 채팅에서 답합니다.

### 편집

_녹화를 열어둔 상태에서는 "이거"가 지금 보고 있는 클립으로 자동 해석됩니다._

- **"처음 10초를 잘라줘."** 자르기가 타임라인에 즉시 나타나며, 내보내기 전까지는 아무것도 다시 인코딩되지 않습니다.
- **"음이랑 어를 제거하고 다시 이어붙여줘."** 에이전트가 전사에서 필러 단어를 찾아 같은 방식의 자르기를 적용합니다.
- **"이 세 클립을 이 순서대로 하나로 합쳐줘."** 에이전트가 전사와 챕터를 유지하면서 클립들을 이어붙입니다.

### 공유와 검토

- **"누가 이 클립을 보고 있어?"** 읽기만 하는 질문입니다. 에이전트가 사람과 전사를 읽는 다른 에이전트로 구분한 조회수로 답합니다.
- **"이거 디자인 팀에 보기 전용으로 공유해줘."** 녹화의 공개 범위와 접근 권한이 즉시 업데이트됩니다.

</Cards>

## 흔치 않은 액션

클립의 모든 기능이 에이전트가 미리 불러온 일급 액션인 것은 아닙니다. Rewind의 화면 메모리 액션이 좋은 예로, Rewind를 켠 다음에야 의미가 있기 때문입니다. 요청에 이런 액션이 필요할 때, 에이전트는 호출하기 전에 이름으로 알맞은 도구를 검색합니다. 모든 단축키를 외우는 대신 커맨드 팔레트를 검색하는 것과 비슷합니다. 일상적인 라이브러리 및 편집 작업을 벗어나는 요청에서는 보통 짧은 멈춤으로 이를 알아챌 수 있습니다.
