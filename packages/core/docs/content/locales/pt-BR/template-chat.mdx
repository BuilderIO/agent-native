# Chat

Chat é um starter para desenvolvedores que querem criar o próprio agente. Crie o aplicativo e você recebe uma tela de conversa funcional, um histórico de chats salvo e login, com uma única action de exemplo que o agente já consegue usar. Ele substitui as semanas de trabalho para ligar manualmente uma interface de chat, o armazenamento de conversas e o login a um modelo, para que você comece com um aplicativo pronto para publicar e dedique seu tempo ao que o seu agente realmente faz.

Chat não é um produto acabado para uma tarefa específica. Se você não é desenvolvedor, ou quer algo pronto para usar hoje, comece com [Clips](/docs/template-clips) para gravações de tela, [Slides](/docs/template-slides) para apresentações ou [Design](/docs/template-design) para protótipos interativos.

## O que você recebe

Depois de entrar, o Chat abre na página "Comece aqui", com uma caixa de mensagem. Pergunte qualquer coisa e o agente responde em uma conversa em tela cheia. O restante do que está incluído é propositalmente pequeno.

- **Um chat em tela cheia.** As conversas ocupam a tela inteira, com a caixa de mensagem centralizada até você enviar a primeira mensagem.
- **Uma lista de conversas.** A barra lateral lista seus chats para que você possa iniciar um novo, reabrir um antigo, renomeá-lo, fixá-lo ou arquivá-lo.
- **Uma página Primeiros passos.** Uma página inicial curta com links para os guias de como adicionar sua primeira action e sua primeira tela. Você pode editá-la ou substituí-la.
- **Login e equipes.** Login, cadastro e organizações funcionam desde o início.
- **Uma action de exemplo.** O agente já consegue executar um exemplo simples, para que você veja como uma action funciona antes de escrever a sua.
- **Páginas de administração.** Um visualizador de banco de dados e um painel de observabilidade estão incluídos, mesmo que você nunca os abra.
- **Espaço para mini-apps.** Rotas para pequenas ferramentas isoladas chamadas Extensões estão incluídas, mas desligadas. Um desenvolvedor pode ligá-las.

O Chat deixa de fora tudo o que é específico de um negócio: sem dados prontos, painéis, formulários ou conexões com serviços externos. Você adiciona esses itens.

## Chat em um workspace com múltiplos apps

Se você estiver executando o Chat junto com outros aplicativos sob o [Dispatch](/docs/template-dispatch), ele pode servir como a porta de entrada do seu workspace. Uma única conversa pode alcançar os aplicativos ao redor em vez de existir isolada. Veja [Chat em um workspace com múltiplos apps](/docs/template-chat-integrations) para saber como a conexão funciona.
