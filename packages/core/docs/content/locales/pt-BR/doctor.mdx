# Doctor

Apps e workspaces gerados contêm código-fonte que pode ser alterado no fluxo de desenvolvimento do repositório, inclusive por um frame de agente ao qual ferramentas de workspace e escrita foram concedidas intencionalmente. `agent-native doctor` verifica no código-fonte invariantes críticos de segurança. Ele é somente leitura: nunca edita o código, apenas relata resultados.

`agent-native doctor` verifica problemas de segurança e migração. `migration-manifest` encontra imports listados no `migration-manifest.json` instalado e não pode ser desativado. `feature-dependencies` detecta recursos configurados cujo pacote peer opcional não pode ser resolvido.

Execute a verificação prévia da migração:

```bash
agent-native doctor --only migration-manifest
```

Pré-visualize o upgrade e o diff do codemod sem gravar arquivos:

```bash
npx agent-native upgrade --codemods --dry-run
```

Aplique as reescritas de imports compatíveis:

```bash
npx agent-native upgrade --codemods
```

`--codemods` aplica as reescritas compatíveis por padrão. Adicione `--dry-run` para pré-visualizar sem gravar arquivos. Revise o diff e os avisos antes de aplicar. `--yes` é aceito por compatibilidade e não altera o comportamento. `migration-manifest` não pode ser desativado. Entradas `planned` são apenas avisos e não são reescritas. Entradas ativas são achados; o codemod só as reescreve quando o export de destino está instalado. Exports removidos exigem migração manual. Siga o guia vinculado ao achado ou o [guia de migração do Core 0.197.0](/docs/upgrading-to-0-197), que lista `ts-morph` e os pacotes opcionais de recursos. `guardsRun` na saída JSON lista os guards executados.

O CLI adiciona os comandos `pnpm doctor` e `pnpm agent-native:doctor` a cada novo app e workspace. A partir da raiz de um workspace, ele verifica cada app em `apps/<name>`. Builds falham por padrão quando há achados; use `failOnBuild: false` apenas como exceção revisada.

Entradas marcadas como `planned` aparecem apenas como avisos e não são reescritas. Entradas ativas são achados; o codemod só as reescreve quando o export de destino está instalado.
