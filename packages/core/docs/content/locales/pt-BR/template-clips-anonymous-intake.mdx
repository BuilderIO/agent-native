# Recepção anônima do Clips

Esse fluxo permite que um visitante envie uma gravação privada sem entrar no Clips. O produto confiável cria o link de recepção. O link fica separado dos links de leitura do agente.

Consulte o [guia completo em inglês](/docs/template-clips-anonymous-intake) para integração, limites de segurança e requisitos de hospedagem própria.
