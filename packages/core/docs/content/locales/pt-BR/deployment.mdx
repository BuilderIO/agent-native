## Antes do deploy: escolha um banco persistente {#persistent-database}

Todo app publicado precisa de um banco SQL persistente. Defina `DATABASE_URL` no ambiente de deploy antes do primeiro deploy de produção. Use `DATABASE_AUTH_TOKEN` quando o provedor exigir um token separado.

Apps independentes precisam de um `BETTER_AUTH_SECRET` estável. Workspaces com requisições assinadas entre apps precisam de `A2A_SECRET`.

## Destinos compatíveis

O Agent-Native oferece suporte a Node.js, Vercel, Netlify, Cloudflare, AWS Lambda e Deno Deploy.

Consulte a [referência de variáveis de ambiente de deploy](/docs/deployment-environment-variables) para configurações avançadas, segredos e produção.
