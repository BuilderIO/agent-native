# Conteúdo

O Conteúdo é o Obsidian de código aberto para MDX: um espaço de trabalho de
documentos compatível com arquivos locais, onde o agente pode ler, escrever,
reorganizar e publicar páginas para você. Abra um documento e peça "reescreva
este parágrafo para ficar mais conciso" ou "crie uma página chamada
Planejamento do T4 com subpáginas para Metas, Métricas e Riscos". O resultado
é o mesmo, seja você mesmo quem faz isso ou quem pede ao agente.

## O que você pode fazer com isso

- **Escreva e organize documentos.** Edição de texto rico, uma árvore de páginas com aninhamento infinito, favoritos, comentários, histórico de versões e compartilhamento. Veja [Escrevendo e organizando documentos](/docs/template-content-editing).
- **Crie bancos de dados no estilo Notion.** Tabelas em que cada linha é o seu próprio documento, com propriedades tipadas e visualizações em tabela, lista, galeria, quadro, calendário, linha do tempo e formulário. Veja [Bancos de dados, propriedades e formulários](/docs/template-content-databases).
- **Colete envios estruturados.** Transforme um banco de dados em um formulário de admissão no qual o agente, o Slack ou outro aplicativo podem enviar dados com segurança. Veja [Bancos de dados, propriedades e formulários](/docs/template-content-databases).
- **Edite arquivos no disco como no Obsidian** e mantenha os documentos sincronizados com o Notion ou o Builder CMS. Veja [Sincronização com arquivos locais, Notion e Builder CMS](/docs/template-content-sync).
- **Colabore em tempo real.** Várias pessoas (e o agente) podem editar o mesmo documento ao mesmo tempo sem que as alterações de uma sobrescrevam as da outra.
- **Compartilhe documentos** com colegas de equipe ou torne-os públicos. São privados por padrão, com funções de visualizador, editor e administrador.
- **Peça qualquer coisa ao agente**: "Reescreva este parágrafo." "Adicione um TL;DR no topo." "Encontre todas as minhas anotações de reuniões da semana passada." "Crie um banco de dados de inscrições beta com um formulário para envios pelo Slack."

## Primeiros passos

Demonstração ao vivo: [content.agent-native.com](https://content.agent-native.com).

Ao abrir o aplicativo, clique em **+ Nova página** na barra lateral, dê um título a ela e comece a escrever. Para usar o agente, digite na barra lateral:

- "Crie uma página chamada Onboarding e adicione três subpáginas abaixo dela."
- "Reescreva este parágrafo para ficar mais conciso." (com uma página aberta)
- "Adicione uma seção sobre preços com três marcadores."
- "Resuma este documento em um TL;DR no topo."
- "Extraia as últimas atualizações do Notion." (depois de vincular uma página do Notion)

Selecione um texto e pressione Cmd+I para focar o agente com essa seleção já carregada. Assim, "deixe isso mais impactante" opera exatamente sobre o que você destacou.

Para criar sua própria cópia do Conteúdo:

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

Veja [Primeiros passos](/docs/getting-started) para o restante da configuração (`cd`, `pnpm install`, `pnpm dev`) e os fundamentos do framework.
