# Conteúdo

O Conteúdo é o Obsidian de código aberto para MDX: um espaço de trabalho de
documentos compatível com arquivos locais, onde o agente pode ler, escrever,
reorganizar e publicar páginas para você. Abra um documento e peça "reescreva
este parágrafo para ficar mais conciso" ou "crie uma página chamada
Planejamento do T4 com subpáginas para Metas, Métricas e Riscos". O resultado
é o mesmo, seja você mesmo quem faz isso ou quem pede ao agente.

## O que ele substitui

<Comparison>

### Before

- Obsidian, ou uma pasta de arquivos Markdown locais, para notas privadas
- Um espaço de trabalho separado no Notion para documentos que uma equipe pode navegar em conjunto
- Um CMS headless para qualquer coisa que vá para um site no ar
- Copiar o conteúdo entre os três manualmente sempre que um deles ficar desatualizado

### After

- Um único espaço de trabalho para páginas privadas, documentos de equipe e conteúdo publicado
- O mesmo documento pode sincronizar com arquivos locais, Notion ou Builder CMS, em vez de ser redigitado em cada um deles
- O agente lê e escreve através das mesmas actions e das mesmas páginas que você usa
- Uma alteração vinda de uma fonte externa chega como um conjunto de mudanças revisável, nunca como uma sobrescrita silenciosa

</Comparison>

Os documentos são privados por padrão, com compartilhamento nos níveis de visualizador, editor e administrador, e um modo de leitura pública para quando você quiser deixar um deles disponível para o mundo. Várias pessoas (e o agente) podem editar a mesma página ao mesmo tempo sem que as alterações de uma sobrescrevam as da outra. Veja [Escrevendo e organizando documentos](/docs/template-content-editing), [Bancos de dados, propriedades e formulários](/docs/template-content-databases) e [Sincronização com arquivos locais, Notion e Builder CMS](/docs/template-content-sync) para se aprofundar em cada um desses temas.

## Comece agora {#get-started}

```bash
npx @agent-native/core@latest create my-content --standalone --template content
```

Veja [Conteúdo: Guia do desenvolvedor](/docs/template-content-developers#quick-start) para instalação, primeira execução e conexão com um LLM.

Ao abrir o aplicativo, clique em **+ Nova página** na barra lateral, dê um título a ela e comece a escrever, ou peça diretamente ao agente:

- "Crie uma página chamada Onboarding e adicione três subpáginas abaixo dela."
- "Reescreva este parágrafo para ficar mais conciso." (com uma página aberta)
- "Extraia as últimas atualizações do Notion." (depois de vincular uma página do Notion)

Selecione um texto e pressione Cmd+I para focar o agente com essa seleção já carregada — "deixe isso mais impactante" então opera exatamente sobre o que você destacou.
