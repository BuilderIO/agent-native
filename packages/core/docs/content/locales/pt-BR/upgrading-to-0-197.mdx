# Atualizar apps existentes para Core 0.197.0

Use este guia para atualizar um app existente para Core 0.197.0. Execute os
comandos na raiz do app ou workspace e mantenha um diff revisável antes de
começar. Verifique separadamente as configurações dos ambientes remotos: a CLI
pode ler arquivos de ambiente locais, mas não consegue inspecionar ambientes
remotos nem configurações de recursos salvas no banco de dados.

## 1. Visualizar o upgrade e os codemods de imports

Use a CLI incluída no Core 0.197.0 para carregar o manifesto de migração dessa
versão:

    npx @agent-native/core@0.197.0 upgrade --codemods --dry-run

Depois que o Core 0.197.0 estiver instalado no app, a mesma prévia fica disponível pelo binário local do CLI:

    npx agent-native upgrade --codemods --dry-run

O comando `--codemods` usa `ts-morph`. Se o pacote ainda não puder ser resolvido pelo app, instale-o primeiro como dependência de desenvolvimento: `pnpm add -D ts-morph`.

`--codemods` aplica as alterações de import compatíveis por padrão. Adicione `--dry-run` para
pré-visualizar as mudanças previstas nas dependências, o diff dos arquivos e os avisos antes
de continuar. `--yes` não é mais necessário.

O codemod usa os manifestos ativos de migração do Core e do Toolkit. Ele analisa
somente arquivos .ts e .tsx (exceto arquivos de declaração, gerados e diretórios de
dependências) e reescreve especificadores de import e re-export compatíveis.
Quando exports nomeados migram para módulos diferentes, ele pode dividir uma
declaração por símbolo, preservando aliases e imports somente de tipos. Também
reescreve caminhos simples de CSS @import e adiciona uma dependência ausente
quando uma reescrita resolvida cruza o limite de um pacote.

O diagnóstico também detecta formas CommonJS com `require()` e formas de `import()` dinâmico, mas o codemod não reescreve essas expressões de chamada. Substitua-as usando o novo destino indicado no relatório e execute novamente o Vite ou `agent-native doctor`. Caminhos CSS `@import url(...)` são modificados pelo codemod com ou sem aspas.

Ele não altera os pontos de chamada nem move seus arquivos. Movimentos não
resolvidos ou planejados permanecem sem alteração e geram avisos. Ele não pode
dividir imports ou exports default, namespace, side-effect ou star; não divide imports CSS por símbolo. Revise esses casos
manualmente. Exports removidos podem exigir mudanças no código; siga o guia de
migração citado no aviso da CLI.

A prévia também mostra o plano completo do upgrade: overrides ou patches do
framework que bloqueiam a operação, atualizações pendentes de versões
@agent-native/\*, dependências de recursos inferidas da configuração local, a
instalação do gerenciador de pacotes, atualização das skills de scaffold e
typecheck quando o pacote raiz tiver esse script. O comando muda as versões
para latest no registry e depois fixa as versões resolvidas pela instalação.
Execute quando 0.197.0 for a versão atual desejada; se precisar de uma versão
exata mais tarde, confira os pins resolvidos.

## 2. Confirmar o Toolkit e os pacotes opcionais

Imports movidos para `@agent-native/toolkit/*` exigem `@agent-native/toolkit`. O codemod adiciona o Toolkit quando move para lá um import ou export compatível e resolvido. Se o app usa um export do Toolkit e a dependência não foi adicionada, instale a versão do Toolkit correspondente ao Core 0.197.0:

    pnpm add @agent-native/toolkit@0.197.0
    # npm install @agent-native/toolkit@0.197.0
    # yarn add @agent-native/toolkit@0.197.0

### Dependências selecionadas pelo CLI de atualização

O CLI adiciona estas dependências quando as verificações do ambiente local correspondem. Ele não consegue inspecionar ambientes remotos nem configurações de recursos armazenadas no banco de dados; verifique produção e prévia separadamente.

## 3. Aplicar o upgrade

Depois de revisar a simulação e confirmar os pacotes dos recursos, aplique o
plano:

    npx agent-native upgrade --codemods

Esse único comando atualiza especificações elegíveis de dependências
@agent-native/\*, alinha as dependências de recursos detectados, executa o
gerenciador de pacotes, fixa as versões resolvidas do Agent-Native, aplica os
codemods compatíveis, atualiza as skills de scaffold e executa o script
typecheck da raiz quando existir. Não execute outro upgrade apenas para aplicar
os codemods. Corrija avisos e erros do app no código do app; não adicione
overrides nem patches do framework.

## 4. Verificar o resultado

Revise o diff completo, especialmente avisos de codemods ignorados e versões de
dependências, e então execute:

    npx @agent-native/core@0.197.0 upgrade check
    pnpm typecheck

Use o comando equivalente de typecheck para npm ou Yarn e execute os testes e o
build relevantes do app. Confirme que a tabela de peers opcionais cobre as
configurações locais e de produção. Pesquise os imports antigos da tabela
abaixo; ocorrências restantes devem ser intencionais, não suportadas pelo
manifesto ou explicadas por um aviso.
