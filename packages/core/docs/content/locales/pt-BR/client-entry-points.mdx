# Pontos de entrada

`app/entry.client.tsx` hidrata o HTML renderizado pelo servidor no navegador, e `app/entry.server.tsx` renderiza esse HTML no servidor. Ambos são wrappers leves gerados pelo React Router. Você raramente precisa editá-los.

```ts filename="app/entry.server.tsx"
import {
  createDocumentRequestHandler,
  streamTimeout,
} from "@agent-native/core/server/entry-server";
import { ServerRouter } from "react-router";

export default createDocumentRequestHandler(ServerRouter);
export { streamTimeout };
```

Recorra a eles apenas para personalização avançada de SSR, por exemplo mudando o comportamento de streaming. Páginas, layout e dados comuns não precisam de mudanças aqui. Veja [Roteamento](/docs/client-routing) para adicionar páginas em vez disso.
