# Portal

O Portal emparelha um computador para execução entre dispositivos. Abra **Configurações → Workspace → Emparelhar ou reparar** e salve o token do dispositivo no arquivo privado `~/.agent-native/remote-device.json` do computador.

Os modos de execução são **Local**, **Computer** e **Cloud**. **Cloud** está em lista de espera e não inicia uma execução até que o acesso seja habilitado.
