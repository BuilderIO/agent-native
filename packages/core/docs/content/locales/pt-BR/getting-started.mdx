# Primeiros passos

Os apps Agent-Native dão ao agente e à interface de usuário as mesmas
[ações](/docs/actions), dados SQL e estado da aplicação. Este caminho começa com
o Chat, que já armazena o histórico do chat em SQL. Adicione suas próprias tabelas
somente quando o app precisar persistir dados do domínio.

<Steps>

### Crie um app de chat e configure um agente

Gere o template Chat, instale as dependências, inicie o servidor de desenvolvimento
e configure um agente. Você terá um app de chat funcional para ampliar.
**Você está aqui.**

### Adicione uma ação

Defina um analisador de texto tipado e renderize o resultado como um gráfico no chat.

### Adicione uma página

Crie uma rota React que chame a mesma ação fora da transcrição.

</Steps>

## 1. Crie um app de chat {#create-your-app}

Você precisará de [Node.js 22+](https://nodejs.org) e [pnpm](https://pnpm.io).

Abra um terminal, vá até o diretório onde deseja criar seu app Agent Native e execute:

```bash
npx @agent-native/core@latest create my-app --template chat
cd my-app
pnpm install
pnpm dev
```

O app abre em `http://localhost:8080`. Se você vir a tela de login, cadastre-se
com um login fictício. O desenvolvimento local não exige verificação de e-mail.

O template Chat inclui threads de chat duráveis, autenticação, sincronização em
tempo real, um diretório `actions/` e as ações padrão `view-screen` e `navigate`.

### Escolha um ponto de partida diferente

Se o Chat não for o ponto de partida certo, execute `create` sem `--template` e
escolha outra opção na CLI. Consulte [Criando modelos](/docs/creating-templates)
para conhecer os outros caminhos.

## 2. Configure um agente {#connect-ai}

O template Chat abre diretamente na superfície de chat. Se o agente ainda não estiver
pronto para responder, abra **Configurações > Gerenciar agente** ou use
**Cmd/Ctrl+K > Gerenciar agente** para configurar um modelo e um provedor.

Quando o agente responder, continue com [Adicionar uma ação](/docs/getting-started-actions).
