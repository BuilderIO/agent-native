# Adicione uma UI ao seu agente

O Agent-Native dá ao agente existente um workspace para chat, aprovações, estado de fluxo e permissões. O provedor mantém raciocínio, ferramentas, contexto e execuções longas.

Esta página explica **como adicionar uma UI a agentes Microsoft Foundry, Gemini Enterprise, Anthropic Managed Agents ou OpenAI**.

## Escolha uma conexão {#choose-a-connection-path}

| Backend                  | Conexão no Agent-Native    | Configuração                               |
| ------------------------ | -------------------------- | ------------------------------------------ |
| Microsoft Foundry        | A2A 1.0                    | URL do Agent Card e segredo Entra          |
| Gemini Enterprise        | A2A                        | URL do Agent Card e segredo Google         |
| Anthropic Managed Agents | Managed Agents API         | ID do agente, ambiente e chave do vault    |
| OpenAI Agents API        | Endpoint A2A personalizado | URL do Agent Card e credencial do provedor |
| Qualquer agente A2A      | A2A                        | URL do Agent Card e credenciais opcionais  |

Abra **Settings → Agent → Sub-agents** e selecione **Connect agent** (proprietários e administradores). Os botões Connect abrem o formulário de conexão com o provedor correto. Os segredos ficam no vault do workspace.

## Microsoft Foundry {#microsoft-foundry}

Cole a URL do Agent Card A2A v1.0 e escolha as credenciais Entra. Para serviço a serviço use `https://ai.azure.com/.default` e o papel **Foundry Agent Consumer**.

## Gemini Enterprise {#gemini-enterprise}

Cole a URL personalizada do card A2A e escolha o segredo bearer. O Agent-Native valida o card e a interface JSON-RPC antes de salvar.

## Anthropic Managed Agents {#anthropic-managed-agents}

Escolha **Anthropic Managed Agents**, informe os IDs do agente e do ambiente e selecione a chave de API. Sessões e aprovações aparecem no chat Agent-Native.

## A2A personalizado {#custom-a2a}

Use **Add by URL** para agentes internos ou auto-hospedados. Cards A2A 0.3 e 1.0 são validados e falhas aparecem com estados claros.

Quando o streaming não está disponível, a conexão usa `message/send`.

## Registros {#registries}

Navegue pela [Global A2A Registry](https://www.a2a-registry.org). Verifique card, host e autenticação antes de adicionar o agente e usar um segredo.

## Camada de UI {#ui-layer}

[A2A](/docs/a2a-protocol) transporta a tarefa delegada e o workspace Agent-Native mantém o estado do usuário. Veja [Connected agents](/docs/agent-mentions#mentioning-agents) e [External agents](/docs/external-agents).
