# Fazer deploy de um app

Consulte o [guia completo em inglês para fazer deploy de um app](/docs/deploy-an-app) para ver as etapas e os comandos de cada provedor.

Comece pelo [guia de início](/docs/getting-started). Antes do deploy, defina `DATABASE_URL` nas configurações de ambiente do provedor de hospedagem, não apenas no `.env` local. Gere um `BETTER_AUTH_SECRET` estável com `openssl rand -hex 32` e salve-o no mesmo lugar. **Continue as local dev** funciona apenas localmente; o app publicado usa cadastro e login. Escolha [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Amplify](/docs/aws-amplify), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) ou [Render](/docs/render).

Para vários apps em uma origem, use [Deploy de workspace](/docs/workspace-deployment).
