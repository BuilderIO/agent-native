# Fazer deploy de um app

Consulte o [guia completo em inglês para fazer deploy de um app](/docs/deploy-an-app) para ver as etapas e os comandos de cada provedor.

Antes do deploy, configure um banco SQL persistente e um `BETTER_AUTH_SECRET` estável. Escolha [Node.js](/docs/node-js), [Docker](/docs/docker), [Vercel](/docs/vercel), [Netlify](/docs/netlify), [Cloudflare Pages](/docs/cloudflare#cloudflare-pages), [Cloudflare Workers](/docs/cloudflare#cloudflare-workers), [AWS Lambda](/docs/aws-lambda), [Deno Deploy](/docs/deno-deploy), [Azure Static Web Apps](/docs/azure-static-web-apps), [Koyeb](/docs/koyeb) ou [Render](/docs/render).

Para vários apps em uma origem, use [Deploy de workspace](/docs/workspace-deployment).
