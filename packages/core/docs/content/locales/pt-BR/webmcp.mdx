# WebMCP

WebMCP é uma API experimental do navegador que permite às páginas registrar
ferramentas para que um agente autorizado as descubra e execute. Consulte o
[guia de WebMCP em inglês](/docs/webmcp) sobre registro, consumo, sessões do
navegador e limites de segurança.
Cada execução exige aprovação humana, e a lista ativa de ferramentas é validada antes da chamada.
