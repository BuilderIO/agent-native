# Atualizando a UI em Produção

O agente comum de um app implantado trabalha através de ferramentas do app
(actions, banco de dados, MCP e integrações configuradas) em vez de receber
acesso ambiente ao código-fonte do app. Alterações de código-fonte pertencem
ao fluxo de desenvolvimento do repositório. Um quadro embutido, local ou do
Builder pode editar o repositório quando esse quadro recebe intencionalmente
ferramentas de espaço de trabalho e de escrita.

Em uma implantação de produção padrão com [execução de código em produção](/docs/actions-agent-tools#production-code-execution) desativada, o agente tem acesso a ferramentas do app (actions, banco de dados, MCP), mas não ao sistema de arquivos. Isso significa que o agente pode ler e gravar dados, executar actions e interagir com serviços externos. Ele não pode editar seus componentes React nem adicionar novas rotas em uma instância implantada.

## Builder.io: Edição Visual em Produção {#builderio}

[Builder.io](https://www.builder.io?utm_source=agent-native&utm_medium=docs&utm_campaign=framework&utm_content=deployment) é um fluxo de trabalho gerenciado separado, com capacidade de código, no qual um agente pode modificar a UI do seu app em produção. Use o Builder.io com seu repositório (nível gratuito disponível) e peça alterações de UI diretamente. Nenhuma reimplantação é necessária.

A ação **Use o Builder.io** em Configurações inicia o Builder OAuth (`builder:ai:invoke`) com um callback HTTPS da mesma origem em `/_agent-native/builder/callback`. Assim, domínios hospedados como o Railway funcionam sem uma lista de permissões. As chaves privadas `BUILDER_*` antigas continuam como alternativa em tempo de execução para conexões existentes.

**Como funciona:**

1. Use o Builder.io com seu repositório agent-native (nível gratuito disponível)
2. O Builder.io fornece um quadro de nuvem com o agente, edição visual e colaboração em tempo real
3. Peça ao agente para fazer alterações na UI. Ele edita seus componentes, rotas e estilos ao vivo
4. As alterações são commitadas de volta ao seu repositório

Veja [Superfícies do Agente](/docs/agent-surfaces) para saber mais sobre as opções de agente incorporado e hospedado.
