# Cloudflare

## Cloudflare Workers {#cloudflare-workers}

Use a saída nativa de módulos do Nitro para um Cloudflare Worker. Isso mantém
o SSR habilitado e gera o ponto de entrada do Worker além dos assets
estáticos em `.output/server` e `.output/public`:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Compile e implante o Worker gerado com o Wrangler:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

Você também pode selecionar o preset explicitamente com
`NITRO_PRESET=cloudflare_module`. Configure um banco de dados PostgreSQL externo
durável antes de implantar. O sistema de arquivos de um Worker não é um
armazenamento persistente para o app.

## Trabalho agendado {#cloudflare-scheduled-work}

Automações agendadas, automações por evento na fila e a limpeza de execuções
interrompidas acontecem em uma varredura executada uma vez por minuto. O build
adiciona um
[Cron Trigger](https://developers.cloudflare.com/workers/configuration/cron-triggers/)
`* * * * *` ao `wrangler.json` gerado e mantém os Cron Triggers que você já
tiver declarado. Quando ele dispara, o handler `scheduled` do Worker chama a
varredura diretamente com um token de curta duração assinado com `A2A_SECRET`,
então defina esse segredo antes de implantar:

```bash
npx wrangler secret put A2A_SECRET --config .output/server/wrangler.json
```

- **Tempo de CPU.** No plano gratuito do Workers, cada invocação de Cron Trigger
  recebe 10 ms de tempo de CPU, e uma varredura que executa trabalhos do agente
  precisa de mais. Use o plano pago do Workers para trabalho agendado.
- **Horário.** Cron Triggers rodam em UTC, e um gatilho novo ou alterado pode
  levar até 15 minutos para começar a disparar após uma implantação.
- **Teste local.** Execute o Worker compilado com
  `npx wrangler dev --test-scheduled --config .output/server/wrangler.json` e
  depois faça uma requisição para `/cdn-cgi/handler/scheduled?cron=*+*+*+*+*`
  para disparar a varredura uma vez.

Veja [Como o agendador é executado](/docs/recurring-jobs#how-scheduler-runs)
para os outros hosts.
