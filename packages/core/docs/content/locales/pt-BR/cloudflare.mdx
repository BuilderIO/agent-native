# Cloudflare

## Cloudflare Workers {#cloudflare-workers}

Use a saída nativa de módulos do Nitro para um Cloudflare Worker. Isso mantém
o SSR habilitado e gera o ponto de entrada do Worker além dos assets
estáticos em `.output/server` e `.output/public`:

```ts filename="vite.config.ts"
export default defineConfig({
  plugins: [agentNative({ nitro: { preset: "cloudflare_module" } })],
});
```

Compile e implante o Worker gerado com o Wrangler:

```bash
pnpm build
npx wrangler deploy --config .output/server/wrangler.json
```

Você também pode selecionar o preset explicitamente com
`NITRO_PRESET=cloudflare_module`. Configure um banco de dados PostgreSQL externo
durável antes de implantar. O sistema de arquivos de um Worker não é um
armazenamento persistente para o app.
