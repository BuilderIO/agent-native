# Features

Every core Slides feature: how it works, and how to set it up. See
[Slides](/docs/template-slides) for the overview and [Talk to the
Agent](/docs/template-slides-agent) for the full list of prompts.

## Decks

Everything about creating, editing, presenting, and sharing an individual deck.

### Generate a deck from a prompt

<Steps>

### Brief the agent like you'd brief a person

"Generate a 10-slide pitch deck for a coffee subscription service, audience is investors." Give it a topic, a length, and an audience, and it shapes the outline around them.

### Watch it build slide by slide

The agent plans the outline first, then builds the deck one slide at a time so you watch it appear in the editor rather than waiting for the whole thing to land at once.

### Keep refining in the same conversation

"Add a pricing slide after slide 3." "Make this section shorter." Only the slides you asked about change.

</Steps>

Every new deck defaults to a 16:9 widescreen canvas. Ask the agent to switch it to 1:1 (square), 9:16 (vertical, Stories-style), or 4:5 (portrait) when you need a different shape. Changing it updates the editor canvas, presentation mode, and PDF/PPTX export together, so you never end up with an export that doesn't match what you built.

### Edit slides visually

- **Inline text editing.** Double-click any text to edit it directly on the slide.
- **The bubble menu.** Click a block, a heading, a bullet list, an image, to get quick formatting options for just that block.
- **The slash menu.** Type `/` to insert a new block, a heading, bullets, a table, a code block, an image placeholder, without leaving the keyboard.
- **Reordering.** Drag slides in the filmstrip to reorder them; undo and redo work the way you'd expect.
- **Rich embeds.** A slide can hold a hand-drawn diagram or a live-rendered chart alongside your text and images, not just static HTML.
- **Move and resize generated content.** Drag an object to move it, or drag its resize handles to change its size. To move a bordered section, drag its text.

Select text on a slide and click the **Revise with AI** button in the bubble menu to hand the agent that exact selection. Or select multiple elements on your slide, and click **Send to agent**. Then provide a prompt in the chat window on the right. See [Talk to the Agent](/docs/template-slides-agent) for how selection-aware edits work.

### Present full-screen

Click **Present** to open the deck full-screen. Controls fade out until you move the mouse, and your speaker notes stay visible only to you. Once you're presenting, these shortcuts apply:

| Key                  | Action                                  |
| -------------------- | --------------------------------------- |
| `→`, `↓`, or `Space` | Next slide                              |
| `←` or `↑`           | Previous slide                          |
| `F`                  | Toggle fullscreen                       |
| `S`                  | Open speaker notes in a separate window |
| `Esc`                | Exit presentation mode                  |

### Comment and collaborate in real time

Open the **Comments** panel from the toolbar to see and add comments for the slide you're viewing. The panel is scoped to that slide: switch to a different slide and its contents swap to match, so it never shows the whole deck's comments at once. Select text first to quote it in a new comment, or use the toolbar's **Pin comments** tool to drop a persistent pin directly on an element.

Anyone with edit access can comment and reply in a thread. Resolve a thread once it's addressed. Multiple people (and the agent) can edit the same deck at the same time without clobbering each other's changes. See [Real-Time Collaboration](/docs/real-time-collaboration) for how that works under the hood.

### Share a deck

Share a deck the same way you'd share any Agent-Native resource: keep it private, share it with specific teammates as a viewer or editor, or generate a public read-only link anyone can open without an account. See [Sharing](/docs/sharing) for the full model.

### Restore an earlier version

Every meaningful change, yours or the agent's, snapshots the deck first, so nothing is ever silently lost. Open version history to see a timeline of past snapshots and restore any one of them. Restoring takes its own snapshot first too, so a restore is never a dead end.

### Move decks in and out of other formats

| Direction | Formats                      | What happens                                                                                                                                       |
| --------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Import    | PPTX, DOCX, PDF, Google Docs | Converted into editable slides — a PDF or DOCX becomes one slide per page or section, a PPTX keeps its original slide breakdown and speaker notes. |
| Export    | PPTX                         | Native, editable text, shapes, and images — not a flattened image of each slide.                                                                   |
| Export    | Google Slides                | Slides generates the same PPTX and hands you a ready import link, since Google Slides has no direct "open this URL" import.                        |
| Export    | Standalone HTML              | A single self-contained file with built-in keyboard navigation you can host or email anywhere — no app required to view it.                        |

Bringing in a GitHub repo, a codebase, or a website URL is a different feature from importing a deck's content: those three feed the design-system indexing described in [Design Systems](#design-systems), not slide-by-slide content import.

## Design Systems

A design system is a reusable bundle of brand identity: primary/accent/background colors, heading and body fonts, spacing, logos, and free-form custom instructions ("always lowercase the section labels," "never use stock photography"). It's a separate resource from any one deck. Save one and every new deck can use it instead of generic defaults.

### Add a design system

<Steps>

### Open Design Systems

From the sidebar, open **Design Systems** and click **New design system**.

### Add your brand material

Fill in whatever you have: a company name and website, a GitHub repo, code files, documents, reference images or logos, notes, or custom instructions.

### Click Continue to Generation

This starts building your design system. Exactly what happens next depends on what you provided.

</Steps>

#### What happens next depends on the source

Uploading a Figma file or entering only a GitHub repo builds the design system right away. Anything else opens the agent in the sidebar to finish it there instead. There's no color picker or font picker: brand colors and fonts always come from a source the agent interprets, or from what you type in the notes and custom instructions.

#### Set a default

Mark one design system as your default so every new deck picks it up automatically, or choose one explicitly when starting a new deck.

### Builder integration

A Figma file, a connected codebase or GitHub repo, or a `design.md` needs real analysis, so those go through Builder Design System Intelligence instead of a one-shot local guess.

#### Connect Builder

This requires a connected Builder.io account (a free tier is available). If you haven't connected one yet, the agent prompts you to when it needs to.

#### Builder stays the source of truth

Builder indexes the source and owns the resulting docs, extracted tokens, and usage guidance, not Slides. Slides keeps only a lightweight pointer to the result locally, so the agent fetches the current docs from Builder whenever it applies the design system.

### Figma files

A `.fig` file is the one source that starts indexing the moment you drop it, no agent chat step required. Drag a file onto the Figma panel in the setup dialog, or click to browse for one. Slides uploads it and starts a Builder Design System Intelligence indexing job right away, and the result becomes a design system you can apply to any deck once indexing finishes.

### Apply and tweak per deck

Once a design system is linked to a deck, the **Tweaks** panel gives you quick live overrides, an accent color swatch, title casing, background warmth, without editing the saved system directly. A change you keep persists back to the design system.
