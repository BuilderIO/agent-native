# Add a Page

This is part four of the Getting Started series. In [Persist Data in SQL](/docs/getting-started-database)
you saved analysis results. Here you'll build a route that reads those same rows
through `list-text-analyses`.

## Create the route {#add-a-page}

Route files in `app/routes/` are picked up automatically. Create
`app/routes/text-analyses.tsx`; it will be available at
`http://localhost:8080/text-analyses`.

```tsx filename="app/routes/text-analyses.tsx"
import { useActionQuery } from "@agent-native/core/client/hooks";

type TextAnalysis = {
  id: string;
  input: string;
  charCount: number;
  wordCount: number;
  sentenceCount: number;
  paragraphCount: number;
  createdAt: string;
};

export default function TextAnalysesRoute() {
  const { data: analyses = [] } = useActionQuery<TextAnalysis[]>(
    "list-text-analyses",
    {},
  );

  return (
    <main className="mx-auto flex max-w-3xl flex-col gap-6 p-6">
      <header>
        <h1 className="text-2xl font-semibold">Text analyses</h1>
        <p className="text-muted-foreground">Results saved by the agent.</p>
      </header>
      <section className="flex flex-col gap-3">
        {analyses.length === 0 && (
          <p className="text-muted-foreground">No analyses saved yet.</p>
        )}
        {analyses.map((analysis) => (
          <article key={analysis.id} className="rounded-lg border p-4">
            <p className="text-sm font-medium">{analysis.input}</p>
            <p className="text-xs text-muted-foreground">
              {analysis.wordCount} words, {analysis.charCount} characters,{" "}
              {analysis.sentenceCount} sentences, {analysis.paragraphCount}{" "}
              paragraphs
            </p>
          </article>
        ))}
      </section>
    </main>
  );
}
```

`useActionQuery` calls the same action the agent uses. It also refreshes when a
mutating action completes, so a newly saved analysis appears without a custom
API route or a second data layer.

Open `http://localhost:8080/text-analyses`, or ask the agent:

> Navigate to `/text-analyses`.

The route is enough for this tutorial. Add a sidebar entry later if this becomes
a primary workflow. For the full `view-screen`, `navigate`, and application-state
patterns, see [Context Awareness](/docs/context-awareness).
