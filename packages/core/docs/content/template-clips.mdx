# Clips

Clips is an agent-native screen recording app. Record your screen and the agent transcribes, titles, summarizes, and indexes it into one searchable library, so you can ask "find the clip where we discussed the rollout plan" and search across every recording you've ever made. It replaces Loom with one app, so every recording you make lives in one searchable place you own, instead of a separate tool with its own transcript.

The agent is a first-class editor across every recording, and everything you capture is yours, not a SaaS vendor's. Clips also makes a shared recording readable by any agent, not only its own. Pasting a clip's share link into Claude, ChatGPT, or another assistant lets it read the transcript and see timestamped screen frames without downloading raw video. See [Clips in a Multi-App Workspace](/docs/template-clips-integrations) for how that works.

## What it replaces

<Comparison>

### Before

- Loom for screen recordings
- A separate tool, or manual work, for transcripts, titles, and summaries
- Re-recording or re-uploading a clip just to get AI cleanup on it
- No way for an outside agent to actually understand what's in a recording

### After

- One recorder, with Loom import for anything you've already got there
- The agent titles, summarizes, and chapters every recording automatically
- Trim, remove filler words, or combine clips just by asking
- Share links that any agent can read, not only Clips' own

</Comparison>

## Clips in a multi-app workspace

If you run Clips alongside other apps in [Dispatch](/docs/template-dispatch), a recording stops being something you only watch by hand. Other apps can pull ready transcripts into Brain, hand a CRM automation a durable call-evidence link, or ask Clips' agent a question directly, the same way you would in chat. See [Clips in a Multi-App Workspace](/docs/template-clips-integrations) for how this works.

## What you can do with it

- **Record your screen or import from Loom.** Try "record my screen" or paste a public Loom link to bring it into your library. See [Create a clip](/docs/template-clips-features#create-a-clip).
- **Edit non-destructively through chat.** Try "remove the ums and uhs" or "trim the first 10 seconds." See [Non-destructive editing](/docs/template-clips-features#non-destructive-editing).
- **Share and protect what you record.** Set visibility, a password, or an expiry date, and let any agent read a shared clip's transcript. See [Share](/docs/template-clips-features#share).
