Go from zero to an action callable from your **UI**, **HTTP**, **CLI**, **MCP**, and **plain TypeScript** in under two minutes.

`npx @agent-native/actions init` detects your stack, installs the `.agents/skills/agent-native-actions/SKILL.md` coding-agent skill (so Claude Code, Codex, and Cursor build new features as actions automatically), and adds the smallest possible setup:

- **Vite (React, SolidJS, Vue, Svelte):** Adds 1 plugin line (`agentNativeActionsPlugin()`) to `vite.config.ts`. No route files needed.
- **Next.js:** Wraps `next.config.ts` with `withAgentNativeActions()` and adds one single catch-all route at `app/api/agent-native/[...path]/route.ts` (serves both HTTP actions and MCP).
- **Nuxt / SvelteKit:** Adds the single catch-all server handler and Vite/Nuxt integration.
- **Plain Node / No Framework:** Creates `actions/` and adds `"action": "actions"` to `package.json`.

## 1. Define a Simple Action {#define-action}

Create one file per operation inside `actions/`. The filename becomes the action name (`actions/create-todo.ts` → `create-todo`).

```ts
// actions/create-todo.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "Create a new todo item",
  schema: z.object({
    title: z.string().describe("What needs to be done"),
  }),
  run: async ({ title }, ctx) => {
    return db.todos.create({ title, userId: ctx.user.id });
  },
});
```

Add a read action alongside it with `http: { method: "GET" }` and `readOnly: true`:

```ts
// actions/list-todos.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "List todo items for the signed-in user",
  schema: z.object({
    done: z.boolean().optional().describe("Filter by completion status"),
  }),
  http: { method: "GET" },
  readOnly: true,
  run: async ({ done }, ctx) => {
    return db.todos.findMany({ where: { userId: ctx.user.id, done } });
  },
});
```

### From the CLI {#call-from-cli}

```bash
# Discover every action in the repo
pnpm action --list

# Run an action with flags or JSON
pnpm action create-todo --title "Ship docs"
pnpm action list-todos --done false
```

### Over HTTP {#call-from-http}

```bash
curl "http://localhost:3000/api/agent-native/actions/list-todos?done=false"

curl -X POST http://localhost:3000/api/agent-native/actions/create-todo \
  -H "Content-Type: application/json" \
  -d '{"title":"Ship docs"}'
```

### Over MCP (Claude, Cursor, ChatGPT, Codex) {#call-from-mcp}

Point any Streamable HTTP MCP client at your app's single endpoint:

```text
http://localhost:3000/api/agent-native/mcp
```

Or connect locally over `stdio` without running a web server at all:

```json
{
  "mcpServers": {
    "my-app": {
      "command": "npx",
      "args": ["@agent-native/actions", "mcp"]
    }
  }
}
```

### Without a Framework (Plain Node / TypeScript) {#call-without-framework}

No web framework required. Call actions directly in scripts, cron jobs, workers, or tests:

```ts
import { createActions } from "@agent-native/actions";
import createTodo from "./actions/create-todo";
import listTodos from "./actions/list-todos";

const actions = createActions({
  actions: { "create-todo": createTodo, "list-todos": listTodos },
});

const todo = await actions.call(
  "create-todo",
  { title: "Ship docs" },
  { user: { id: "user_1" } },
);
```

## 3. Wire Your Existing Auth (Optional) {#add-auth}

Add `actions/context.ts` to resolve your current user from cookies, bearer tokens, or local CLI env — every surface uses the same context:

```ts
// actions/context.ts
import {
  createActionBuilder,
  type ActionContextInput,
} from "@agent-native/actions";
import { getSession } from "../lib/auth";

export async function createContext({ caller, request }: ActionContextInput) {
  if (caller === "cli") {
    const devUserId =
      process.env.NODE_ENV !== "production"
        ? process.env.DEV_USER_ID
        : undefined;
    return { caller, user: devUserId ? { id: devUserId } : null };
  }
  const session = request ? await getSession(request) : null;
  return { caller, user: session?.user ?? null };
}

export type AppContext = Awaited<ReturnType<typeof createContext>>;
export const defineAppAction = createActionBuilder<AppContext>();
```
