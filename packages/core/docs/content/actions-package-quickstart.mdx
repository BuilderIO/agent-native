# Quickstart

Install `@agent-native/actions`, define a read and write action, and call them from your UI, HTTP API, CLI, MCP server, or plain TypeScript.

## Prerequisites

- Node.js 20+
- Zod v3/v4 (or any [Standard Schema](https://standardschema.dev) validator)

`init` inspects `package.json`, installs `.agents/skills/agent-native-actions/SKILL.md`, creates `actions/hello.ts`, generates `.generated/actions.ts` and `.generated/action-types.d.ts`, adds `"action": "actions"` to `scripts`, and scaffolds the catch-all route for your stack:

- **Next.js:** creates `app/api/agent-native/[...path]/route.ts` and prints the 1-line `withAgentNativeActions()` wrapper to add to `next.config.ts`.
- **Vite (React, SolidJS, Vue, Svelte):** prints the 1-line `agentNativeActionsPlugin()` entry to add to `vite.config.ts`.
- **Nuxt / SvelteKit:** creates the catch-all server handler and prints the 1-line `nuxt.config.ts` or `vite.config.ts` plugin entry.
- **Plain Node / TypeScript:** creates `actions/hello.ts` and `.generated/actions.ts` with no web server required.

## 2. Define Actions {#define-action}

Create one file per operation inside `actions/`. The filename becomes the action name (`actions/create-todo.ts` → `create-todo`):

```ts
// actions/create-todo.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "Create a new todo item",
  schema: z.object({
    title: z.string().describe("What needs to be done"),
  }),
  run: async ({ title }) => {
    return db.todos.create({ title });
  },
});
```

Add a read-only action with `http: { method: "GET" }` and `readOnly: true`:

```ts
// actions/list-todos.ts
import { defineAction } from "@agent-native/actions";
import { z } from "zod";
import { db } from "../lib/db";

export default defineAction({
  description: "List todo items",
  schema: z.object({
    done: z.boolean().optional().describe("Filter by completion status"),
  }),
  http: { method: "GET" },
  readOnly: true,
  run: async ({ done }) => {
    return db.todos.findMany({ where: { done } });
  },
});
```

Running your dev server (or `npx @agent-native/actions generate`) writes two files:

- `.generated/actions.ts` — static registry (`actions`) and `AppActions` type for explicit client factories (`createActionHooks<AppActions>()`).
- `.generated/action-types.d.ts` — ambient module augmentation so the default hook imports infer input and output types automatically.

## 3. Call Your Actions {#call-everywhere}

### UI Hooks {#call-from-ui}

```tsx
import { useActionQuery, useActionMutation } from "@agent-native/actions/react";

export function TodoList() {
  const { data: todos } = useActionQuery("list-todos", { done: false });
  const createTodo = useActionMutation("create-todo");

  return (
    <button onClick={() => createTodo.mutate({ title: "Ship docs" })}>
      Add todo ({todos?.length ?? 0})
    </button>
  );
}
```

Using another UI framework? Import the matching binding:

- **SolidJS (`@agent-native/actions/solid`):** `createActionQuery("list-todos", () => ({ done: false }))` & `createActionMutation("create-todo")` — see [SolidJS](/docs/actions-package-solid).
- **Vue 3 (`@agent-native/actions/vue`):** `useActionQuery("list-todos", () => ({ done: false }))` & `useActionMutation("create-todo")` — see [Vue & Nuxt](/docs/actions-package-vue).
- **Svelte 5 (`@agent-native/actions/svelte`):** `createActionQuery("list-todos", () => ({ done: false }))` & `createActionMutation("create-todo")` — see [Svelte & SvelteKit](/docs/actions-package-svelte).

Mutations invalidate active queries by default. Pass `invalidate: ["list-todos"]` to scope invalidation or `invalidate: false` to disable it.

### CLI {#call-from-cli}

After `init` adds `"action": "actions"` to `package.json` (or invoke `npx @agent-native/actions` directly):

```bash
pnpm action --list
pnpm action create-todo --title "Ship docs"
pnpm action list-todos --done false
```

### HTTP {#call-from-http}

```bash
curl "http://localhost:3000/api/agent-native/actions/list-todos?done=false"

curl -X POST http://localhost:3000/api/agent-native/actions/create-todo \
  -H "Content-Type: application/json" \
  -d '{"title":"Ship docs"}'
```

### MCP {#call-from-mcp}

When mounted on a web server, Streamable HTTP MCP is served at `/api/agent-native/mcp`. For local CLI/MCP usage without a web server, connect over `stdio`:

```json
{
  "mcpServers": {
    "my-app": {
      "command": "npx",
      "args": ["@agent-native/actions", "mcp"]
    }
  }
}
```

### Plain Node / TypeScript {#call-without-framework}

Call actions directly in scripts, workers, or tests with no HTTP server:

```ts
import { createActions } from "@agent-native/actions";
import createTodo from "./actions/create-todo";
import listTodos from "./actions/list-todos";

const actions = createActions({
  actions: { "create-todo": createTodo, "list-todos": listTodos },
});

const todo = await actions.call("create-todo", { title: "Ship docs" });
```

To pass a custom context object to a context-aware registry, provide it as `{ ctx }` in the third argument: `actions.call("create-todo", { title: "Ship docs" }, { ctx: { caller: "server", user: { id: "user_1" } } })`.

## 4. Add Auth Context (Optional) {#add-auth}

Create `actions/context.ts` to resolve the current user from cookies, bearer tokens, or local CLI env, and export a typed `defineAppAction` helper:

```ts
// actions/context.ts
import {
  createActionBuilder,
  type ActionContextInput,
} from "@agent-native/actions";
import { getSession } from "../lib/auth";

export async function createContext({ caller, request }: ActionContextInput) {
  if (caller === "cli") {
    const devUserId =
      process.env.NODE_ENV !== "production"
        ? process.env.DEV_USER_ID
        : undefined;
    return { caller, user: devUserId ? { id: devUserId } : null };
  }
  const session = request ? await getSession(request) : null;
  return { caller, user: session?.user ?? null };
}

export type AppContext = Awaited<ReturnType<typeof createContext>>;
export const defineAppAction = createActionBuilder<AppContext>();
```

Then import `defineAppAction` instead of `defineAction` in actions that read `ctx.user` or enforce `authorize(input, ctx)`.
